## 数据分布的中心位置

中位数是一种衡量集中趋势的统计量，用于描述一个分布的典型值。[均值](../introduction-to-the-mean/)是所有数值的数值平衡点，而中位数是一种位置度量，即将有序数据分成大小相等的两组的那个值。由于中位数仅依赖于观测值的相对排序，因此在存在离群值时仍然稳定；当分布偏态时，中位数比[算术平均数](../arithmetic-mean/)更为可取。在这种情况下，均值会向较长的尾部偏移而中位数不会，因此两个指标之间的差距衡量了数据的偏度。

形式上，设 $n$ 个数值观测值按升序排列：

$$x_{1} \leq x_{2} \leq \dots \leq x_{n}$$

若 $n$ 为奇数，中位数是数列的中心元素：

$$\tilde{M} = x_{\left(\frac{n+1}{2}\right)}$$

若 $n$ 为偶数，中位数是两个中间值的平均值：

$$\tilde{M} = \frac{x_{\left(\frac{n}{2}\right)} + x_{\left(\frac{n}{2}+1\right)}}{2}$$

> 在两种情况下，中位数以下的观测值个数与中位数以上的观测值个数相等，因此数据的划分是平衡的。

## 例 1

首先计算观测值个数为奇数时的中位数。下表列出了同一家公司七名员工的月薪：

| 员工 $x_i$ | 工资（\$） |
|:---:|:---:|
| $x_1$ | 1,200 |
| $x_2$ | 1,300 |
| $x_3$ | 1,400 |
| $x_4$ | 1,500 |
| $x_5$ | 3,000 |
| $x_6$ | 3,200 |
| $x_7$ | 4,000 |

共有 $n = 7$ 个观测值，中位数是中心位置的值：

$$\tilde{M} = x_{\left(\frac{n+1}{2}\right)} = x_{4}$$

有序列表的第四个值是 $1{,}500$，因此中位数工资为 \$1,500。

> 一半员工的月收入低于 \$1,500，另一半高于 \$1,500。

## 中位数的距离定义

中位数还使观测值的总绝对偏差最小化：

$$\tilde{M} \in \arg\min_{m} \sum_{i=1}^{n} |x_i - m|$$

其中 $|x_i - m|$ 是观测值 $x_i$ 与候选值 $m$ 之间的[距离](../absolute-value/)。在这一刻画中，中位数是最接近整体数据的值，接近程度用总距离而非数值的代数平衡来衡量。

将 $m$ 向右移动一个小量 $\varepsilon$，会使左侧每个观测值的偏差增加 $\varepsilon$，同时使右侧每个观测值的偏差减少相同的量，因此总和变化为 $\varepsilon$ 乘以两侧个数之差。将 $m$ 移向包含更多观测值的一侧会减小总和，当两侧包含相同数量的观测值时达到最小值，这正是中位数的位置定义。

> 当 $n$ 为奇数时，最小值点唯一，即中心观测值。当 $n$ 为偶数时，两个中心值之间的[区间](../intervals/)内每个点都给出相同的最小总和，取平均值的约定选取了该区间的中点。

- - -

将此性质应用于例 1 的数据，工资（以美元计）为：

$$1200, 1300, 1400, 1500, 3000, 3200, 4000$$

设 $S(m) = \sum_{i=1}^{n} |x_i - m|$ 表示候选值 $m$ 的总绝对偏差。当 $m = 1200$ 时：

$$
\begin{align}
S(1200) &= |1200 - 1200| + |1300 - 1200| + |1400 - 1200| + |1500 - 1200| \\[6pt]
&+ |3000 - 1200| + |3200 - 1200| + |4000 - 1200| \\[6pt]
&= 0 + 100 + 200 + 300 + 1800 + 2000 + 2800 = 7200
\end{align}
$$

当 $m = 1300$ 时，同样的计算给出：

$$
\begin{align}
S(1300) &= |1200 - 1300| + |1300 - 1300| + |1400 - 1300| + |1500 - 1300| \\[6pt]
&+ |3000 - 1300| + |3200 - 1300| + |4000 - 1300| \\[6pt]
&= 100 + 0 + 100 + 200 + 1700 + 1900 + 2700 = 6700
\end{align}
$$

对其余候选值重复计算，得到如下总和。

| $m$ | $S(m)$ |
|:---:|:---:|
| 1,200 | 7,200 |
| 1,300 | 6,700 |
| 1,400 | 6,400 |
| 1,500 | 6,300 |
| 3,000 | 7,800 |
| 3,200 | 8,400 |
| 4,000 | 12,400 |

最小的总和为 $S(1500) = 6300$，因此使绝对偏差总和最小的值是 $1500$，与位置定义所得的中位数相同。

## 例 2

下一个例子中观测值个数为偶数。下表列出了同一街区最近售出的六套房屋的售价：

| 房屋 $x_i$ | 价格（\$） |
|:---:|:---:|
| $x_1$ | 180,000 |
| $x_2$ | 190,000 |
| $x_3$ | 200,000 |
| $x_4$ | 220,000 |
| $x_5$ | 300,000 |
| $x_6$ | 450,000 |

共有 $n = 6$ 个观测值，中位数是两个中心值的平均值：

$$\tilde{M} = \frac{x_{\left(\frac{n}{2}\right)} + x_{\left(\frac{n}{2}+1\right)}}{2} = \frac{x_{3} + x_{4}}{2}$$

代入对应的价格得到：

$$\tilde{M} = \frac{200{,}000 + 220{,}000}{2} = 210{,}000$$

中位数房价为 \$210,000。

> 一半房屋的售价低于 \$210,000，另一半高于 \$210,000。

## 例 3

当数据被分组为频率类时，单个数值不再可用，需在包含中位数的类内通过插值来估计中位数。下表列出了某组家庭的月用电量（单位：kWh），分为四个类：

| 类区间（kWh） | 频率 $f_i$ |
|:---:|:---:|
| (100, 200] | 5 |
| (200, 300] | 8 |
| (300, 400] | 12 |
| (400, 500] | 5 |

观测值总数为：

$$n = \sum f_i = 5 + 8 + 12 + 5 = 30$$

第一步是确定包含中间观测值的类。由于 $n = 30$，中间位置为：

$$\frac{n}{2} = \frac{30}{2} = 15$$

然后计算累积频率，即截至每个类的观测值累积总数，用以确定中位数类：

| 类区间（kWh） | 频率 $f_i$ | 累积频率 |
|:---:|:---:|:---:|
| (100, 200] | 5 | 5 |
| (200, 300] | 8 | 13 |
| (300, 400] | 12 | 25 |
| (400, 500] | 5 | 30 |

第十五个观测值落在类 $(300, 400]$ 中，因此该类为中位数类。对于分组数据，在假设每类内观测值均匀分布的前提下，中位数为：

$$\tilde{M} = L + \frac{\frac{n}{2} - F}{f_m} \times c$$

在此公式中，$L$ 是中位数类的下界，$F$ 是中位数类之前各类的累积频率，$f_m$ 是中位数类的频率，$c$ 是类宽。在本例中，$L = 300$、$F = 13$、$f_m = 12$、$c = 100$，因此：

$$\tilde{M} = 300 + \frac{15 - 13}{12} \times 100 = 300 + \frac{2}{12} \times 100 \approx 316.7$$

估计的中位数用电量约为 $317$ kWh。

> 此值是估计值而非观测中位数。分组数据仅保证中位数落在类 $(300, 400]$ 中，插值结果取决于该类内所假设的均匀程度。

## 中位数与分位数

中位数是分位数的一个特例。分位数是将有序分布等分为若干部分的统计量。中位数是分隔观测值下 50% 与上 50% 的分位数，记作 $x_{0.5}$。

考虑一个[实数](../real-numbers/) $p$，满足 $0 < p < 1$。阶为 $p$ 的分位数，记作 $x_p$，是划分有序数据的值，使得占比为 $p$ 的观测值小于或等于它，其余占比 $1 - p$ 的观测值大于它。

分位数 $x_p$ 也是某个最小化问题的解。对于候选值 $m$，每个观测值贡献非对称偏差：

$$
g(x_i, m) =
\begin{cases}
(1 - p)|x_i - m| & \text{若 } x_i \le m \\[6pt]
p|x_i - m| & \text{若 } x_i > m
\end{cases}
$$

分位数是使总损失最小化的值：

$$x_p \in \arg\min_{m} \sum_{i=1}^{n} g(x_i, m)$$

> 当 $p = 0.5$ 时，两个权重相等，总损失为绝对偏差总和的一半，因此该准则恰好退化为中位数的距离定义。

最常见的分位数有其各自的名称。

+ $x_{0.25}$，即第一个四分位数，是四分之一观测值所处的值之下。
+ $x_{0.50}$，即中位数，是将数据等分为两半的值。
+ $x_{0.75}$，即第三个四分位数，是四分之三观测值所处的值之下。

十分位数和百分位数以同样的方式将分布分为十份和一百份，因此第 $k$ 百分位数就是阶为 $k/100$ 的分位数。例 3 中的插值公式也可从中位数推广到任意分组数据的分位数，只需将中间位置 $n/2$ 替换为 $np$，并将中位数类替换为包含该位置的类。

- - -

分位数间距是一种离散程度的度量，描述分布中心部分的离散程度。给定两个阶 $p_1$ 和 $p_2$（满足 $0 < p_1 < p_2 < 1$），分位数间距是对应两个分位数之差：

$$\mathrm{IQR} = x_{p_2} - x_{p_1}$$

当两个分位数分别是第一个和第三个四分位数，即 $p_1 = 0.25$ 和 $p_2 = 0.75$ 时，分位数间距变为：

$$\mathrm{IQR} = x_{0.75} - x_{0.25}$$

该区间包含中心 50% 的观测值。由于它忽略了分布尾部中的值，因此以对离群值稳健的方式描述了数据的变异性。

## 例 4

下表列出了某公司十名员工的月薪：

| $i$ | $x_i$（工资，\$） |
|:---:|:---:|
| 1 | 2,200 |
| 2 | 2,400 |
| 3 | 2,600 |
| 4 | 2,700 |
| 5 | 2,800 |
| 6 | 2,900 |
| 7 | 3,100 |
| 8 | 3,300 |
| 9 | 3,400 |
| 10 | 3,700 |

共有 $n = 10$ 个观测值，第一个和第三个四分位数的位置为：

$$
\begin{align}
Q_1 &= x_{0.25} = x_{(n+1) \times 0.25} = x_{2.75} \\[6pt]
Q_3 &= x_{0.75} = x_{(n+1) \times 0.75} = x_{8.25}
\end{align}
$$

这些位置是分数排名，因此在相邻观测值之间进行插值。位置 $2.75$ 位于第二个和第三个值之间：

$$x_{0.25} = 2400 + 0.75 \times (2600 - 2400) = 2400 + 150 = 2550$$

位置 $8.25$ 位于第八个和第九个值之间：

$$x_{0.75} = 3300 + 0.25 \times (3400 - 3300) = 3300 + 25 = 3325$$

第一个与第三个四分位数之间的分位数间距为：

$$\mathrm{IQR} = x_{0.75} - x_{0.25} = 3325 - 2550 = 775$$

工资的分位数间距为 $775$ 美元。

> 中心 50% 的员工工资落在 \$775 的范围内。
