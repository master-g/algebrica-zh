## 定义

调和均值是[幂均值](../introduction-to-the-mean/)之一。与[算术均值](../arithmetic-mean/)不同，当数据以倒数关系组合而不是相加时，它更适用。它先取每个数值的倒数，求这些倒数的平均值，再对这个平均值取倒数。

对于速度、单位成本或生产率等速率和比率，如果每个数值对应相同的固定数量，调和均值就是合适的平均值。算术均值会给予较大数值更多权重，而调和均值会给予较小数值更多权重。调和均值的一般形式为：

$$M_h = \frac{n}{\displaystyle\sum_{i=1}^{n} \frac{1}{x_i}}$$

在这个表达式中，$x_1, x_2, \ldots, x_n$ 是[正值](../types-of-numbers/)，$n$ 是元素个数。调和均值的倒数等于这些倒数的算术均值：

$$\frac{1}{M_h} = \frac{1}{n}\sum_{i=1}^{n}\frac{1}{x_i}$$

从右向左读取这个恒等式，可以从倒数恢复 $M_h$；因此，调和均值与倒数的算术均值可以相互确定。

+ 调和均值只对正值定义，因为零没有倒数，而混合符号还可能使分母变为零。
+ 较小的数值在结果中的权重比较大的数值更高。
+ 它总是小于或等于[几何均值](../geometric-mean/)，而几何均值又小于或等于算术均值。
+ 当工作量或路程相同而速度不同时，调和均值是真实的平均速率。

> 调和均值常写作 $M_{-1}$，因为它是赫尔德族中指数 $s=-1$ 的幂均值。

## 示例 1

一辆汽车行驶在一条被分成两个等长路段的道路上。第一半程的速度为 $60$ km/h，第二半程的速度为 $90$ km/h。两段路程相同，但所需时间不同。低速路段耗时更长，因此低速对平均值的影响更大。两个速度的算术均值是 $75$ km/h，但它并不是这次行程的平均速度。

设两个速度分别为 $v_1$ 和 $v_2$，每半程的长度为 $d$。汽车在第一半程用时 $t_1 = d/v_1$，在第二半程用时 $t_2 = d/v_2$，因此平均速度 $\bar{v}$ 等于总路程除以总时间：

$$\bar{v} = \frac{2d}{t_1 + t_2} = \frac{2d}{\frac{d}{v_1} + \frac{d}{v_2}} = \frac{2}{\frac{1}{v_1} + \frac{1}{v_2}}$$

约去距离 $d$ 后，平均速度就是两个速度的调和均值。代入 $v_1 = 60$ 和 $v_2 = 90$，得到：

$$M_h = \frac{2}{\frac{1}{60} + \frac{1}{90}} = \frac{2}{\frac{5}{180}} = \frac{360}{5} = 72$$

调和均值计入了低速行驶所耗费的额外时间，因此这次行程的平均速度为 $72$ km/h。

## 示例 2

一台机器完成五批大小相同的生产任务，每批任务的工作速率不同。下表列出每批任务的速率，单位为每分钟生产的产品数。

| 批次 | 速率（单位/分钟） |
|:------:|:-------------------:|
| 1 | 10 |
| 2 | 12 |
| 3 | 8 |
| 4 | 15 |
| 5 | 9 |

每批生产的产品数量相同，因此总体平均速率是调和均值，而不是算术均值。对于相同的产出，较慢的一批需要更多时间，所以它在平均值中的权重更高。

代入观测值可得：

$$
\begin{align}
M_h &= \frac{5}{\frac{1}{10} + \frac{1}{12} + \frac{1}{8} + \frac{1}{15} + \frac{1}{9}} \\[6pt]
&= \frac{5}{0.1 + 0.0833 + 0.125 + 0.0667 + 0.1111} \\[6pt]
&= \frac{5}{0.4861} \approx 10.29
\end{align}
$$

因此，平均生产速率约为每分钟 $10.3$ 个单位。

## 两个数的调和均值

对于两个正值 $a$ 和 $b$，倒数之和为 $\frac{a+b}{ab}$，因此调和均值可化简为：

$$M_h = \frac{2}{\frac{1}{a}+\frac{1}{b}} = \frac{2ab}{a+b}$$

令 $A=\frac{a+b}{2}$ 表示这两个数的算术均值，令 $G=\sqrt{ab}$ 表示几何均值。将 $M_h$ 与 $A$ 相乘，因子 $a+b$ 会约去，剩下 $ab$，于是：

$$M_h A = ab = G^2$$

因此，几何均值是算术均值与调和均值的几何均值，即 $G=\sqrt{A M_h}$。由于 $G \le A$，恒等式 $M_h A = G^2$ 给出 $M_h = G^2/A \le G$，所以 $M_h \le G \le A$；只有当 $a=b$ 时等号成立。

> 恒等式 $M_h A = G^2$ 只对两个数成立。对于 $1, 1, 4$，调和均值为 $\frac{4}{3}$，算术均值为 $2$，而 $M_h A = \frac{8}{3}$ 不同于 $G^2 = 2\sqrt[3]{2}$。

- - -

在构成[调和级数](../harmonic-series/)基础的调和数列 $1, \frac{1}{2}, \frac{1}{3}, \ldots$ 中，首项之后的每一项都是它相邻两项的调和均值，因为 $\frac{1}{n-1}$ 与 $\frac{1}{n+1}$ 的倒数的算术均值为 $n$。这一性质对应于[等差数列](../arithmetic-sequence/)，其中每一项都是相邻两项的算术均值。调和均值的名称就来自这个数列；毕达哥拉斯学派将它与振动弦的长度和音乐和谐联系起来。

## 界与变化规律

当单个数值增大时，调和均值不会减小，因为较大的 $x_i$ 会降低其倒数 $\frac{1}{x_i}$，从而缩小分母。因此，正值数据的调和均值位于最小值和最大值之间：

$$\min_i x_i \le M_h \le \max_i x_i$$

只有当所有数值都相等时才会出现等号。较大的数值只向分母中加入一个较小的倒数，对调和均值的影响很小；较小的数值会加入较大的倒数，并主导总和。让部分数值趋于无穷大、同时至少固定一个数值时，调和均值仍保持有限；因此，单个很大的观测值不像对算术均值那样，不能将调和均值无限抬高。

三个均值之间的不等式对任意数量的数值都成立，而不仅仅是两个数。正值的几何均值为 $G = \left(\prod_{i=1}^{n} x_i\right)^{1/n}$，而这些数值倒数的几何均值为 $\frac{1}{G}$，因为对每个因子取倒数就会对乘积取倒数。将算术—几何均值不等式应用于这些倒数，得到：

$$\frac{1}{M_h} = \frac{1}{n}\sum_{i=1}^{n}\frac{1}{x_i} \ge \left(\prod_{i=1}^{n}\frac{1}{x_i}\right)^{1/n} = \frac{1}{G}$$

在正数之间取倒数会反转不等号，因此 $M_h \le G$。将同一个不等式应用于原数值，可得 $G \le A$；所以对于任意 $n$，都有 $M_h \le G \le A$，只有当所有 $x_i$ 都相等时等号成立。

## 应用

二分类器的 $F_1$ 分数是精确率 $P$ 与召回率 $R$ 的调和均值。精确率是预测为正例的样本中实际正确的比例，召回率是实际正例中被识别出来的比例：

$$F_1 = \frac{2}{\frac{1}{P} + \frac{1}{R}} = \frac{2PR}{P+R}$$

调和均值会接近两个量中较小的那个，因此高精确率无法弥补较差的召回率；无论精确率多高，只要召回率接近零，$F_1$ 就会接近零。

在物理学中，并联电阻通过倒数进行组合，因为所有支路的电压相同，而电流相加。两个电阻 $R_1$ 和 $R_2$ 并联时，等效电阻为：

$$R_{\mathrm{eq}} = \frac{1}{\frac{1}{R_1} + \frac{1}{R_2}} = \frac{R_1 R_2}{R_1 + R_2}$$

这个值是这一对电阻调和均值的一半；$n$ 个电阻并联时，等效电阻为 $\frac{M_h}{n}$。同样的规则适用于串联电容器；薄透镜的焦距也是物距与像距的调和均值的一半。

## 加权调和均值

当各观测值的重要性不相等时，每个数值 $x_i$ 都有一个由其出现频率或相关性决定的权重 $w_i>0$。加权调和均值为：

$$M_{hw} = \frac{\sum_{i=1}^{n} w_i}{\displaystyle\sum_{i=1}^{n} \frac{w_i}{x_i}}$$

在这个表达式中，$x_i>0$ 是观测值，$w_i$ 是它们的权重。

+ 加权调和均值通过权重 $w_i$ 将简单调和均值推广开来。
+ 权重较大的观测值会对结果产生更强的影响。
+ 当所有权重相等时，加权调和均值会退化为简单调和均值。

对于市盈率这样的比率，加权形式是正确的平均值。一份投资组合持有某只股票 $30000$ 美元、市盈率为 $10$；同时持有另一只股票 $10000$ 美元、市盈率为 $40$。按照投资金额为每个比率加权，得到：

$$M_{hw} = \frac{30000 + 10000}{\frac{30000}{10} + \frac{10000}{40}} = \frac{40000}{3250} \approx 12.3$$

两只股票市盈率的[加权算术均值](../arithmetic-mean/)为 $17.5$，高于真实值，因为它对市盈率较高的股票赋予了过大的权重。加权调和均值才是投资组合真实的市盈率，即总市值除以总收益。
