## 定义

伯努利分布描述一个恰好有两个互斥结果的试验，这两个结果称为成功和失败。这样的试验称为伯努利试验。[离散随机变量](../discrete-random-variables/)在试验成功时取值 $1$、失败时取值 $0$，就服从伯努利分布。该分布只有一个参数 $p \in [0,1]$，表示成功的概率；失败的概率为 $1-p$。记作 $X \sim \mathrm{Bernoulli}(p)$。

伯努利分布由 $P(X = 1) = p$ 和 $P(X = 0) = 1-p$ 定义。对于 $x \in \{0,1\}$，这两种情形可以合并为概率质量函数：

$$P(X = x) = b(x;p) = p^{x}(1-p)^{1-x}$$

在此表达式中，$x \in \{0,1\}$ 是试验观察到的结果。对于每个 $x \notin \{0,1\}$，概率 $P(X = x)$ 都为零。当 $p=0$ 或 $p=1$ 时，该分布是退化的，因为其中一个结果以概率 $1$ 发生。

等价地，如果 $A$ 是满足 $P(A) = p$ 的事件，那么它的示性函数在 $A$ 上取 $1$、在补集上取 $0$，并且服从参数为 $p$ 的伯努利分布。

> 二项分布把这个模型延伸到固定次数的独立伯努利试验。

- - -

对于 $X \sim \mathrm{Bernoulli}(p)$，其概率质量函数、均值、方差和标准差如下。

[class="table-1"]

|                                         |
| --------------------------------------- |
| $P(X = x) = b(x;p) = p^{x}(1-p)^{1-x}$  |
| $\mu = E(X) = p$                        |
| $\sigma^{2} = \mathrm{Var}(X) = p(1-p)$ |
| $\sigma = \sqrt{p(1-p)}$                |

[/class]

## 伯努利分布的均值

伯努利分布的[均值](../introduction-to-the-mean/)或[期望值](../mean-or-expected-value-of-a-random-variable/)，是按照概率对 $0$ 和 $1$ 这两个取值加权得到的。我们从离散随机变量期望值的定义出发：

$$\mu = E(X) = \sum_{x \in \{0,1\}} xb(x;p)$$

对于伯努利分布，概率质量函数为：

$$b(x;p) = p^{x}(1-p)^{1-x}$$

这个求和只有两项，每个 $x$ 的取值对应一项：

$$E(X) = 0 \cdot (1-p) + 1 \cdot p$$

第一项为零，因此均值就等于参数本身：

$$\mu = E(X) = p$$

> 对试验进行独立重复时，[样本均值](../arithmetic-mean/)就是观察到的成功比例。根据大数定律，随着试验次数增加，它会收敛到 $p$。

## 伯努利分布的方差

伯努利分布的[方差](../variance-and-covariance-of-a-random-variable/)是结果相对于均值 $\mu=p$ 的平方偏差的期望值。可以利用二阶矩计算：

$$\sigma^{2} = \mathrm{Var}(X) = E(X^{2}) - [E(X)]^{2}$$

伯努利随机变量只取 $0$ 和 $1$。平方不会改变这两个值，因此 $X^{2} = X$，二阶矩就等于 $X$ 本身的均值：

$$E(X^{2}) = 0^{2}(1-p) + 1^{2}p = p$$

将 $E(X^{2}) = p$ 和 $E(X) = p$ 代入定义，得到方差：

$$\sigma^{2} = \mathrm{Var}(X) = p - p^{2} = p(1-p)$$

> 利用[配方法](../completing-the-square/)得到的恒等式 $p(1-p) = 1/4 - (p-1/2)^{2}$ 表明，当 $p = 1/2$ 时，方差达到最大值 $1/4$。当 $p$ 趋近于 $0$ 或 $1$ 时，一个结果比另一个更可能发生，方差随之减小。

## 示例 1

考虑对单个电子元件进行质量控制测试。检查时给元件通电，只有达到指定电压才视为功能正常。令 $X$ 为表示测试结果的随机变量：

+ 当元件达到要求的标准（成功）时，$X = 1$。
+ 当元件未通过测试（失败）时，$X = 0$。

假设历史数据表明成功率为 $0.85$，我们以此作为参数 $p = 0.85$。随机变量 $X$ 于是服从参数为 $p$ 的伯努利分布，其概率质量函数为：

$$P(X = x) = p^{x}(1-p)^{1-x}$$

要计算成功的概率，只需在 $x = 1$ 处代入概率质量函数：

$$P(X = 1) = p^{1}(1-p)^{0} = 0.85$$

在 $x = 0$ 处进行同样的计算，可以得到失败的概率：

$$P(X = 0) = p^{0}(1-p)^{1} = 0.15$$

因此，元件通过测试的概率为 $0.85$，即 85%。

> 只有当抽样元件和测试条件能够代表正在检查的元件时，历史成功率才可以用来估计 $p$。

## 二项模型中的伯努利分布

设 $X_{1},\ldots,X_{n}$ 是具有相同参数 $p$ 的独立伯努利随机变量。它们的和

$$Y = X_{1} + \cdots + X_{n}$$

统计 $n$ 次试验中的成功次数，并且服从二项分布。对于 $k \in \{0,\ldots,n\}$，其概率质量函数为：

$$P(Y = k) = \binom{n}{k}p^{k}(1-p)^{n-k}$$

[二项式系数](../binomial-coefficient/)统计 $n$ 次试验中安排 $k$ 次成功的方法数，而因子 $p^{k}(1-p)^{n-k}$ 是每一种安排的概率。[期望值的线性性](../mean-or-expected-value-of-a-random-variable/)给出二项分布的均值 $np$，而独立性给出其方差 $np(1-p)$。

下表比较这两个分布。伯努利分布描述一次成功—失败试验，而二项分布统计固定次数、成功概率为 $p$ 的独立试验中的成功次数。

| 特征 | 伯努利 | 二项 |
| ---------------- | ---------- | ----------------- |
| 试验次数 | $1$        | $n$               |
| 参数 | $p$        | $n, p$            |
| 支集 | $\{0,1\}$  | $\{0, \dots, n\}$ |
| 均值 | $p$        | $np$              |
| 方差 | $p(1-p)$   | $np(1-p)$         |
