## 定义

算术均值是最常见的平均数，属于幂均值家族。对于一组数据，它等于所有观测值的总和除以其[数量](../types-of-numbers/)。它基于加法聚合，因此适合线性合并的量，例如原始测量值，或不会按比例或[指数方式](../exponential-function/)增长的数值。算术均值是分布的平衡点，即数据围绕其达到平衡的值。

对于数值 $x_1, x_2, \dots, x_n$，算术均值为：

$$M_a = \frac{1}{n}\sum_{i=1}^{n} x_i$$

这里的 $n$ 表示元素个数。

+ 算术均值适用于任意一组[实数](../types-of-numbers/)，包括负值和零。
+ 算术均值对极端值敏感，因此离群值可能使结果发生偏移；在某些情形下，中位数或[几何均值](../geometric-mean/)更合适。

## 示例 1

下面的数据集包含五个数值。

| $x_i$ | 数值 |
|---|---|
| $x_1$ | 7.2 |
| $x_2$ | 4.8 |
| $x_3$ | 9.1 |
| $x_4$ | 5.5 |
| $x_5$ | 6.4 |

取 $n=5$，代入这些数值可得：

$$M_a = \frac{7.2 + 4.8 + 9.1 + 5.5 + 6.4}{5} = \frac{33.0}{5} = 6.6$$

该数据集的算术均值为 $M_a=6.6$。

## 代数性质

平移、缩放以及合并数据集都会改变算术均值，而这些变化都可以直接从定义推出。

各数值与均值的偏差之和为零。由于 $\sum_{i=1}^{n} x_i = nM_a$，有

$$\sum_{i=1}^{n} (x_i - M_a) = \sum_{i=1}^{n} x_i - nM_a = nM_a - nM_a = 0$$

正偏差与负偏差彼此抵消，因此 $M_a$ 是使数据达到平衡的值。给每个数值加上常数 $c$，均值也会增加同一个常数，因为该常数可以从求和中提出：

$$\frac{1}{n}\sum_{i=1}^{n} (x_i + c) = \frac{1}{n}\sum_{i=1}^{n} x_i + c = M_a + c$$

将每个数值乘以常数 $c$，均值也会乘以 $c$，因为这个因子可以从求和中提出：

$$\frac{1}{n}\sum_{i=1}^{n} cx_i = c\cdot\frac{1}{n}\sum_{i=1}^{n} x_i = cM_a$$

这两条规则可以合并为一条线性规则。对于变换后的数值 $y_i = ax_i + b$，其均值为 $aM_a + b$；因此，改变单位或原点时，均值会与每个观测值以相同方式变换。合并数据集的均值是各部分均值的加权均值。设第一组有 $n_1$ 个数值，均值为 $M_1$；第二组有 $n_2$ 个数值，均值为 $M_2$，则合并后的均值的分子包含全部 $n_1 + n_2$ 个数值的总和：

$$M_c = \frac{n_1M_1 + n_2M_2}{n_1 + n_2}$$

两组的大小就是权重，这将数据集合并与下一节介绍的加权算术均值联系起来。

## 加权算术均值

当各数据点的贡献不相等时，每个观测值 $x_i$ 都有一个由其重要性或出现频率确定的权重 $w_i$。加权算术均值为：

$$M_{aw} = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}$$

这里的 $x_i$ 是观测值，且 $w_i>0$ 是它们的权重。

+ 加权算术均值通过权重 $w_i$ 将简单算术均值推广了开来。
+ 权重较大的观测值会对结果产生更大的影响。
+ 当所有权重都相等时，加权算术均值会退化为简单算术均值。

## 示例 2

一家公司计算其月度销售额的加权算术均值。每个月的工作日数不同，这些天数就是权重。

| 月份 | $x_i$ = 日销售额（美元） | $w_i$ = 工作日数 |
|:---:|:---:|:---:|
| 一月 | 420 | 20 |
| 二月 | 380 | 22 |
| 三月 | 460 | 18 |
| 四月 | 400 | 21 |
| 五月 | 440 | 19 |

将数据代入公式：

$$
\begin{align}
M_{aw} &= \frac{(420 \times 20) + (380 \times 22) + (460 \times 18) + (400 \times 21) + (440 \times 19)}{20 + 22 + 18 + 21 + 19} \\[6pt]
&= \frac{8400 + 8360 + 8280 + 8400 + 8360}{100} \\[6pt]
&= \frac{41800}{100} \\[12pt]
&= 418
\end{align}
$$

该公司销售额的加权算术均值为每天 $M_{aw}=418$ 美元。

## 毕达哥拉斯均值与均值不等式

算术均值是三种毕达哥拉斯均值之一，另外两种是[几何均值](../geometric-mean/)和[调和均值](../harmonic-mean/)。对于正值 $x_1, \dots, x_n$，几何均值是乘积的 $n$ 次方根，调和均值则是倒数的平均值的倒数：

$$G = \left( \prod_{i=1}^{n} x_i \right)^{\frac{1}{n}} \qquad H = \frac{n}{\sum_{i=1}^{n} \frac{1}{x_i}}$$

三者都可以看作同一组数值在不同指数下的[幂均值](../introduction-to-the-mean/)，其中算术均值对应指数 $1$，几何均值是在指数趋近 $0$ 时的极限，调和均值对应指数 $-1$。对于正值，这三种均值满足链式不等式：

$$H \le G \le M_a$$

只有当所有数值都相等时，整个链式不等式才处处取等号。两条不等式对一对正数 $a$ 和 $b$ 已经成立，一般情形则可用同样的论证应用于幂均值而得出。$M_a \ge G$ 这一不等式建立在两个平方根之差的平方上。由于平方总是非负的，有

$$(\sqrt{a} - \sqrt{b})^2 \ge 0$$

展开平方得到 $a - 2\sqrt{ab} + b \ge 0$，移项可得：

$$\frac{a + b}{2} \ge \sqrt{ab}$$

左边是 $a$ 与 $b$ 的算术均值，右边是它们的几何均值，因此 $M_a \ge G$；当且仅当 $a = b$ 时取等号。$G \ge H$ 这一不等式可以用同样的思路应用于倒数得到。由于平方总是非负的，有

$$\left( \frac{1}{\sqrt{a}} - \frac{1}{\sqrt{b}} \right)^2 \ge 0$$

展开并整理得到 $\frac{1}{a} + \frac{1}{b} \ge \frac{2}{\sqrt{ab}}$，两边取倒数可得：

$$\sqrt{ab} \ge \frac{2}{\frac{1}{a} + \frac{1}{b}}$$

左边是 $a$ 与 $b$ 的几何均值，右边是它们的调和均值，因此 $G \ge H$；同样，当且仅当 $a = b$ 时取等号。这两个结果合在一起，就得到完整的链式不等式 $H \le G \le M_a$。

## 样本均值与总体均值

当数据是从更大总体中抽取的样本时，样本的算术均值可以估计整个总体的均值。总体均值就是底层分布的[期望值](../mean-or-expected-value-of-a-random-variable/)。对于[离散随机变量](../discrete-random-variables/)，它是所有可能取值按其概率加权后的总和：

$$\mu = E(X) = \sum_x xf(x)$$

对于[连续随机变量](../continuous-random-variables/)，求和变为在整个取值范围上，对概率密度加权后的积分：

$$\mu = E(X) = \int_{-\infty}^{+\infty} xf(x) \ dx$$

根据样本计算出的算术均值就是[样本均值](../sampling-distributions/)，它是估计 $\mu$ 的自然估计量。

设样本包含 $n$ 个相互独立的观测值 $X_1, \dots, X_n$，每个观测值都来自均值为 $\mu$、方差为 $\sigma^2$ 的分布。样本均值是随机变量

$$\overline{X} = \frac{1}{n} \sum_{i=1}^{n} X_i$$

由于期望具有线性性质，它的期望值等于总体均值：

$$E(\overline{X}) = \frac{1}{n} \sum_{i=1}^{n} E(X_i) = \frac{1}{n}\cdot n\mu = \mu$$

期望值等于目标量的估计量称为无偏估计量，因此样本均值是总体均值的无偏估计量。

随着样本增大，样本均值围绕 $\mu$ 的波动范围会缩小。由于观测值相互独立，它们之和的方差等于各方差之和，而因子 $\frac{1}{n}$ 提出后要平方：

$$\mathrm{var}(\overline{X}) = \frac{1}{n^2} \sum_{i=1}^{n} \mathrm{var}(X_i) = \frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}$$

样本均值的方差等于总体方差除以样本量，因此它不依赖于分布的形状；样本越大，估计值就越集中在 $\mu$ 附近。

> 恒等式 $\mathrm{var}(\overline{X}) = \sigma^2/n$ 假设观测值相互独立且具有相同的方差。观测值之间的相关性会改变均值的方差。

- - -

对于大样本，$\overline{X}$ 的分布接近正态分布；而对于来自正态总体的小样本，标准化后的样本均值服从 Student 的 $t$ 分布。方差更小的估计量更有效率；对于正态总体，样本均值比样本中位数更有效率，因为中位数的方差约为均值方差的 $\pi/2$ 倍。因此，当数据接近正态分布时，均值是更精确的中心概括。

对于中等程度偏斜的分布，若用 M、O、D 分别表示均值、众数和中位数，则它们满足近似关系：

$$M - O \approx 3(M - D)$$

均值会沿着较长尾部的方向，距离峰值最远，因此均值与中位数之间的差距可以衡量数据的偏度。
