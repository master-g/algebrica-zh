## 定义

二项分布是一种离散概率分布，用于描述一系列固定次数、相互独立且成功概率相同的[伯努利试验](../bernoulli-distribution/)中成功的次数。它的参数是整数 $n \ge 1$（试验次数）和概率 $p \in [0,1]$。对于每个 $x \in \{0,1,\ldots,n\}$，模型给出恰好观察到 $x$ 次成功的概率。这类试验具有以下性质：

+ 每次试验恰好有两个互斥结果：成功，概率为 $p$；失败，概率为 $1-p$。
+ 各次试验相互独立。
+ 所有试验中的成功概率 $p$ 保持不变。
+ 试验次数 $n$ 预先固定。
+ 随机变量 $X$ 表示 $n$ 次试验中的成功次数。

在 $n$ 次试验中恰好获得 $x$ 次成功的概率为：

$$P(X = x) = b(x; n, p) = \binom{n}{x} p^{x} q^{n-x}$$

在此表达式中，$q = 1-p$ 是失败的概率。每一种包含 $x$ 次成功和 $n-x$ 次失败的固定排列，其概率都是 $p^{x}q^{n-x}$；[二项式系数](../binomial-coefficient/) $\binom{n}{x}$ 统计这些排列的数量。对于每个 $x \notin \{0,1,\ldots,n\}$，概率 $P(X = x)$ 都为零。当 $p=0$ 或 $p=1$ 时，该分布是退化的，因为成功次数已经确定。

由于 $p + q = 1$，二项模型满足任何概率分布都必须满足的条件：

$$\sum_{x=0}^{n} b(x; n, p) = (p+q)^{n} = 1$$

> 二项分布与[二项式定理](../binomial-theorem/)有关，因为 $(p+q)^{n}$ 的展开式中，每个可能的成功次数 $x$ 对应一项，而该项恰好是 $b(x; n, p)$。

- - -

对于 $X \sim \mathrm{Bin}(n, p)$，其概率质量函数、均值、方差和标准差如下。

[class="table-1"]

|                                                                               |
| ----------------------------------------------------------------------------- |
| $P(X = x) = b(x; n, p) = \binom{n}{x} p^{x} q^{n-x} \quad x = 0, 1, \dots, n$  |
| $\mu = E(X) = np$                                                              |
| $\sigma^{2} = \mathrm{Var}(X) = np(1-p)$                                       |
| $\sigma = \sqrt{np(1-p)}$                                                      |

[/class]

## 二项分布的均值

二项分布的[均值](../introduction-to-the-mean/)或[期望值](../mean-or-expected-value-of-a-random-variable/)，是大量重复进行该试验时预期成功次数的平均值。我们从期望值的定义出发：

$$\mu = E(X) = \sum_{x=0}^{n} xP(X = x)$$

代入二项分布的概率质量函数，得到：

$$E(X) = \sum_{x=0}^{n} x\binom{n}{x} p^{x} (1-p)^{n-x}$$

利用恒等式：

$$x\binom{n}{x} = n\binom{n-1}{x-1}$$

这个恒等式通过同时将 $n$ 和 $x$ 减一，联系了两个二项式系数。将其应用到求和的每一项，并提出因子 $np$，得到：

$$E(X) = np \sum_{x=1}^{n} \binom{n-1}{x-1} p^{x-1} (1-p)^{(n-1)-(x-1)}$$

这个求和等于 $1$，因为它是参数为 $n-1$ 和 $p$ 的二项分布的总概率。因此：

$$\mu = E(X) = np$$

当 $p$ 固定时，均值与试验次数成正比；当 $n$ 固定时，均值与成功概率成正比。$n$ 次试验中的预期成功次数是 $np$。

- - -

也可以把二项随机变量 $X$ 写成 $n$ 个相互独立的伯努利变量 $X_1, X_2, \ldots, X_n$ 之和：每个变量以概率 $p$ 取 $1$（成功），以概率 $1-p$ 取 $0$（失败）：

$$X = X_1 + X_2 + \cdots + X_n$$

每一项的期望值都是 $E(X_i) = p$，因此根据[期望值的线性性](../mean-or-expected-value-of-a-random-variable/)：

$$E(X) = E(X_1) + E(X_2) + \cdots + E(X_n) = np$$

## 二项分布的方差

二项分布的[方差](../variance-and-covariance-of-a-random-variable/)是成功次数相对于均值 $\mu = np$ 的平方偏差的期望值。可以利用二阶矩计算：

$$\sigma^{2} = \mathrm{Var}(X) = E(X^{2}) - [E(X)]^{2}$$

为计算它，再次将 $X$ 写成 $n$ 个相互独立的伯努利变量 $X_1, X_2, \ldots, X_n$ 之和，每个变量的成功概率都是 $p$：

$$X = X_1 + X_2 + \cdots + X_n$$

伯努利变量的方差为 $\mathrm{Var}(X_i) = p(1-p)$。由于各次试验独立，和的方差等于各方差之和：

$$\mathrm{Var}(X) = \mathrm{Var}(X_1) + \mathrm{Var}(X_2) + \cdots + \mathrm{Var}(X_n)$$

$n$ 项中的每一项都等于 $p(1-p) = pq$，因此二项分布的方差为：

$$\sigma^{2} = npq = np(1-p)$$

> 当 $p$ 固定时，方差随试验次数 $n$ 线性增长。当 $n$ 固定时，方差在 $p = 1/2$ 处达到最大值；当 $p = 0$ 或 $p = 1$ 时，方差为零，因为此时每次试验的结果都是确定的。

## 示例 1

一家工厂生产电子传感器，每个传感器都要经过测试，以确认它在特定温度条件下能否正常工作。假设从一批产品中随机选取 $6$ 个传感器。设测试结果相互独立，且每个传感器通过测试的概率为 $p = 0.7$。我们希望求出 $6$ 个传感器中恰好有 $4$ 个在测试中正常工作的概率。

由于测试相互独立，通过测试的传感器数服从参数为 $n = 6$、$p = 0.7$ 的二项分布，所求概率为：

$$
\begin{align}
b(4; 6, 0.7) &= \binom{6}{4} (0.7)^{4} (0.3)^{2} \\[6pt]
&= \frac{6!}{4!2!} (0.7)^{4} (0.3)^{2} \\[6pt]
&= 15 \times 0.2401 \times 0.09 = 0.324135
\end{align}
$$

> 对于整数 $m \ge 1$，[阶乘](../factorial/) $m!$ 是从 $1$ 到 $m$ 的正整数之积。按照约定，$0! = 1$。

因此，六个传感器中恰好四个通过测试的概率约为 $0.324$，即 32.4%。

## 累积二项分布

在一些问题中，我们关心的不是恰好有 $x$ 次成功的概率，而是 $n$ 次伯努利试验中至多有 $r$ 次成功的概率。对于整数 $r \in \{0,1,\ldots,n\}$，将二项分布从 $x = 0$ 到 $x = r$ 的各项相加，即可得到该概率：

$$B(r; n, p) = \sum_{x=0}^{r} b(x; n, p)$$

在此表达式中，$b(x; n, p)$ 是二项分布的概率质量函数。写出概率质量函数后，累积概率为：

$$P(X \le r) = B(r; n, p) = \sum_{x=0}^{r} \binom{n}{x} p^{x} (1-p)^{n-x}$$

同一个累积函数还可以通过取补集，给出上尾概率和区间概率。对于整数 $0 \le a \le b \le n$，分别有：

$$P(X \ge a) = 1-B(a-1; n, p) \qquad P(a \le X \le b) = B(b; n, p)-B(a-1; n, p)$$

按照约定，$B(-1; n, p) = 0$。

累积二项分布表列出 $P(X \le r)$ 在 $n$ 和 $p$ 的一些组合下的预先计算值，这与[标准正态 Z 表](../standard-normal-z-table/)列出[正态分布](../normal-distribution/)的累积概率相似。下面给出这类表格的一个简化部分。

| $n$ | $r$ | $p = 0.05$ | $p = 0.10$ | $p = 0.20$ | $p = 0.30$ | $p = 0.40$ | $p = 0.50$ | ... |
| --- | --- | ---------- | ---------- | ---------- | ---------- | ---------- | ---------- | --- |
| $1$ | $0$ | 0.950      | 0.900      | 0.800      | 0.700      | 0.600      | 0.500      | ... |
| $1$ | $1$ | 1.000      | 1.000      | 1.000      | 1.000      | 1.000      | 1.000      | ... |
| $2$ | $0$ | 0.903      | 0.810      | 0.640      | 0.490      | 0.360      | 0.250      | ... |
| $2$ | $1$ | 0.998      | 0.990      | 0.960      | 0.910      | 0.840      | 0.750      | ... |
| $2$ | $2$ | 1.000      | 1.000      | 1.000      | 1.000      | 1.000      | 1.000      | ... |
| ... | ... | ...        | ...        | ...        | ...        | ...        | ...        | ... |

行与列的交点给出累积概率 $P(X \le r)$，即在相应 $n$ 和 $p$ 下至多获得 $r$ 次成功的概率。这张表取代了逐项计算求和的过程。

## 二项分布的正态近似

二项分布是离散的，但当预期成功次数和失败次数都足够大时，可以用连续的[正态分布](../normal-distribution/)近似。$np \ge 5$ 和 $n(1-p) \ge 5$ 是常用的初步判据，不过所需的精度取决于具体问题。在这些条件下，如果 $X \sim \mathrm{Bin}(n,p)$，就用具有相同均值和方差的正态随机变量 $Y$ 的分布来近似它：

$$Y \sim \mathcal{N}(np,npq)$$

这种近似简化了计算，因为二项概率可以用正态分布的[Z 表](../standard-normal-z-table/)来估计。

- - -

固定 $p \in (0,1)$，对每个 $n$ 令 $X_n \sim \mathrm{Bin}(n,p)$。德莫弗—拉普拉斯定理指出，标准化变量依分布收敛到[标准正态分布](../normal-distribution/)。当试验次数趋于无穷时：

$$Z_n = \frac{X_n-np}{\sqrt{np(1-p)}} \xrightarrow{d} \mathcal{N}(0,1)$$

> 符号 $\xrightarrow{d}$ 表示依分布收敛，即随着 $n$ 增大，标准化变量的分布趋近于标准正态分布。

## 示例 2

为说明正态近似，考虑一家生产小型电子元件的公司。在质量控制中，每件产品都要接受测试，以检查是否符合要求的电气规格。假设测试了 $100$ 个元件，测试结果相互独立，每个元件通过测试的概率为 $p = 0.9$。我们希望求出通过检验的元件数介于 $85$ 和 $92$ 之间的概率。

令 $X$ 表示通过测试的元件数。所求概率为：

$$P(85 \le X \le 92) = \sum_{x=85}^{92} b(x; 100, 0.9)$$

这里 $np = 90$，$n(1-p) = 10$，因此两个预期次数都满足正态近似的初步判据。近似分布的参数为：

$$
\begin{align}
\mu &= np = 100 \times 0.9 = 90 \\[6pt]
\sigma &= \sqrt{npq} = \sqrt{100 \times 0.9 \times 0.1} = 3
\end{align}
$$

二项随机变量 $X$ 是离散的，因为它只取[整数](../integers/)值；而正态分布是连续的。因此，$X$ 介于 $85$ 和 $92$ 之间的概率，更适合用正态曲线下从 $85$ 下方半个单位到 $92$ 上方半个单位的面积来近似，也就是把离散边界替换为：

$$x_1 = 84.5 \qquad x_2 = 92.5$$

利用[变换](../normal-distribution/) $z = (x-\mu)/\sigma$ 对边界进行标准化：

$$z_1 = \frac{84.5 - 90}{3} \approx -1.83 \qquad z_2 = \frac{92.5 - 90}{3} \approx 0.83$$

用标准化变量 $Z$ 表示，概率变为：

$$P(85 \le X \le 92) = \sum_{x=85}^{92} b(x; 100, 0.9) \approx P(-1.83 \le Z \le 0.83)$$

区间概率等于两个累积概率之差：

$$P(-1.83 \le Z \le 0.83) = P(Z \le 0.83) - P(Z \le -1.83)$$

查阅[标准正态 Z 表](../standard-normal-z-table/)可得：

$$P(Z \le 0.83) \approx 0.7967 \qquad P(Z \le -1.83) \approx 0.0336$$

将两个数相减，得到：

$$P(-1.83 \le Z \le 0.83) \approx 0.7967 - 0.0336 = 0.7631$$

因此，经过连续性校正的正态近似给出概率 $0.763$，即通过质量测试的元件数在 $85$ 到 $92$ 之间的概率为 76.3%。

作为比较，直接计算二项和得到的结果约为 $0.7541$。因此，报告的正态近似比精确的二项概率高约 $0.0090$。

## 二项分布与超几何分布的比较

当每次试验的成功概率相同，且一次试验不会影响下一次时，适用二项分布。这种情形精确对应于有放回抽样。对于从有限总体中不放回抽样，当样本量相对于总体规模较小时，二项分布可以作为近似；否则，每次抽取后总体构成都会发生明显变化，此时[超几何分布](../hypergeometric-distribution/)才是精确模型。

当抽样比例 $n/N$ 不可忽略时，各次试验的成功概率会发生变化，有限总体模型为：

$$X \sim \mathrm{Hyp}(N, K, n)$$

在此记号中，$K$ 是总体中的成功数。二项模型的试验相互独立且成功概率固定，而超几何模型描述不放回抽样。

## 二项分布与泊松分布的联系

固定 $\lambda > 0$ 和整数 $x \ge 0$。对每个 $n$，令 $p_n = \lambda/n$，并设 $X_n \sim \mathrm{Bin}(n,p_n)$。当 $n$ 趋于无穷时，二项概率收敛到[泊松分布](../poisson-distribution/)的相应概率：

$$\lim_{n \to \infty}P(X_n = x) = \lim_{n \to \infty}\binom{n}{x}\left(\frac{\lambda}{n}\right)^{x}\left(1-\frac{\lambda}{n}\right)^{n-x} = \frac{e^{-\lambda}\lambda^{x}}{x!}$$

> 泊松极限模型描述稀有事件，也就是在大量独立试验中每次发生概率都很小的事件。
