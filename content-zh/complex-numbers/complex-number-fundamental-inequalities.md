## 引言

[域](../fields/) $\mathbb{C}$ 的一个定义性特征，是不存在与其算术运算相容的全序。正如[复数](../complex-numbers-introduction/)一文所述，无法在 $\mathbb{C}$ 上定义关系 $\leq$，使其与[加法和乘法](../complex-number-operations/)相容。因此，对任意复数而言，$z_1 < z_2$ 这类说法没有意义；$\mathbb{R}$ 中可用的比较方法也不能迁移到复数情形。

仍然保留下来、并使定量理论成为可能的是[模](../complex-numbers-introduction/) $|z|$。它为每个复数赋予一个非负实数，通过它可以比较大小、估计距离，并为和与积给出界。本文汇集的不等式构成了这些比较的基本工具。它们会反复出现在复数列的分析、复数项级数的收敛，以及由解析条件定义的平面区域的几何描述中。

> 下文从最简单的估计——关于实部和虚部的估计——出发，逐步过渡到三角不等式及其推论，最后以柯西—施瓦茨不等式作结；后者为其余不等式提供了统一的视角。

## 涉及实部和虚部的不等式

设 $z = a + bi$ 是一个[复数](../complex-numbers-introduction/)，其中 $a = \mathrm{Re}(z)$，$b = \mathrm{Im}(z)$。模定义为 $|z| = \sqrt{a^2 + b^2}$，由此可以推出三条初等不等式，用来比较模与各分量的[绝对值](../absolute-value/)。

第一条断言，任一分量的绝对值都不超过模：

$$|\mathrm{Re}(z)| \leq |z|, \qquad |\mathrm{Im}(z)| \leq |z|$$

证明很直接。由于 $a^2 \leq a^2 + b^2$，开平方得到 $|a| \leq \sqrt{a^2 + b^2} = |z|$；对 $b$ 同理。实部的不等式当且仅当 $b = 0$ 时取等号，即 $z$ 为实数。类似地，虚部的不等式当且仅当 $a = 0$ 时取等号，即 $z$ 为纯虚数。

从几何上看，这意味着[向量](../vectors/)投影到任一坐标轴上的长度不能超过向量本身。只有在退化情形——向量已经与该坐标轴对齐——投影才会等于原向量的长度。

- - -

第二条不等式反转了比较方向，用分量给出了模的上界：

$$|z| \leq |\mathrm{Re}(z)| + |\mathrm{Im}(z)|$$

该界来自代数恒等式 $(|a| + |b|)^2 = a^2 + 2|a||b| + b^2$，其中交叉项非负。因此有 $a^2 + b^2 \leq (|a| + |b|)^2$，开平方即可得到结论。当且仅当 $|a||b| = 0$，也就是至少一个分量为零时，等号成立。

这三条不等式使我们能够在 $|z|$ 的界与分量的界之间相互转换。

## 三角不等式

复数算术中最重要的不等式是三角不等式：和的模不超过各模之和。对任意 $z_1, z_2 \in \mathbb{C}$，均有

$$|z_1 + z_2| \leq |z_1| + |z_2|$$

证明依赖于[复数运算](../complex-number-operations/)一文中建立的恒等式 $|z|^2 = z\overline{z}$。这个恒等式把模的计算转化为[共轭复数](../complex-numbers-introduction/)的代数运算。展开和的模的平方，得到：

$$
\begin{align}
|z_1 + z_2|^2 &= (z_1 + z_2)\overline{(z_1 + z_2)} \\[6pt]
              &= (z_1 + z_2)(\overline{z_1} + \overline{z_2}) \\[6pt]
              &= |z_1|^2 + z_1 \overline{z_2} + \overline{z_1} z_2 + |z_2|^2
\end{align}
$$

中间两项互为共轭复数，因此它们的和是实数，等于其中任一项实部的两倍：

$$z_1 \overline{z_2} + \overline{z_1} z_2 = 2\mathrm{Re}(z_1 \overline{z_2})$$

由上一节关于实部的不等式，有 $\mathrm{Re}(z_1 \overline{z_2}) \leq |z_1 \overline{z_2}| = |z_1||z_2|$。代入这个界，得到

$$|z_1 + z_2|^2 \leq |z_1|^2 + 2|z_1||z_2| + |z_2|^2 = (|z_1| + |z_2|)^2$$

两边均为非负数，开平方即完成证明。

- - -

三角不等式当且仅当 $\mathrm{Re}(z_1 \overline{z_2}) = |z_1 \overline{z_2}|$ 时取等号，也就是当且仅当 $z_1 \overline{z_2}$ 为非负实数。从几何上看，这意味着 $z_1$ 与 $z_2$ 位于从原点出发的同一条射线上，或者二者之一为零。其他情形下不等式严格成立。

其几何含义很直观。把 $z_1$ 和 $z_2$ 看作平面中的[向量](../vectors/)，和 $z_1 + z_2$ 就是以这两个向量为边的平行四边形的对角线。对角线长度不可能超过两条边长之和；仅当平行四边形退化为一条线段，即两个向量平行且方向相同，二者才相等。

- - -

差也有一个有用的推论。将 $z_2$ 换成 $-z_2$，并注意到 $|-z_2| = |z_2|$，便得到

$$|z_1 - z_2| \leq |z_1| + |z_2|$$

这个估计可以直接解释为复平面两点间距离的界：从 $z_1$ 到 $z_2$ 的距离不超过这两个点各自到原点的距离之和。

## 反三角不等式

三角不等式有一个伴随结论，通常称为反三角不等式，它给出了差的模的下界。对任意 $z_1, z_2 \in \mathbb{C}$，有

$$\bigl||z_1| - |z_2|\bigr| \leq |z_1 - z_2|$$

推导基于一个简单的改写。从恒等式 $z_1 = (z_1 - z_2) + z_2$ 出发，对右侧应用三角不等式，得到：

$$|z_1| \leq |z_1 - z_2| + |z_2|$$

移项得 $|z_1| - |z_2| \leq |z_1 - z_2|$。交换 $z_1$ 和 $z_2$ 的角色，并使用 $|z_2 - z_1| = |z_1 - z_2|$，便得到对称的估计 $|z_2| - |z_1| \leq |z_1 - z_2|$。合并这两个不等式，即得关于模之差绝对值的所需界。

和正向三角不等式一样，当 $z_1$ 与 $z_2$ 位于从原点出发的同一条射线上时取等号。

- - -

反三角不等式有一个重要的分析后果。把模看作映射 $|\cdot| : \mathbb{C} \to \mathbb{R}$，模是常数为 $1$ 的利普希茨函数。该不等式恰好说明，模的变化不会大于两点之间的距离。因此，模在 $\mathbb{C}$ 上一致连续；在复值表达式的数列、级数与极限分析中，人们经常使用这一性质。

> 常数为 $1$ 的利普希茨连续性是一致连续性的强形式。它保证 $z$ 的任意小变化所造成的 $|z|$ 的变化，在绝对值上都不超过 $z$ 自身的变化。

## 广义三角不等式

三角不等式可以推广到任意长度的有限和。对任意 $n \geq 1$ 以及任意复数 $z_1, z_2, \ldots, z_n$，有

$$\left|\sum_{k=1}^{n} z_k\right| \leq \sum_{k=1}^{n} |z_k|$$

证明对 $n$ 使用[数学归纳法](../principle-of-mathematical-induction/)。$n = 1$ 时两边都化为 $|z_1|$，结论显然；$n = 2$ 时正是原来的三角不等式。假设对某个 $n \geq 2$ 界成立。把 $n+1$ 项的和写成两个复数之和：前 $n$ 项的和与最后一项。由三角不等式可得：

$$\left|\sum_{k=1}^{n+1} z_k\right| = \left|\sum_{k=1}^{n} z_k + z_{n+1}\right| \leq \left|\sum_{k=1}^{n} z_k\right| + |z_{n+1}|$$

对右侧第一项应用归纳假设，得到：

$$\left|\sum_{k=1}^{n+1} z_k\right| \leq \sum_{k=1}^{n} |z_k| + |z_{n+1}| = \sum_{k=1}^{n+1} |z_k|$$

因此第 $n+1$ 步也成立，归纳完成。

- - -

等号条件比两项情形更值得注意。当且仅当所有非零被加项都位于从原点出发的同一条射线上时取等号。换言之，存在固定的单位向量 $e^{i\alpha}$ 以及非负实数 $r_1, r_2, \ldots, r_n$，使得对每个 $k$ 都有 $z_k = r_k e^{i\alpha}$。指数因子 $e^{i\alpha}$ 是与共同方向对应的单位复数，详见[欧拉公式](../eulers-formula/)一文。在这一条件下，和本身是 $e^{i\alpha}$ 的非负倍数，其模等于各项模之和。

广义三角不等式是复数项[级数](../geometric-series/)理论的基础。特别是绝对收敛的概念依赖于这个估计：它使我们可以用模的偏和（它们是实数且非负）来控制偏和的模。

## 柯西—施瓦茨不等式

柯西—施瓦茨不等式是一个定量上的细化，它把复数乘积之和与各自模的平方和联系起来。其有限形式是：对任意复数 $a_1, \ldots, a_n$ 和 $b_1, \ldots, b_n$，有

$$\left|\sum_{k=1}^{n} a_k \overline{b_k}\right|^2 \leq \left(\sum_{k=1}^{n} |a_k|^2\right) \left(\sum_{k=1}^{n} |b_k|^2\right)$$

一种标准推导考虑任意复参数 $t$ 下的非负量：

$$P(t) = \sum_{k=1}^{n} |a_k - t b_k|^2$$

令 $\sigma = \sum_{k=1}^{n} a_k \overline{b_k}$，展开模的平方，得到：

$$
\begin{align}
P(t) &= \sum_{k=1}^{n} (a_k - t b_k)\bigl(\overline{a_k} - \overline{t}\overline{b_k}\bigr) \\[6pt]
     &= \sum_{k=1}^{n} |a_k|^2 - t\overline{\sigma} - \overline{t}\sigma + |t|^2 \sum_{k=1}^{n} |b_k|^2
\end{align}
$$

若 $\sum_{k=1}^{n} |b_k|^2 = 0$，则所有 $b_k$ 都为零，不等式显然成立。在其他情形下，取 $t = \sigma / \sum_{k=1}^{n} |b_k|^2$ 可使 $P(t)$ 最小，代入该值，得到

$$0 \leq P(t) = \sum_{k=1}^{n} |a_k|^2 - \frac{|\sigma|^2}{\sum_{k=1}^{n} |b_k|^2}$$

整理最后一个不等式，得到

$$|\sigma|^2 \leq \left(\sum_{k=1}^{n} |a_k|^2\right) \left(\sum_{k=1}^{n} |b_k|^2\right)$$

这正是柯西—施瓦茨不等式。

当某个 $t$ 使 $P(t) = 0$ 时取等号，这意味着对每个下标 $k$ 都有 $a_k = t b_k$。换言之，当且仅当元组 $(a_1, \ldots, a_n)$ 与 $(b_1, \ldots, b_n)$ 在 $\mathbb{C}^n$ 中成比例时取等号。

> 同一个不等式在每个[内积空间](../inner-product-spaces/)中都成立。它用诱导范数给内积提供界，并蕴含三角不等式。在实内积空间中，它还保证任意两个非零向量之间的夹角公式有定义。

## 示例与应用

第一个例子说明初等分量不等式的用法。设 $z = a + bi$ 满足 $|z| \leq 5$。由 $|a| \leq |z|$ 得 $-5 \leq a \leq 5$，对 $b$ 也有相应的界，因此点 $z$ 落在以原点为中心、边长为 $10$ 的正方形内。反过来，若 $|a| \leq 3$ 且 $|b| \leq 4$，不等式 $|z| \leq |a| + |b|$ 给出较宽松的界 $|z| \leq 7$。更精确的估计 $|z| \leq \sqrt{9 + 16} = 5$ 需要完整的[勾股计算](../pythagorean-theorem/)，但能得到更紧的结果。

- - -

第二个应用涉及[多项式](../polynomials/)根的位置。考虑一个 $n$ 次首一多项式：

$$p(z) = z^n + a_{n-1} z^{n-1} + \cdots + a_1 z + a_0$$

设 $z_0 \in \mathbb{C}$ 是 $p$ 的一个[根](../roots-of-a-polynomial/)，于是 $z_0^n = -a_{n-1} z_0^{n-1} - \cdots - a_0$。对右侧应用广义三角不等式，得到

$$|z_0|^n \leq \sum_{k=0}^{n-1} |a_k| \cdot |z_0|^k$$

令 $M = \max_{0 \leq k \leq n-1} |a_k|$，并假设 $|z_0| > 1$。右侧的上界为 $M \cdot \frac{|z_0|^n - 1}{|z_0| - 1} \leq M \cdot \frac{|z_0|^n}{|z_0| - 1}$，由此可推出 $|z_0| - 1 \leq M$。因此 $p$ 的每个根都满足

$$|z_0| \leq 1 + M$$

这是柯西给出的经典界：所有首一多项式的复根都位于一个闭圆盘内，其半径由最大系数决定。这个论证把三角不等式与[等比级数](../geometric-series/)结合起来，说明基本估计如何为多项式方程提供实质性的结构信息。

- - -

第三个应用直接使用柯西—施瓦茨不等式。给定复数 $z_1, \ldots, z_n$，在不等式中取 $a_k = z_k$、$b_k = 1$，得到

$$\left|\sum_{k=1}^{n} z_k\right|^2 \leq n \sum_{k=1}^{n} |z_k|^2$$

这个估计把 $n$ 项之和的模平方与各项模平方之和进行比较，右侧还带有被加项数量这一权重。与涉及模的线性和的广义三角不等式不同，这里的右端取决于 $|z_k|$ 的二次平均；当各模一致有界时，它只按 $\sqrt{n}$ 增长。正是这种更精细的行为，使柯西—施瓦茨不等式成为正交和与傅里叶展开分析的核心工具之一。
