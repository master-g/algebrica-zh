## 引言

[域](../fields/) $\mathbb{C}$ 的一个基本特征是：它不存在与其算术运算相容的全序。正如[复数](../complex-numbers-introduction/)一文所述，无法在 $\mathbb{C}$ 上定义一个与[加法和乘法](../complex-number-operations/)相容的关系 $\leq$。因此，对任意复数而言，$z_1 < z_2$ 这类说法都没有意义；$\mathbb{R}$ 中的比较方法也不能直接推广到复数域。

不过，[模](../complex-numbers-introduction/) $|z|$ 仍可为每个复数对应一个非负实数，从而用来比较大小、估计距离，并为和与积给出界。本文收集的不等式构成了这些比较的基本工具。它们在复数列的分析、复数项级数的收敛，以及由解析条件定义的平面区域的几何描述中反复出现。

> 以下内容从最简单的估计——即关于实部和虚部的估计——出发，逐步过渡到三角不等式及其推论，最后以柯西—施瓦茨不等式作结，后者为其余不等式提供了一个统一的视角。

## 涉及实部和虚部的不等式

设 $z = a + bi$ 为一个[复数](../complex-numbers-introduction/)，其中 $a = \mathrm{Re}(z)$，$b = \mathrm{Im}(z)$。模由 $|z| = \sqrt{a^2 + b^2}$ 定义，由此定义可推出三条初等不等式，用于将模与各分量的[绝对值](../absolute-value/)进行比较。

第一条断言：实部或虚部的绝对值都不超过模：

$$|\mathrm{Re}(z)| \leq |z|, \qquad |\mathrm{Im}(z)| \leq |z|$$

证明很直接。由于 $a^2 \leq a^2 + b^2$，开平方即得 $|a| \leq \sqrt{a^2 + b^2} = |z|$；对 $b$ 同理。第一个不等式取等号当且仅当 $b = 0$，即 $z$ 位于实轴上；第二个不等式取等号当且仅当 $a = 0$，即 $z$ 位于虚轴上。

从几何上看，这意味着一个[向量](../vectors/)向任一坐标轴的投影不可能长于该向量本身。仅当向量恰好与相应坐标轴重合时，投影长度才等于向量长度。

- - -

第二条不等式反转了比较方向，给出了用分量表示的模的一个上界：

$$|z| \leq |\mathrm{Re}(z)| + |\mathrm{Im}(z)|$$

该上界源自代数恒等式 $(|a| + |b|)^2 = a^2 + 2|a||b| + b^2$，其中的交叉项非负。因此有 $a^2 + b^2 \leq (|a| + |b|)^2$，开平方即得结论。等号成立当且仅当 $|a||b| = 0$，即至少有一个分量为零。

这三条不等式允许将 $|z|$ 的界转化为各分量的界，反之亦然。

## 三角不等式

复数算术中最重要的不等式是三角不等式：和的模不超过各项模之和。对任意 $z_1, z_2 \in \mathbb{C}$，均有

$$|z_1 + z_2| \leq |z_1| + |z_2|$$

证明依赖于在关于[复数运算](../complex-number-operations/)的讨论中建立的恒等式 $|z|^2 = z\overline{z}$，它将模的计算转化为[共轭复数](../complex-numbers-introduction/)的代数运算。展开和的模的平方，得到如下结果。

$$
\begin{align}
|z_1 + z_2|^2 &= (z_1 + z_2)\overline{(z_1 + z_2)} \\[6pt]
              &= (z_1 + z_2)(\overline{z_1} + \overline{z_2}) \\[6pt]
              &= |z_1|^2 + z_1 \overline{z_2} + \overline{z_1} z_2 + |z_2|^2
\end{align}
$$

中间两项互为共轭复数，因此其和为实数，等于其中任一项实部的两倍：

$$z_1 \overline{z_2} + \overline{z_1} z_2 = 2\mathrm{Re}(z_1 \overline{z_2})$$

由上一节建立的关于实部的不等式，有 $\mathrm{Re}(z_1 \overline{z_2}) \leq |z_1 \overline{z_2}| = |z_1||z_2|$。代入该上界，得到如下估计。

$$|z_1 + z_2|^2 \leq |z_1|^2 + 2|z_1||z_2| + |z_2|^2 = (|z_1| + |z_2|)^2$$

两边均为非负，开平方即完成证明。

- - -

三角不等式取等号，当且仅当 $\mathrm{Re}(z_1 \overline{z_2}) = |z_1 \overline{z_2}|$，也就是 $z_1 \overline{z_2}$ 为非负实数。从几何上看，这意味着 $z_1$ 与 $z_2$ 位于从原点出发的同一射线上，或两者之一为零。除此以外，不等式严格成立。

其几何含义是直观的。将 $z_1$ 和 $z_2$ 解释为平面中的[向量](../vectors/)，则和 $z_1 + z_2$ 是以这两个向量为邻边的平行四边形的对角线。对角线的长度不超过两条邻边长度之和，且仅当平行四边形退化为一条线段，即两向量平行且方向相同时，二者才相等。

- - -

将 $z_2$ 替换为 $-z_2$，并注意到 $|-z_2| = |z_2|$，即可得到关于差的常用估计：

$$|z_1 - z_2| \leq |z_1| + |z_2|$$

该估计可直接解释为复平面上两点间距离的上界：从 $z_1$ 到 $z_2$ 的距离不超过这两个点各自到原点的距离之和。

## 反三角不等式

三角不等式还有一个伴随结论，通常称为反三角不等式。它给出了差的模的一个下界：对任意 $z_1, z_2 \in \mathbb{C}$，均有

$$\bigl||z_1| - |z_2|\bigr| \leq |z_1 - z_2|$$

推导基于一个简单的改写。从恒等式 $z_1 = (z_1 - z_2) + z_2$ 出发，对其右端应用三角不等式，得：

$$|z_1| \leq |z_1 - z_2| + |z_2|$$

移项即得 $|z_1| - |z_2| \leq |z_1 - z_2|$。交换 $z_1$ 与 $z_2$ 的角色，并利用 $|z_2 - z_1| = |z_1 - z_2|$，便得到对称的估计 $|z_2| - |z_1| \leq |z_1 - z_2|$。合并这两个不等式，便得到所需结论。

等号条件与正向三角不等式相同：当且仅当 $z_1$ 与 $z_2$ 方向相同或至少一个为零时成立。

- - -

反三角不等式有一个重要的分析推论。将模视为映射 $|\cdot| : \mathbb{C} \to \mathbb{R}$，则模函数是利普希茨连续的，利普希茨常数为 $1$。该不等式恰好表明模的变化不超过两点之间的距离。由此可知，模在 $\mathbb{C}$ 上一致连续；这种连续性在分析复值数列、级数与极限时常被使用。

> 利普希茨连续（常数为 $1$）是一致连续的一种强形式。它保证 $z$ 的任意小的变化所产生的 $|z|$ 的变化幅度不超过 $z$ 本身的变化幅度。

## 广义三角不等式

三角不等式可以推广到任意长度的有限和。对任意 $n \geq 1$ 和任意复数 $z_1, z_2, \ldots, z_n$，成立如下结果。

$$\left|\sum_{k=1}^{n} z_k\right| \leq \sum_{k=1}^{n} |z_k|$$

证明通过对 $n$ 进行[数学归纳法](../principle-of-mathematical-induction/)来完成。$n = 1$ 的情形是平凡的，因为两边都化为 $|z_1|$，而 $n = 2$ 的情形恰好就是原始的三角不等式。假设该界对某个 $n \geq 2$ 成立。把 $n + 1$ 项之和拆成前 $n$ 项之和与最后一项，三角不等式给出：

$$\left|\sum_{k=1}^{n+1} z_k\right| = \left|\sum_{k=1}^{n} z_k + z_{n+1}\right| \leq \left|\sum_{k=1}^{n} z_k\right| + |z_{n+1}|$$

对右端第一项应用归纳假设，得：

$$\left|\sum_{k=1}^{n+1} z_k\right| \leq \sum_{k=1}^{n} |z_k| + |z_{n+1}| = \sum_{k=1}^{n+1} |z_k|$$

因此该估计在第 $n + 1$ 步成立，归纳完成。

- - -

等号条件比两项情形需要更多注意。当且仅当所有非零被加项位于同一条自原点出发的射线上时等号成立（全零情形也满足等号），即存在固定的单位复数 $e^{i\alpha}$ 和非负实数 $r_1, r_2, \ldots, r_n$，使得对每个 $k$ 均有 $z_k = r_k e^{i\alpha}$。指数因子 $e^{i\alpha}$ 是表示共同方向的单位复数，如[欧拉公式](../eulers-formula/)条目所述。在此条件下，和本身也是 $e^{i\alpha}$ 的非负倍数，其模等于各模之和。

广义三角不等式是复数项[级数](../geometric-series/)理论的基石。特别地，绝对收敛的概念依赖于这一估计，因为它使得人们能够用模的偏和（均为实数且非负）来控制偏和的模。

## 柯西—施瓦茨不等式

柯西—施瓦茨不等式是一条基本估计，它将复数乘积之和与各自模的平方和联系起来。其有限形式如下：对任意复数 $a_1, \ldots, a_n$ 和 $b_1, \ldots, b_n$，有

$$\left|\sum_{k=1}^{n} a_k \overline{b_k}\right|^2 \leq \left(\sum_{k=1}^{n} |a_k|^2\right) \left(\sum_{k=1}^{n} |b_k|^2\right)$$

一种标准证明如下：对任意复参数 $t$，考虑非负量：

$$P(t) = \sum_{k=1}^{n} |a_k - t b_k|^2$$

令 $\sigma = \sum_{k=1}^{n} a_k \overline{b_k}$ 并展开模的平方，得

$$
\begin{align}
P(t) &= \sum_{k=1}^{n} (a_k - t b_k)\bigl(\overline{a_k} - \overline{t}\overline{b_k}\bigr) \\[6pt]
     &= \sum_{k=1}^{n} |a_k|^2 - t\overline{\sigma} - \overline{t}\sigma + |t|^2 \sum_{k=1}^{n} |b_k|^2
\end{align}
$$

若 $\sum_{k=1}^{n} |b_k|^2 = 0$，则每个 $b_k$ 均为零，不等式平凡成立。在其余情形中，选取 $t = \sigma / \sum_{k=1}^{n} |b_k|^2$ 使 $P(t)$ 最小，代入此值得到以下估计。

$$0 \leq P(t) = \sum_{k=1}^{n} |a_k|^2 - \frac{|\sigma|^2}{\sum_{k=1}^{n} |b_k|^2}$$

整理最后一个不等式，得到上界：

$$|\sigma|^2 \leq \left(\sum_{k=1}^{n} |a_k|^2\right) \left(\sum_{k=1}^{n} |b_k|^2\right)$$

此即柯西—施瓦茨不等式。

等号成立当且仅当两个向量线性相关。若第二个向量非零，则等价于存在某个 $t$ 使 $P(t) = 0$，即对每个下标 $k$ 有 $a_k = t b_k$；若第二个向量为零，则对任意第一个向量等号也成立。换言之，等号恰在 $(a_1, \ldots, a_n)$ 与 $(b_1, \ldots, b_n)$ 于 $\mathbb{C}^n$ 中线性相关时取到。

> 柯西—施瓦茨不等式的作用远不限于上述场景。在内积空间理论中——$\mathbb{C}^n$ 是其典型的有限维实例——该不等式成为基本估计，由此可推出角度的几何概念、平行四边形恒等式以及正交性的整套结构。

## 示例与应用

第一个例子涉及基本分量不等式的运用。设 $z = a + bi$ 满足 $|z| \leq 5$。由估计 $|a| \leq |z|$ 得 $-5 \leq a \leq 5$，而 $b$ 的相应上界表明点 $z$ 落在以原点为中心、边长为 $10$ 的正方形内。反过来，若 $|a| \leq 3$ 且 $|b| \leq 4$，不等式 $|z| \leq |a| + |b|$ 给出较宽松的上界 $|z| \leq 7$。直接使用模的定义（或[勾股定理](../pythagorean-theorem/)）可得更紧的估计 $|z| \leq \sqrt{9 + 16} = 5$。

- - -

第二个应用涉及[多项式](../polynomials/)根的定位。考虑 $n$ 次首一多项式：

$$p(z) = z^n + a_{n-1} z^{n-1} + \cdots + a_1 z + a_0$$

设 $z_0 \in \mathbb{C}$ 是 $p$ 的一个[根](../roots-of-a-polynomial/)，即 $z_0^n = -a_{n-1} z_0^{n-1} - \cdots - a_0$。对右端应用广义三角不等式，得到以下上界。

$$|z_0|^n \leq \sum_{k=0}^{n-1} |a_k| \cdot |z_0|^k$$

令 $M = \max_{0 \leq k \leq n-1} |a_k|$ 并假设 $|z_0| > 1$，右端有上界 $M \cdot \frac{|z_0|^n - 1}{|z_0| - 1} \leq M \cdot \frac{|z_0|^n}{|z_0| - 1}$，由此推出不等式 $|z_0| - 1 \leq M$。因此 $p$ 的每个根都满足以下估计。

$$|z_0| \leq 1 + M$$

这是柯西给出的经典上界（柯西根界），断言首一多项式的所有复根都落在半径由各系数模的最大值决定的闭圆盘内。上述推导利用了根的模大于 $1$ 的假设；当根的模不超过 $1$ 时，由于上述估计中的半径不小于 $1$，根显然满足该估计，因此结论对所有根均成立。论证虽简短，却将三角不等式与[等比级数](../geometric-series/)结合，展示了基本估计如何导出关于多项式方程的实质性结构信息。

- - -

第三个应用直接使用柯西—施瓦茨不等式。给定复数 $z_1, \ldots, z_n$，在不等式中取 $a_k = z_k$ 和 $b_k = 1$，得

$$\left|\sum_{k=1}^{n} z_k\right|^2 \leq n \sum_{k=1}^{n} |z_k|^2$$

对上式开平方可得

$$
\left|\sum_{k=1}^{n} z_k\right|
\leq
\sqrt{n}\left(\sum_{k=1}^{n}|z_k|^2\right)^{1/2}.
$$

这个估计在已知二范数上界时尤其有用；若仅知每个 $|z_k| \leq C$，右端至多为 $nC$，仍随项数 $n$ 线性增长，而不是 $\sqrt{n}$ 量级。另一方面，柯西—施瓦茨不等式还给出

$$
\sum_{k=1}^{n}|z_k|
\leq
\sqrt{n}\left(\sum_{k=1}^{n}|z_k|^2\right)^{1/2},
$$

因此这里的上界一般不比广义三角不等式的右端更小，不能视为通常意义上的改进。它的重要性来自内积与二范数结构，尤其适用于正交性和傅里叶分析；本例取等号当且仅当 $z_1 = \cdots = z_n$。
