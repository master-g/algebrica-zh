## 定理陈述

设 $f : [a,b] \to \mathbb{R}$ 在闭[区间](../intervals/) $[a,b]$ 上[连续](../continuous-functions/)，且 $y$ 位于端点值之间，即 $f(a) \le y \le f(b)$ 或 $f(b) \le y \le f(a)$。那么至少存在一个点 $c \in [a,b]$ 满足：

$$f(c) = y$$

高度介于 $f(a)$ 与 $f(b)$ 之间的每条水平线，都会在区间 $[a,b]$ 上方与 $f$ 的图像相交。

![图 1](/assets/differential-calculus-theorems/svg/intermediate-value-theorem-1.svg)

这个定理是一个存在性结论。它既不定位 $c$，也不保证 $c$ 唯一。一个介值可能只取得一次，也可能取得多次。函数 $f(x) = x^3 - 4x$ 在 $[-3,3]$ 上满足 $f(-3) = -15$ 和 $f(3) = 15$，而值 $0$ 在 $x = -2$、$x = 0$ 和 $x = 2$ 三个点处取得。

## 博尔查诺零点定理

当 $y = 0$ 时，介值定理具有如下形式。假设 $f$ 在 $[a,b]$ 上连续，且端点值异号，即：

$$f(a)f(b) < 0$$

那么 $f$ 在开区间 $(a,b)$ 的某个点 $c$ 处有零点。这个结果称为零点定理或博尔查诺定理。博尔查诺在 1817 年发表了一个不借助图像的解析证明。

这些假设不限制零点的数量，连续函数可以有无穷多个零点。

## 逐次二分证明

假设 $f(a) < 0 < f(b)$。如果符号相反，就用 $-f$ 替代 $f$，因为它们有相同的零点。

令 $a_0 = a$、$b_0 = b$。假设已经构造出区间 $[a_n,b_n]$，满足 $f(a_n) < 0 < f(b_n)$。其中点为：

$$m_n = \frac{a_n + b_n}{2}$$

如果 $f(m_n) = 0$，那么 $m_n$ 就是一个零点，构造停止。如果 $f(m_n) > 0$，令 $a_{n+1} = a_n$、$b_{n+1} = m_n$，保留左半区间。如果 $f(m_n) < 0$，令 $a_{n+1} = m_n$、$b_{n+1} = b_n$，保留右半区间。无论哪种情形，新端点都异号：

$$f(a_{n+1}) < 0 < f(b_{n+1})$$

每个新区间的长度都是前一个区间的一半。经过 $n$ 步后，其长度为：

$$b_n - a_n = \frac{b-a}{2^n}$$

如果构造永不停止，则 $(a_n)$ 递增、$(b_n)$ 递减，并且两个数列都包含在 $[a,b]$ 中。每个有界的[单调数列](../monotone-sequences/)都[收敛](../convergent-and-divergent-sequences/)，所以这两个数列都有极限。由于 $b_n - a_n \to 0$，它们的极限相等。将公共极限记为 $c$。因为 $[a,b]$ 是闭集，所以 $c \in [a,b]$。

> 这一步的收敛使用了[实数](../real-numbers/)的完备性。在 $\mathbb{Q}$ 中，区间可能在 $\mathbb{R}$ 中收敛到一个不属于定义域的无理数。例如，将 $f(x) = x^2 - 2$ 限制在 $[1,2] \cap \mathbb{Q}$ 上，它是连续的并且变号，但没有有理零点。

由于 $f$ 在 $c$ 处连续，有 $f(a_n) \to f(c)$ 和 $f(b_n) \to f(c)$。$(f(a_n))$ 的每一项都为负，所以 $f(c) \le 0$。$(f(b_n))$ 的每一项都为正，所以 $f(c) \ge 0$。因此：

$$f(c) = 0$$

> 严格不等式在极限中会变成非严格不等式。由 $f(a_n) < 0$ 我们只能推出 $f(c) \le 0$，因此单独看任意一个数列都不能确定结论。

还有一种证明使用集合 $S = \{\ x \in [a,b] \mid f(x) < 0\ \}$。这个集合非空，因为 $a \in S$，并且以上界 $b$ 为界，所以它有一个[上确界](../supremum-and-infimum/) $c$。$b$ 附近的连续性说明 $c < b$。如果 $f(c) < 0$，连续性会给出一个大于 $c$ 的 $S$ 中的点，与 $c$ 的定义矛盾。如果 $f(c) > 0$，连续性会给出 $c$ 左侧的一个区间，其中不含 $S$ 的点。这样，一个小于 $c$ 的数就会成为 $S$ 的上界，再次产生矛盾。因此 $f(c) = 0$。在二分证明中，$c$ 也是嵌套区间的极限，而这些区间可以计算出来。

## 从零点到任意值

零点定理蕴含一般的介值定理。如果 $y = f(a)$，取 $c = a$；如果 $y = f(b)$，取 $c = b$。剩下的是严格不等式的情形。先假设 $f(a) < y < f(b)$，并定义：

$$g(x) = f(x) - y$$

值恒为 $y$ 的常函数是连续的，所以 $g$ 在 $[a,b]$ 上连续。它的端点值满足 $g(a) = f(a) - y < 0$ 以及 $g(b) = f(b) - y > 0$。博尔查诺定理给出一个点 $c \in (a,b)$，使 $g(c) = 0$；等价地，$f(c) = y$。当 $f(b) < y < f(a)$ 时端点符号反过来，完全相同的论证仍然适用。

反过来，零点定理正是介值定理中 $y = 0$ 的情形。因此，这两个陈述是等价的。

## 假设发挥作用之处

函数必须在整个[定义域](../determining-the-domain-of-a-function/)上连续，而且定义域必须是一个区间。去掉任一条件，结论都可能失败。

在 $[-1,1]$ 上的一个反例是阶跃函数：

$$
f(x) =
\begin{cases}
-1 & x \le 0 \\[6pt]
1 & x > 0
\end{cases}
$$

![图 2](/assets/differential-calculus-theorems/svg/intermediate-value-theorem-2.svg)

端点值为 $f(-1) = -1$ 和 $f(1) = 1$，但函数不会取得严格介于两者之间的任何值。它只在原点处不同于[符号函数](../sign-function/)，在那里有一个跳跃[间断点](../discontinuities-of-real-functions/)。它在原点处的[单侧极限](../limits/)存在但不相同。

当定义域不连通时，连续性本身还不够。函数 $f(x) = 1/x$ 在 $[-1,0) \cup (0,1]$ 的每一点处都连续，并且满足 $f(-1) = -1$ 和 $f(1) = 1$，但它从不为零。它的定义域是两个不相交区间的并。在每个区间上，函数都保持固定符号，所以分别在两个区间上应用定理并不会产生矛盾。

逆命题不成立。函数可能在每个区间上都具有介值性，却仍然不连续。例如，当 $x \neq 0$ 时令 $g(x) = \sin(1/x)$，并令 $g(0) = 0$，它具有这一性质，但在原点不连续。[达布定理](../darboux-theorem/)指出，每个[导数](../derivatives/)都具有介值性，即使该导数不连续。

## 区间的像

如果 $f$ 在区间 $I$ 上连续，那么[像](../functions/) $f(I)$ 仍然是一个区间。

设 $u,v \in f(I)$ 且 $u < v$。选取 $p,q \in I$ 使 $u = f(p)$、$v = f(q)$，并假设 $u < y < v$。端点为 $p$ 和 $q$ 的闭区间包含在 $I$ 中，因为 $I$ 包含其任意两点之间的所有点。$f$ 在这个闭区间上的限制满足定理的假设。因此，对 $p$ 与 $q$ 之间的某个点 $c$ 有 $f(c) = y$，所以 $y \in f(I)$。于是 $f(I)$ 包含其任意两个元素之间的每个数，因此是一个区间。

如果 $f$ 在闭有界区间 $[a,b]$ 上连续，那么[魏尔斯特拉斯定理](../weierstrass-theorem/)说明 $f$ 有最小值 $m$ 和最大值 $M$。因此 $f([a,b])$ 是包含在 $[m,M]$ 中并且包含 $m$ 和 $M$ 的区间。所以：

$$f([a,b]) = [m,M]$$

> 像不一定与定义域属于同一类型。映射 $f(x) = x^2$ 将开区间 $(-1,1)$ 映射到 $[0,1)$，后者既不是开集也不是闭集。如果定义域是紧集，那么它的连续像也是紧集，因此是一个闭有界区间。

## 例 1

考虑多项式函数 $f : [1,2] \to \mathbb{R}$：

$$f(x) = x^3 - x - 1$$

[多项式函数](../polynomial-function/)在整个实线上连续，所以 $f$ 在 $[1,2]$ 上连续。端点值为：

$$
\begin{align}
f(1) &= 1 - 1 - 1 = -1 \\[6pt]
f(2) &= 8 - 2 - 1 = 5
\end{align}
$$

端点值异号，因此方程 $x^3 - x - 1 = 0$ 在 $(1,2)$ 中至少有一个解。二分法通过保留端点异号的一半来缩小位置：

$$
\begin{align}
f(1.5) &= 0.875 > 0 \quad \rightarrow \quad c \in (1,1.5) \\[6pt]
f(1.25) &= -0.296875 < 0 \quad \rightarrow \quad c \in (1.25,1.5) \\[6pt]
f(1.375) &= 0.224609375 > 0 \quad \rightarrow \quad c \in (1.25,1.375)
\end{align}
$$

三步之后，根属于长度为 $0.125$ 的区间。经过 $n$ 步后，包含根的区间长度为 $1/2^n$，所以可以预先规定其宽度。由于 $f'(x) = 3x^2 - 1 > 0$ 在 $[1,2]$ 上成立，函数在那里[严格递增](../increasing-and-decreasing-functions/)，所以根是唯一的。这个根是塑性数，精确到小数点后五位的值为 $1.32472$。

## 奇次多项式的实根

具有实系数且次数为奇数的多项式至少有一个[实根](../roots-of-a-polynomial/)。

设 $p(x) = a_nx^n + \dots + a_0$，其中 $n$ 为奇数且 $a_n \neq 0$。如果 $a_n < 0$，就用 $-p$ 替代 $p$，因为它们有相同的根。因此可以假设 $a_n > 0$。下面的[极限](../limits/)比较 $p$ 与它的最高次项：

$$\lim_{|x| \to \infty} \frac{p(x)}{a_nx^n} = 1$$

这个极限说明，当 $|x|$ 很大时，最高次项决定 $p(x)$ 的符号。由于 $n$ 为奇数，当 $x \to +\infty$ 时 $p(x) \to +\infty$，当 $x \to -\infty$ 时 $p(x) \to -\infty$。因此存在某些点 $u < v$，满足 $p(u) < 0 < p(v)$。在 $[u,v]$ 上对 $p$ 应用博尔查诺定理，得到一个实根。

如果次数为偶数且最高次系数为正，则两个极限都是 $+\infty$，所以不会得到变号。例如，$p(x) = x^2 + 1$ 没有实根。根的数量和位置将在[多项式方程](../polynomial-equations/)中进一步研究。

## 连续自映射的不动点

设 $f : [a,b] \to [a,b]$ 连续。那么 $f$ 有一个不动点，即存在一个点 $x_0$ 使 $f(x_0) = x_0$。

由于 $f$ 的值都在 $[a,b]$ 中，定义 $g(x) = f(x) - x$，它在 $[a,b]$ 上连续。包含关系 $f(a) \in [a,b]$ 给出 $f(a) \ge a$，从而 $g(a) \ge 0$。同样，$f(b) \in [a,b]$ 给出 $f(b) \le b$，从而 $g(b) \le 0$。如果 $g$ 的某个端点值为零，那么相应端点就是不动点。否则 $g(a) > 0 > g(b)$，零点定理给出某个点 $x_0 \in (a,b)$，使 $g(x_0) = 0$。因此 $f(x_0) = x_0$。

$f$ 的图像位于正方形 $[a,b]^2$ 中，连接其左边和右边，并且与对角线相交。这个结果是布劳威尔不动点定理的一维情形；该定理针对从 $\mathbb{R}^n$ 中的闭球映射到自身的连续映射。

## 这个定理的应用

+ 在[不等式的符号分析](../sign-analysis-in-inequalities/)中，不含零点且包含在定义域内的每个子区间上，连续函数都保持固定符号。
+ 与[魏尔斯特拉斯定理](../weierstrass-theorem/)结合，该定理说明连续函数在闭有界区间上满足 $f([a,b]) = [m,M]$。
+ [积分中值定理](../definite-integrals/)随之成立，因为连续函数的平均值位于最小值和最大值之间，因此一定能取得该平均值。
+ 连续且[严格单调](../increasing-and-decreasing-functions/)的函数有一个定义域为区间的[逆函数](../inverse-function/)。
+ [达布定理](../darboux-theorem/)指出，每个导数都有介值性，包括不连续的导数。
