## 定义

[指数函数](../exponential-function/)是形如 $e^x$ 或 $\alpha^x$ 的函数，其中 $\alpha > 0$ 且 $\alpha \neq 1$。数 $e$ 在分析学中占据核心地位，因为它是唯一一个使指数函数在求导后保持自身不变的底数。对于形如 $\alpha^x$ 且 $\alpha > 0$ 的一般指数函数，求导会引入一个额外因子：

$$\frac{d}{dx}\alpha^x = \alpha^x \ln \alpha$$

其中的[对数](../logarithms/)项反映了所选底数如何缩放函数的增长。恰好有一种情形会使这个额外因子消失。当 $\ln \alpha = 1$ 时，导数就化简为函数自身：

$$\frac{d}{dx}\alpha^x = \alpha^x$$

满足这一条件的唯一数是 $e \approx 2.718$。因此，函数 $e^x$ 是唯一一个在求导后保持不变的指数函数，并且同样的性质也延伸到积分。这一结构特征解释了为什么 $e$ 在微积分中如此基础。指数函数的[积分](../indefinite-integrals/)分为两种不同情形，取决于底数是 $e$ 还是一般的正数 $\alpha \neq 1$。$e^x$ 的积分为：

$$\int e^x \ dx = e^x + c \tag{1}$$

这个结果源于 $e^x$ 的[导数](../derivatives/)就是 $e^x$ 自身。对右侧求导可得：

$$\frac{d}{dx}\left[e^x + c\right] = \frac{d}{dx}e^x + \frac{d}{dx}c = e^x + 0 = e^x$$

这就确认了 $e^x + c$ 确实是 $e^x$ 的一个反导数。$\alpha^x$ 的积分为：

$$\int \alpha^x \ dx = \frac{1}{\ln \alpha} \cdot \alpha^x + c \tag{2}$$

直接验证即可确认这个公式：

$$\frac{d}{dx}\left[ \frac{1}{\ln \alpha} \cdot \alpha^x + c \right] = \frac{1}{\ln \alpha} \cdot (\ln \alpha \cdot \alpha^x) = \alpha^x$$

因子 $1/\ln \alpha$ 恰好抵消了求导产生的对数项，结果便还原为原来的被积函数。

## 指数积分的标准形式

下表汇总了标准指数被积函数的反导数：左侧是被积函数，右侧是相应的反导数。常数 $a$ 和 $b$ 为实数，且 $a \neq 0$；$\alpha > 0$ 且 $\alpha \neq 1$。在最后一行，$f(x)$ 是任意可导函数。这些形式涵盖了积分题中最常见的情形。

[class="table-1"]

|    |                                            |                                                                |
| -- | ------------------------------------------ | -------------------------------------------------------------- |
| 1. | $$\int e^x \ dx$$                          | $$e^x + c$$                                                    |
| 2. | $$\int \alpha^x \ dx$$                     | $$\dfrac{1}{\ln \alpha} \alpha^x + c$$                         |
| 3. | $$\int e^{ax + b} \ dx$$                   | $$\dfrac{1}{a} e^{ax + b} + c$$                                |
| 4. | $$\int \alpha^{ax + b} \ dx$$              | $$\dfrac{1}{a \ln \alpha} \alpha^{ax + b} + c$$                |
| 5. | $$\int e^{f(x)} f'(x) \ dx$$               | $$e^{f(x)} + c$$                                               |

[/class]

> 每个公式都说明，积分会保留被积函数的指数结构。反导数与原函数的差别仅在于一个乘法常数，而这个常数取决于指数中的系数或幂的底数。

## 例 1

考虑下面的积分：

$$\int (e^x + 3^x) \ dx$$

根据[不定积分](../indefinite-integrals/)的线性性质，和的积分等于各项积分之和：

$$\int (f(x) + g(x)) \ dx = \int f(x) \ dx + \int g(x) \ dx$$

应用这一性质，积分可以拆分为：

$$\int (e^x + 3^x) \ dx = \int e^x \ dx + \int 3^x \ dx$$

第一个积分直接由公式 $(1)$ 得到：

$$\int e^x \ dx = e^x + c$$

第二个积分使用公式 $(2)$，其中 $\alpha = 3$：

$$\int 3^x \ dx = \frac{1}{\ln 3} \cdot 3^x + c$$

合并两部分：

$$\int (e^x + 3^x) \ dx = e^x + \frac{1}{\ln 3} \cdot 3^x + c$$

> 这个反导数是两个指数项之和，每一项都由自己的底数决定。

## 线性自变量的指数函数

在应用中，一个常见情形是指数的自变量为线性函数 $ax + b$，其中 $a \neq 0$。相应的积分公式为：

$$\int e^{ax + b} \ dx = \frac{1}{a} e^{ax + b} + c$$

因子 $1/a$ 抵消了[链式法则](../the-derivative-of-a-composite-function/)在求导时引入的系数。直接验证可得：

$$\frac{d}{dx}\left[ \frac{1}{a} e^{ax + b} + c \right] = \frac{1}{a} \cdot a \cdot e^{ax + b} = e^{ax + b}$$

这与原来的被积函数一致。

当指数是可导函数 $f(x)$ 时，可以通过[换元积分](../integration-by-substitution/)推广这个公式：

$$\int e^{f(x)} \cdot f'(x) \ dx = e^{f(x)} + c$$

被积函数必须包含指数 $e^{f(x)}$，并乘以其指数的导数。在此条件下，积分可以直接完成，反导数为 $e^{f(x)} + c$。当因子 $f'(x)$ 不在被积函数中时，需要先进行代数变形或使用合适的换元，才能应用这一规则。

同样的推理也适用于底数为任意 $\alpha$ 的指数函数。当指数是 $ax + b$ 而不是 $x$ 时，求导会产生两个因子：一个来自指数中的系数 $a$，另一个来自底数的 $\ln \alpha$。相应的公式为：

$$\int \alpha^{ax + b} \ dx = \frac{1}{a \ln \alpha} \alpha^{ax + b} + c$$

直接对右侧求导即可确认结果。这类表达式经常出现在更复杂的积分被化简为基本组成部分的中间步骤中。

## 例 2

考虑下面的积分，其中包含两个底数不同的指数项之积：

$$\int 8^x \cdot 2^{-3x + 4} \ dx$$

可以利用[幂的性质](../powers/)化简被积函数。第二个因子中的 $2$ 的指数可拆分为：

$$2^{-3x + 4} = 2^{-3x} \cdot 2^4 = 16 \cdot 2^{-3x}$$

将这一恒等式代入积分，并利用线性性质提出常数 $16$：

$$\int 8^x \cdot 2^{-3x + 4} \ dx = 16 \int 8^x \cdot 2^{-3x} \ dx$$

底数 $8$ 可以改写为 $2$ 的幂，因为 $8 = 2^3$。于是，被积函数化简为单个 $2$ 的幂：

$$
\begin{align}
16 \int 8^x \cdot 2^{-3x} \ dx &= 16 \int (2^3)^x \cdot 2^{-3x} \ dx \\[6pt]
                               &= 16 \int 2^{3x} \cdot 2^{-3x} \ dx \\[6pt]
                               &= 16 \int 2^{3x - 3x} \ dx \\[6pt]
                               &= 16 \int 1 \ dx
\end{align}
$$

常数函数 $1$ 的积分是 $x + c$，因此最终结果为：

$$\int 8^x \cdot 2^{-3x + 4} \ dx = 16x + c$$

> 一旦将原被积函数中的两个指数因子化为相同底数，表面的复杂性就会消失，积分也随之化为常数的积分。

## 例 3

考虑下面的积分，其中两个因子都是线性自变量的指数函数，且底数相关：

$$\int 9^{x - 1} \cdot 3^{-x + 2} \ dx$$

利用幂的性质，可以拆分两个指数：

$$9^{x - 1} \cdot 3^{-x + 2} = 9^x \cdot 9^{-1} \cdot 3^{-x} \cdot 3^2$$

由于 $3^2 = 9$，因子 $9^{-1} \cdot 9$ 化为 $1$，被积函数简化为：

$$9^x \cdot 3^{-x}$$

将 $9^x$ 改写为 $3^{2x}$，两个底数为 $3$ 的指数因子之积便合并为一个幂：

$$9^x \cdot 3^{-x} = 3^{2x} \cdot 3^{-x} = 3^{2x - x} = 3^x$$

因此，积分化为标准形式 $\int \alpha^x \ dx$，其中 $\alpha = 3$：

$$\int 9^{x - 1} \cdot 3^{-x + 2} \ dx = \int 3^x \ dx$$

应用公式 $(2)$，最终结果为：

$$\int 9^{x - 1} \cdot 3^{-x + 2} \ dx = \frac{1}{\ln 3} \cdot 3^x + c$$

> 化为公共底数是关键步骤：当两个因子都表示为 $3$ 的幂后，被积函数就成为单个指数函数，积分也可以直接完成。

## 例 4

考虑下面的积分：

$$\int e^{3x - 2} \ dx$$

指数是 $x$ 的线性函数，因此可以直接应用形如 $e^{ax + b}$ 的指数函数标准规则。$3x - 2$ 的导数是 $3$，所以反导数中的补偿因子为 $1/3$：

$$\int e^{3x - 2} \ dx = \frac{1}{3} e^{3x - 2} + c$$

直接对右侧求导可确认结果：

$$\frac{d}{dx}\left[ \frac{1}{3} e^{3x - 2} + c \right] = \frac{1}{3} \cdot 3 \cdot e^{3x - 2} = e^{3x - 2}$$

求导后恢复出原来的被积函数，因此这个反导数与积分规则一致。

## 一个常见的疏忽

积分指数函数时，一个常见错误来源是指数带有不等于 $1$ 的系数。常见的错误写法是：

$$\int e^{3x - 2} \ dx = e^{3x - 2} + c$$

其中遗漏了因子 $1/3$。对提出的反导数求导即可发现错误：

$$\frac{d}{dx} e^{3x - 2} = 3 e^{3x - 2}$$

结果是原被积函数的三倍，这说明单独的 $e^{3x - 2}$ 并不是它自身的反导数。只要指数具有 $ax + b$ 的形式且 $a \neq 1$，反导数中就必须出现补偿因子 $1/a$，因为链式法则会在求导时引入乘法常数 $a$。

## 例 5

考虑下面的积分，其中指数不再是 $x$ 的线性函数：

$$\int x \ e^{x^2} \ dx$$

指数 $x^2$ 是二次函数，因此不能直接应用形如 $e^{ax + b}$ 的指数函数规则。不过，被积函数的结构提示了合适的策略。$x^2$ 的导数是 $2x$，而被积函数中已经含有因子 $x$。乘以并除以 $2$ 可以引入缺少的常数，而不改变积分的值：

$$\int x \ e^{x^2} \ dx = \frac{1}{2} \int 2x \ e^{x^2} \ dx$$

现在，被积函数符合 $e^{f(x)} f'(x)$ 的标准形式，其中 $f(x) = x^2$，所以标准表中的公式 $(5)$ 适用，积分可以直接完成：

$$\int x \ e^{x^2} \ dx = \frac{1}{2} e^{x^2} + c$$

直接对右侧求导可确认结果：

$$\frac{d}{dx}\left[ \frac{1}{2} e^{x^2} + c \right] = \frac{1}{2} \cdot 2x \cdot e^{x^2} = x e^{x^2}$$

> 求导后恢复出原被积函数，从而验证了所得反导数。

## 缺少匹配因子时

去掉前一个例子中的因子 $x$ 后，这个因子的作用就显现出来了。所得积分为：

$$\int e^{x^2} \ dx$$

这个积分不存在能够用初等函数表示的反导数。它的反导数通常用虚误差函数 $\mathrm{erfi}(x)$ 表示，该函数定义为：

$$\mathrm{erfi}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{t^2} \ dt$$

这里说 $\mathrm{erfi}(x)$ 不是初等函数，是指它不能通过多项式、指数函数、对数函数和三角函数的有限次代数运算、复合与求逆得到。使用它是因为被积函数 $e^{t^2}$ 没有初等反导数。[微积分基本定理](../fundamental-theorem-of-calculus/)可以从定义积分直接给出它的导数，反复求导则表明它处处可无限次求导。

与前一个例子的对比说明了因子 $x$ 的作用。在 $\int x \ e^{x^2} \ dx$ 中，因子 $x$ 在乘上常数 $1/2$ 后，提供了指数 $x^2$ 的导数。被积函数符合 $e^{f(x)} f'(x)$ 的标准形式，因此反导数是初等函数。当因子 $x$ 缺失时，这种匹配关系也随之消失，积分便超出了可以用初等技巧求解的范围。

> 当无法得到初等闭式表达式时，相应[定积分](../definite-integrals/)的值仍然可以通过[数值积分](../numerical-integration/)近似计算，例如有限区间上的 $\int e^{x^2} \ dx$。

## 含指数因子的分部积分

有些含指数函数的积分无法仅靠代数变形化为标准形式。当被积函数是指数函数与多项式的乘积，或指数函数与另一个超越函数的乘积时，[分部积分](../integration-by-parts/)提供了一种系统方法。这一方法基于公式：

$$\int u(x) v'(x) \ dx = u(x) v(x) - \int u'(x) v(x) \ dx$$

选择 $u(x)$ 和 $v'(x)$ 是决定性的一步。当存在指数因子时，通常适合取 $v'(x) = e^{ax + b}$，因为指数函数在积分后除了乘法常数外保持不变，而剩余因子经过求导会逐步化简。

- - -

最简单的情形是一次多项式与指数函数的乘积。考虑积分：

$$\int x \ e^x \ dx$$

令 $u(x) = x$，$v'(x) = e^x$，则 $u'(x) = 1$，而 $v(x) = e^x$。代入分部积分公式：

$$\int x \ e^x \ dx = x \ e^x - \int e^x \ dx = x \ e^x - e^x + c$$

最终表达式可以因式分解为：

$$\int x \ e^x \ dx = (x - 1) e^x + c$$

直接求导即可确认结果，并恢复出原被积函数：

$$\frac{d}{dx}\left[ (x - 1) e^x + c \right] = e^x + (x - 1) e^x = x \ e^x$$

- - -

当[多项式](../polynomials/)因子的次数大于 $1$ 时，应用一次公式还不够，必须重复这个过程。考虑积分：

$$\int x^2 \ e^x \ dx$$

令 $u(x) = x^2$，$v'(x) = e^x$，第一次应用公式得到：

$$\int x^2 \ e^x \ dx = x^2 \ e^x - \int 2x \ e^x \ dx$$

剩余积分与前一个例子的结构相同，而且已经计算过。代入所得结果：

$$\int x^2 \ e^x \ dx = x^2 \ e^x - 2(x - 1) e^x + c = (x^2 - 2x + 2) e^x + c$$

同样的推理可推广到任意多项式 $P(x)$（次数为 $n$）。连续应用 $n$ 次分部积分后，多项式因子会降为常数，积分也就结束了。一般的递推关系为：

$$\int x^n \ e^x \ dx = x^n \ e^x - n \int x^{n - 1} \ e^x \ dx$$

这个关系把 $x^n e^x$ 的积分表示为 $x^{n - 1} e^x$ 的积分，并在有限步内产生闭式反导数。

- - -

当指数函数的指数本身是 $x$ 的线性函数时，还会出现另一种变化。此时使用相同的技巧，唯一的调整是补偿因子 $1/a$ 要出现在 $e^{ax + b}$ 的反导数中。考虑积分：

$$\int x \ e^{2x} \ dx$$

令 $u(x) = x$，$v'(x) = e^{2x}$，则 $v'(x)$ 的反导数为 $v(x) = \tfrac{1}{2} e^{2x}$。分部积分公式给出：

$$\int x \ e^{2x} \ dx = \frac{x}{2} e^{2x} - \int \frac{1}{2} e^{2x} \ dx = \frac{x}{2} e^{2x} - \frac{1}{4} e^{2x} + c$$

提出公共的指数因子，最终结果为：

$$\int x \ e^{2x} \ dx = \frac{1}{4} e^{2x} (2x - 1) + c$$

指数中的系数 $a = 2$ 不会改变这一过程的结构：它只是在每次积分时引入因子 $1/2$，并最终传递到结果中。

## 决策流程

下面的分步流程总结了对一般指数积分的解法选择。

+ 当被积函数是底数为常数的 $e^x$ 或 $\alpha^x$ 时，直接应用相应公式：$\int e^x \ dx = e^x + c$ 或 $\int \alpha^x \ dx = \tfrac{1}{\ln \alpha} \alpha^x + c$。
+ 当指数是线性函数 $ax + b$ 时，使用补偿因子：对于自然底数，$\int e^{ax + b} \ dx = \tfrac{1}{a} e^{ax + b} + c$；对于一般底数，$\int \alpha^{ax + b} \ dx = \tfrac{1}{a \ln \alpha} \alpha^{ax + b} + c$。
+ 当指数是可导函数 $f(x)$，且被积函数包含 $f'(x)$（必要时相差一个乘法常数）时，调整这个常数并应用 $\int e^{f(x)} f'(x) \ dx = e^{f(x)} + c$。
+ 当被积函数是指数函数与多项式 $P(x)$ 的乘积时，取 $u(x) = P(x)$、$v'(x) = e^{ax + b}$，应用分部积分。当多项式次数为 $n > 1$ 时，重复这一过程；每次应用都会使次数降低一阶，直到剩下常数。
+ 当被积函数是两个底数相关的指数函数之积时，利用幂的性质把两个因子化为公共底数，化简后回到前面的某一种情形。
+ 当以上方法都不适用时，积分可能无法用初等函数表示闭式结果。像 $\int e^{x^2} \ dx$ 或 $\int e^x/x \ dx$ 这样的积分通常用虚误差函数 $\mathrm{erfi}(x)$ 或指数积分 $\mathrm{Ei}(x)$ 等特殊函数表示，而它们的定积分形式最好通过[数值积分](../numerical-integration/)处理。
