## 用多项式除法积分有理函数

[有理函数](../rational-functions/)是两个多项式之商，相应的[不定积分](../indefinite-integrals/)一般写成：

$$\int \frac{N(x)}{D(x)} \ dx$$

其中 $N(x)$ 和 $D(x)$ 是具有实系数的[多项式](../polynomials/)，且 $D(x)$ 不恒等于零。计算这类积分所采用的策略取决于分子和分母的次数关系。先讨论 $N(x)$ 的次数大于或等于 $D(x)$ 次数的情形。

- - -

根据多项式的一般性质，总能将多项式 $N(x)$ 除以一个非零多项式 $D(x)$，即进行[除法](../polynomial-division/)。这一运算的结果由两个多项式组成：

+ 商多项式 $Q(x)$。
+ 余式多项式 $R(x)$，其次数严格小于 $D(x)$ 的次数。

这个过程产生如下形式的恒等式：

$$N(x) = Q(x) D(x) + R(x)$$

等式两边同时除以 $D(x)$：

$$\frac{N(x)}{D(x)} = Q(x) + \frac{R(x)}{D(x)}$$

再对两边积分：

$$\int \frac{N(x)}{D(x)} \ dx = \int Q(x) \ dx + \int \frac{R(x)}{D(x)} \ dx$$

- - -

决定方法选择的是分子与分母次数的比较。当 $\deg N(x) \geq \deg D(x)$ 时，有理函数是不真分式，必须先通过多项式长除法将其化简。只有完成这一步预处理后，积分才会变成容易处理的形式。

当 $\deg N(x) < \deg D(x)$ 时，有理函数已经是真分式，接下来要关注分母的因式分解。分母的代数结构决定了所用技巧：

+ 当分母是单个一次因子时，简单换元通常可以立即完成积分。
+ 当分母分解为互异的一次因子时，部分分式分解会把表达式化为初等项之和。
+ 当某个一次因子重复出现时，该因子的每个幂次都会在分解中产生自己的项，形成一个小型的分式层级。
+ 当存在不可约二次因子时，需要配方，并自然导出反正切项。

> 一旦有理函数被化为真分式，分母就主导整个策略。它在实数范围内的因式分解决定了部分分式分解的结构。积分随后系统地化为对数原函数和反三角原函数。

## 例 1

计算下面有理函数的积分：

$$\int \frac{x^3 + x + 1}{x^2 + 1} \ dx$$

第一步是将分子除以分母作[多项式除法](../polynomial-division/)，得到：

$$Q(x) = x \qquad R(x) = 1$$

因此：

$$\frac{x^3 + x + 1}{x^2 + 1} = x + \frac{1}{x^2 + 1}$$

> 两个多项式相除的方法在[多项式](../polynomials/)页面中有详细讨论。

- - -

积分拆分为两项：

$$\int \frac{x^3 + x + 1}{x^2 + 1} \ dx = \int x \ dx + \int \frac{1}{x^2 + 1} \ dx$$

分别计算每一项，并合并积分常数：

$$\int \frac{x^3 + x + 1}{x^2 + 1} \ dx = \frac{x^2}{2} + \arctan(x) + c$$

## 分母为一次式的积分

真分式最简单的情形是分母为一次多项式。积分形式为：

$$\int \frac{c}{ax + b} \ dx$$

其中 $a$、$b$ 和 $c$ 是实常数，且 $a \neq 0$。分子是常数，因此次数条件 $\deg N(x) < \deg D(x)$ 自动满足。

这类积分通过[换元积分](../integration-by-substitution/)求解。令 $t = ax + b$，得到 $dt = a \ dx$，于是积分变为：

$$\int \frac{c}{ax + b} \ dx = \frac{c}{a} \int \frac{1}{t} \ dt = \frac{c}{a} \ln|t| + k$$

换回原变量：

$$\int \frac{c}{ax + b} \ dx = \frac{c}{a} \ln|ax + b| + k$$

绝对值是必要的，因为一次表达式 $ax + b$ 在 $x = -b/a$ 处变号，而自然对数只对正数定义。这个公式适用于不包含该点的任意区间，在这些区间上被积函数保持连续。这一情形也构成了更一般情形的基本构件。一旦真分式被分解为部分分式，所有分母为简单一次因子的项都会化为这里讨论的积分形式。因此，上面得到的对数原函数会在后续讨论中反复出现。

## 例 2

计算下面有理函数的积分：

$$\int \frac{2}{6x + 1} \ dx$$

作换元 $t = 6x + 1$。对等式两边关于 $x$ 求导：

$$\frac{dt}{dx} = 6 \quad \Rightarrow \quad dx = \frac{dt}{6}$$

将其代入积分：

$$\int \frac{2}{6x + 1} \ dx = \int \frac{2}{t} \cdot \frac{dt}{6} = \frac{1}{3} \int \frac{1}{t} \ dt$$

剩余积分是[不定积分](../indefinite-integrals/)页面中回顾过的初等形式之一，其原函数是 $t$ 的绝对值的自然对数：

$$\frac{1}{3} \int \frac{1}{t} \ dt = \frac{1}{3} \ln|t| + c$$

代入 $t = 6x + 1$ 换回原变量，最终结果为：

$$\int \frac{2}{6x + 1} \ dx = \frac{1}{3} \ln|6x + 1| + c$$

## 部分分式分解

在许多情形中，有理函数的积分无法通过观察直接计算。即使表达式看起来相对简单，代数变形也未必能立即显出反导数。这时，[部分分式分解](../partial-fraction-decomposition/)提供了一种系统方法，可以把函数重写为初等项之和，而这些项的积分都是已知的。将有理函数分解为更简单的组成部分后，就能得到非常适合积分的表达式。为了在不同于前面例子的情形中说明这一思想，考虑积分：

$$\int \frac{7x + 5}{(x - 1)(3x + 2)} \ dx$$

乍看之下，这个表达式的结构并没有提示出明显的原函数。一旦把被积函数分解为部分分式，计算就会变得直接。出发点是：

$$\frac{7x + 5}{(x - 1)(3x + 2)} = \frac{A}{x - 1} + \frac{B}{3x + 2} \tag{1}$$

等式两边乘以 $(x - 1)(3x + 2)$，得到恒等式：

$$7x + 5 = A(3x + 2) + B(x - 1)$$

系数 $A$ 和 $B$ 可以通过在方便的取值 $x = 1$ 和 $x = -2/3$ 处求值来确定：

$$A = 4 \qquad B = -5$$

将这些值代入恒等式 $(1)$：

$$\frac{7x + 5}{(x - 1)(3x + 2)} = \frac{4}{x - 1} - \frac{5}{3x + 2}$$

积分变为：

$$\int \left( \frac{4}{x - 1} - \frac{5}{3x + 2} \right) dx$$

根据[不定积分](../indefinite-integrals/)的线性性质，可以分别处理每一项：

$$4 \int \frac{1}{x - 1} \ dx \qquad 5 \int \frac{1}{3x + 2} \ dx$$

两个积分都化为初等的[对数](../logarithms/)形式：

$$4 \ln|x - 1| + c_1 \qquad \frac{5}{3} \ln|3x + 2| + c_2$$

合并常数并化简：

$$\int \frac{7x + 5}{(x - 1)(3x + 2)} \ dx = 4 \ln|x - 1| - \frac{5}{3} \ln|3x + 2| + c$$

> 这个例子说明，原本看不出积分路径的有理函数，在改写为部分分式后就完全可以处理了。这一方法把积分转化为一组标准形式，使计算既系统又清晰。

## 重复的一次因子

当有理函数的分母含有幂次大于一的一次因子时，部分分式分解需要作结构上的调整。形如 $A/(x - r)$ 的单项已经不足以描述函数在重复根附近的行为。该因子的每个幂次都必须在分解中贡献一项。

当分母含有因子 $(x - r)^k$ 时，部分分式分解中相应的部分为：

$$\frac{A_1}{x - r} + \frac{A_2}{(x - r)^2} + \dots + \frac{A_k}{(x - r)^k}$$

每个分子都是常数，分母则遍历 $(x - r)$ 从一次幂到重数 $k$ 的所有幂次。一般而言，省略其中任何一项都会使系数方程组不相容。

写出分解后，积分逐项进行。第一项产生对数，而所有形如 $A_j/(x - r)^j$ 且 $j \geq 2$ 的项都会积分为带负指数的 $(x - r)$ 的幂：

$$\int \frac{1}{(x - r)^j} \ dx = \frac{(x - r)^{1 - j}}{1 - j} + c \qquad (j \geq 2)$$

因此，对数项只出现一次，与一次幂相对应；更高次幂则贡献不含对数的有理表达式。

## 例 3

考虑积分：

$$\int \frac{3x + 1}{(x - 1)^2 (x + 2)} \ dx$$

分母包含重数为二的因子 $x - 1$ 和简单因子 $x + 2$。根据重复一次因子的通用规则，部分分式分解具有如下形式：

$$\frac{3x + 1}{(x - 1)^2 (x + 2)} = \frac{A}{x - 1} + \frac{B}{(x - 1)^2} + \frac{C}{x + 2}$$

等式两边乘以公共分母 $(x - 1)^2 (x + 2)$，得到多项式恒等式：

$$3x + 1 = A(x - 1)(x + 2) + B(x + 2) + C(x - 1)^2$$

通过在方便的 $x$ 值处代入恒等式来确定系数。代入 $x = 1$ 会消去所有含因子 $x - 1$ 的项，恒等式化为 $4 = 3B$，因此：

$$B = \frac{4}{3}$$

代入 $x = -2$ 会消去所有含因子 $x + 2$ 的项，恒等式化为 $-5 = 9C$，因此：

$$C = -\frac{5}{9}$$

系数 $A$ 不能通过直接代入得到，因为不存在某个 $x$ 值能够同时消去所有依赖于 $A$ 的项。标准方法是比较恒等式两边 $x$ 的最高次幂的系数。左侧不含 $x^2$ 项，因此该系数为零。右侧展开乘积后可见，$x^2$ 的系数是 $A + C$。令两边相等，得到 $A + C = 0$，从而：

$$A = \frac{5}{9}$$

将刚刚得到的值代入分解：

$$\frac{3x + 1}{(x - 1)^2 (x + 2)} = \frac{5/9}{x - 1} + \frac{4/3}{(x - 1)^2} - \frac{5/9}{x + 2}$$

积分拆分为三项，每一项都有已知的原函数：

$$\frac{5}{9} \int \frac{1}{x - 1} \ dx + \frac{4}{3} \int \frac{1}{(x - 1)^2} \ dx - \frac{5}{9} \int \frac{1}{x + 2} \ dx$$

第一项和第三项产生对数原函数，第二项则产生带负指数的有理表达式。合并这些贡献，原有理函数的一个反导数是：

$$\frac{5}{9} \ln|x - 1| - \frac{4}{3} \cdot \frac{1}{x - 1} - \frac{5}{9} \ln|x + 2| + c$$

最终表达式说明，因子 $x - 1$ 的两个不同幂次会产生性质不同的原函数：一次幂产生对数，平方幂产生有理项。

> 重复因子 $(x - 1)^2$ 为反导数贡献了两个不同的项。只有一次幂产生对数，而更高次幂给出带负指数的有理表达式。每个重数大于一的一次因子都遵循同样的模式。

## 分母中的不可约二次因子

并非每个多项式都能在实数范围内分解为一次因子。若二次表达式 $ax^2 + bx + c$ 的[判别式](../quadratic-formula/)满足 $b^2 - 4ac < 0$，则它没有实根，也不能写成 $(x - r_1)(x - r_2)$，其中 $r_1, r_2 \in \mathbb{R}$。

在实数域上，这样的二次多项式称为不可约二次式。当这种因子出现在有理函数的分母中时，部分分式分解的策略会略有变化。在线性情形中，每个因子 $(x - r)$ 都会产生如下形式的项：

$$\frac{A}{x - r}$$

现在没有实根可以与这些项对应。因此二次因子必须完整地保留在分母中。不可约二次因子 $ax^2 + bx + c$ 贡献的项形如：

$$\frac{Ax + B}{ax^2 + bx + c}$$

分子的次数必须严格小于分母；在二次情形中，这意味着分子次数为一。只使用常数无法提供足够的自由度来匹配原有理函数。分解完成后，通常通过[配方法](../completing-the-square/)重写二次分母，再进行积分。经过适当换元，积分化为：

$$\int \frac{1}{u^2 + a^2} \ du$$

其反导数为：

$$\frac{1}{a}\arctan\!\left(\frac{u}{a}\right) + c$$

[反正切](../arctangent-and-arccotangent/)的出现反映了表达式 $u^2 + a^2$ 所编码的几何结构：它在实数范围内不会为零，并且在分析上对应于反[正切函数](../tangent-function/)的导数。

## 例 4

考虑下面的积分：

$$\int \frac{5x^2 + 3x - 2}{(x + 1)(x^2 + 2x + 3)} \ dx$$

分母已经写成乘积形式。一个因子 $x + 1$ 是一次式，另一个因子 $x^2 + 2x + 3$ 则值得仔细考察。它的判别式是：

$$\Delta = 2^2 - 4 \cdot 1 \cdot 3 = 4 - 12 = -8 < 0$$

因此它没有实零点，在 $\mathbb{R}$ 上不可约。这决定了部分分式分解的形式：

$$\frac{5x^2 + 3x - 2}{(x + 1)(x^2 + 2x + 3)} = \frac{A}{x + 1} + \frac{Bx + C}{x^2 + 2x + 3}$$

等式两边乘以 $(x + 1)(x^2 + 2x + 3)$ 消去分母，得到恒等式：

$$5x^2 + 3x - 2 = A(x^2 + 2x + 3) + (Bx + C)(x + 1)$$

一个方便的第一步是在 $x = -1$ 处求值。第二项在这个取值处为零，于是：

$$5(-1)^2 + 3(-1) - 2 = A\bigl((-1)^2 + 2(-1) + 3\bigr)$$

左侧化简为 $5 - 3 - 2 = 0$，右侧则为 $A(1 - 2 + 3) = 2A$。因此 $0 = 2A$，所以：

$$A = 0$$

由于 $A = 0$，恒等式化为：

$$5x^2 + 3x - 2 = (Bx + C)(x + 1)$$

展开右侧：

$$(Bx + C)(x + 1) = Bx^2 + (B + C)x + C$$

逐项比较系数：

$$B = 5 \qquad B + C = 3$$

由第二个关系可得 $C = -2$。因此分解化简为：

$$\frac{5x^2 + 3x - 2}{(x + 1)(x^2 + 2x + 3)} = \frac{5x - 2}{x^2 + 2x + 3}$$

积分明显简化：

$$\int \frac{5x - 2}{x^2 + 2x + 3} \ dx$$

此时的标准策略是将分子与分母的导数联系起来。由于：

$$\frac{d}{dx}(x^2 + 2x + 3) = 2x + 2$$

把分子重写为这个导数的倍数与一个常数之和：

$$5x - 2 = \frac{5}{2}(2x + 2) - 7$$

相应地，积分拆分为：

$$\frac{5}{2} \int \frac{2x + 2}{x^2 + 2x + 3} \ dx - 7 \int \frac{1}{x^2 + 2x + 3} \ dx$$

- - -

对于第一部分，分子正好是分母的导数，因此产生对数：

$$\frac{5}{2} \ln|x^2 + 2x + 3|$$

由于这个二次式的判别式为负，它始终为正，所以[绝对值](../absolute-value/)并非严格必要，不过保留它也没有问题。

- - -

对于第二部分，配方得到 $x^2 + 2x + 3 = (x + 1)^2 + 2$，因此积分变为：

$$-7 \int \frac{1}{(x + 1)^2 + 2} \ dx$$

作换元 $u = x + 1$，并令 $a^2 = 2$：

$$-\frac{7}{\sqrt{2}} \arctan\!\left(\frac{x + 1}{\sqrt{2}}\right)$$

合并所有部分，一个反导数为：

$$\frac{5}{2} \ln(x^2 + 2x + 3) - \frac{7}{\sqrt{2}} \arctan\!\left(\frac{x + 1}{\sqrt{2}}\right) + c$$

> 因子 $x + 1$ 起初似乎需要在分解中单独占一项。计算系数后，这一贡献却完全消失了。因此必须始终写出完整的分解：最初看似必不可少的项，最终可能会相互抵消。

## 决策流程

下面的分步流程总结了一般有理函数的积分方法。

+ 当 $\deg N(x) \geq \deg D(x)$ 时，进行多项式长除法，写成 $N(x) = Q(x) D(x) + R(x)$ 且 $\deg R(x) < \deg D(x)$，将积分拆分为 $\int Q(x) \ dx + \int R(x)/D(x) \ dx$，然后从真分式部分重新开始。
+ 当 $D(x)$ 是单个一次因子 $ax + b$ 时，作换元 $t = ax + b$。结果是对数 $\tfrac{c}{a}\ln|ax + b| + k$。
+ 当 $D(x)$ 分解为互异的一次因子时，为每个因子写出一项 $A_i/(x - r_i)$ 的部分分式分解，通过在根处求值或比较系数确定各系数，然后逐项积分：每一项都会产生对数。
+ 当 $D(x)$ 含有重复一次因子 $(x - r)^k$ 时，从 $A_1/(x - r)$ 到 $A_k/(x - r)^k$ 为每个幂次各写一项，并逐项积分：一次幂产生对数，更高次幂产生有理项。
+ 当 $D(x)$ 含有不可约二次因子 $ax^2 + bx + c$，且 $b^2 - 4ac < 0$ 时，在分解中加入 $(Ax + B)/(ax^2 + bx + c)$。把分子拆成分母导数的倍数与一个常数，再分别积分：导数部分产生对数，常数部分通过配方化简并产生反正切。
+ 当有理结构中同时出现多项式与指数函数的乘积，或多项式与三角函数的乘积时，通常的替代方法是[分部积分](../integration-by-parts/)。对于关于 $\sin x$ 和 $\cos x$ 的有理被积函数，[魏尔斯特拉斯换元](../weierstrass-substitution/)是自然的工具。
