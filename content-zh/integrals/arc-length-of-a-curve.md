## 从直线段到曲线弧

直线段的长度概念很直接，因为平面上的两个点确定唯一一条直线，而欧氏距离提供了明确的测量方式。当两点之间的路径不是直线，而是沿着函数图像延伸时，沿曲线放置一根实体细线并测量其长度的直观想法，就必须转化为精确的解析定义。实现这一目标的构造正是[定积分](../definite-integrals/)所依据的构造：用长度已知的简单对象近似曲线，再通过极限过程逐步细化这个近似。

考虑函数 $f(x)$，它定义在闭区间 $[a, b]$ 上，并且在该区间上[连续可导](../continuous-functions/)。图像上横坐标从 $a$ 到 $b$ 的那段弧是一条平面曲线，问题是如何为它赋予一个量化长度的实数。具体构造是在曲线内接一条折线，计算这条折线的长度，然后不断添加顶点，使顶点间距趋于零，从而细化近似。

## 折线近似与微分元

**定义 1。** 设 $P = \\{\ x_0, x_1, \dots, x_n \ \\}$ 是区间 $[a, b]$ 的一个[划分](../riemann-integrability-criteria/)，满足：

$$a = x_0 < x_1 < \cdots < x_n = b$$

将点 $(x_k, f(x_k))$ 与每个分割点对应；用直线段连接相邻点，就得到内接于曲线的折线，而折线总长是相邻顶点之间欧氏距离的总和。第 $k$ 段的长度为：

$$\ell_k = \sqrt{(x_k - x_{k-1})^2 + (f(x_k) - f(x_{k-1}))^2}$$

![图 1](/assets/integrals/svg/arc-length-of-a-curve-1.zh.svg)

由于 $f$ 在 $[x_{k-1}, x_k]$ 上可导，[中值定理](../lagrange-theorem/)保证存在开区间 $(x_{k-1}, x_k)$ 内的一点 $\xi_k$，使得：

$$f(x_k) - f(x_{k-1}) = f'(\xi_k)(x_k - x_{k-1})$$

将这个恒等式代入 $\ell_k$ 的表达式，并在根式下提出 $(x_k - x_{k-1})^2$，得到：

$$\ell_k = \sqrt{1 + [f'(\xi_k)]^2} \ (x_k - x_{k-1})$$

因此，内接折线的总长度等于函数 $\sqrt{1 + [f'(x)]^2}$ 关于划分 $P$ 的一个黎曼和。当划分的网格趋于零时，只要被积函数[黎曼可积](../riemann-integrability-criteria/)，这个黎曼和就收敛到一个定积分。

## 直角坐标形式的弧长

上面的构造导出了平面直角坐标中函数图像曲线的基本定义。设函数 $f$ 在闭[区间](../intervals/) $[a, b]$ 上具有连续的[导数](../derivatives/)。$f$ 的图像从 $x = a$ 到 $x = b$ 的弧长定义为：

$$L = \int_a^b \sqrt{1 + [f'(x)]^2} \ dx \tag{1}$$

假设 $f'$ 在 $[a, b]$ 上连续是必要的，因为它保证被积函数连续，从而保证黎曼可积。导数仅有界但不连续的函数，仍可能具有定义良好的弧长；但上面的初等证明不再适用，讨论需要更一般的可求长曲线框架。

> 表达式 $\sqrt{1 + [f'(x)]^2} \ dx$ 称为弧长微分元，通常记作 $ds$。它表示自变量发生无穷小增量 $dx$ 时曲线对应的无穷小长度，并满足恒等式 $ds^2 = dx^2 + dy^2$；这正是将勾股定理应用于两条直角边为 $dx$ 和 $dy = f'(x) \ dx$ 的无穷小三角形。

## 例 1

计算函数 $f(x) = x^2$ 在区间 $[0, 1]$ 上所描述的抛物线弧长。函数的导数为：

$$f'(x) = 2x$$

代入公式 $(1)$，弧长表示为：

$$L = \int_0^1 \sqrt{1 + 4x^2} \ dx$$

被积函数具有 $\sqrt{1 + (2x)^2}$ 的结构，因此适合使用双曲换元 $2x = \sinh t$。微分变换如下：

$$2 \ dx = \cosh t \ dt$$

于是 $dx = \tfrac{1}{2}\cosh t \ dt$。利用双曲恒等式 $1 + \sinh^2 t = \cosh^2 t$，根式化简为 $\cosh t$。因此积分变为：

$$L = \int_0^{\operatorname{arsinh} 2} \cosh t \cdot \frac{1}{2}\cosh t \ dt = \frac{1}{2}\int_0^{\operatorname{arsinh} 2} \cosh^2 t \ dt$$

应用标准恒等式 $\cosh^2 t = \tfrac{1}{2}(1 + \cosh 2t)$，可得反导数：

$$\int \cosh^2 t \ dt = \frac{1}{2}t + \frac{1}{4}\sinh 2t + c$$

代入上下限，并使用 $\sinh 2t = 2\sinh t \cosh t$，以及 $\sinh(\operatorname{arsinh} 2) = 2$ 和 $\cosh(\operatorname{arsinh} 2) = \sqrt{5}$，得到闭式结果：

$$L = \frac{1}{4}\operatorname{arsinh} 2 + \frac{\sqrt{5}}{2}$$

因此，原点与点 $(1, 1)$ 之间的抛物线弧长等于 $\tfrac{\sqrt{5}}{2} + \tfrac{1}{4}\ln(2 + \sqrt{5})$，因为反双曲正弦可以用[对数](../logarithms/)表示为 $\operatorname{arsinh} u = \ln(u + \sqrt{1 + u^2})$。

> 上面的积分也可以通过形如 $2x = \tan \theta$ 的[三角换元](../trigonometric-substitution-for-integrals/)处理；这种换元会把根式化为 $\sec \theta$，并产生等价的闭式表达式。

## 参数形式的弧长

几何和物理中出现的许多曲线，包括圆、椭圆、摆线和螺线，都不能写成单值函数的图像。对于这类曲线，需要引入一个称为参数的辅助变量，并将运动点的两个坐标描述为参数的函数。随着参数在一个实区间内变化，该点描出整条曲线；当参数恰好等于横坐标时，就恢复直角坐标描述这一特殊情形。

考虑由下式参数化的平面曲线：

$$\begin{cases} x = x(t) \\[6pt] y = y(t) \end{cases} \quad t \in [\alpha, \beta]$$

其中 $x(t)$ 和 $y(t)$ 是区间 $[\alpha, \beta]$ 上的连续可导函数。对参数区间作划分，并重复折线近似的构造；与相邻参数值 $t_{k-1}$ 和 $t_k$ 对应的两点之间的弦长为：

$$\ell_k = \sqrt{[x(t_k) - x(t_{k-1})]^2 + [y(t_k) - y(t_{k-1})]^2}$$

分别对 $x$ 和 $y$ 应用中值定理，并令划分的网格趋于零，就得到参数形式的弧长公式：

$$L = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2} \ dt \tag{2}$$

根式下的表达式是参数化所对应速度向量的模的平方，这一观察提示了公式的运动学解释。如果把参数 $t$ 理解为时间，那么 $\sqrt{[x'(t)]^2 + [y'(t)]^2}$ 就是沿曲线运动的点的瞬时速率，对它在整个时间区间上积分，就得到运动经过的距离。

> 一条曲线通常有许多不同的参数化，但只要参数化是正则且单射，弧长只取决于曲线的几何图像以及遍历曲线的区间。这种在重新参数化下保持不变的性质十分基本，反映了长度的内在几何性质。

## 两种形式之间的关系

直角坐标公式是参数公式的特殊情形。取参数 $t = x$，参数化就变为：

$$\begin{cases} x(t) = t \\[6pt] y(t) = f(t) \end{cases}$$

于是 $x'(t) = 1$ 且 $y'(t) = f'(t)$。将这些表达式代入公式 $(2)$，立即得到公式 $(1)$。因此，参数表示严格地更一般；当曲线具有竖直切线或自交时，直角坐标形式会失效，而参数表示仍然适用。

## 例 2

利用参数表示，计算以原点为中心、半径为 $r$ 的圆的[周长](../circumference/)：

$$\begin{cases} x(t) = r\cos t \\[6pt] y(t) = r\sin t \end{cases} \quad t \in [0, 2\pi]$$

参数函数的导数为：

$$x'(t) = -r\sin t \qquad y'(t) = r\cos t$$

将它们代入参数弧长公式，并利用基本三角恒等式 $\sin^2 t + \cos^2 t = 1$，被积函数大幅简化：

$$\sqrt{[x'(t)]^2 + [y'(t)]^2} = \sqrt{r^2\sin^2 t + r^2\cos^2 t} = r$$

因此，积分变成在区间 $[0, 2\pi]$ 上计算常值函数，结果立即得到：

$$L = \int_0^{2\pi} r \ dt = 2\pi r$$

> 参数公式重新得到圆周长的表达式；这一致性是检验上述构造是否协调的有用方式。

## 例 3

考虑一个半径为 $r$ 的圆沿直线无滑动滚动时，其圆周上一点生成的摆线。摆线一个完整拱弧的标准参数化为：

$$\begin{cases} x(t) = r(t - \sin t) \\[6pt] y(t) = r(1 - \cos t) \end{cases} \quad t \in [0, 2\pi]$$

参数分量的导数为：

$$x'(t) = r(1 - \cos t) \qquad y'(t) = r\sin t$$

将这两个分量的平方相加，并使用[恒等式](../trigonometric-identities/) $1 - \cos t = 2\sin^2(t/2)$ 和 $\sin t = 2\sin(t/2)\cos(t/2)$，被积函数会化为更简单的表达式。直接计算得到：

$$
\begin{align}
[x'(t)]^2 + [y'(t)]^2 &= r^2(1 - \cos t)^2 + r^2\sin^2 t \\[6pt]
                      &= 2r^2(1 - \cos t)
\end{align}
$$

再次应用半角恒等式，表达式变为 $4r^2\sin^2(t/2)$，开平方得到 $2r |\sin(t/2)|$。由于在积分区间上 $t/2 \in [0, \pi]$，正弦非负，可以去掉绝对值。因此，弧长积分化为：

$$L = \int_0^{2\pi} 2r\sin(t/2) \ dt$$

$\sin(t/2)$ 的反导数是 $-2\cos(t/2)$，代入上下限可得：

$$
\begin{align}
L &= 2r\bigl[-2\cos(t/2)\bigr]_0^{2\pi} \\[6pt]
  &= 2r(-2\cos\pi + 2\cos 0) \\[6pt]
  &= 2r(2 + 2) \\[6pt]
  &= 8r
\end{align}
$$

因此，摆线一个完整拱弧的长度等于滚动圆半径的八倍。这个结果由克里斯托弗·雷恩于 1658 年证明，值得注意的原因有两个：长度是半径的整数倍，而一条超越曲线在这里产生了一个完全代数的值。

## 条件与局限

上面得到的公式建立在相关导数存在且在整个积分区间上连续的假设之上。当这种正则性在孤立点处失效时，积分通常可以解释为[反常积分](../improper-integrals/)，而弧长仍可能是有限的。另一方面，也存在长度无限的连续曲线；经典例子来自分形几何，其中最熟悉的是科赫雪花。对于这类曲线，初等公式失去意义，讨论要回到可求长曲线的一般理论；在该理论中，弧长直接定义为所有内接折线长度的[上确界](../supremum-and-infimum/)。

> 当这个上确界有限时，称曲线是可求长的。闭有界区间上的连续可导曲线都是可求长的，对它们而言，上确界会退化为积分公式计算出的值。可求长曲线的类严格大于 $C^1$ 类曲线，并为长度概念最一般的表述提供了恰当框架。当无法闭式求出弧长积分时，仍然可以通过[数值积分](../numerical-integration/)近似其值。
