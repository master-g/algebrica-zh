## 引言

微分方程是这样一种[方程](../equations/)，其未知量是一个[函数](../functions/)，并且其中出现了该函数的一个或多个[导数](../derivatives/)。相比之下，代数方程的未知量是数。对于单变量函数 $y = y(x)$，$n$ 阶微分方程具有如下隐式形式：

$$F\left(x, y, y', y'', \ldots, y^{(n)}\right) = 0$$

$F$ 对 $y^{(n)}$ 的依赖意味着方程中出现了 $n$ 阶导数。在一个[区间](../intervals/) $I$ 上，解是函数 $y:I \to \mathbb{R}$，它具有方程所要求的全部导数，并且在 $I$ 的每一点都满足方程。[定义域](../determining-the-domain-of-a-function/)也是解的一部分，因为方程和所需导数必须在整个 $I$ 上有定义。例如，$\ln|x| + C$ 在不包含 $0$ 的区间上是 $y' = 1/x$ 的解，但在包含 $0$ 的区间上不是解。

一个一阶例子是：

$$y' + y = 0$$

对于每个[实数](../real-numbers/) $C$，函数 $y(x) = Ce^{-x}$ 的导数为 $y'(x) = -Ce^{-x}$。代入可得：

$$y'(x) + y(x) = -Ce^{-x} + Ce^{-x} = 0$$

反过来，如果 $y$ 是任意一个解，根据乘积法则有 $\left(e^xy\right)' = e^x(y' + y) = 0$。因此 $e^xy = C$，且 $y = Ce^{-x}$。所以，取 $C \in \mathbb{R}$ 的函数 $y(x) = Ce^{-x}$ 构成 $\mathbb{R}$ 上的通解。这个解族中的某一个成员称为特解；初值条件可以选出其中一个成员。

写成等价形式 $y' = -y$ 时，方程表示某个量以与当前量成正比的速率减少。条件 $y(0) = y_0 > 0$ 给出特解 $y(x) = y_0e^{-x}$，其值每经过长度为 $\ln(2)$ 的区间就减半。放射性衰变和电容放电模型都具有 $y' = -ky$ 的形式，其中 $k > 0$ 决定时间尺度，半衰期为 $\ln(2)/k$。

## 常微分方程与偏微分方程

[常微分方程](../ordinary-differential-equations/)只有一个自变量，所有导数都相对于这个变量。若 $y$ 依赖于 $x$，下面的方程就是常微分方程，因为 $x$ 是它唯一的自变量：

$$y'' + x^2y' - y = \sin(x)$$

[偏微分方程](../partial-differential-equations/)的未知函数有两个或更多自变量，并且至少包含一个[偏导数](../partial-derivatives/)。若 $u = u(x,t)$ 表示位置 $x$ 和时间 $t$ 处的温度，则一维热方程为：

$$\frac{\partial u}{\partial t} = k\frac{\partial^2u}{\partial x^2} \qquad k > 0$$

相对于 $t$ 的导数表示时间变化率，而相对于 $x$ 的二阶导数衡量空间曲率。

## 按阶分类

方程的阶数就是其最高阶导数的阶数。因此，如果出现了 $y^{(n)}$ 而不存在更高阶导数，那么方程就是 $n$ 阶方程。线性性是另一种独立的分类方式。

+ $y' = x-y$ 是一阶方程。
+ $y'' + 4y = 0$ 是二阶方程。
+ $y''' + yy' = e^x$ 是三阶方程。

对于标准形式的标量方程，阶数也是标准初值数据中数值的个数。在存在性与唯一性定理的假设成立时，一阶方程的初值问题指定一个值，而二阶方程的初值问题指定两个值。

二阶方程 $y'' + 4y = 0$ 的通解由[正弦和余弦](../sine-and-cosine/)表示为：

$$y(x) = A\cos(2x) + B\sin(2x)$$

$y(x_0)$ 和 $y'(x_0)$ 的值会确定这两个常数。

## 一阶微分方程

在[一阶微分方程](../first-order-differential-equations/)中会出现 $y'$，但不会出现[高阶导数](../higher-order-derivatives/)。其隐式形式为：

$$F(x,y,y') = 0$$

如果能够解出 $y'$，其标准形式为：

$$y' = f(x,y)$$

在一阶方程中，如果可以写成 $y' = g(x)h(y)$，则称其为[可分离方程](../separable-differential-equations/)；如果形式为 $y' + p(x)y = q(x)$，则称其为线性方程。有些一阶方程同时具有可分离性和线性。下面是一个可分离方程：

$$y' = 2xy$$

设在某个区间上 $y \neq 0$。两边除以 $y$，即可分离两个变量：

$$\frac{1}{y}\frac{dy}{dx} = 2x$$

对两边积分得到：

$$\ln|y| = x^2 + C_1$$

[对数](../logarithms/)中的[绝对值](../absolute-value/)是必要的，因为 $1/y$ 在 $y > 0$ 和 $y < 0$ 上都有反导数。两边取指数得到解族：

$$y(x) = Ce^{x^2}$$

除以 $y$ 时排除了零解，因此要在解族中补上 $C = 0$。[链式法则](../chain-rule/)可以验证该公式：

$$y'(x) = 2xCe^{x^2} = 2xy(x)$$

这个方程也是线性的，因为它可以写成 $y' - 2xy = 0$，其中系数 $-2x$ 只依赖于自变量。阶数和线性性彼此独立。一阶方程可以是线性的，也可以是非线性的；线性方程则可以出现在任意阶数。

## 线性与非线性微分方程

在[线性微分方程](../linear-differential-equations/)中，未知函数及其导数构成线性组合。对于 $n$ 阶方程，这个组合为：

$$a_n(x)y^{(n)} + a_{n-1}(x)y^{(n-1)} + \cdots + a_1(x)y' + a_0(x)y = g(x)$$

最高阶系数 $a_n(x)$ 在整个区间上都不为零，每个系数都只是自变量 $x$ 的函数。未知函数及其导数的幂为一，彼此之间也不相乘，且没有一个是非线性函数的自变量。当整个区间上 $g(x) = 0$ 时，方程称为齐次方程；否则称为非齐次方程。

将左端记为 $L[y]$。如果 $y_1$ 和 $y_2$ 是齐次方程的解，且 $c_1,c_2$ 是常数，那么线性性给出：

$$L[c_1y_1 + c_2y_2] = c_1L[y_1] + c_2L[y_2] = 0$$

因此，齐次解构成一个[向量空间](../vector-spaces/)。当系数连续且 $a_n$ 在区间上没有零点时，这个向量空间的维数为 $n$。于是，$n$ 个线性无关的解通过[线性组合](../linear-combinations/)给出所有解。上面出现的 $A\cos(2x) + B\sin(2x)$ 就是 $y'' + 4y = 0$ 的通解。

非齐次方程的两个解之差是相应齐次方程的解，因为相减两个方程会消去右端的 $g(x)$。因此，每个解都可以写成 $y = y_p + y_h$，其中 $y_p$ 是非齐次方程的一个固定解，$y_h$ 是任意齐次解。这些性质来自线性性，对非线性方程一般不成立。

当 $n = 1$ 时，除以最高阶系数可得：

$$y' + p(x)y = q(x)$$

下面的方程是一阶线性方程：

$$y' + 2y = e^x$$

积分因子 $\mu(x)$ 必须满足 $\mu' = 2\mu$，因此取 $\mu(x) = e^{2x}$。两边乘以 $e^{2x}$ 后，根据[乘积法则](../differentiation-rules/)，左端就是一个乘积的导数：

$$e^{2x}y' + 2e^{2x}y = e^{3x}$$

因此方程等价于：

$$\left(e^{2x}y\right)' = e^{3x}$$

积分并除以 $e^{2x}$，得到：

$$
\begin{align}
e^{2x}y &= \frac{1}{3}e^{3x} + C \\[6pt]
y &= \frac{1}{3}e^x + Ce^{-2x}
\end{align}
$$

其中 $\frac{1}{3}e^x$ 是一个特解，而 $Ce^{-2x}$ 是相应齐次方程的通解。

更一般的方法见[一阶线性微分方程](../first-order-linear-differential-equations/)条目。

在[非线性微分方程](../nonlinear-differential-equations/)中，未知函数或其至少一个导数会出现在非线性项中。下面这些例子的非线性来源各不相同：

+ 在 $yy' = x$ 中，未知函数与其导数相乘。
+ 在 $(y')^2 + y = 0$ 中，导数被平方。
+ 在 $y'' + \sin(y) = 0$ 中，正弦函数作用于未知函数。

例如，$y' = x+y^2$ 是一阶非线性方程，而 $y'' + 4y = 0$ 是二阶线性方程。

## 自治方程与方程组

在自治常微分方程中，自变量不会显式出现。一阶自治方程的形式为 $y' = f(y)$。人口 $P(t)$ 的 Logistic 方程就是自治方程：

$$P' = rP\left(1-\frac{P}{K}\right) \qquad r,K > 0$$

变化率只取决于当前人口，而时间不会显式出现。该方程是一阶的、自治的、可分离的，也是非线性的。常值函数 $P(t) = 0$ 和 $P(t) = K$ 是它的平衡解。

如果 $0 < P(0) < K$，解是递增的，并且具有[Sigmoid 函数](../sigmoid-function/)的形状。

[微分方程组](../systems-of-differential-equations/)是关于多个未知函数及其导数的一组方程。两个相互作用种群的模型为：

$$
\begin{align}
x' &= ax-bxy \\[6pt]
y' &= -cy+dxy
\end{align}
$$

这里 $x$ 和 $y$ 是时间的未知函数，$a,b,c,d$ 是正的常数。乘积 $xy$ 使这个方程组成为非线性系统。令 $z_1 = y$、$z_2 = y'$、$\ldots$、$z_n = y^{(n-1)}$，就能把一个标准形式的 $n$ 阶方程转换为关于 $z_1,\ldots,z_n$ 的一阶方程组。

## 初值条件与边界条件

微分问题由方程和关于其解的条件组成。[初值问题](../initial-value-problems/)在自变量的同一个点给出所有规定值。下面的问题在 $x = 0$ 处给出一个条件：

$$y' = 2y \qquad y(0) = 3$$

这个微分方程的解族为 $y(x) = Ce^{2x}$。条件 $y(0) = 3$ 给出 $C = 3$，因此解为：

$$y(x) = 3e^{2x}$$

对于标准形式的 $n$ 阶标量方程，初值数据是在某一点给出 $y,y',\ldots,y^{(n-1)}$ 的值。

[边值问题](../boundary-value-problems/)在不同的点给出条件，通常是在区间端点给出。下面的问题在两个点处给出条件：

$$y'' + y = 0 \qquad y(0) = 0 \qquad y\left(\frac{\pi}{2}\right) = 1$$

该微分方程的一般解为 $y(x) = A\cos(x) + B\sin(x)$。第一个边界条件给出 $A = 0$，第二个随即给出 $B = 1$。因此解为：

$$y(x) = \sin(x)$$

仅有条件并不能保证解唯一。方程 $y'' + y = 0$ 在 $[0,\pi]$ 上若满足 $y(0) = 0$ 和 $y(\pi) = 1$，则无解，因为每个函数 $B\sin(x)$ 都在两个端点处为零。如果条件为 $y(0) = y(\pi) = 0$，那么每个函数 $B\sin(x)$ 都是解。因此，边值问题可能无解、有一个解或有多个解。

存在性定理给出至少存在一个解的充分条件，而唯一性定理给出这样的充分条件：具有相同数据的两个解必须相等。[连续性](../continuous-functions/)本身并不能保证唯一性。例如，问题 $y' = 3\sqrt[3]{y^2}$、$y(0) = 0$ 同时有 $y(x) = 0$ 和 $y(x) = x^3$ 两个解。对于 $y(x) = x^3$，方程两边都是 $3x^2$；而对于 $y(x) = 0$，方程两边都为零。

对于线性方程，设其系数和右端项在区间 $I$ 上连续，且最高阶系数在那里没有零点。那么，在 $I$ 中一点上提出的初值问题在整个区间 $I$ 上恰有一个解。对于非线性方程 $y' = f(x,y)$，如果 $f$ 连续，并且关于 $y$ 在初始点附近局部满足 Lipschitz 连续性，则存在唯一的局部解。问题 $y' = e^y$、$y(0) = 0$ 的解为 $y(x) = -\ln(1-x)$，最大区间是 $(-\infty,1)$。右端项对每个实数 $y$ 都有定义，但当 $x$ 从左侧趋近 $1$ 时，解无界。因此，局部解未必能延拓到 $f$ 的整个定义域。

## 显式、隐式与数值描述

显式解会把因变量单独写出，例如 $y(x) = Ce^{-x}$。隐式解是变量之间的一个关系。下面的关系定义了 $yy' = x$ 的一个隐式解族：

$$y^2-x^2 = C$$

对 $x$ 求导得到 $2yy'-2x = 0$，这与微分方程等价。在 $y = 0$ 的点之外，解出 $y$ 可得显式分支 $y = \pm\sqrt{x^2+C}$。每个符号都在 $x^2+C > 0$ 的区间上给出一个解。

初值问题的解未必能用初等函数表示。例如，问题 $y' = e^{-x^2}$、$y(0) = 0$ 的解为 $y(x) = \int_0^x e^{-t^2} \ dt$，这不是初等函数。当不存在初等公式时，人们会研究解的存在性和唯一性、解的性质或数值近似。对于初值问题 $y' = f(x,y)$、$y(x_0) = y_0$，步长为 $h$ 的[欧拉法](../euler-method/)使用如下递推式：

$$x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + hf(x_n,y_n)$$

数值 $y_n$ 近似于解在点 $x_n$ 处的值。无需闭式公式，定性分析也可以确定单调性和稳定性等性质。在最高阶系数非零的点上，系数为解析函数的线性方程具有局部解，这些解可以用[幂级数](../power-series/)表示。
