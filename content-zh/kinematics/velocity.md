## 运动学与位置函数

运动学用位置、速度和[加速度](../acceleration/)关于时间的函数描述物体的运动，而不研究产生运动的力。这里有三个基本概念。

+ 质点是理想化的物体，与运动过程中经过的距离相比，它的尺寸可以忽略不计。
+ 轨迹是质点在空间中运动时描出的曲线。
+ 当轨迹位于一条直线上时，这种运动称为直线运动。

在直线轨迹上，一个坐标就能确定物体的位置。在直线上确定原点和正方向后，时刻 $t$ 的位置是实数 $s(t)$，[函数](../functions/) $s$ 就完整描述了这一运动。速度的单位是长度除以时间，国际单位制单位为米每秒 $(\mathrm{m/s})$，也写作 $\mathrm{m\ s^{-1}}$。

> $s$ 的图像画在时间–位置平面中，横轴表示时间，纵轴表示位置。这个图像不是运动轨迹。竖直向上抛出的物体沿一条线段运动，而它的位置图像是一条抛物线。

## 直线上的位置与位移

质点 $P$ 沿直线运动。它在时刻 $t_1$ 的位置是坐标 $s_1 = s(t_1)$，在稍后的时刻 $t_2$ 的位置是 $s_2 = s(t_2)$。这段时间内的位移是两个坐标之差，经过的时间是两个时刻之差：

$$\Delta s = s_2 - s_1 \qquad \Delta t = t_2 - t_1$$

![图 1](/assets/kinematics/svg/velocity-1.svg)

位移带有符号。当质点沿直线正方向运动时位移为正，沿相反方向运动时为负；无论质点在两个时刻之间走过怎样的路径，只要两个坐标重合，位移就是零。两个量的比值衡量坐标变化的快慢：

$$\frac{\Delta s}{\Delta t} = \frac{s_2 - s_1}{t_2 - t_1}$$

当质点在相等的时间间隔内发生相等的位移时，对 $t_1$ 和 $t_2$ 的每一种选择，这个比值都具有相同的值 $v$，而 $v$ 是沿取向直线的速度有符号标量分量。在其他情况下，比值依赖于所取的区间，因此它描述的是整个区间，而非某一个时刻。固定时刻 $t$，考虑持续时间 $\Delta t$ 趋于零的区间。如果相应的比值有有限极限，该极限就是瞬时标量速度：

$$v(t) = \lim_{\Delta t \to 0} \frac{\Delta s}{\Delta t} = \lim_{\Delta t \to 0} \frac{s(t + \Delta t) - s(t)}{\Delta t}$$

[差商](../difference-quotient/)的[极限](../limits/)按定义就是 $s$ 关于时间的[导数](../derivatives/)。因此，仅当 $s$ 在 $t$ 处可导时，$v(t)$ 才存在；在这样的时刻，$s$ 也[连续](../continuous-functions/)。平均速度属于一个有限区间，而瞬时速度属于一个单独的时刻。

## 平均速度

在有限区间上取比值 $\Delta s/\Delta t$，就得到运动的平均速度，即位移除以经过的时间：

$$v_{\mathrm{avg}} = \frac{\Delta s}{\Delta t}$$

一列火车在 9:00 发车、11:30 到达，行驶了两个车站之间的 $216\ \mathrm{km}$。经过的时间是 $2.5\ \mathrm{h}$，因此平均速度为：

$$v_{\mathrm{avg}} = \frac{216\ \mathrm{km}}{2.5\ \mathrm{h}} = 86.4\ \mathrm{km/h}$$

这个数值是整个旅程的平均值。火车在车站停留，在开放线路上运行时的速度高于 $86.4\ \mathrm{km/h}$，所以平均速度不能确定它在任何单一时刻的速度。

- - -

如果 $s(t)$ 是时刻 $t$ 的位置，那么在 $t_1$ 和 $t_2$（其中 $t_1 < t_2$）之间的平均速度为：

$$v_{\mathrm{avg}} = \frac{s(t_2) - s(t_1)}{t_2 - t_1}$$

右侧是 $s$ 在 $[t_1, t_2]$ 上的[差商](../difference-quotient/)，因此平均速度就是位置图像上两点 $(t_1, s(t_1))$ 和 $(t_2, s(t_2))$ 所确定割线的斜率。

![图 2](/assets/kinematics/svg/velocity-2.svg)

分子是位移，而不是路程。当物体回到出发位置时，分子为零；因此在物体确实运动过的某个区间上，平均速度仍可能为零。

## 抛物线图像上的平均速度

一个物体以初速度 $40\ \mathrm{m/s}$ 竖直向上离开地面。忽略空气阻力，取重力加速度为 $10\ \mathrm{m/s^2}$，则它相对于发射点的高度为：

$$s(t) = -5t^2 + 40t \qquad 0 \leq t \leq 8$$

这里 $s$ 以米为单位，$t$ 以秒为单位。物体在 $t = 4$ 时达到 $80\ \mathrm{m}$ 的最大高度，在 $t = 8$ 时回到发射点。从 $t = 1$ 开始的三个区间给出三种不同的平均速度；此时高度为 $s(1) = 35\ \mathrm{m}$。

在区间 $[1, 3]$ 上，$s(3) = 75\ \mathrm{m}$，平均速度为：

$$v_{\mathrm{avg}} = \frac{s(3) - s(1)}{3 - 1} = \frac{75 - 35}{2} = 20\ \mathrm{m/s}$$

在区间 $[1, 5]$ 上，$s(5) = 75\ \mathrm{m}$，平均速度为：

$$v_{\mathrm{avg}} = \frac{s(5) - s(1)}{5 - 1} = \frac{75 - 35}{4} = 10\ \mathrm{m/s}$$

在区间 $[1, 7]$ 上，$s(7) = 35\ \mathrm{m}$，平均速度为：

$$v_{\mathrm{avg}} = \frac{s(7) - s(1)}{7 - 1} = \frac{35 - 35}{6} = 0\ \mathrm{m/s}$$

前两个区间的位移都是 $40\ \mathrm{m}$，因为物体在 $t = 3$ 和 $t = 5$ 时处于相同高度。第二个区间持续时间是第一个的两倍，因此它的平均速度是第一个的一半。

第三个区间关于达到最大高度的时刻对称。物体上升 $45\ \mathrm{m}$ 后又下降 $45\ \mathrm{m}$，走过的路程为 $90\ \mathrm{m}$，但位移为零；因此尽管物体在区间内每个时刻都在运动，平均速度仍为零。

## 瞬时速度

平均速度不能说明物体在单一时刻运动得有多快。固定 $t_1$，令第二个时刻 $t$ 趋于 $t_1$。区间围绕 $t_1$ 收缩，相应的平均速度有一个[极限](../limits/)，这个极限定义了 $t_1$ 时刻的瞬时速度：

$$v(t_1) = \lim_{t \to t_1} \frac{s(t) - s(t_1)}{t - t_1}$$

极限符号下的每个比值都是经过固定点 $(t_1, s(t_1))$ 和图像上另一个点的割线斜率。当 $t \to t_1$ 时，第二个点沿曲线向第一个点滑动，割线绕固定点转动，直到变为切线。瞬时速度就是位置图像在 $t_1$ 处切线的斜率。

![图 3](/assets/kinematics/svg/velocity-3.svg)

对于这个上抛物体，可以在 $t_1 = 1$ 处计算该极限。从右侧逼近时，区间 $[1, t]$ 给出：

| 区间 | $v_{\mathrm{avg}}$（单位：$\mathrm{m/s}$） |
| --- | --- |
| $[1, 3]$ | $20$ |
| $[1, 2]$ | $25$ |
| $[1, 1.1]$ | $29.5$ |
| $[1, 1.01]$ | $29.95$ |

从左侧逼近时，区间 $[t, 1]$ 给出：

| 区间 | $v_{\mathrm{avg}}$（单位：$\mathrm{m/s}$） |
| --- | --- |
| $[0, 1]$ | $35$ |
| $[0.9, 1]$ | $30.5$ |
| $[0.99, 1]$ | $30.05$ |

两张表中的数值分别从下方和上方趋于 $30\ \mathrm{m/s}$。一次计算即可确认这一数值。取第二个时刻为 $1 + h$，其中 $h \neq 0$，差商为：

$$
\begin{align}
\frac{s(1+h) - s(1)}{h} &= \frac{-5(1+h)^2 + 40(1+h) - 35}{h} \\[6pt]
&= \frac{-5 - 10h - 5h^2 + 40 + 40h - 35}{h} \\[6pt]
&= \frac{30h - 5h^2}{h} \\[6pt]
&= 30 - 5h
\end{align}
$$

由于分子在 $h = 0$ 时为零，因子 $h$ 可以约去。所得表达式对负的 $h$ 同样成立，因此涵盖了表中记录的两种逼近方式。令 $h$ 趋于零，得到瞬时速度：

$$v(1) = \lim_{h \to 0} (30 - 5h) = 30\ \mathrm{m/s}$$

在任意时刻 $t$，同样的代数运算给出差商 $40 - 10t - 5h$，因此速度函数为：

$$v(t) = \lim_{h \to 0} (40 - 10t - 5h) = 40 - 10t$$

物体刚发射时的标量速度为 $40\ \mathrm{m/s}$；它在 $t = 4$ 达到最大高度时速度为零；返回途中速度为 $-40\ \mathrm{m/s}$，负号表示向下运动。速率是绝对值 $|v(t)|$，它非负且没有方向。因此当 $v(t) \geq 0$ 时速率等于 $v(t)$，当 $v(t) < 0$ 时速率等于 $-v(t)$。

- - -

因此，在导数存在的每个时间[区间](../intervals/)上，速度函数就是位置函数的导数：

$$v(t) = \frac{ds}{dt}$$

对于这个抛体，[求导法则](../differentiation-rules/)给出导数 $-10t + 40$，与上面通过极限得到的表达式相同。[加速度](../acceleration/)是 $v$ 的导数，因此它是位置的[二阶导数](../higher-order-derivatives/)。

## 速度向量

对于沿空间曲线运动的物体，时刻 $t$ 的位置是从固定原点指向物体所在点的[向量](../vectors/) $\mathbf{r}(t)$。在 $t$ 与 $t + \Delta t$ 之间，物体的位移为：

$$\Delta \mathbf{r} = \mathbf{r}(t + \Delta t) - \mathbf{r}(t)$$

比值 $\Delta\mathbf{r}/\Delta t$ 是平均速度向量，并且平行于连接两个位置的弦。它的极限定义了速度向量：

$$\mathbf{v}(t) = \lim_{\Delta t \to 0} \frac{\Delta \mathbf{r}}{\Delta t} = \frac{d\mathbf{r}}{dt}$$

![图 4](/assets/kinematics/svg/velocity-4.svg)

随着 $\Delta t$ 减小，弦逐渐与轨迹重合。当 $\mathbf{v}(t) \neq \mathbf{0}$ 时，该向量在时刻 $t$ 所在点处与轨迹相切，并指向运动方向。它的模就是速率。对于沿单位向量 $\mathbf{i}$ 做直线运动的物体，位置为 $\mathbf{r}(t) = s(t)\mathbf{i}$，上述定义化为：

$$\mathbf{v}(t) = \frac{ds(t)}{dt}\mathbf{i}$$

标量 $v(t) = \frac{ds(t)}{dt}$ 是 $\mathbf{v}(t)$ 沿取向直线的分量，且速率满足 $\|\mathbf{v}(t)\| = |v(t)|$。

## 匀速直线运动

匀速直线运动的轨迹是直线，速度保持不变，因此相等的位移对应相等的时间间隔。设速度的恒定值为 $v$，$t = 0$ 时的位置为 $s_0$。位置函数为：

$$s(t) = s_0 + vt$$

位置图像是斜率为 $v$ 的[直线](../lines/)。直线的每条割线都具有该直线本身的斜率，因此在每个区间上平均速度都等于瞬时速度；匀速直线运动是唯一具有这一性质的运动。

一辆汽车以 $v = 12\ \mathrm{m/s}$ 的速度沿直路行驶，初始位置为 $s_0 = 6\ \mathrm{m}$，其位置函数为 $s(t) = 6 + 12t$，对应的数值如下。

| $t$（单位：$\mathrm{s}$） | $s$（单位：$\mathrm{m}$） |
| --- | --- |
| $0$ | $6$ |
| $1$ | $18$ |
| $2$ | $30$ |
| $3$ | $42$ |
| $4$ | $54$ |

汽车每秒前进 $12\ \mathrm{m}$。在任意区间 $[t_1, t_2]$ 上，差商为：

$$\frac{s(t_2) - s(t_1)}{t_2 - t_1} = \frac{(6 + 12t_2) - (6 + 12t_1)}{t_2 - t_1} = \frac{12(t_2 - t_1)}{t_2 - t_1} = 12$$

这个结果与区间无关，因此当 $t_2 \to t_1$ 时极限仍为 $12$，速度函数是常数 $v(t) = 12\ \mathrm{m/s}$。
