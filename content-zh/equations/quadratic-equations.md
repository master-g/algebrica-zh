## 引言

二次方程是含有一个变量的二次[多项式方程](../polynomial-equations/)。其标准形式如下：

$$ax^2 + bx + c = 0$$

在该表达式中，$a$、$b$、$c$ 为实系数，$x$ 为未知数，且 $a \neq 0$。系数 $a$ 乘以二次项 $x^2$，系数 $b$ 乘以一次项 $x$，$c$ 为常数项。

+ 系数 $a$、$b$、$c$ 为常数，而 $x$ 为变量。
+ 当 $a = 0$ 时，方程退化为[线性方程](../linear-equations/) $bx + c = 0$。
+ 若 $a = 0$ 且 $b = 0$ 同时成立，则方程变为常数方程，其解要么不存在，要么有无穷多个，取决于 $c \neq 0$ 还是 $c = 0$。

将等号替换为关系 $<$、$>$、$\leq$ 或 $\geq$ 之一，方程即变为[二次不等式](../quadratic-inequalities/)，可通过研究同一二次表达式的符号来求解。

二次方程是[三项方程](../trinomial-equations/)的最简单情形，其一般形式为：

$$ax^{2n} + bx^{n} + c = 0$$

令 $n = 1$，便恢复到标准二次形式 $ax^2 + bx + c = 0$。当 $n \geq 2$ 时，方程可化为关于辅助变量 $y = x^n$ 的二次方程，并可用相同的方法求解。

## 几何解释

$y = ax^2 + bx + c$ 的图像，当 $a \neq 0$ 时，是由变量 $x$ 和 $y$ 所定义的平面中的一条[抛物线](../parabola/)。关于这种对应关系的更完整说明，见[二次方程的几何意义](../geometrical-meaning-quadratic-equations/)条目。

![图 1](/assets/equations/svg/quadratic-equations.zh.svg)

当系数 $a > 0$ 时，抛物线开口向上，函数在顶点处取得最小值。当 $a < 0$ 时，抛物线开口向下，函数在顶点处取得最大值。

方程 $ax^2 + bx + c = 0$ 的实数解对应于抛物线与 $x$ 轴相交的点。[判别式](../quadratic-formula/) $\Delta = b^2 - 4ac$ 的符号决定了这种情形：

+ 当 $\Delta > 0$ 时，抛物线在两个不同的点处穿过该轴。
+ 当 $\Delta = 0$ 时，抛物线与该轴相切。
+ 当 $\Delta < 0$ 时，抛物线不与该轴相交，方程没有实数解。

> 条件 $a \neq 0$ 保证了该方程描述的是抛物曲线，而非[线性方程](../linear-equations/)。

## 求解方法

当系数 $b$ 或系数 $c$ 等于零时，二次方程是[不完全的](../incomplete-quadratic-equations/)。在这种情况下，方程取较简单的形式，可以直接求解，无需应用一般公式。求解任何二次方程的第一步是将其改写为标准形式：

$$ax^2 + bx + c = 0$$

这种形式使我们能够识别各项系数，并计算[判别式](../quadratic-formula/) $\Delta = b^2 - 4ac$。判别式决定了解的性质：

+ 当 $\Delta > 0$ 时，有两个不同的实根。
+ 当 $\Delta = 0$ 时，有一个二重实根。
+ 当 $\Delta < 0$ 时，有一对共轭复根。

最一般的方法是[求根公式](../quadratic-formula/)。然而在某些情况下，[因式分解](../factoring-quadratic-equations/)或[配方法](../completing-the-square/)可以更直接地得到解。

[代数学基本定理](../roots-of-a-polynomial/)保证二次方程在 $\mathbb{C}$ 中恰有两个根（按重数计算）。当 $\Delta \geq 0$ 时，两个根都是实数；当 $\Delta < 0$ 时，两个根构成一对[共轭复数](../quadratic-equations-with-complex-solutions/)。

## 求根公式

给定标准形式 $ax^2 + bx + c = 0$ 的二次方程，[求根公式](../quadratic-formula/)将其根表示为：

$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

+ $a$、$b$、$c$ 为实系数，且 $a \neq 0$。
+ $\pm$ 符号给出两个解，分别对应正负号。
+ 二次方程在 $\mathbb{C}$ 中恰有两个根（按重数计算）。
+ 由 [韦达公式](../vieta-formulas/)，两根满足 $x_1 + x_2 = -b/a$ 与 $x_1x_2 = c/a$。

判别式还有如下性质：

$$\Delta = a^2(x_1 - x_2)^2$$

该等式直接表明：当两根为实数时 $\Delta \geq 0$；当且仅当两根相等时 $\Delta = 0$。

> 当判别式为负时，解为复数。关于 [复数解的二次方程](../quadratic-equations-with-complex-solutions/) 的专题条目对此情形有完整讨论。

## 因式分解

二次方程可以[因式分解](../factoring-quadratic-equations/) 为如下形式：

$$ax^2 + bx + c = 0 \quad \Longleftrightarrow \quad a(x - x_1)(x - x_2) = 0$$

在此等式中，$x_1$ 与 $x_2$ 是方程的两个根。由 [韦达公式](../vieta-formulas/)，两根满足如下关系：

$$x_1 + x_2 = -\frac{b}{a}$$

$$x_1x_2 = \frac{c}{a}$$

当线性因式可以通过观察或简单试探确定时，此方法十分有效。无理根并不妨碍直接分解，如恒等式 $x^2 - 2 = (x - \sqrt{2})(x + \sqrt{2})$ 所示。当因式不明显时，[求根公式](../quadratic-formula/)提供了一种系统的方法。若系数为实数且判别式为负，则该多项式不能分解为实线性因式之积。

## 如何求解二次方程

第一步是将方程改写为标准形式 $ax^2 + bx + c = 0$，把所有项移到同一边并化简系数。这一步决定了方程是否真正是二次方程，因为首项系数必须满足 $a \neq 0$。

在套用求根公式之前，应先检查各项系数。若 $b = c = 0$，则方程退化为 $ax^2 = 0$，并具有二重根 $x = 0$。若 $b = 0$，可将 $x^2$ 单独分离出来，通过对两边开平方来求解。若 $c = 0$，则提取 $x$ 作为公因式，将问题归结为零积性质。这些就是[不完全二次方程](../incomplete-quadratic-equations/)。

当三个项都存在时，公因式、完全平方式三项式或简单的因式分解都可能直接给出根。当二次式能够较为容易地化为一个二项式的平方时，[配方法](../completing-the-square/)十分有用。若看不出这样的结构，则计算判别式：

$$\Delta = b^2 - 4ac$$

$\Delta$ 的符号决定了根的性质。当 $\Delta > 0$ 时，方程有两个不同的实根；当 $\Delta = 0$ 时，有一个二重实根；当 $\Delta < 0$ 时，有一对共轭复根。代入求根公式即得根：

$$x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a}$$

所得的值应加以化简，并写成一个解集合。将它们代入原方程可以直接验证，尤其是当方程需要若干初步变换时。

## 含参二次方程

二次方程研究的一个自然延伸，是系数不再为固定数值，而是依赖于一个外部参数的情形。这类方程称为[含参二次方程](../quadratic-equations-with-parameters/)，或称文字系数二次方程，其形式为：

$$a(k)x^2 + b(k)x + c(k) = 0, \quad a(k) \neq 0$$

参数 $k$ 取值不同，方程随之改变，其解的性质也随之改变。分析的关键在于判别式：

$$\Delta(k) = b(k)^2 - 4a(k)c(k)$$

正如经典情形一样，它决定了方程究竟是有两个不同的实数解、一个重根，还是一对共轭复数解。

在使用判别式之前，必须先检验条件 $a(k) \neq 0$。使 $a(k) = 0$ 成立的参数值不属于二次情形，但原方程仍需另行分析。当 $b(k) \neq 0$ 时，它退化为线性方程。若同时 $b(k) = 0$，则当 $c(k) \neq 0$ 时方程无解，当 $c(k) = 0$ 时 $x$ 的任何值都是解。

## 示例

以下各方程展示了系数形式如何决定最简便的求解方法。当线性因式可直接识别时，我们使用[因式分解](../factoring-quadratic-equations/)；当没有明显的简单分解时，则使用[求根公式](../quadratic-formula/)。最后三个方程分别展示了不完全二次方程、重根以及配方法。

[class="table-1"]

|                                     |
| :---------------------------------- |
| $9x^2 + 7x - 2 = 0$                 |
| $p^2x^2 + (p^2 - q^2)x - q^2 = 0$   |
| $x^2 + x + 2 = 0$                   |
| $\sqrt{7}x^2 - 6x - 13\sqrt{7} = 0$ |
| $z^2 - 32z - 105 = 0$               |
| $\sqrt{2}x^2 - 3x - 2\sqrt{2} = 0$  |
| $n^2 + 7n + 15 = 5$                 |
| $3x^2 - 12 = 0$                      |
| $4x^2 - 12x + 9 = 0$                 |
| $x^2 + 6x + 1 = 0$                   |
[/class]

我们首先求解第一个方程。常数项的乘积必须为 $-2$，而因式 $(9x - 2)$ 与 $(x + 1)$ 给出了所需的线性系数：

$$9x^2 + 7x - 2 = (9x - 2)(x + 1)$$

因此该方程等价于：

$$(9x - 2)(x + 1) = 0$$

由零因式性质可得：

$$9x - 2 = 0 \quad \text{或} \quad x + 1 = 0$$

故 $x = 2/9$ 或 $x = -1$。对应的[抛物线](../parabola/) $y = 9x^2 + 7x - 2$ 与 $x$ 轴交于 $(-1, 0)$ 和 $(2/9, 0)$，与 $y$ 轴交于 $(0, -2)$。其顶点为：

$$V\left(-\frac{7}{18}, -\frac{121}{36}\right)$$

该方程有两个不同的实数解，$x_1 = -1$ 和 $x_2 = 2/9$。

- - -

为使第二个方程为二次方程，我们假设 $p \neq 0$。其左端可直接分解为：

$$p^2x^2 + (p^2 - q^2)x - q^2 = (x + 1)(p^2x - q^2)$$

方程变为：

$$(x + 1)(p^2x - q^2) = 0$$

令每个因式等于零，得：

$$x + 1 = 0 \quad \text{或} \quad p^2x - q^2 = 0$$

对于满足 $p \neq 0$ 的每个 $p, q \in \mathbb{R}$，方程有两个不同的实数解，$x_1 = -1$ 和 $x_2 = q^2/p^2$。

- - -

第三个多项式在 $\mathbb{R}$ 上没有简单的分解，因此我们计算其[判别式](../quadratic-formula/)：

$$\Delta = 1^2 - 4(1)(2) = -7$$

由于判别式为负，求根公式给出两个[共轭复数](../quadratic-equations-with-complex-solutions/)值：

$$
\begin{align}
x_{1,2} &= \frac{-1 \pm \sqrt{-7}}{2} \\[6pt]
&= \frac{-1 \pm i\sqrt{7}}{2}
\end{align}
$$

抛物线 $y = x^2 + x + 2$ 不与 $x$ 轴相交，而与 $y$ 轴交于 $(0, 2)$。其顶点为 $V(-1/2, 7/4)$，位于 $x$ 轴上方。该方程没有实数解，只有两个共轭复数 $x_1 = (-1 + i\sqrt{7})/2$ 和 $x_2 = (-1 - i\sqrt{7})/2$。

- - -

在第四个方程中，无理系数使直接分解不那么明显。因此我们确定 $a = \sqrt{7}$、$b = -6$、$c = -13\sqrt{7}$，并计算判别式：

$$
\begin{align}
\Delta &= (-6)^2 - 4(\sqrt{7})(-13\sqrt{7}) \\[6pt]
&= 36 + 364 \\[6pt]
&= 400
\end{align}
$$

求根公式给出：

$$x_{1,2} = \frac{6 \pm 20}{2\sqrt{7}}$$

分别化简这两个值得：

$$x_1 = \frac{26}{2\sqrt{7}} = \frac{13\sqrt{7}}{7}, \qquad x_2 = \frac{-14}{2\sqrt{7}} = -\sqrt{7}$$

该方程有两个不同的实数解，$x_1 = 13\sqrt{7}/7$ 和 $x_2 = -\sqrt{7}$。

- - -

对于第五个方程，我们寻找两个整数，其乘积为 $-105$，其和为 $-32$。整数 $-35$ 和 $3$ 同时满足这两个条件，因此该多项式分解为：

$$z^2 - 32z - 105 = (z - 35)(z + 3)$$

方程等价于：

$$(z - 35)(z + 3) = 0$$

由零因式性质得 $z - 35 = 0$ 或 $z + 3 = 0$。该方程有两个不同的实数解，$z_1 = 35$ 和 $z_2 = -3$。

- - -

对于第六个方程，我们应用求根公式，其中 $a = \sqrt{2}$、$b = -3$、$c = -2\sqrt{2}$。判别式为：

$$
\begin{align}
\Delta &= (-3)^2 - 4(\sqrt{2})(-2\sqrt{2}) \\[6pt]
&= 9 + 16 \\[6pt]
&= 25
\end{align}
$$

代入公式得：

$$x_{1,2} = \frac{3 \pm 5}{2\sqrt{2}}$$

两个值分别化简如下：

$$x_1 = \frac{8}{2\sqrt{2}} = 2\sqrt{2}, \qquad x_2 = \frac{-2}{2\sqrt{2}} = -\frac{\sqrt{2}}{2}$$

该方程有两个不同的实数解，$x_1 = 2\sqrt{2}$ 和 $x_2 = -\sqrt{2}/2$。

- - -

第七个方程必须先写成标准形式。两边减去 $5$，得：

$$n^2 + 7n + 10 = 0$$

整数 $5$ 和 $2$ 的乘积为 $10$，和为 $7$，因此左端分解为：

$$n^2 + 7n + 10 = (n + 5)(n + 2)$$

故方程等价于：

$$(n + 5)(n + 2) = 0$$

该方程有两个不同的实数解，$n_1 = -5$ 和 $n_2 = -2$。

- - -

第八个方程是不完全的，因为它缺少一次项。将常数项移到右端，得：

$$3x^2 = 12$$

由于乘以 $x^2$ 的系数为 $3$，我们将两边除以 $3$，以分离出未知数的平方：

$$x^2 = 4$$

取 $4$ 的两个平方根，得：

$$x_{1,2} = \pm 2$$

该方程有两个不同的实数解，$x_1 = -2$ 和 $x_2 = 2$。

- - -

对于第九个方程，判别式为：

$$\Delta = (-12)^2 - 4(4)(9) = 144 - 144 = 0$$

为零的判别式表明该方程有一个实重根。左端也是一个完全平方三项式：

$$4x^2 - 12x + 9 = (2x - 3)^2$$

因此方程变为：

$$(2x - 3)^2 = 0$$

只有被平方的式子为零时，其平方才为零，故 $2x - 3 = 0$，从而 $x = 3/2$。该方程有唯一的实根 $x = 3/2$，其重数为二。

- - -

第十个方程展示了配方法。将常数项移到右端，得：

$$x^2 + 6x = -1$$

$x$ 的系数为 $6$，其一半的平方为 $9$。两边加上 $9$ 保持等式成立，并将左端化为完全平方式：

$$x^2 + 6x + 9 = 8$$

故方程等价于：

$$(x + 3)^2 = 8$$

取两个平方根，得：

$$x + 3 = \pm\sqrt{8} = \pm 2\sqrt{2}$$

两边减去 $3$，得：

$$x_{1,2} = -3 \pm 2\sqrt{2}$$

该方程有两个不同的实数解，$x_1 = -3 - 2\sqrt{2}$ 和 $x_2 = -3 + 2\sqrt{2}$。
