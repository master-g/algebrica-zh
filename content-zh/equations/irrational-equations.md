## 无理方程的定义

无理方程，又称为根式方程，是这样一类[方程](../equations/)：其未知数 $x$ 出现在[根式](../radicals/)内，或者被提升为分数[指数](../powers/)幂。它们构成一类独特的问题，仅凭标准的代数变形无法求解。根式与非整数指数的存在对 $x$ 的可取值施加了额外的限制，因此[定义域分析](../determining-the-domain-of-a-function/)成为必不可少的预备步骤。

无理方程是形如 $F(x) = 0$ 的方程，其中至少有一项含有函数的分数幂，即指数的分母大于一的幂。等价地，这些方程含有根式表达式。其定义项具有如下形式：

$$f(x)^{\frac{p}{q}} \quad \text{其中 } q > 1$$

以根式符号记作：

$$\sqrt[q]{f(x)}$$

典型的形式将[多项式](../polynomials/)置于 $n$ 次根号之下，或者将其提升为倒数幂：

$$\sqrt[n]{f(x)} = g(x)$$

$$f(x)^{\frac{1}{n}} = g(x)$$

在这些表达式中，$f(x)$ 与 $g(x)$ 是具有任意次数、[实系数](../types-of-numbers/)的[多项式](../polynomials/)。

> 求解这类方程通常需要通过将两边同时提升到合适的幂来消去根式。这一过程可能引入增根，因此必须将每个候选解对照由原始根式表达式所确定的定义域约束加以验证。

## 无理方程的一般形式

最常见的有三种结构形态。下表将每种方程的根式形式与其等价的指数形式进行对照，其中根式以分数指数来表示。

[class="table-1"]

| | |
|--------|--------|
| $$\sqrt[n]{f(x)} = g(x)$$ | $$f(x)^{1/n} = g(x)$$ |
| $$\sqrt[n]{f(x)} = k$$ | $$f(x)^{1/n} = k$$ |
| $$\sqrt[n]{x^m}$$ | $$x^{m/n}$$ |

[/class]

> 根式会对[定义域](../determining-the-domain-of-a-function/)施加明确的[限制](../limits/)；在消去根式之后，必须对候选解加以检验。代数变形可能给出若干可能的答案，但每一个都必须仔细验证。

## 如何求解无理方程

求解策略取决于根式的结构以及未知数在表达式中的位置。尽管存在这些差异，整体方法仍遵循若干必不可少的步骤：

+ 通过考虑根指数的奇偶性来确定[定义域](../determining-the-domain-of-a-function/)，并施加相应的条件。
+ 通过将方程两边提升到合适的幂来消去根式。
+ 求解所得方程，并通过验证每个解是否属于原始定义域且满足初始方程，来核对其有效性。

## 一般形式的细致考察

无理方程以几种结构形式出现，识别这些形式至关重要。变量在根式中所处的位置，以及指数的取值，共同决定定义域以及可以应用的代数运算。

- - -

第一种极为常见的情况是偶指数 $n$。这类方程的一般形式为：

$$\sqrt[n]{f(x)} = g(x), \quad n \in 2\mathbb{Z}$$

其中 $2\mathbb{Z}$ 表示偶[整数](../integers/)构成的集合。由于偶次根仅在被开方数非负时才有定义，求解之前必须施加特定的存在条件：

+ 施加定义域：$f(x) \ge 0$ 与 $g(x) \ge 0$。
+ 通过将两边同时取 $n$ 次幂来消去根式。
+ 解所得的代数方程。
+ 将每个解代回原方程加以检验。
+ 仅保留满足全部定义域条件的那些值。

> 条件 $g(x) \ge 0$ 也必须加以验证，因为偶指数根只能产生非负实数值，不可能等于一个负量。

- - -

当方程具有如下形式时：

$$\sqrt[n]{f(x)} = k$$

且 $k$ 为非负实数，定义域由满足下列条件的变量值给出：

$$f(x) \ge 0$$

只有对这些值，被开方数才有定义。求解该方程时：

+ 施加定义域条件 $f(x) \ge 0$。
+ 通过将两边同时取 $n$ 次幂来消去根式。
+ 解所得的代数方程。
+ 将每个候选解代回原方程加以检验。
+ 仅保留满足定义域与原等式的那些值。

- - -

若方程具有如下形式：

$$\sqrt[n]{f(x)} = k$$

且 $k$ 为负实数，则该方程无解。偶指数根式不可能产生负值，因此对于变量的任何实数值，该等式都不可能成立。

- - -

当出现下列情形时，问题更为一般：

$$\sqrt[n]{f(x)} = g(x)$$

且 $g(x)$ 为有理函数。此时确定定义域需要分析两边。$x$ 的容许值是满足下列[不等式组](../systems-of-inequalities/)的那些值：

$$
\begin{cases}
f(x) \ge 0 \\[6pt]
g(x) \ge 0
\end{cases}
$$

定义域一旦确立，便可通过将两边同时取 $n$ 次幂来变换方程，得到等价的代数方程：

$$f(x) = \bigl(g(x)\bigr)^n$$

在这些条件下，根式有定义，等式有意义，所得方程与原方程保持一致。

- - -

若方程写作如下形式：

$$f(x)^{1/n} = g(x), \quad n \in 2\mathbb{Z}$$

且 $g(x)$ 对某些实数 $x$ 取负值，则方程在这些点处无解。当 $n$ 为偶数时，表达式 $f(x)^{1/n}$ 是一个偶指数根，只能产生非负实数。每当 $g(x) < 0$ 时，等式都不可能成立。可能的解只存在于 $g(x) \ge 0$ 处，并且这些解还必须满足 $f(x) \ge 0$，以使被开方数有定义。

## 无理方程与有理方程之别

无理方程与[有理方程](../rational-equations/)的区别，在于变量 $x$ 在表达式中出现的方式。有理方程由多项式的比值构成，因此未知数仅出现在以多项式表达式为组成部分的分数的分子或分母中。一个例子是：

$$\frac{2x}{2x - 1}$$

它完全停留于有理表达式的框架之内。

而无理方程的特征在于变量出现在根号之内，或被取分数次幂。它们涉及[根式](../radicals/)记号，通常带有明确的根指数，其结构会引入在求解之前必须加以考虑的定义域限制。一个典型例子是：

$$\frac{2x}{\sqrt{2x - 1}}$$

其中平方根使该方程成为无理方程。识别一个方程究竟是有理的还是无理的，是必不可少的第一步，因为每一类都需要不同的求解技巧，并具有各自的代数约束。

## 奇数次根式

当根式的根指数 $n$ 为奇数时，方程的性质尤其易于处理。与偶次根式对根号内的式子施加限制不同，奇次根式对任何实数输入都可以求值。因此，该表达式在整个实数轴上都有意义，无需对定义域施加限制。对负数开奇次方的能力极大简化了方程的结构。

若 $n = 2k + 1$ 为奇数，则函数：

$$x \longmapsto \sqrt[n]{x}$$

对每一个 $x \in \mathbb{R}$ 都有定义。这是因为任意实数的奇数次幂仍为实数，无论该数是正数、负数还是零。取奇次方根作为其逆运算因此始终可行，且绝不会引入与符号相关的矛盾。含有奇次根式的一般无理方程可以写成：

$$\sqrt[n]{f(x)} = g(x), \quad n \in 2\mathbb{Z} + 1$$

只需将两边同时取 $n$ 次幂，即可将其转化为等价的代数方程：

$$f(x) = \bigl(g(x)\bigr)^{n}$$

此处根式不会引入诸如 $f(x) \ge 0$ 或 $g(x) \ge 0$ 的额外不等式约束；任何限制都仅来自根式之外的式子，例如分母或进一步的根式。一个数值例子可以说明这一点：

$$\sqrt[3]{-8} = -2$$

因为：

$$(-2)^3 = -8$$

更一般地，对于任意实数 $a$ 和任意奇数根指数 $n = 2k + 1$：

$$\sqrt[n]{a} = a^{1/n}$$

其结果仍是实数。奇指数根式与分式幂之间的这一对应关系，解释了为什么此类无理方程通常可以直接通过代数运算求解，而无需像偶指数情形那样预先进行定义域检查。

## 将根式分别置于等号两侧

在求解含有根式的方程时，将根式分别置于等号两侧是有益的做法。这可以避免在求幂运算时引入增根。考虑如下无理方程：

$$\sqrt{2x} - \sqrt{x + 1} = 0$$

- - -

直接对左侧进行平方会引入一个交叉项，使计算变得复杂：

$$
\begin{align}
&(\sqrt{2x} - \sqrt{x + 1})^2 = 0 \\[6pt]
&2x + (x + 1) - 2\sqrt{2x}\cdot\sqrt{x+1} = 0
\end{align}
$$

- - -

更可取的做法是在平方之前先把根式分别置于两侧：

$$
\begin{align}
&\sqrt{2x} = \sqrt{x + 1} \\[6pt]
&(\sqrt{2x})^2 = (\sqrt{x + 1})^2 \\[6pt]
&2x = x + 1 \\[6pt]
&2x - x = 1 \\[6pt]
&x = 1
\end{align}
$$

## 例 1

解无理方程：

$$\sqrt{x^2 - 2} = \sqrt{4x}$$

该方程具有形式 $\sqrt[n]{f(x)} = g(x)$，其根指数 $n$ 为偶数。容许解集合通过求解[不等式组](../systems-of-inequalities/)确定：

$$
\begin{cases}
f(x) \geq 0 \\[6pt]
g(x) \geq 0
\end{cases}
$$

将根号下的多项式代入得：

$$
\begin{cases}
x^2 - 2 \geq 0 \\[6pt]
4x \geq 0
\end{cases}
$$

求解[二次](../quadratic-equations/)不等式 $x^2 - 2 \geq 0$ 时，先求得边界点 $x_{1,2} = \pm\sqrt{2}$，因此第一个[不等式](../inequalities/)的解集为：

$$(-\infty, -\sqrt{2}] \ \cup \ [\sqrt{2}, +\infty)$$

第二个不等式给出 $x \geq 0$。两个条件的交集给出容许集合，可用图示法表示：

[shortcode="intervals"]
|     | $-\sqrt{2}$ | $0$      | $+\sqrt{2}$ |     |
|:----|:-----------:|:--------:|:-----------:|:----|
|     | sign+r-o    |          | sign+l-o    |     |
|     |             | sign+l-o |             |     |
|     |             |          | sign+l-o-h  |     |
[/shortcode]

该不等式组的解集为 $[\sqrt{2}, +\infty)$。

- - -

为求解原方程，将根式分别隔离到等号两侧，并将两边平方：

$$
\begin{align}
&\sqrt{x^2 - 2} = \sqrt{4x} \\[6pt]
&x^2 - 2 = 4x \\[6pt]
&x^2 - 4x - 2 = 0
\end{align}
$$

这是一个[二次方程](../quadratic-equations/)，用[求根公式](../quadratic-formula/)求解：

$$
\begin{align}
x_{1,2} &= \frac{-(-4) \pm \sqrt{(-4)^2 - 4 \cdot 1 \cdot (-2)}}{2 \cdot 1} \\[6pt]
&= \frac{4 \pm \sqrt{16 + 8}}{2} \\[6pt]
&= \frac{4 \pm \sqrt{24}}{2} \\[6pt]
&= \frac{4 \pm 2\sqrt{6}}{2} \\[6pt]
&= 2 \pm \sqrt{6}
\end{align}
$$

- - -

在验证解之前，先检查它们是否属于容许集合 $[\sqrt{2}, +\infty)$：

+ $x_2 = 2 + \sqrt{6} \approx 4.449 \in [\sqrt{2}, +\infty)$
+ $x_1 = 2 - \sqrt{6} \approx -0.449 \notin [\sqrt{2}, +\infty)$

值 $x_1 = 2 - \sqrt{6}$ 是平方过程中引入的增根，应予舍去。还需验证 $x_2 = 2 + \sqrt{6}$ 满足原方程：

$$
\begin{align}
&\sqrt{(2 + \sqrt{6})^2 - 2} = \sqrt{4(2 + \sqrt{6})} \\[6pt]
&\sqrt{4 + 4\sqrt{6} + 6 - 2} = \sqrt{8 + 4\sqrt{6}} \\[6pt]
&\sqrt{8 + 4\sqrt{6}} = \sqrt{8 + 4\sqrt{6}}
\end{align}
$$

等式成立。因此方程的解为：

$$x = 2 + \sqrt{6}$$
