## 定义

含未知数 $x_1, x_2, \ldots, x_n$ 的线性方程是一次[方程](../equations/)，其中每个变量以等于 $1$ 的指数出现，且绝不与另一变量相乘。其标准形式为：

$$a_1x_1 + a_2x_2 + \ldots + a_nx_n = b$$

在此表达式中，各符号含义如下：

+ $x_1, x_2, \ldots, x_n \in \mathbb{R}$ 为未知数
+ $a_1, a_2, \ldots, a_n \in \mathbb{R}$ 为系数，其中至少有一个 $a_i \neq 0$
+ $b \in \mathbb{R}$ 为常数项
+ 当 $b = 0$ 时，该方程称为齐次方程

将等号替换为不等号所得的同次代数关系定义了[线性不等式](../linear-inequalities/)，可用类似的方法求解。

「线性」一词指的是左端的一个精确代数性质。若记左端为 $L$，即：

$$L(x_1, \ldots, x_n) = a_1x_1 + \ldots + a_nx_n$$

则 $L$ 满足线性的两条定义性质：

$$L(x + y) = L(x) + L(y)$$

$$L(\lambda x) = \lambda L(x)$$

这两个恒等式正是如下几何事实的代数对应：使解集成为一条直线、一个平面，或更一般地一个超平面。同样的线性概念构成了[向量空间](../vector-spaces/)与[线性映射](../linear-maps/)的基础，也解释了为何线性方程在数学中占据如此核心的地位。

线性方程可含有任意有限个未知数。例如，表达式 $ax + by + c = 0$ 是关于两个变量 $x$ 与 $y$ 的线性方程，写成标准形式后其常数项为 $-c$。

> 线性方程是[线性方程组](../systems-of-linear-equations/)与[矩阵](../matrices/)演算赖以建立的基础，也提供了同时表述和求解涉及多个未知数的问题的语言。

## 解的类型

线性方程解集的几何性质取决于未知数的个数以及方程是否为齐次。在每种情形下，解集都是 $\mathbb{R}^n$ 的一个仿射子空间，即线性子空间的平移，当方程非退化时其维数等于 $n - 1$。各种情形可概括如下。

+ 含一个未知数时，解退化为实数轴上的单个点。
+ 含两个未知数时，解构成平面内的一条[直线](../lines/)，若方程为齐次则经过原点。
+ 含三个未知数时，解构成空间中的一个[平面](../planes/)，齐次情形下同样经过原点。
+ 含 $n > 3$ 个未知数时，解集是 $\mathbb{R}^n$ 的一个超平面，即维数为 $n - 1$ 的仿射子空间。

> 维数恰好下降一，反映了一个线性方程对 $n$ 个未知数施加了一个标量约束这一事实。施加更多独立的线性条件相当于对各超平面求交，自然地引出[线性方程组](../systems-of-linear-equations/)的理论。

## 一元线性方程

含一个未知数的线性方程，通过初等代数变形，总能化简为如下标准形式：

$$ax = b$$

该方程的行为完全取决于系数 $a$ 与 $b$，需要区分三种情形。

当 $a \neq 0$ 时，方程存在唯一解，该解可由两边同除以 $a$ 得到：

$$x = \frac{b}{a}$$

这正是标准定义所考虑的情形——标准定义要求至少有一个系数非零。其余两种情形仅当原方程化简后退化为 $0 \cdot x = b$ 时才会出现，它们揭示了真正的线性方程与不再依赖未知数的关系之间的界限。

当 $a = 0$ 且 $b = 0$ 时，方程变为 $0 = 0$，它是一个对任意实数都成立的恒等式。解集为整个 $\mathbb{R}$，此时方程称为不定方程。

当 $a = 0$ 且 $b \neq 0$ 时，方程化为 $0 = b$，这是一个无解的矛盾式。解集为空集，此时方程称为不可能方程。

上述三种情形并非抽象的奇趣。当系数依赖于一个或多个实参数时，这些情形会系统性地出现，从而产生形如 $a(k)x = b(k)$ 的[含参线性方程](../linear-equations-with-parameters/)。使 $a(k) = 0$ 成立的 $k$ 的取值，恰是那些在确定、不定与不可能三种情形之间切换方程状态的取值，而识别它们正是参数情形的核心问题。

## 例 1

考虑方程：

$$2x + 3 = 11x$$

未知数 $x$ 取遍整个[实数](../types-of-numbers/)集合，对其[定义域](../determining-the-domain-of-a-function/)不作任何限制。为求解该方程，我们将所有含 $x$ 的项移到一边，常数项移到另一边，将其化为标准形式 $ax = b$：

$$
\begin{align}
2x + 3 &= 11x \\[6pt]
2x - 11x &= -3 \\[6pt]
-9x &= -3
\end{align}
$$

未知数的系数为 $-9 \neq 0$，因此方程属于确定的情形，存在唯一解。两边同除以 $-9$，得到：

$$x = \frac{-3}{-9} = \frac{1}{3}$$

为验证结果，将 $x = 1/3$ 代入原方程，检验两边是否给出相同的值：

$$
\begin{align}
2 \left( \frac{1}{3} \right) + 3 &= 11 \left( \frac{1}{3} \right) \\[6pt]
\frac{2}{3} + \frac{9}{3} &= \frac{11}{3} \\[6pt]
\frac{11}{3} &= \frac{11}{3}
\end{align}
$$

恒等式得到确认，方程的唯一解为：

$$x = \frac{1}{3}$$

## 二元线性方程

二元线性方程的标准形式为：

$$ax + by = c$$

在该表达式中 $a, b, c \in \mathbb{R}$，其中 $a$ 与 $b$ 至少有一个不为零。在几何上，其解集是笛卡尔平面上的一条[直线](../lines/)，而该方程就是这条直线的隐式表示。常数项 $c$ 决定了直线的位置：当 $c \neq 0$ 时直线不经过原点，而当 $c = 0$ 时方程退化为齐次形式，对应的直线经过原点。

通解可通过将其中一个未知数取为自由参数得到。假设 $b \neq 0$ 且令 $x = \lambda$，则方程给出：

$$y = \frac{c - a\lambda}{b}, \qquad \lambda \in \mathbb{R}$$

参数 $\lambda$ 的每一个值都给出平面上位于该直线上的一点，当 $\lambda$ 在 $\mathbb{R}$ 上变化时，整条直线便被描绘出来。$\lambda$ 与被选作自由变量的未知数二者的角色可以互换，而不影响解的几何内容。

> 同一个方程 $ax + by = c$ 在 $b \neq 0$ 成立时可改写为显式形式 $y = mx + q$，其斜率为 $m = -a/b$，截距为 $q = c/b$。隐式形式更为一般，因为它也涵盖了 $b = 0$ 的那些铅直线，而这些直线无法以显式形式表示。

- - -

当 $c = 0$ 时，方程变为：

$$ax + by = 0$$

并表示一条经过原点的直线。其解集是 $\mathbb{R}^2$ 的一个一维[向量子空间](../vector-spaces/)，由任意一个与系数向量 $(a, b)$ 正交的非零向量张成。一种特别对称、使结构一目了然的参数化为：

$$x = \lambda b, \qquad y = -\lambda a, \qquad \lambda \in \mathbb{R}$$

这对 $(b, -a)$ 确是方程的解，因为 $ab + b(-a) = 0$，而其余每一个解都是它的标量倍数。这是贯穿整个理论的一个现象的第一个具体实例：齐次线性方程的解构成一个向量子空间，而对应的非齐次方程的解构成由平移得到的仿射子空间。

## 例 2

考虑齐次线性方程：

$$2x - 3y = 0$$

系数为 $a = 2$ 与 $b = -3$，因此该方程表示笛卡尔平面上过原点的一条直线。解出 $y$，便得到显式形式：

$$y = \frac{2}{3} x$$

由此可知该直线斜率为 $2/3$。方程的每个解 $(x, y)$ 都满足此关系，而整个解集合可通过引入实参数 $\lambda$ 写成：

$$x = \lambda, \qquad y = \frac{2}{3} \lambda, \qquad \lambda \in \mathbb{R}$$

同一条直线也容许在一般讨论中引入的对称参数化 $x = \lambda b = -3\lambda$、$y = -\lambda a = -2\lambda$。两种描述仅相差参数的一次重新标度，并给出相同的点集合：在第一种参数化中作替换 $\lambda \mapsto -3\lambda$，即可得到第二种参数化。

![图 1](/assets/equations/svg/linear-equations-1.zh.svg)

任取 $\lambda$ 的值，例如 $\lambda = 3$ 与 $\lambda = -6$（任何实数均可），便得到直线上的具体点：

+ 当 $\lambda = 3$ 时，得到点对 $(x, y) = (3, 2)$
+ 当 $\lambda = -6$ 时，得到点对 $(x, y) = (-6, -4)$

直接代入原方程可验证两组点对均满足该方程。图中画出了方程为 $2x - 3y = 0$ 的直线以及刚刚算得的两个点。

因此方程 $2x - 3y = 0$ 的解集合就是过原点、方程如下的直线：

$$y = \tfrac{2}{3} x$$

## 三元一次方程

三元一次方程的标准形式为：

$$ax + by + cz = d$$

其中 $a, b, c, d \in \mathbb{R}$，且 $a$、$b$、$c$ 中至少有一个不为零。从几何上看，其解集合是三维空间中的一张平面，而该方程就是这张平面的隐式表示。系数向量 $(a, b, c)$ 垂直于该平面，决定其朝向；常数项 $d$ 则控制平面到原点的距离：当 $d = 0$ 时，平面经过原点，方程是齐次的；否则该平面是齐次平面的一个平行平移。

通解通过选取两个未知数作为自由参数得到。设 $c \neq 0$，并令 $x = \lambda$、$y = \mu$，方程给出：

$$z = \frac{d - a\lambda - b\mu}{c}, \qquad \lambda, \mu \in \mathbb{R}$$

每一对 $(\lambda, \mu)$ 确定平面上的一点，当两个参数在 $\mathbb{R}$ 上独立变化时，即可描绘出整张平面。所需自由参数的个数——本例中为两个——等于平面的维数，这与「$n$ 个未知数的一个线性方程将维数降低一」的一般原理相一致。

当 $d = 0$ 时，方程化为：

$$ax + by + cz = 0$$

表示一张过原点的平面。其解集合是 $\mathbb{R}^3$ 的一个二维[向量子空间](../vector-spaces/)，由所有与系数向量 $(a, b, c)$ 正交的向量构成。上述参数化描述同样适用，其中 $d = 0$：

$$x = \lambda, \qquad y = \mu, \qquad z = -\frac{a\lambda + b\mu}{c}, \qquad \lambda, \mu \in \mathbb{R}$$

> 被选为因变量的那个未知数，其选择是约定性的。若 $c = 0$ 但 $a \neq 0$ 或 $b \neq 0$，则可改为分离 $x$ 或 $y$ 来进行同样的构造。不依赖于该选择的是所得到的几何对象：平面本身，其朝向由法向量 $(a, b, c)$ 固定。

## 例 3

考虑齐次线性方程：

$$x + 2y - z = 0$$

系数分别为 $a = 1$、$b = 2$、$c = -1$，所以该方程表示三维空间中过原点的一个平面，其法向量为 $(1, 2, -1)$。为求通解，我们解出 $z$，得到：

$$z = x + 2y$$

两个未知量 $x$ 和 $y$ 可作为自由参数，令 $x = \lambda$、$y = \mu$，且 $\lambda, \mu \in \mathbb{R}$。代回后，第三个坐标随之确定：

$$z = \lambda + 2\mu$$

该方程的解集合由所有形如下式的三元组构成：

$$(x, y, z) = (\lambda, \mu, \lambda + 2\mu), \qquad \lambda, \mu \in \mathbb{R}$$

为两个参数赋予具体数值，即可得到平面上的具体点。

+ 当 $\lambda = 1$、$\mu = 0$ 时，得到 $(1, 0, 1)$。
+ 当 $\lambda = 0$、$\mu = 1$ 时，得到 $(0, 1, 2)$。
+ 当 $\lambda = 2$、$\mu = -1$ 时，得到 $(2, -1, 0)$。

直接代入即可验证，这三个三元组都满足原方程。

两个三元组 $(1, 0, 1)$ 与 $(0, 1, 2)$ [线性无关](../rank-of-a-matrix/)，且张成整个平面，即每个解都可写成[线性组合](../linear-combinations/) $\lambda (1, 0, 1) + \mu (0, 1, 2)$。这对向量构成了由方程所定义的 $\mathbb{R}^3$ 的二维子空间的一组基，而上面写出的参数化形式，恰好是用这组基表示该子空间中任一向量的表达式。

方程 $x + 2y - z = 0$ 的解集合即过原点的平面，其方程为：

$$(x, y, z) = (\lambda, \mu, \lambda + 2\mu), \qquad \lambda, \mu \in \mathbb{R}$$

[三元线性方程组](../systems-of-linear-equations-in-three-variables/)页面讨论多个此类平面的交集及其初等求解方法。

## 含参线性方程

上述理论的自然推广，是允许系数依赖于一个或多个实参数，而非固定常数。由此引出[含参线性方程](../linear-equations-with-parameters/)，即如下形式的关系族：

$$a(k)x + b(k) = c(k)$$

其行为随赋予 $k$ 的取值而变化。将方程化为标准形可得 $a(k)x = c(k) - b(k)$，此前在单变量情形讨论中出现的三种情形，于此自然呈现。

+ 对于使 $a(k) \neq 0$ 成立的 $k$ 取值，方程是确定的，且存在唯一解 $x = (c(k) - b(k)) / a(k)$。
+ 对于使 $a(k) = 0$ 且 $c(k) - b(k) = 0$ 的取值，方程化为恒等式 $0 = 0$，被任意实数 $x$ 所满足。
+ 对于使 $a(k) = 0$ 且 $c(k) - b(k) \neq 0$ 的取值，方程不可能成立，无解。

> 研究含参方程，本质上就是确定 $k$ 中使这三种情形相互转变的临界取值。使 $a(k)$ 为零的点是临界点，因为正是在这些点处，方程可能失去其确定性，退化为恒等式或矛盾方程。
