## 引言

对数方程是指未知数出现在[对数](../logarithms/)内部的[方程](../equations/)。求解对数方程依赖于对数的性质，以及这些性质如何使未知数得以分离。对数方程的一般形式为：

$$\log_a f(x) = g(x)$$

+ $a$ 是对数的底数，必须满足 $a > 0$ 和 $a \neq 1$。
+ $f(x)$，即对数的真数，必须大于零，因为[对数函数](../logarithmic-function/)仅对正[数](../types-of-numbers/)有定义。

> 求解对数方程依赖于对对数性质的牢固掌握，尤其是积、商和幂运算律，它们使复杂表达式得以化简，未知数得以分离。

## 如何求解对数方程

对数方程的求解可分为四个步骤。

+ 通过要求每个对数的真数为正、每个底数大于零且不等于一来确定方程的[定义域](../determining-the-domain-of-a-function/)。

+ 对于单个对数 $\log_a f(x)$，这些条件为：

$$\begin{cases} a > 0 \\[6pt] a \neq 1 \\[6pt] f(x) > 0 \end{cases}$$

+ 运用[对数性质](../logarithms/)，如积、商和幂运算律，合并并化简各项对数。目的是将方程化为更简单的形式，使未知数得以分离。

+ 方程化简后，通过去掉对数来求解未知数。这一步通常相当于将两边都转化为指数形式。

+ 将解代回原方程，验证每个解是否都落在第一步所确定的定义域内。

> 第一步中得到的定义域限制往往会给未知数引入附加条件。这些条件的系统讨论见关于[对数不等式](../logarithmic-inequalities/)的专门条目，它是对数方程求解的补充。

## 对数方程的化简形式

对数方程化简后，通常归结为几种标准形式之一。第一种是同底数两对数相等：

$$\log_a f(x) = \log_a g(x)$$

由于对数函数是单射，两个同底数对数相等当且仅当它们的真数相等。因此，只需令真数相等并求解所得方程：

$$f(x) = g(x)$$

> 这一等价关系仅在两个对数表达式都有定义时成立。在令真数相等之前，务必验证 $f(x) > 0$、$g(x) > 0$，以及底数满足 $a > 0$ 和 $a \neq 1$。

- - -

第二种标准形式是对数与常数相等：

$$\log_a f(x) = b$$

此处无法进一步化简，因此求解时利用对数的定义并转化为指数形式，得到：

$$f(x) = a^b$$

- - -

第三种标准形式出现在同一个对数被提升到不同的幂、且具有一个底数和一个真数时：

$$\log_a^2(x + c) + \log_a(x + c) + k = 0$$

此时，代换 $z = \log_a(x + c)$ 将方程转化为：

$$z^2 + z + k = 0$$

问题化为[二次方程](../quadratic-equations/)，或更一般地，化为 $n$ 次方程，可用[求根公式](../quadratic-formula/)或对 $n > 2$ 次[多项式](../polynomials/)使用[综合除法](../synthetic-division/)来求解。

## 例 1

我们求解对数方程：

$$\log_3(2x + 1) = \log_3(x^2)$$

- - -

第一步是确定定义域，要求每个对数的真数均为正。由此得到两个条件：

$$2x + 1 > 0 \rightarrow x > -\frac{1}{2}$$

$$x^2 > 0 \rightarrow x \neq 0$$

[shortcode="intervals"]
|     | $-\frac{1}{2}$  | $0$      |     |
|:----|------------|---------------|-----|
|     | sign+l-o-h |     |     |
|     |   | sign+r-o-h sign+l-o-h    |     |
[/shortcode]

将两个条件联立，定义域 $D$ 由区间的并集给出：

$$\left( -\frac{1}{2}, 0 \right) \cup (0, +\infty)$$

- - -

各对数底数相同，且方程具有形式 $\log_a f(x) = \log_a g(x)$，因此可以令真数相等。将所有项移到一边，得到标准的[二次方程](../quadratic-equations/)：

$$x^2 - 2x - 1 = 0$$

用[求根公式](../quadratic-formula/)求解：

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

其中 $a = 1$、$b = -2$、$c = -1$。代入这些值得到：

$$
\begin{align}
x &= \frac{-(-2) \pm \sqrt{(-2)^2 - 4 \cdot 1 \cdot (-1)}}{2 \cdot 1} \\[6pt]
  &= \frac{2 \pm \sqrt{4 + 4}}{2} \\[6pt]
  &= \frac{2 \pm \sqrt{8}}{2} \\[6pt]
  &= \frac{2 \pm 2\sqrt{2}}{2} \\[6pt]
  &= 1 \pm \sqrt{2}
\end{align}
$$

- - -

还需验证两个解是否都落在定义域内：

+ $x = 1 + \sqrt{2} \approx 2.414$ 满足 $x > -\frac{1}{2}$ 和 $x \neq 0$。
+ $x = 1 - \sqrt{2} \approx -0.414$ 满足 $x > -\frac{1}{2}$ 和 $x \neq 0$。

两个值都属于 $D$，因此方程有两个解：

$$x = 1 \pm \sqrt{2}$$

## 例 2

我们求解一个通过乘积法则合并两个对数并化简为常数形式的对数方程：

$$\log_2(x - 1) + \log_2(x + 1) = 3$$

- - -

第一步是确定定义域。两个真数都必须为正，由此得到两个条件：

$$x - 1 > 0 \rightarrow x > 1$$

$$x + 1 > 0 \rightarrow x > -1$$

这两个条件同时成立仅当 $x > 1$，因此定义域为区间：

$$D = (1, +\infty)$$

- - -

两个对数底数相同且相加，因此[乘积法则](../logarithms/)可将它们合并为一个对数：

$$\log_2\bigl[(x - 1)(x + 1)\bigr] = 3$$

展开乘积得到二次表达式的一个对数：

$$\log_2(x^2 - 1) = 3$$

此时方程为常数形式 $\log_a f(x) = b$，转为指数形式即可消去对数：

$$x^2 - 1 = 2^3$$

- - -

得到的[二次方程](../quadratic-equations/)直接求解：

$$
\begin{align}
&x^2 - 1 = 8 \\[6pt]
&x^2 = 9 \\[6pt]
&x = \pm 3
\end{align}
$$

接下来将候选解与定义域 $D = (1, +\infty)$ 比较：

+ $x = 3$ 满足 $x > 1$，是可取的。
+ $x = -3$ 不满足 $x > 1$，必须舍去。

$x = -3$ 是合并两个对数时引入的增根，因为它使原来的真数变为负数。因此方程只有一个解：

$$x = 3$$

## 例 3

我们求解一个同一个对数被平方的对数方程，展示换元形式：

$$\log_2^2 x - 3\log_2 x + 2 = 0$$

- - -

对数的真数必须为正，因此定义域为：

$$D = (0, +\infty)$$

同一个对数表达式 $\log_2 x$ 以指数 2 和 1 出现，因此换元 $z = \log_2 x$ 将方程化为[二次方程](../quadratic-equations/)：

$$z^2 - 3z + 2 = 0$$

将三项式因式分解得到：

$$(z - 1)(z - 2) = 0$$

因此两个值为 $z_1 = 1$ 和 $z_2 = 2$。

- - -

回代 $z = \log_2 x$ 得到两个基本对数方程。第一个是：

$$\log_2 x = 1$$

得到 $x = 2^1 = 2$。第二个是：

$$\log_2 x = 2$$

得到 $x = 2^2 = 4$。两个值都为正，因此属于定义域 $D$。方程有两个解：

$$x_1 = 2 \qquad x_2 = 4$$

## 解的存在性与个数

对数方程解的个数反映了[对数函数](../logarithmic-function/)的行为。对于底数 $a > 1$，函数 $\log_a x$ 严格递增；而对于 $0 < a < 1$，它严格递减；两种情况下它都是单射，因此对于任意实数 $b$，基本方程 $\log_a x = b$ 都恰好有一个解。正是这一性质证明了将两个同底数对数的真数相等的做法是合理的。

定义域条件才是限制可取解个数的关键。积法则与商法则等代数变形可能会扩大变形后方程的定义域，从而引入满足该方程却不满足原方程的值。

因此，必须像例 2 中那样，对每个候选解逐一核验最初确定的定义域——在例 2 中，两个代数根之一不得不被舍去。

核验定义域这一步骤，正是将正确解与增根区分开来的关键，它与[指数方程](../exponential-equations/)中相应的要求如出一辙：在那类方程中，两个函数之间的反函数关系支配着同样的推理。
