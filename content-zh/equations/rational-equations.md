## 什么是有理方程

有理方程至少包含一个分子和分母都是[多项式](../polynomials/)的分式。之所以称为有理方程，是因为它们可以表示为两个多项式之比。有理方程可以在两边都出现分式，但通过将每一项移到一边并在公分母上合并结果，总可以化为标准形：

$$\frac{P(x)}{Q(x)} = 0$$

其中 $P(x)$ 和 $Q(x)$ 是多项式，且 $Q(x) \neq 0$。当等号替换为不等号时，同样的标准形构成[有理不等式](../rational-inequalities/)的基础，通过对该比值进行符号分析来求解。多项式是由若干[单项式](../monomials/)相加减而成的组合，其一般形式如下：

$$a_nx^n + a_{n-1}x^{n-1} + \dotsb + a_2x^2 + a_1x + a_0$$

其中各符号含义如下：

+ $a_nx^n$ 是一个单项式
+ $a$ 是一个实数，作为该项的系数
+ $n$ 是一个非负[整数](../integers/)，作为变量的指数

## 有理方程与无理方程的区别

有理方程与[无理方程](../irrational-equations/)的区别在于结构。有理方程由分子和分母都是多项式的分式构成，总可以写成两个多项式之比。无理方程含有不同次根式，以[根式](../radicals/)记号表示，并用根指数标明其次数，其解一般不能描述为有理数。

- - -

这一区别可通过两个例子来说明：

+ $\dfrac{2x}{2x-1}$ 是有理式，因为它仅含多项式项之比
+ $\dfrac{1}{\sqrt{2x-1}}$ 是一个[无理](../irrational-equations/)式，因为变量出现在根式内

## 如何求解有理方程

求解有理方程分为三个阶段：

+ 求出使分母为零的值。这些值必须排除，因为它们会使表达式无定义。所有允许值（即每个分母都不为零的那些值）的集合，构成该方程的存在条件。
+ 求出各分母中出现的[多项式](../polynomials/)的最小公倍式，将方程两边乘以该最小公倍式以去分母，再求解所得的分子多项式方程。
+ 将每个解与存在条件进行比较，舍弃任何使分母为零的值，并验证其余解满足原方程。

> 将解与存在条件进行比较是必要的。去分母过程可能产生解了变形后的方程却违反原方程的值。这样的值是增根，必须舍弃，这一现象与[失根](../loss-of-roots/)有关。

## 只有一个有效解的例子

求解有理方程：

$$\frac{1}{x+1} + \frac{1}{x+2} = 0$$

第一步是确定使分母为零的值，因为这些值会导致表达式无定义：

$$
\begin{align}
x + 1 = 0 \quad &\rightarrow \quad x = -1 \\[6pt]
x + 2 = 0 \quad &\rightarrow \quad x = -2
\end{align}
$$

值 $x = -1$ 和 $x = -2$ 必须从解集中排除，因为它们会使分母为零。

将两个分式通分并合并得到：

$$
\begin{align}
&\frac{x+2}{(x+1)(x+2)} + \frac{x+1}{(x+1)(x+2)} = 0 \\[6pt]
&\frac{x+2+x+1}{(x+1)(x+2)} = 0 \\[6pt]
&\frac{2x+3}{(x+1)(x+2)} = 0
\end{align}
$$

当分式的分子为零时，分式等于零。令 $2x + 3 = 0$ 得到一个一次[线性方程](../linear-equations/)，其唯一解为 $x = -\frac{3}{2}$。该值不在使分母为零的值之列，故而是有效解。将其代入原方程验证结果：

$$
\begin{align}
\frac{1}{-\frac{3}{2}+1} + \frac{1}{-\frac{3}{2}+2} &= 0 \\[6pt]
\frac{1}{-\frac{1}{2}} + \frac{1}{\frac{1}{2}} &= 0 \\[6pt]
-2 + 2 &= 0
\end{align}
$$

等式成立。因此该方程的解为：

$$x = -\frac{3}{2}$$

## 含增根的例子

下一个例子说明为什么不能省略与存在条件的比较。考虑方程：

$$\frac{x}{x-2} + \frac{2}{x+1} = \frac{6}{(x-2)(x+1)}$$

分母在使因子 $x-2$ 与 $x+1$ 为零的值处为零：

$$
\begin{align}
x - 2 = 0 \quad &\rightarrow \quad x = 2 \\[6pt]
x + 1 = 0 \quad &\rightarrow \quad x = -1
\end{align}
$$

因此存在条件要求 $x \neq 2$ 与 $x \neq -1$。各分母的最小公倍式为 $(x-2)(x+1)$，因为第三个分母已经与该乘积相同。将方程两边乘以这个公分母以去分母，得到一个多项式方程：

$$
\begin{align}
x(x+1) + 2(x-2) &= 6 \\[6pt]
x^2 + x + 2x - 4 &= 6 \\[6pt]
x^2 + 3x - 10 &= 0
\end{align}
$$

结果是一个[二次方程](../quadratic-equations/)。将该三项式因式分解得到：

$$(x+5)(x-2) = 0$$

乘积在其中一个因子为零时为零，从而得到两个候选解 $x = -5$ 与 $x = 2$。第二个候选解与其中一个被排除的值相同，因此它违反了存在条件，必须作为增根舍弃。只剩下 $x = -5$，将其代入原方程验证其有效性：

$$
\begin{align}
\frac{-5}{-5-2} + \frac{2}{-5+1} &= \frac{6}{(-5-2)(-5+1)} \\[6pt]
\frac{-5}{-7} + \frac{2}{-4} &= \frac{6}{(-7)(-4)} \\[6pt]
\frac{5}{7} - \frac{1}{2} &= \frac{6}{28} \\[6pt]
\frac{3}{14} &= \frac{3}{14}
\end{align}
$$

等式成立，而候选解 $x = 2$ 会导致除以零。因此方程的唯一解为：

$$x = -5$$
