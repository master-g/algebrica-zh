## 为何解会消失

失根发生于代数变形消去了一个或多个[根](../roots-of-a-polynomial/)，所得结果只是[方程](../equations/)解集的一部分。最常见的原因是方程两边同除以含有未知数的表达式，而这一运算只有在能保证该表达式不为零时才有效。例如，考虑方程：

$$x(2x-5) = x$$

一个常见错误是约去两边都出现的因子 $x$。这样就把方程化为关于 $x$ 的一次方程：

$$2x - 5 = 1$$

$$x = \frac{6}{2} = 3$$

约分等价于两边同除以 $x$，这一运算的前提是 $x \neq 0$。$x = 0$ 这一情形被悄然丢弃，于是丢失了一个解。

更一般地，任何含有未知数的因子只有在验证其不可能等于零之后，才能从两边约去。当这一条件无法确立时，必须对方程进行因式分解，而不能通过除法化简。

## 正确方法

正确的方法是在任何进一步变形之前，先把方程化为标准形式。不是试图约去因子，而是把所有项移到一边，使方程呈 $ax^2 + bx + c = 0$ 的形式。从方程：

$$x(2x-5) = x$$

展开左边，并从两边减去 $x$，得到：

$$
\begin{align}
2x^2 - 5x - x &= 0 \\[6pt]
2x^2 - 6x &= 0 \\[6pt]
2x(x - 3) &= 0
\end{align}
$$

结果是一个[不完全二次方程](../incomplete-quadratic-equations/)，其中常数项 $c$ 为零。应用零乘积性质，乘积 $2x(x-3)$ 为零当且仅当两个因子中至少有一个为零。

分别令每个因子等于零，得到方程的两个解：

$$x_1 = 0 \qquad x_2 = 3$$

> 因错误约分而被丢弃的解 $x_1 = 0$，作为因式形式的直接结果被重新找回。该方程有两个不同的实数解，而由错误步骤得到的值只给出其中一个。

## 为何除法会丢失解

两种步骤不一致的原因，可以通过比较每一步的逻辑内容来精确说明。将 $x(2x-5) = x$ 的两边除以 $x$，用方程 $2x - 5 = 1$ 替换了原方程，但两者只有在附加假设 $x \neq 0$ 下才等价。因此，除法并没有把方程变换为等价的方程；它把方程变换成了在受限定义域 $x \neq 0$ 上成立的方程，而值 $x = 0$ 在被检验之前就被排除了。

相比之下，因式分解保留了完整的方程。恒等变形 $x(2x-5)-x=2x(x-3)$ 对每个实数 $x$ 都成立，因此方程 $x(2x-5)-x=0$ 与 $2x(x-3)=0$ 完全等价。在任何阶段都没有从定义域中移除任何值，所以不会有解丢失。这正是化为乘积为零的结构性优势：因式形式的解集与原方程的解集完全一致。

## 平方后的增根与符号分支

求解[无理方程](../irrational-equations/)时，第二个常见的失根诱因，并不在于平方这一步本身。对定义域内有意义的方程两边同时平方，会保留原方程的全部解，只是可能引入增根。真正的失根，发生在后续只保留两种可行符号中的一种，或施加了原方程并不要求的额外限制时。考虑方程：

$$\sqrt{2x + 1} = x - 1$$

两边同时平方，得到：

$$
\begin{align}
2x + 1 &= (x-1)^2 \\[6pt]
2x + 1 &= x^2 - 2x + 1 \\[6pt]
x^2 - 4x &= 0 \\[6pt]
x(x - 4) &= 0
\end{align}
$$

两个候选解是 $x_1 = 0$ 和 $x_2 = 4$。代回原方程，$x_1 = 0$ 得到 $\sqrt{1} = -1$，此式不成立，因此 $x_1 = 0$ 是平方引入的增根。候选解 $x_2 = 4$ 得到 $\sqrt{9} = 3$，此式成立，因此它是唯一的真正解。

> 本例中没有失根，但它说明检验为何不可或缺。平方本身只可能引入增根；后续若只保留部分符号分支或施加额外限制，才可能丢掉真正的解。

相关失根的典型情形，是去掉绝对值时只保留了两种可行符号中的一种。形如 $|f(x)| = g(x)$ 的方程首先要求 $g(x) \geq 0$；在此前提下，它等价于 $f(x) = g(x)$ 或 $f(x) = -g(x)$ 两个分支，而平方会把两者同时包含在内。若改用单一符号去掉绝对值来处理同一问题，被丢掉的分支可能含有真正的解。因此，当方程中出现偶次根式或绝对值时，必须完整保留所有可行分支，并把候选解代回原方程逐一检验。

## 有理方程中的失根

求解[有理方程](../rational-equations/)时，一个常见的错误是为了消去分母中的未知数，把方程两边同乘分母。当分母中含有未知数时，这一步只有在分母不为零处才成立。把使分母为零的取值排除在外，并不会丢失任何解，因为这些取值本来就不属于定义域。真正的风险在另一侧：若不把候选解对照定义域检验，就可能保留一个并不真正满足原方程的取值，即增根。

真正的失根，发生在求解之前先约去分母中某个因子以化简方程的时候。约分会无声地把使该因子为零的每一个取值排除在考虑之外。这样做是否无害，取决于该取值是否已被定义域排除在外。考虑方程：

$$\frac{x^2 - 4}{x - 2} = 0$$

从分子与分母中约去因子 $(x-2)$ 后得到 $x + 2 = 0$，故 $x = -2$。值 $x = 2$ 因使分母为零而被排除出定义域。因此该方程恰有一个解 $x = -2$，并未失根：这次约分之所以无害，正是因为 $x = 2$ 本来就不是定义域内的允许取值。

当被约去的因子并不对应于定义域限制时，情况就不同了。考虑方程：

$$x(x - 3) = 2(x - 3)$$

两边同时约去 $(x - 3)$ 后得到 $x = 2$。然而值 $x = 3$ 同样满足原方程，因为当 $x = 3$ 时两边都等于零，而正是这次约分把这个解丢掉了。把方程化为标准形式则可以把它保留下来：

$$
\begin{align}
x(x - 3) - 2(x - 3) &= 0 \\[6pt]
(x - 3)(x - 2) &= 0
\end{align}
$$

再由零乘积性质，得到两个解 $x_1 = 2$ 与 $x_2 = 3$；而错误的化简只保留了其中一个。

## 一般原则

求解方程时，有几条原则有助于避免无意中失根。

最稳妥的策略是把所有项移到一边，把方程化成等于零的形式，再对所得表达式分解因式。一旦方程写成若干因子相乘等于零的形式，由零乘积性质，每个解都对应至少一个因子为零，不会漏掉任何一个解。

除非已知该表达式在整个定义域内都非零，否则应避免用含有未知数的表达式同时除方程两边。一旦看似必须做这样的除法，就必须把除式为零的情形单独分析，因为它本身可能给出一个真正的解。

当方程中含有偶次根式或绝对值时，每一种可行的符号都必须作为候选解保留。只盯着主根或单一符号而不考察另一种可能，是解集不完整的一个常见来源。

把每一个候选解代回原方程，依然是不可或缺的一步，尤其是在两边同时平方之后，或进行任何并非严格可逆的变换之后。这样的检验既能发现非等价变换引入的增根，也能发现沿途可能丢掉的真正解。
