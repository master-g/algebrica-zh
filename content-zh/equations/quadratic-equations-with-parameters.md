## 定义

[二次方程](../quadratic-equations/)通常以其经典形式引入，其中所有系数都是固定的实数。标准表达式是每个二次方程的基本模型：

$$ax^{2} + bx + c = 0$$

二次方程背后的关键概念与[抛物线](../parabola/)的几何性质以及[判别式](../quadratic-formula/)的行为密切相关。这些要素决定了图像如何弯曲、顶点位于何处，以及方程是有两个实数解、一个重根解还是一对[复根](../quadratic-equations-with-complex-solutions/)。

![图 1](/assets/equations/svg/quadratic-equations.zh.svg)

然而在许多情形中，系数并非常数，而是依赖于一个作为参数处理的外部量。数 $a$、$b$ 和 $c$ 成为实参数 $k$ 的函数，方程取更一般的形式：

$$a(k)x^{2} + b(k)x + c(k) = 0, \qquad a(k) \neq 0$$

条件 $a(k) \neq 0$ 防止方程在参数变化时退化为[含参线性方程](../linear-equations-with-parameters/)，确保对所有可取的 $k$ 值保持二次结构。

> 本页聚焦于二次方程情形。关于不同次数的含参方程的更广泛讨论，参见[含参方程](../equations-with-parameters/)。

## 判别式的作用

判别式描述了二次方程的解的行为。当系数依赖于参数时，这一概念不变，但判别式成为该参数的函数。从系数 $a(k)$、$b(k)$ 和 $c(k)$ 出发，得到：

$$\Delta(k) = b(k)^{2} - 4a(k)c(k)$$

在这种形式下，判别式给出了每个 $k$ 值对应的根的变化图景。其符号决定了解的性质：

+ 当 $\Delta(k) > 0$ 时，方程有两个不同的实数解。
+ 当 $\Delta(k) = 0$ 时，方程有一个实数解，表现为二重根。
+ 当 $\Delta(k) < 0$ 时，方程有两个[共轭复数解](../quadratic-equations-with-complex-solutions/)。

## 示例 1

考虑二次方程：

$$x^{2} + kx + 1 = 0$$

本例之所以有用，是因为每个系数都以简单的方式依赖于参数 $k$：

$$a(k) = 1 \qquad b(k) = k \qquad c(k) = 1$$

在标准情形下，判别式为 $\Delta = b^{2} - 4ac$，其符号决定了解的性质。将 $a(k)$、$b(k)$ 和 $c(k)$ 代入同一公式，得：

$$\Delta(k) = b(k)^{2} - 4a(k)c(k)$$

化简得：

$$\Delta(k) = k^{2} - 4$$

为确定何时存在实数解，我们研究[二次不等式](../quadratic-inequalities/)：

$$k^{2} - 4 \ge 0$$

解得两个独立的区间：

$$k \le -2 \quad\text{或}\quad k \ge 2$$

在上述两个区间的内部，判别式为正，二次方程有两个不同的实根；在边界点 $k = \pm 2$ 处，判别式为零，方程有一个二重解。当参数位于区间

$$-2 < k < 2$$

时，判别式为负，方程没有实根，而是产生一对共轭复数解。下表总结了 $k - 2$、$k + 2$ 及其乘积在由临界点 $k = -2$ 和 $k = 2$ 确定的三个区间上的[符号分析](../sign-analysis-in-inequalities/)：

[class="table-sign"]

|                       |        | $-2$ | $2$ |
|:---------------------:|:------:|:----:|:---:|
| $k - 2 > 0$           | $-$    | $-$  | $+$ |
| $k + 2 > 0$           | $-$    | $+$  | $+$ |
| $(k - 2)(k + 2) > 0$  | $+$    | $-$  | $+$ |

[/class]

- - -

当根为实数时，给出其显式表达式是有用的。对该族方程应用求根公式，以闭式给出两个实数解：

$$x = \frac{-k \pm \sqrt{k^{2} - 4}}{2}$$

该表达式展示了每个根如何依赖于参数 $k$，并使我们能够研究当 $k$ 变化时解沿实数轴如何移动。根据以上分析，结论如下：

+ 若 $k < -2$ 或 $k > 2$，方程有两个不同的实数解。
+ 若 $k = \pm 2$，有一个实二重解。
+ 若 $-2 < k < 2$，方程有两个共轭复数解。

## 参数变化的几何解释

继续讨论示例 1 的方程。当参数 $k$ 变化时，考察对应抛物线图像如何变化是有益的。对 $k$ 的每个值，我们关联[抛物线](../parabola/)：

$$y = x^{2} + kx + 1$$

因此分析根等价于研究这条曲线在何处与 $x$ 轴相交。随着参数移动，整个抛物线族平滑地变化，其行为可分为三种情形来描述。

- - -

当 $|k|$ 很大时（$k \to +\infty$ 或 $k \to -\infty$），线性项 $kx$ 占主导地位，两个根相距甚远。简单的[渐近](../asymptotes/)分析表明，一个根趋于 $0$，而另一个根的行为近似于 $-k$。从几何上看，两个交点相距甚远：一个根趋近原点，另一个根沿与参数符号相反的方向远离原点；抛物线的对称轴和顶点随参数移动而变化。

- - -

在临界值 $k = \pm 2$ 处，判别式为零。此时抛物线恰好在一点与 $x$ 轴相切：图像只有一个切点，方程有一个二重根，顶点位于轴上。

- - -

在区间 $-2 < k < 2$ 内，判别式为负，因此方程没有实数解。从几何上看，抛物线完全不与 $x$ 轴相交。由于首项系数为正，抛物线开口向上，在此区域内顶点严格位于 $x$ 轴上方。整条曲线位于轴的一侧，这反映了根进入复平面。

## 示例 2

考虑一个更复杂的含参二次方程：

$$(a + 2)x^{2} + (3a - 1)x + (a - 4) = 0, \qquad a \neq -2$$

其中条件 $a \neq -2$ 确保 $x^{2}$ 的系数不为零，因此对参数的每个允许值，该表达式始终是真正的二次方程。目标是确定对哪些 $a$ 的值，方程有两个不同的实数解。与通常一样，这取决于[判别式](../quadratic-formula/)的符号。为避免与参数 $a$ 混淆，将当前二次方程的系数记为 $A$、$B$、$C$，因此一般公式为：

$$\Delta = B^{2} - 4AC$$

代入当前方程的系数，得到：

$$\Delta(a) = (3a - 1)^{2} - 4(a + 2)(a - 4)$$

- - -

展开两部分，首先计算平方：

$$(3a - 1)^{2} = 9a^{2} - 6a + 1$$

然后计算二次项系数与常数项系数的乘积：

$$(a + 2)(a - 4) = a^{2} - 2a - 8$$

将这些表达式代入判别式并合并同类项，得到简化形式：

$$\Delta(a) = 5a^{2} + 2a + 33$$

- - -

这是关于 $a$ 的二次函数，首项系数为正。为判断它是否能取零或负值，考察其判别式：

$$2^{2} - 4 \cdot 5 \cdot 33 = 4 - 660 < 0$$

由于该值为负，与 $5a^{2} + 2a + 33$ 关联的抛物线不与水平轴相交：对所有实数值 $a$，它恒为正。因此：

$$\Delta(a) > 0 \quad \forall\, a \in \mathbb{R}$$

对参数 $a$ 的每个实数值，方程都有两个不同的实数解，但 $a = -2$ 除外，因为该值会使 $x^{2}$ 的系数为零，从而将表达式降为线性方程。

## 示例 3

考虑含参二次方程：

$$x^{2} - (a - 4)x + (a^{2} - a) = 0$$

其中 $a$ 是实参数。我们要求 $a$ 的取值，使两个解的乘积严格小于 $2$。对于一般的首一二次方程：

$$x^{2} + bx + c = 0$$

两解的乘积满足 $x_{1}x_{2} = c$。

> 这一恒等式来自首一二次多项式的[因式分解形式](../factoring-quadratic-equations/)，其中 $x^{2} + bx + c = (x - x_{1})(x - x_{2})$。展开乘积后，常数项表现为 $x_{1}x_{2}$，因此两解的乘积等于 $c$。

- - -

此处常数项为 $c = a^{2} - a$，要求两解的乘积小于 $2$，得到不等式：

$$a^{2} - a < 2$$

将所有项移到左边，得到：

$$a^{2} - a - 2 < 0$$

左边的二次[多项式](../polynomials/)分解为：

$$a^{2} - a - 2 = (a - 2)(a + 1)$$

因此临界点为 $a = -1$ 和 $a = 2$。为确定表达式的取负区间，我们分析两个因子的符号：

[class="table-sign"]

|                      |     | $-1$ | $2$ |
|:--------------------:|:---:|:----:|:---:|
| $a - 2 > 0$          | $-$ | $-$  | $+$ |
| $a + 1 > 0$          | $-$ | $+$  | $+$ |
| $(a - 2)(a + 1) < 0$ | $+$ | $-$  | $+$ |

[/class]

- - -

符号表显示，当参数位于两根之间时，$(a - 2)(a + 1) < 0$：

$$-1 < a < 2$$

两解的乘积满足 $x_{1}x_{2} < 2$，当且仅当 $-1 < a < 2$。
