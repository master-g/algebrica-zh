## 定义

方程是断言两个表达式取相同值的数学陈述，通常写作 $F(x) = G(x)$，其中一个或多个变量作为未知数在某个指定的[集合](../types-of-numbers/)中取值，例如 $\mathbb{R}$ 或 $\mathbb{C}$。求解方程就是确定在适当的[定义域](../determining-the-domain-of-a-function/)内使等式成立的所有变量值。许多方程可以重新整理成如下形式：

$$F(x) = 0$$

这种表示简化了方程的研究，凸显了其结构，并为不同的求解方法提供了统一的框架。

方程的解是使等式成立的任何变量值。根据方程及其结构，解集合可能包含：

+ 唯一解
+ 多个解
+ 无穷多个解
+ 完全无解

> 在某些情形下，例如三角方程，解集合可以是无限的，因为所涉及的函数是周期性的。

在其他情形下，尤其是多项式、指数或超越方程，解可能不位于实数之中。当没有实数值满足方程时，自然的背景就变成了[复平面](../complex-numbers-introduction/)，在那里解仍然可以存在并被有意义地解释。

一个例子是判别式为负的二次方程，它没有实数根，但总有两个共轭复数解，详见[具有复数解的二次方程](../quadratic-equations-with-complex-solutions/)页面。

## 等价方程与可容许的运算

当两个方程具有相同的解集合时，它们是等价的。求解方程的目标是施加一列保持这种等价性的变换，将方程化简为更简单的形式，使其中的解一目了然。

某些运算保证得到等价方程。在两边加上或减去相同的表达式，或将两边乘以非零常数，不会改变解集合。这些操作构成大多数初等求解方法的基。作为一个例子，方程 $2x + 4 = 0$ 等价于 $x + 2 = 0$，后者由两边除以 $2$ 得到，两个方程都具有唯一的解 $x = -2$。

其他运算可能以不太明显的方式破坏等价性。两边乘以一个含有变量的表达式，当该表达式在 $x$ 的某个值处为零时，可能引入增根。类似地，两边平方——这是[无理方程](../irrational-equations/)的一种常用技巧——可能产生满足变换后的方程但不满足原方程的解。反过来，两边除以一个变量表达式，可能在该表达式为零的点处消去解，这一现象详见[失根](../loss-of-roots/)页面。

## 代数方程

代数方程是指其两边均完全由[多项式](../polynomials/)构成的方程。一元多项式是下列形式的形式表达式：

$$P(x) = a_{n}x^{n} + a_{n-1}x^{n-1} + \cdots + a_{1}x + a_{0}$$

在该表达式中，$n$ 为非负整数，系数 $a_0, a_1, \ldots, a_n$ 属于一个固定的域（通常为 $\mathbb{R}$ 或 $\mathbb{C}$），且当 $n \geq 1$ 时 $a_n \neq 0$。[整数](../integers/) $n$ 为该多项式的次数。代数方程取 $P(x) = Q(x)$ 的形式，或等价地取 $P(x) - Q(x) = 0$，这使问题归结为求单个多项式的根。代数方程按所涉多项式的次数进行分类。

[线性方程](../linear-equations/)的次数为 $1$。变量出现的幂不超过一次，且只要最高次项系数非零，解就是唯一的。

[二次方程](../quadratic-equations/)的次数为 $2$，其标准形式为 $ax^2 + bx + c = 0$，其中 $a \neq 0$。其解的性质由[判别式](../quadratic-formula/) $\Delta = b^2 - 4ac$ 决定。

+ 若 $\Delta > 0$，则有两个不同的实数解。
+ 若 $\Delta = 0$，则有一个实数重根解。
+ 若 $\Delta < 0$，则解为一对共轭复数。

三次方程的次数为 $3$，其一般形式为 $ax^3 + bx^2 + cx + d = 0$。根据[代数学基本定理](../roots-of-a-polynomial/)，每一个次数为 $n$、系数属于 $\mathbb{C}$ 的多项式在 $\mathbb{C}$ 中恰有 $n$ 个根（按重数计算）。因此，三次方程在 $\mathbb{C}$ 中恰有三个根，它们可能全为实数，或为一个实根与两个共轭复根。

次数高于三的方程遵循同样的原理：次数为 $n$ 的[多项式方程](../polynomial-equations/)在 $\mathbb{C}$ 中恰有 $n$ 个根（按重数计算），不过用根式表示根的显式公式仅存在到四次，这一事实由伽罗瓦理论精确阐明。

在高次方程中，[二项式](../binomial-equations/)方程和[三项方程](../trinomial-equations/)值得特别关注。这些是次数大于二、仅含两个或三个不同项的方程，通常可通过换元或因式分解为低次多项式来求解。

## 有理方程

[有理方程](../rational-equations/)至少含有一个分式表达式，其分子与分母均为多项式。其一般形式中两边都涉及多项式之比，且总可化为下列形式：

$$\frac{P(x)}{Q(x)} = 0$$

这是通过将所有项移到一边并在公分母上合并得到的，限制条件为 $Q(x) \neq 0$。一种标准做法是用所有分母的最小公倍数乘两边以消去分母，从而将问题转化为多项式方程。

> 此步骤需谨慎：任何使分母为零的值从一开始就必须从解集合中排除，且消去分母后得到的候选解必须对照这些被排除的值进行检验。

## 无理方程

[无理方程](../irrational-equations/)的变量位于根式内部。典型方程只含一个根式，例如：

$$\sqrt[n]{f(x)} = g(x)$$

其中 $f(x)$ 和 $g(x)$ 是实系数多项式。标准做法是先分离根式，再两边同时 $n$ 次方以消去根式。当方程中含多个根式时，需反复迭代：每一步分离出一个新的根式，重复该过程，直至没有根式残留。每次两边同时取幂时，这种变换都不保等价性，可能引入增解。

因此，必须把每个候选解代回原方程进行检验；根式越多，这一要求就越重要。

## 绝对值方程

[绝对值方程](../absolute-value-equations/)是未知数出现在[绝对值](../absolute-value/)表达式中的方程。最简单的情形形如 $|x| = a$，其中 $a$ 是实常数，解集合完全取决于 $a$ 的符号。

+ 若 $a > 0$，方程恰有两个解 $x = a$ 与 $x = -a$，因为这两个值在实数轴上到原点的距离相同。
+ 若 $a = 0$，唯一解是 $x = 0$，因为实数的绝对值当且仅当该数本身为零时才为零。
+ 若 $a < 0$，方程在 $\mathbb{R}$ 内无解，因为绝对值非负，不可能等于负常数。

> 含多项式或分式表达式的绝对值方程，往往需要根据内部表达式的符号分情况讨论。每一个候选解都必须代回原方程进行检验，因为分情况处理的过程可能引入增解。

## 超越方程

超越方程是指一个或多个变量出现在超越函数中的方程，例如[指数函数](../exponential-function/)、[对数函数](../logarithmic-function/)或[三角函数](../sine-function/)，这些函数无法表示为代数运算的有限组合。这类方程超出了多项式或有理式的形式，常常难以求得闭式解：在许多情形下不存在显式的求根公式，只能借助数值方法逼近。

[对数方程](../logarithmic-equations/)的变量出现在对数表达式中，例如 $2\log_2{(2 - x)^2} = 0$。通常通过对数性质——如幂运算律、积与商的规则、换底公式——来化简表达式并分离出变量。

[指数方程](../exponential-equations/)的变量位于指数表达式中的指数位置。常见形式如 $a^x = b$，其中 $a$ 和 $b$ 是常数，$x$ 是未知数。

[三角方程](../trigonometric-equations/)涉及周期性三角函数，如 $\sin(x)$、$\cos(x)$ 或 $\tan(x)$，其中含变量。由于这些函数具有周期性，三角方程往往有无穷多个解。

## 方程组

当多个方程必须同时由同一组未知数满足时，便得到一个方程组。这样的方程组由涉及相同变量的两个或更多方程组成，其解是同时满足所有方程的取值。

根据方程的形式，方程组可分为[线性](../systems-of-linear-equations/)方程组和非线性方程组。分析它们常常需要超出单一方程求解的技巧。对于含两个未知数的情形，图像法、代入法与消元法见[二元线性方程组](../systems-of-linear-equations-in-two-variables/)；更一般的线性方程组还可使用矩阵方法。
