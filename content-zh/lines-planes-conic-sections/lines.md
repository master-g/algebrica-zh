## 坐标平面中的直线

直线是向两个相反方向无限延伸的点的集合，没有厚度，也没有端点。两个不同的点确定唯一一条直线。在笛卡尔平面上，直线是关于变量 $x$ 和 $y$ 的[一次方程](../linear-equations/)的[解集](../equations/)。

$$ax + by + c = 0$$

系数 $a$、$b$、$c$ 都是[实数](../real-numbers/)，其中 $a$ 和 $b$ 至少有一个不为零。这种形式称为隐式的，因为它没有对任一变量求解。当直线不平行于 $y$ 轴时，其方程可以对 $y$ 求解，写成显式形式：

$$y = mx + q$$

数 $m$ 是斜率，衡量 $y$ 相对于 $x$ 的变化率；$q$ 是 $y$ 截距，即直线与 $y$ 轴交点的纵坐标。这一显式形式是一个二元线性方程。$x$ 截距是使 $y = 0$ 成立的 $x$ 的值，即直线方程的[根](../roots-of-a-polynomial/)。

一个点在直线上的充要条件是它的坐标满足方程，即代入后两边相等。点 $(2, 5)$ 在直线 $y = 2x + 1$ 上，因为 $2(2) + 1 = 5$，方程成立。

隐式形式的系数并不唯一。将 $ax + by + c = 0$ 乘以非零常数 $\lambda$，得到 $\lambda ax + \lambda by + \lambda c = 0$，其解相同。因此，直线只决定 $a$、$b$、$c$ 的比值，而不是它们各自的值。隐式形式也称为直线的一般式。当且仅当 $c = 0$ 时原点属于该直线，因为将 $(0, 0)$ 代入方程后只剩下常数项。过原点的直线的显式方程为 $y = mx$。

## 截距式

一条与两条坐标轴都在非原点处相交的直线，可以用它的截距来表示。设它在 $x$ 轴上的交点为 $(p, 0)$，在 $y$ 轴上的交点为 $(0, q)$，且 $p \ne 0$ 和 $q \ne 0$。其方程为：

$$\frac{x}{p} + \frac{y}{q} = 1$$

$p$ 是 $x$ 截距，$q$ 是 $y$ 截距。代入 $(p, 0)$ 得到 $\frac{p}{p} + \frac{0}{q} = 1$，代入 $(0, q)$ 得到 $\frac{0}{p} + \frac{q}{q} = 1$，因此两个点都满足该方程。这种形式不适用于经过原点的直线——此时 $p$ 和 $q$ 均为零，分母也会为零——也不适用于平行于坐标轴的直线，因为后者只与两条坐标轴之一相交。

举例来说，取一条在 $x$ 轴上的交点为 $(3, 0)$、在 $y$ 轴上的交点为 $(0, 5)$ 的直线。当 $p = 3$ 和 $q = 5$ 时，截距式为：

$$\frac{x}{3} + \frac{y}{5} = 1$$

将两边乘以 $15$ 可消去分母，得到隐式方程 $5x + 3y - 15 = 0$。

## 斜率与倾角

平行于 $y$ 轴的直线是竖直的，其上各点的横坐标都相同。它的方程为：

$$x = k$$

平行于 $x$ 轴的直线是水平的，其上各点的纵坐标都相同。它的方程为：

$$y = k$$

水平直线的斜率为 $0$。竖直直线没有斜率，因为它无法写成 $y = mx + q$ 的形式。

每条非水平直线都与 $x$ 轴相交于一点。直线的[倾角](../angles-and-angular-measure/) $\theta$ 从 $x$ 轴的正方向按逆时针方向量到该直线，取值范围为 $0 \le \theta < \pi$。水平直线的倾角为 $0$。对于非竖直直线，倾角与斜率满足：

$$m = \tan\theta$$

当 $\theta = \pi/2$ 时[正切](../tangent-and-cotangent/)无意义，这恰好对应竖直直线没有斜率这一事实。锐倾角给出正斜率，钝倾角给出负斜率。

象限的平分线是经过原点、倾角分别为 $\pi/4$ 和 $3\pi/4$ 的两条直线。第一条直线斜率为 $1$，方程为 $y = x$，它是坐标相等的点的轨迹，这些点位于第一、三象限。第二条直线斜率为 $-1$，方程为 $y = -x$，其上的点坐标互为相反数，位于第二、四象限。

举例说明，求下列直线的倾角：

$$5x + 2y = 10$$

解出 $y$ 得：

$$y = -\frac{5}{2}x + 5$$

故斜率为：

$$m = -\frac{5}{2}$$

斜率为负，因此倾角为钝角，由 $\tan\theta = -\frac{5}{2}$ 需将[反正切](../arctangent-and-arccotangent/)的主值加上 $\pi$：

$$\theta = \pi + \arctan\left(-\frac{5}{2}\right) \approx \pi - 1.190 \approx 1.951$$

该倾角约为 $1.951$ 弧度，即约 $111.8°$。

## 平行与垂直

斜率分别为 $m_r$ 和 $m_s$ 的两条直线 $r$ 与 $s$，当斜率相等时平行：

$$m_r = m_s$$

当斜率互为负倒数时垂直：

$$m_r = -\frac{1}{m_s}$$

第二个条件等价于 $m_r m_s = -1$，且仅当两条直线都不是竖直或水平直线时适用。

![图 1](/assets/lines-planes-conic-sections/svg/lines-3.zh.svg)

> 平行于 $y$ 轴的直线没有斜率，而平行于 $x$ 轴的直线斜率为 $0$。这两条直线相互垂直，是上述斜率条件未涵盖的情形。

相应的隐式条件也适用于竖直直线。设直线 $r$ 的方程为 $ax + by + c = 0$，直线 $s$ 的方程为 $a'x + b'y + c' = 0$。当 $b$ 与 $b'$ 非零时，斜率分别为 $m_r = -a/b$ 与 $m_s = -a'/b'$，在 $m_r = m_s$ 中消去分母可得：

$$ab' - a'b = 0$$

当 $b$ 或 $b'$ 为零时该条件仍然成立，并且恰好表示两条直线具有相同方向，也包括重合直线。类似代入可得：

$$aa' + bb' = 0$$

左端是法向量 $(a,b)$ 与 $(a',b')$ 的[点积](../vectors/)。前一条注释中的竖直线与水平线满足这一条件：$x = k$ 的 $a = 1$、$b = 0$，而 $y = k$ 的 $a' = 0$、$b' = 1$。

每个条件在给定一点后都确定一条直线。过点 $P(x_P, y_P)$ 且平行于 $r: y = m_r x + q_r$ 的直线斜率为 $m_r$，因此其方程可写成 $y = m_r x + q$，其中 $q$ 尚待确定。要求 $P$ 满足该方程，得到 $y_P = m_r x_P + q$，所以：

$$q = y_P - m_r x_P$$

当 $m_r \ne 0$ 时，过 $P$ 的垂线斜率为 $-1/m_r$。当 $m_r = 0$ 时，垂线是竖直直线 $x = x_P$。

例如，取方程为 $2x + 3y - 6 = 0$ 的直线 $r$ 以及点 $P(4, -1)$。解出 $y$ 得 $y = -\frac{2}{3}x + 2$，所以 $m_r = -\frac{2}{3}$。过 $P$ 的平行线具有相同斜率，其截距为 $q = -1 + \frac{2}{3}(4) = \frac{5}{3}$，方程为：

$$y = -\frac{2}{3}x + \frac{5}{3}$$

消去分母得到隐式形式 $2x + 3y - 5 = 0$。过 $P$ 的垂线斜率为 $\frac{3}{2}$，截距为 $q = -1 - \frac{3}{2}(4) = -7$，所以其方程为：

$$y = \frac{3}{2}x - 7$$

消去分母后得到 $3x - 2y - 14 = 0$。其系数满足条件 $aa' + bb' = 2(3) + 3(-2) = 0$。

## 两条直线的夹角

平面内两条不同的直线要么平行，要么相交。平行线的夹角为 $0$。相交直线形成两对对顶角，两直线的夹角取其中较小者，因此介于 $0$ 与 $\pi/2$ 之间。

![图 2](/assets/lines-planes-conic-sections/svg/lines-2.zh.svg)

若两条非竖直直线的倾角为 $\theta_1$ 和 $\theta_2$，且 $\theta_1 \le \theta_2$，令 $\varphi = \theta_2 - \theta_1$。对[角的差](../trigonometric-identities/)应用正切公式：

$$\tan\varphi = \tan(\theta_2 - \theta_1) = \frac{\tan\theta_2 - \tan\theta_1}{1 + \tan\theta_1\tan\theta_2}$$

当 $\varphi \ne \pi/2$ 时，较小的角 $\theta$ 的正切为 $|\tan\varphi|$。将其他正切替换为相应的斜率可得：

$$\tan\theta = \left|\frac{m_2 - m_1}{1 + m_1 m_2}\right|$$

[绝对值](../absolute-value/)保证右端非负，符合较小角的要求。当 $m_1 = m_2$ 时分子为零且 $\theta = 0$，两条直线平行。当 $1 + m_1 m_2 = 0$ 时表达式无定义且 $\theta = \pi/2$，两条直线垂直，并且 $m_1 m_2 = -1$。

例如，求直线 $2x - y - 4 = 0$ 与 $3x + 4y - 12 = 0$ 的夹角。它们的斜率分别为 $m_1 = 2$ 与 $m_2 = -3/4$，因此夹角的正切为：

$$\tan\theta = \left|\frac{-\frac{3}{4} - 2}{1 + 2\left(-\frac{3}{4}\right)}\right| = \left|\frac{-\frac{11}{4}}{-\frac{1}{2}}\right| = \frac{11}{2}$$

夹角为 $\theta = \arctan\frac{11}{2} \approx 1.391$ 弧度，约 $79.70°$。

## 过两点的直线

考虑过两点 $P(x_P, y_P)$ 和 $Q(x_Q, y_Q)$ 的直线。当 $x_P = x_Q$ 时，两点横坐标相同，直线平行于 $y$ 轴，其方程为：

$$x = x_P$$

当 $x_P \ne x_Q$ 时，直线的斜率为：

$$m = \frac{y_Q - y_P}{x_Q - x_P}$$

利用此斜率及点 $P$，点斜式方程为：

$$y - y_P = m(x - x_P)$$

将 $m$ 作为自由参数时，点斜式 $y - y_P = m(x - x_P)$ 描述了过 $P$ 的直线束，即经过该点的所有直线族。$m$ 的每个取值给出一个非竖直成员，竖直直线 $x = x_P$ 补全该族。若 $m$ 取上面求得的斜率，对应成员还经过 $Q$。该直线束称为真直线束，$P$ 是它的中心。

保持斜率不变而让点变化，可以得到第二个族。若 $q$ 为自由参数且 $m$ 固定，方程 $y = mx + q$ 描述所有斜率为 $m$ 的直线，它们彼此平行。这个族是方向为 $m$ 的非真直线束。平面上的每一点恰好位于其中一条成员上，正如真直线束对每个给定斜率恰好有一条成员。

在斜率公式与点斜式之间消去 $m$，可得到对称式：

$$\frac{y - y_P}{y_Q - y_P} = \frac{x - x_P}{x_Q - x_P}$$

在退化情形下，两个分母之一会为零：两点纵坐标相同时左侧分母为零，横坐标相同时右侧分母为零。交叉相乘可得无分母的方程：

$$(y - y_P)(x_Q - x_P) = (y_Q - y_P)(x - x_P)$$

该方程对任意两个不同的点都成立。当 $x_P = x_Q$ 时左端恒为零，而 $y_Q \ne y_P$，于是方程化为开头得到的竖直直线 $x = x_P$。当 $y_P = y_Q$ 时，对右端作同样的论证可得 $y = y_P$。

例如，求过 $P(1, 2)$ 和 $Q(3, 6)$ 的直线的方程。斜率等于纵坐标之差与横坐标之差的比：

$$m = \frac{y_Q - y_P}{x_Q - x_P} = \frac{6 - 2}{3 - 1} = \frac{4}{2} = 2$$

斜率为 $2$，取点 $P(1, 2)$，由点斜式得：

$$y - 2 = 2(x - 1)$$

展开并化简，得到显式式：

$$y = 2x - 2 + 2 = 2x$$

过 $P(1, 2)$ 和 $Q(3, 6)$ 的直线方程为 $y = 2x$。

同一直线还有基于一点和方向向量（而非斜率）的[向量与参数描述](../vector-and-parametric-equations-of-a-line/)。对于这条直线，方向向量为 $Q - P = (2, 4)$，与该直线平行。

三点共线，是指存在一条直线同时包含这三点。任取其中两点即可确定一条直线，因此只需检验第三点是否满足该方程。设 $A(-2, -3)$、$B(1, 3)$、$C(3, 7)$。过 $A$、$B$ 的直线斜率为：

$$m = \frac{3 - (-3)}{1 - (-2)} = \frac{6}{3} = 2$$

点斜式给出 $y + 3 = 2(x + 2)$，即 $y = 2x + 1$。代入 $C$ 的横坐标得到 $2(3) + 1 = 7$，正是 $C$ 的纵坐标，所以三点共线。当三点横坐标各不相同时，也可用斜率作同样检验：恰当且仅当 $m_{AB} = m_{AC}$ 时三点共线。

将过 $A$、$B$ 的直线的无分母方程代入第三点，可得 $(y_C - y_A)(x_B - x_A) = (y_B - y_A)(x_C - x_A)$。这等价于如下[行列式](../determinant/)为零：

$$
\det\begin{pmatrix}
x_A & y_A & 1 \\[6pt]
x_B & y_B & 1 \\[6pt]
x_C & y_C & 1
\end{pmatrix} = 0
$$

每一行包含一个点的坐标及其后的 $1$，因此判据与点的列举顺序无关，也包含竖直直线的情形。对 $A(-2, -3)$、$B(1, 3)$、$C(3, 7)$ 沿第一行展开，得到 $-2(3 - 7) + 3(1 - 3) + (7 - 9) = 8 - 6 - 2 = 0$。

## 点到直线的距离

点 $P(x_P, y_P)$ 到方程为 $ax + by + c = 0$ 的直线 $r$ 的距离，是从该点向直线作垂线时，$P$ 到垂足的线段长度。该距离为：

$$d = \frac{\left|ax_P + by_P + c\right|}{\sqrt{a^2 + b^2}}$$

系数 $a$、$b$、$c$ 是隐式形式 $ax + by + c = 0$ 中的系数，因此在代入 $P$ 的坐标之前，必须先将直线写成这一形式。

![图 3](/assets/lines-planes-conic-sections/svg/lines-1.zh.svg)

分母 $\sqrt{a^2+b^2}$ 是直线法向量 $\mathbf{n}=(a,b)$ 的长度，由[勾股定理](../pythagorean-theorem/)给出。除以这个量使表达式归一化，从而使距离不依赖于写出直线方程所用的系数。

将隐式方程本身除以 $\pm\sqrt{a^2+b^2}$，并选择符号使常数项非正，可将直线改写为法线式：

$$x\cos\alpha + y\sin\alpha = p$$

$x$ 和 $y$ 的系数是 $\alpha$ 的[余弦与正弦](../sine-and-cosine/)，因此它们是单位法向量 $(\cos\alpha,\sin\alpha)$ 的分量。角 $\alpha$ 从 $x$ 轴正方向量到该法向量。常数 $p\ge0$ 是原点到直线的距离。在 $P=(0,0)$ 处，距离公式给出 $d=|c|/\sqrt{a^2+b^2}$。

当 $p>0$ 时，非正的常数项确定除数的符号。此时单位法向量唯一，$\alpha$ 在模 $2\pi$ 的意义下确定，因此 $(\alpha, p)$ 唯一标识一条直线。经过原点的直线满足 $p=0$，所以两个相反的单位法向量都可取，$\alpha$ 只在模 $\pi$ 的意义下确定。

例如，求点 $(4, 1)$ 到直线 $y = x - 1$ 的距离。将直线写成隐式形式得 $x - y - 1 = 0$，因此 $a = 1$、$b = -1$、$c = -1$。代入该点的坐标得：

$$d = \frac{\left|1(4) - 1 - 1\right|}{\sqrt{1^2 + (-1)^2}} = \frac{2}{\sqrt{2}} = \sqrt{2} \approx 1.41$$

该点到直线约 $1.41$ 个单位。

## 两条直线的交点

两条直线的公共点，是由它们的方程构成的[二元线性方程组](../systems-of-linear-equations-in-two-variables/)的解。方程组可能有一个、零个或无穷多个解。斜率不同的两条直线相交于一点，方程组有一个解。斜率相同的两条直线在截距不同时没有公共点，方程组无解。当截距也相同时，两个方程描述同一条直线，其每个点都是方程组的解，两条直线重合。

![图 4](/assets/lines-planes-conic-sections/svg/lines-4.svg)

隐式形式给出了不排除竖直直线的同样分类。设 $r: ax + by + c = 0$、$s: a'x + b'y + c' = 0$，当 $ab' - a'b \ne 0$ 时，方程组恰有一个解。当该量为零时，两条直线方向相同，剩余情形由常数项区分。若三元组 $(a, b, c)$ 与 $(a', b', c')$ 不成比例，两条直线平行且不重合；若它们成比例，两个方程相差一个非零因子，描述同一条直线。当所有系数都非零时，三种情形为：

$$\frac{a}{a'} \ne \frac{b}{b'} \qquad \frac{a}{a'} = \frac{b}{b'} \ne \frac{c}{c'} \qquad \frac{a}{a'} = \frac{b}{b'} = \frac{c}{c'}$$

直线 $x - 2y + 3 = 0$ 与 $x - 2y - 1 = 0$ 属于第二种情形，因为只有常数项不同。将第一条直线乘以 $-2$ 得 $-2x + 4y - 6 = 0$，其系数与第一条成比例，因此属于第三种情形，描述同一条直线。

例如，考虑直线 $y = x + 2$ 与 $y = -2x + 8$。它们斜率不同，因此相交于一点，可通过求解下列方程组得到：

$$
\begin{cases}
y = x + 2 \\[6pt]
y = -2x + 8
\end{cases}
$$

令两个等式的右端相等，消去 $y$，得到关于 $x$ 的方程：

$$
\begin{align}
x + 2 &= -2x + 8 \\[6pt]
3x &= 6 \\[6pt]
x &= 2
\end{align}
$$

将 $x = 2$ 代入第一个方程，得到 $y = 2 + 2 = 4$。两条直线相交于点 $(2, 4)$。
