## 坐标平面中的直线

直线是向两个相反方向无限延伸的点的集合，没有厚度，也没有端点。两个不同的点确定唯一一条直线。在笛卡尔平面上，直线是关于变量 $x$ 和 $y$ 的[一次方程](../linear-equations/)的解集。其隐式形式为：

$$ax + by + c = 0$$

系数 $a$、$b$、$c$ 都是[实数](../real-numbers/)，其中 $a$ 和 $b$ 至少有一个不为零。这种形式称为隐式的，因为它没有对任一变量求解。当直线不平行于 $y$ 轴时，其方程可以对 $y$ 求解，写成显式形式：

$$y = mx + q$$

数 $m$ 是斜率，衡量 $y$ 相对于 $x$ 的变化率；$q$ 是 $y$ 截距，即直线与 $y$ 轴交点的纵坐标。这一显式形式是二元[线性方程](../linear-equations/)。$x$ 截距是使 $y = 0$ 成立的 $x$ 的值，即直线方程的根。

一个点在直线上的充要条件是它的坐标满足方程，即代入后两边相等。点 $(2, 5)$ 在直线 $y = 2x + 1$ 上，因为 $2(2) + 1 = 5$，方程成立。

## 截距式

一条与两条坐标轴都在非原点处相交的直线，可以用它的截距来表示。设它在 $x$ 轴上的交点为 $(p, 0)$，在 $y$ 轴上的交点为 $(0, q)$，且 $p \ne 0$ 和 $q \ne 0$。其方程为：

$$\frac{x}{p} + \frac{y}{q} = 1$$

$p$ 是 $x$ 截距，$q$ 是 $y$ 截距。代入 $(p, 0)$ 得到 $\frac{p}{p} + \frac{0}{q} = 1$，代入 $(0, q)$ 得到 $\frac{0}{p} + \frac{q}{q} = 1$，因此两个点都满足该方程。这种形式排除了经过原点的直线——此时 $p$ 和 $q$ 均为零，分母为零——以及平行于坐标轴的直线，因为后者只与两条坐标轴之一相交。

举例来说，取一条在 $x$ 轴上的交点为 $(3, 0)$、在 $y$ 轴上的交点为 $(0, 5)$ 的直线。当 $p = 3$ 和 $q = 5$ 时，截距式为：

$$\frac{x}{3} + \frac{y}{5} = 1$$

将两边乘以 $15$ 可消去分母，得到隐式方程 $5x + 3y - 15 = 0$。

## 斜率与倾角

平行于 $y$ 轴的直线是竖直的，其上各点的横坐标都相同。它的方程为：

$$x = k$$

平行于 $x$ 轴的直线是水平的，其上各点的纵坐标都相同。它的方程为：

$$y = k$$

水平直线的斜率为 $0$。竖直直线没有斜率，因为它无法写成 $y = mx + q$ 的形式。

每条非水平直线都与 $x$ 轴相交于一点。直线的[倾角](../angles-and-angular-measure/) $\theta$ 从 $x$ 轴的正方向按逆时针方向量到该直线，取值范围为 $0 \le \theta < \pi$。水平直线的倾角为 $0$。对于非竖直直线，倾角与斜率满足：

$$m = \tan\theta$$

当 $\theta = \pi/2$ 时[正切](../tangent-and-cotangent/)无意义，这恰好对应竖直直线没有斜率这一事实。锐倾角给出正斜率，钝倾角给出负斜率。举例说明，求下列直线的倾角：

$$5x + 2y = 10$$

解出 $y$ 得：

$$y = -\frac{5}{2}x + 5$$

故斜率为：

$$m = -\frac{5}{2}$$

斜率为负，因此倾角为钝角，由 $\tan\theta = -\frac{5}{2}$ 需将[反正切](../arctangent-and-arccotangent/)的主值加上 $\pi$：

$$\theta = \pi + \arctan\left(-\frac{5}{2}\right) \approx \pi - 1.190 \approx 1.951$$

该倾角约为 $1.951$ 弧度，即约 $111.8°$。

## 平行与垂直

斜率分别为 $m_r$ 和 $m_s$ 的两条直线 $r$ 与 $s$，当斜率相等时平行：

$$m_r = m_s$$

当斜率互为负倒数时垂直：

$$m_r = -\frac{1}{m_s}$$

第二个条件等价于 $m_r m_s = -1$，且要求两条直线都不为竖直直线。

![图 1](/assets/lines-planes-conic-sections/svg/lines-3.zh.svg)

> 平行于 $y$ 轴的直线没有斜率，而平行于 $x$ 轴的直线斜率为 $0$。这两条直线相互垂直，这种情况直接处理即可，无需套用上述斜率条件。

## 两条直线的夹角

平面内两条不同的直线要么平行，要么相交。当它们相交且不垂直时，它们形成两对对顶角，一对为锐角，一对为钝角。这两条直线的夹角取其中较小的角，因此它介于 $0$ 与 $\pi/2$ 之间。

![图 2](/assets/lines-planes-conic-sections/svg/lines-2.zh.svg)

若这两条直线的倾角分别为 $\theta_1$ 与 $\theta_2$，且 $\theta_1 < \theta_2$，令倾角差为 $\Delta = \theta_2 - \theta_1$。两直线的夹角是该差与其补角中的较小者。先对倾角差应用[角的差](../trigonometric-identities/)的正切公式：

$$\tan\Delta = \tan(\theta_2 - \theta_1) = \frac{\tan\theta_2 - \tan\theta_1}{1 + \tan\theta_1\tan\theta_2}$$

将每个正切替换为相应的斜率，便得到用斜率 $m_1$ 与 $m_2$ 表示的夹角：

$$\tan\theta = \left|\frac{m_2 - m_1}{1 + m_1 m_2}\right|$$

[绝对值](../absolute-value/)使倾角差为钝角时改取其补角，从而得到两直线间较小的角。当 $m_1 = m_2$ 时分子为零且 $\theta = 0$，两条直线平行。当 $1 + m_1 m_2 = 0$ 时该表达式无意义且 $\theta = \pi/2$，两条直线垂直，由此回到条件 $m_1 m_2 = -1$。

作为一个例子，求直线 $2x - y - 4 = 0$ 与 $3x + 4y - 12 = 0$ 的夹角。它们的斜率分别为 $m_1 = 2$ 与 $m_2 = -3/4$，因此它们夹角的正切为：

$$\tan\theta = \left|\frac{-\frac{3}{4} - 2}{1 + 2\left(-\frac{3}{4}\right)}\right| = \left|\frac{-\frac{11}{4}}{-\frac{1}{2}}\right| = \frac{11}{2}$$

该夹角为 $\theta = \arctan\frac{11}{2} \approx 1.391$ 弧度，约 $79.70°$。

## 过两点的直线

考虑过两点 $P(x_P, y_P)$ 和 $Q(x_Q, y_Q)$ 的直线。当 $x_P = x_Q$ 时，两点横坐标相同，直线平行于 $y$ 轴，其方程为：

$$x = x_P$$

当 $x_P \ne x_Q$ 时，直线的斜率为：

$$m = \frac{y_Q - y_P}{x_Q - x_P}$$

利用此斜率及点 $P$，点斜式方程为：

$$y - y_P = m(x - x_P)$$

以 $m$ 为自由参数来读，点斜式 $y - y_P = m(x - x_P)$ 描述了过 $P$ 的直线束，即所有共享该点的直线族。$m$ 的每个取值给出一个非竖直成员，竖直线 $x = x_P$ 补全该族。将 $m$ 固定为上述所确定的斜率，便选定唯一一条同时经过 $Q$ 的成员。

在斜率公式与点斜式之间消去 $m$ 并交叉相乘，可得到无需除以坐标差的两点式。它适用于任意两个不同点，包括水平直线和竖直直线：

$$(y-y_P)(x_Q-x_P)=(x-x_P)(y_Q-y_P)$$

作为一个例子，求过 $P(1, 2)$ 和 $Q(3, 6)$ 的直线的方程。斜率等于纵坐标之差与横坐标之差的比：

$$m = \frac{y_Q - y_P}{x_Q - x_P} = \frac{6 - 2}{3 - 1} = \frac{4}{2} = 2$$

斜率为 $2$，取点 $P(1, 2)$，由点斜式得：

$$y - 2 = 2(x - 1)$$

展开并化简，得到显式：

$$y = 2x - 2 + 2 = 2x$$

过 $P(1, 2)$ 和 $Q(3, 6)$ 的直线，其方程为 $y = 2x$。

同一直线有一个[向量与参数描述](../vector-and-parametric-equations-of-a-line/)，它由直线上的一点和一个方向向量（而非斜率）构建而成。对于这条直线，方向向量为 $Q - P = (2, 4)$，与该直线平行。

## 点到直线的距离

点 $P(x_P, y_P)$ 到方程为 $ax + by + c = 0$ 的直线 $r$ 的距离，是连接 $P$ 与从 $P$ 向该直线所引垂线之垂足的线段长度。这是点到直线的最短距离，计算公式为：

$$d = \frac{\left|ax_P + by_P + c\right|}{\sqrt{a^2 + b^2}}$$

系数 $a$、$b$、$c$ 是隐式形式 $ax + by + c = 0$ 中的系数，因此在代入 $P$ 的坐标之前，必须先将直线写成这一形式。

![图 3](/assets/lines-planes-conic-sections/svg/lines-1.zh.svg)

分母 $\sqrt{a^2+b^2}$ 是直线法向量 $\mathbf{n}=(a,b)$ 的长度，由[勾股定理](../pythagorean-theorem/)给出。除以这个量使表达式归一化，从而使距离不依赖于写出直线方程所用的系数。

将隐式方程本身除以 $\pm\sqrt{a^2+b^2}$（符号选取使常数项非正），可将直线改写为法线式：

$$x\cos\alpha + y\sin\alpha = p$$

$x$ 和 $y$ 的系数现在是单位法向量 $(\cos\alpha,\sin\alpha)$ 的分量，因此 $\alpha$ 是该法向量与 $x$ 轴正方向之间的夹角。常数 $p\ge0$ 是原点到直线的距离，即距离公式在 $P=(0,0)$ 处的返回值，此时它简化为 $d=|c|/\sqrt{a^2+b^2}$。

举例来说，求点 $(4, 1)$ 到直线 $y = x - 1$ 的距离。将直线写成隐式形式得 $x - y - 1 = 0$，因此 $a = 1$、$b = -1$、$c = -1$。代入该点的坐标得：

$$d = \frac{\left|1(4) - 1 - 1\right|}{\sqrt{1^2 + (-1)^2}} = \frac{2}{\sqrt{2}} = \sqrt{2} \approx 1.41$$

该点到直线约 $1.41$ 个单位。

## 两条直线的交点

斜率相等的两条直线相互平行，永不相交。斜率不同的两条直线相交于一个点，该点的坐标是由两个方程组成的[方程组](../systems-of-linear-equations/)的解。

举例来说，考虑直线 $y = x + 2$ 和 $y = -2x + 8$。它们的斜率不同，因此相交于一点，该点通过求解以下方程组得到：

$$
\begin{cases}
y = x + 2 \\[6pt]
y = -2x + 8
\end{cases}
$$

令两个等式的右边相等，消去 $y$，得到关于 $x$ 的方程：

$$
\begin{align}
x + 2 &= -2x + 8 \\[6pt]
3x &= 6 \\[6pt]
x &= 2
\end{align}
$$

将 $x = 2$ 代入第一个方程，得到 $y = 2 + 2 = 4$。两条直线相交于点 $(2, 4)$。
