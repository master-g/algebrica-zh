## 圆锥曲线简介

在介绍[抛物线](../parabola/)时，我们看到[平面](../planes/)与圆锥相交所得的截线投影到平面后，会形成四种曲线之一：圆周、抛物线、[椭圆](../ellipse/)或[双曲线](../hyperbola/)。这四种曲线统称为圆锥曲线。圆锥曲线是平面上的二次代数曲线，由所有坐标满足关于变量 $x$ 和 $y$ 的一般二次方程的点 $(x, y) \in \mathbb{R}^2$ 构成。该[方程](../equations/)具有如下形式：

$$f(x, y) = a_{11}x^2 + 2a_{12}xy + a_{22}y^2 + 2a_{13}x + 2a_{23}y + a_{33} = 0$$

+ 系数 $a_{ij}$ 为实数。
+ 混合项和一次项前面的因子 $2$ 是一种约定选择，用于简化圆锥曲线的矩阵表示。

要使该方程描述二次曲线，$a_{11}$、$a_{12}$ 和 $a_{22}$ 中至少有一个必须非零；否则该表达式退化为[线性方程](../linear-equations/)，轨迹退化为一条直线。

- - -

所得到的圆锥曲线的具体类型取决于这些系数的相对取值，特别是与二次部分相关的[判别式](../quadratic-formula/)的符号。圆周对应于最简单且最对称的情形，其中 $x^2$ 和 $y^2$ 的系数相等，且混合项 $a_{12}xy$ 为零。

![图 1](/assets/lines-planes-conic-sections/svg/circumference-1.zh.svg)

这种代数对称性源于平面与圆锥相交的方式。当截平面垂直于圆锥的轴线时，所得截面为圆周，其上的所有点到该轴线的距离都相等。任何偏离垂直的情况都会破坏两个二次系数之间的对称性，从而产生其他圆锥曲线之一。

## 什么是圆周

给定平面内一点 $C$（称为圆心），圆周定义为平面上所有到 $C$ 距离相等的点的集合。考虑圆周 $\Gamma$，其圆心为 $C$，半径为 $r$。对于属于 $\Gamma$ 的每一个点 $P$，以下关系成立：

$$d(P, C) = r \qquad r \in \mathbb{R},\ r > 0$$

![图 2](/assets/lines-planes-conic-sections/svg/circumference-2.zh.svg)

设 $C = (x_0, y_0)$ 为圆心的坐标，$P = (x, y)$ 为圆周上的一般点。利用平面上两点间的距离公式，条件 $d(P, C) = r$ 变为：

$$\sqrt{(x - x_0)^2 + (y - y_0)^2} = r$$

由于两边均为非负，平方不会引入增根，于是我们得到圆周方程的标准形式：

$$(x - x_0)^2 + (y - y_0)^2 = r^2$$

展开两个二项式的平方，得到：

$$x^2 - 2xx_0 + x_0^2 + y^2 - 2yy_0 + y_0^2 = r^2$$

将所有项移到等式左边，并引入以下代换：

$$
\begin{align}
a &= -2x_0 \\[6pt]
b &= -2y_0 \\[6pt]
c &= x_0^2 + y_0^2 - r^2
\end{align}
$$

采用这组系数，方程取紧凑形式，即圆周方程的一般形式：

$$x^2 + y^2 + ax + by + c = 0$$

## 由一般式确定圆心与半径

在一般式 $x^2 + y^2 + ax + by + c = 0$ 中，圆心和半径并不像在标准式中那样直接出现。给定系数 $a$、$b$ 和 $c$，我们可以直接求出圆心和半径，并确定该方程表示圆周的条件。我们将一般式与之前得到的系数进行比较：

$$
\begin{align}
a &= -2x_0 \\[6pt]
b &= -2y_0 \\[6pt]
c &= x_0^2 + y_0^2 - r^2
\end{align}
$$

前两个关系式立即给出圆心的坐标：

$$x_0 = -\frac{a}{2} \qquad y_0 = -\frac{b}{2}$$

将这些值代入第三个关系式并求解 $r^2$，可得：

$$r^2 = \frac{a^2}{4} + \frac{b^2}{4} - c$$

由于 $r$ 是一个长度，它必须是非负实数，因此上述方程的右端不能为负。我们将右端记为 $\rho$：

$$\rho = \frac{a^2}{4} + \frac{b^2}{4} - c$$

方程 $x^2 + y^2 + ax + by + c = 0$ 所描述的轨迹的性质完全取决于 $\rho$ 的符号，由此产生三种不同情形。

+ 当 $\rho > 0$ 时，方程表示一个真正的圆周，圆心为 $\left(-\frac{a}{2}, -\frac{b}{2}\right)$，半径为 $r = \sqrt{\rho}$。这是唯一使轨迹成为平面上一条真实曲线的情形。

+ 当取值 $\rho = 0$ 时，半径退化为零，因此方程仅被唯一点 $\left(-\frac{a}{2}, -\frac{b}{2}\right)$ 满足。轨迹退化为一个点，有时称为零半径的退化圆周。

+ 当 $\rho$ 为负时，不存在满足该方程的实数对 $(x, y)$，因为两个平方数之和不可能等于负值。此时轨迹为空，该方程虽然在形式上仍是二次的，却并不描述平面上的任何真实曲线。

因此，条件 $\rho > 0$ 就是以一般式表示的实圆周的存在条件。只要该条件成立，就可以通过配方法将方程 $x^2 + y^2 + ax + by + c = 0$ 还原为标准式，从而直接由上述公式读出圆心和半径。

## 圆盘与圆周

「圆盘」和「圆周」这两个术语常常被混用，但它们指的是两个不同的对象。

+ 圆周是由平面上所有到某一定点（称为圆心）距离相等的点所构成的曲线。它是一个一维对象，一条没有内部的封闭曲线。
+ 圆盘是被一条圆周所围成的平面区域，包含其内部的所有点。它是一个二维对象，一个面。
+ 半径为 $r$ 的圆周的长度为 $L = 2\pi r$，其中 $\pi$ 是任意圆周的长度与其直径之比。
+ 半径为 $r$ 的圆盘的面积为 $A = \pi r^2$。圆周是一条曲线，没有面积，因此「圆周的面积」这一说法没有意义。

## 半径、弦、直径与圆盘

圆周有几个基本要素，它们都是根据圆心和圆周上的点来定义的。

![图 3](/assets/lines-planes-conic-sections/svg/circumference-3.zh.svg)

+ 半径是连接圆心与圆周上任意一点的[线段](../lines/)。
+ 弦是两端点都位于圆周上的线段。
+ 直径是经过圆心的弦；因此它是最长的弦，其长度恰好是半径的两倍。
+ 圆盘是包含圆周上所有点及其内部所有点的集合。

- - -

在这些要素中，弦的长度可以用半径和它在圆心处所张的角直接表示。若 $\theta$ 表示弦所张的圆心角（以[弧度](../angles-and-angular-measure/)为单位），则弦的长度 $c$ 由下面的公式给出，该公式涉及[正弦函数](../sine-function/)：

$$c = 2r\sin\left(\frac{\theta}{2}\right)$$

![图 4](/assets/lines-planes-conic-sections/svg/circumference-4.zh.svg)

弦连同连接其两端点与圆心的两条半径，构成一个顶角为 $\theta$ 的等腰三角形，而表达式 $2r\sin(\theta/2)$ 正是该三角形底边的长度。

## 弧与扇形

弧是由圆周上的两个点所界定的部分。弦的两个端点将圆周分成两段弧，这两段弧都称为该弦所对的弧。

![图 5](/assets/lines-planes-conic-sections/svg/circumference-5.zh.svg)

若 $\theta$ 表示该弧所对应的圆心角（以弧度为单位），$r$ 表示圆周的半径，并以字母 s 表示弧长，则：

$$s = r\theta$$

- - -

扇形是圆盘的一部分，由一段弧以及连接圆心与该弧两个端点的两条半径所围成。采用相同的记号，扇形的面积 $A$ 由以下公式给出：

$$A = \frac{1}{2}r^2\theta$$

![图 6](/assets/lines-planes-conic-sections/svg/circumference-6.zh.svg)

## 圆周长度

两点之间的距离度量的是直线段的长度，因此它本身并不能赋予曲线以长度。圆周的长度通过[极限过程](../limits/)来定义：在圆周内接一个正 $n$ 边形，测量该多边形的周长，再令 $n \to \infty$。随着 $n$ 增大，多边形的顶点沿着曲线分布得越来越稠密，周长趋近于一个有限值，该值即取为圆周的长度。

弦长公式将这一极限显式化。在半径为 $r$ 的圆周中，一个具有 $n$ 条边的正多边形有 $n$ 条相等的弦，每条弦所对的圆心角为 $2\pi/n$。在弦长公式中令 $\theta = 2\pi/n$，则每条边的长度为 $2r\sin(\pi/n)$，于是内接多边形的周长为：

$$p_n = 2nr\sin\left(\frac{\pi}{n}\right)$$

为求 $n \to \infty$ 时的极限，令 $x = \pi/n$，则 $n = \pi/x$ 且 $x \to 0$。周长化为：

$$p_n = 2\pi r\cdot\frac{\sin x}{x}$$

当 $x \to 0$ 时，比值 $\sin(x)/x$ 趋于 $1$，这是[重要极限](../remarkable-limits/)之一，于是周长收敛到：

$$L = \lim_{n \to \infty} 2nr\sin\left(\frac{\pi}{n}\right) = 2\pi r$$

半径为 $r$ 的圆周的长度因而为 $L = 2\pi r$，等价地用直径 $d = 2r$ 表示则为 $L = \pi d$。常数 $\pi$ 是圆周长度与其直径之比 $L/d$，对一切圆周取相同的值，与半径无关。它的小数展开以 $3.14159\ldots$ 开头，且不会终止。

> 阿基米德通过用一个内接正多边形与一个外切正多边形将圆周夹在中间，并比较二者的周长，来估计 $\pi$ 的值。他使用 $96$ 边形，得到了界 $3 + \frac{10}{71} < \pi < 3 + \frac{1}{7}$，这是该常数的第一个严格数值估计。

由弧长公式同样可得此值。完整圆周对应于 $2\pi$ 的圆心角，因此将 $\theta = 2\pi$ 代入 $s = r\theta$ 即得 $2\pi r$，与上面算得的极限结果一致。

## 例题一

对于以原点为中心、半径为 $r = 1$ 的圆周，将 $x_0 = 0$、$y_0 = 0$、$r = 1$ 代入标准形式 $(x - x_0)^2 + (y - y_0)^2 = r^2$，可得：

$$x^2 + y^2 = 1$$

为了用一般形式表示同一个圆周，我们将这个方程与下式比较：

$$x^2 + y^2 + ax + by + c = 0$$

直接观察可得各系数为：

$$a = 0 \qquad b = 0 \qquad c = -1$$

因此，单位圆周的一般形式方程为：

$$x^2 + y^2 - 1 = 0$$

这个方程与[单位圆](../unit-circle/)的方程一致，后者在三角学中用于定义一个角的正弦与余弦。

## 圆周与直线

一条直线相对于圆周的位置，取决于该直线与圆心之间的距离。一条[直线](../lines/)可被归类为割线、切线或相离直线。若记 $D$ 为圆心到直线的距离，$r$ 为半径，则这三种情形互斥且穷尽所有可能。

![图 7](/assets/lines-planes-conic-sections/svg/circumference-7.zh.svg)

当直线与圆周交于两个不同点时，直线为割线，对应 $D < r$。随着直线远离圆心，两个交点逐渐靠近；当 $D = r$ 时，二者合并为单一接触点，此时直线为切线。一旦 $D > r$，直线便不再触及曲线，成为相离直线。

- - -

这种几何分类有一个纯代数的对应。直线与圆周的交点，就是由二者方程所构成方程组的解：

$$
\begin{cases}
x^2 + y^2 + ax + by + c = 0 \\[6pt]
y = mx + q
\end{cases}
$$

将第二个方程中 $y$ 的表达式代入第一个方程，会得到关于未知量 $x$ 的一元二次方程；其实数解的个数恰好等于交点的个数。该方程的判别式 $\Delta$ 对应上述三种几何情形：$\Delta$ 为正时给出两个不同的根，对应割线；$\Delta$ 为零时给出一个二重根，对应切线；$\Delta$ 为负时则无实根，对应相离直线。

## 例题二

给定方程为 $x^2 + y^2 - 2x - 2y - 3 = 0$ 的圆周与方程为 $y = -x + 3$ 的直线，我们要确定该直线是割线、切线还是相离直线，并在前两种情况下求出交点坐标。

交点是由这两个方程组成的方程组的解：

$$
\begin{cases}
x^2 + y^2 - 2x - 2y - 3 = 0 \\[6pt]
y = -x + 3
\end{cases}
$$

我们用[配方法](../completing-the-square/)重写第一个方程：

$$(x - 1)^2 - 1 + (y - 1)^2 - 1 - 3 = 0$$

> 配方法将二次[多项式](../polynomials/)或方程转化为一种等价形式，其中[完全平方三项式](../trinomials/)单独出现在方程的一侧。

- - -

将常数项移到右边，方程组变为：

$$
\begin{cases}
(x - 1)^2 + (y - 1)^2 = 5 \\[6pt]
y = -x + 3
\end{cases}
$$

第一个方程现在表明，给定曲线是以 $(1, 1)$ 为圆心、以 $r = \sqrt{5}$ 为半径的圆周。将第二个方程中 $y$ 的表达式代入第一个方程，得到：

$$(x - 1)^2 + (-x + 2)^2 = 5$$

展开两个平方项，得到：

$$x^2 - 2x + 1 + x^2 - 4x + 4 = 5$$

合并同类项并将所有项移到左边，方程化简为：

$$2x^2 - 6x = 0$$

提取 $2x$ 后，得到等价的[二次方程](../quadratic-equations/)：

$$2x(x - 3) = 0$$

该方程有两个不同的实数解：

$$x = 0 \qquad \lor \qquad x = 3$$

将解代入直线方程 $y = -x + 3$，得到 $y$ 的对应值。对于 $x = 0$，得 $y = 3$；对于 $x = 3$，得 $y = 0$。

因此，交点为：

$$P_1 = (0, 3), \qquad P_2 = (3, 0)$$

由于有两个不同的解，该直线是圆周的割线。
