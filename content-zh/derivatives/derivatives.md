## 引言

设函数 $y = f(x)$ 定义在区间 $[a,b]$ 上。$f$ 在点 $c \in (a,b)$ 处的导数，记为 $f'(c)$，定义为[差商](../difference-quotient/)在 $h \to 0$ 时的极限，前提是该极限存在且有限：

$$f'(c) = \lim_{h \to 0} \frac{f(c+h) - f(c)}{h}$$

如果该极限对于区间内的每一个 $x$ 都存在，那么导数就定义了一个新的函数 $f'(x)$，称为 $f$ 的导数。值 $f'(x)$ 是 $f$ 的图像在点 $x$ 处的切线斜率。

考虑图像上的两个点 $A(c, f(c))$ 和 $B(c+h, f(c+h))$，导数的几何意义便一目了然。差商是过 $A$ 和 $B$ 的割[线](../lines/)的斜率。当 $h \to 0$ 时，点 $B$ 趋近于点 $A$，过 $A$ 和 $B$ 的割线趋向于曲线在 $A$ 处的切线。这条切线的斜率就是函数在该点 $c$ 处的导数。

![IMG. 1](/assets/derivatives/svg/derivatives-1.svg)

将 $A$ 处的切线写成 $y = mx + q$ 的形式，导数 $f'(c)$ 就与斜率系数 $m$ 的值一致。

- - -

如果导数 $f'(c)$ 存在，则函数在点 $c$ 处可导。如果函数在 $c$ 处可导，那么：

+ 函数在该点 $c$ 的某个邻域内有定义。
+ 当 $h \to 0$ 时，$c$ 处的[差商](../difference-quotient/)极限存在且有限。
+ 差商的右极限和左极限均存在且相等。

如果函数 $f(x)$ 在点 $c$ 处可导，则它在该点也是[连续](../continuous-functions/)的。为证明这一点，将函数的增量（对于 $h \neq 0$）写成差商与变量增量的乘积：

$$f(c+h) - f(c) = \frac{f(c+h) - f(c)}{h} \cdot h$$

当 $h \to 0$ 时，差商趋向于 $f'(c)$（由假设可知其存在），而第二个因子趋向于 $0$。因此乘积趋向于零：

$$\lim_{h \to 0} \bigl( f(c+h) - f(c) \bigr) = f'(c) \cdot 0 = 0$$

这意味着 $\lim_{h \to 0} f(c+h) = f(c)$，这正是 $c$ 处连续的定义。逆命题不成立，因为在 $c$ 处连续的函数未必在该处可导，因此可导函数构成连续函数的一个真子集。连续但不可导的点在[不可导点](../points-of-non-differentiability/)词条中讨论。

- - -

求导的逆运算就是[积分](../indefinite-integrals/)。导数与积分之间的联系由[微积分基本定理](../fundamental-theorem-of-calculus/)精确阐述，该定理指出求导与积分是互逆的过程。

> 导数也出现在物理学中。一个经典例子是[速度](../velocity/)，它是位置对时间的导数，而加速度则是速度的导数。

## 例 1

利用导数的定义，计算函数 $f(x) = 2x^2-3x$ 在 $c = 2$ 处的导数：

$$f'(2) = \lim_{h \to 0} \frac{f(2+h) - f(2)}{h}$$

首先，展开平方并合并同类项，计算 $f(2+h)$ 的值：

$$
\begin{align}
f(2+h) &= 2(2+h)^2 - 3(2+h) \\[6pt]
       &= 2(4 + 4h + h^2)-3(2 + h) \\[6pt]
       &= 8 + 8h + 2h^2-6-3h \\[6pt]
       &= 2 + 5h + 2h^2
\end{align}
$$

接下来，计算 $f(2)$ 的值：

$$f(2) = 2(2^2)-3(2) = 8-6 = 2$$

因此差 $f(2+h)-f(2)$ 为：

$$f(2+h)-f(2) = (2 + 5h + 2h^2)-2 = 5h + 2h^2$$

由于 $h \neq 0$，除以 $h$ 是合法的，由此得到差商：

$$\frac{f(2+h)-f(2)}{h} = \frac{5h + 2h^2}{h} = 5 + 2h$$

最后，计算 $h$ 趋于零时的极限：

$$\lim_{h \to 0} (5 + 2h) = 5$$

我们得出，$f(x) = 2x^2 - 3x$ 在 $c = 2$ 处的导数为 $f'(2) = 5$。

## 右导数与左导数

由于导数是差商的极限，正如极限的情形一样，可以定义函数 $y=f(x)$ 的右导数和左导数。

右导数为：

$$f_{+}'(c) = \lim_{h \to 0^+} \frac{f(c+h)-f(c)}{h}$$

左导数为：

$$f_{-}'(c) = \lim_{h \to 0^-} \frac{f(c+h)-f(c)}{h}$$

如果函数在点 $c$ 处的右导数和左导数都存在、有限且彼此相等，则函数在该点可导。更一般地，函数 $y = f(x)$ 在区间 $[a, b]$ 上可导，是指它在区间的所有内部点处可导，并且在 $a$ 处的右导数和 $b$ 处的左导数都存在且有限。

## 基本导数

直接由定义计算导数通常较为繁琐。因此，基本函数的导数通过差商的极限一次性算出，然后作为基本构件使用。结合下一节介绍的求导法则，以下列表使得实践中遇到的大多数函数的导数都能直接计算，无需回到定义。

[class="table-1"]

|                                                |                                      |
| ---------------------------------------------- | ------------------------------------ |
| $f(x) = c$                                     | $f'(x) = 0$                          |
| $f(x) = x$                                     | $f'(x) = 1$                          |
| $f(x) = x^a$，其中 $a \in \mathbb{R}$，$x > 0$ | $f'(x) = ax^{a-1}$                   |
| $f(x) = \sqrt{x}$，其中 $x > 0$                | $f'(x) = \dfrac{1}{2\sqrt{x}}$       |
| $f(x) = a^x$                                   | $f'(x) = a^x \ln(a)$                 |
| $f(x) = \log_a(x)$                             | $f'(x) = \dfrac{1}{x\ln(a)}$         |
| $f(x) = \ln(x)$                                | $f'(x) = \dfrac{1}{x}$               |
| $f(x) = e^x$                                   | $f'(x) = e^x$                        |
| $f(x) = \sin(x)$                               | $f'(x) = \cos(x)$                    |
| $f(x) = \cos(x)$                               | $f'(x) = -\sin(x)$                   |
| $f(x) = \tan(x)$                               | $f'(x) = 1 + \tan^2(x)$              |
| $f(x) = \cot(x)$                               | $f'(x) = -(1 + \cot^2(x))$           |
| $f(x) = \arcsin(x)$                            | $f'(x) = \dfrac{1}{\sqrt{1 - x^2}}$  |
| $f(x) = \arccos(x)$                            | $f'(x) = \dfrac{-1}{\sqrt{1 - x^2}}$ |
| $f(x) = \arctan(x)$                            | $f'(x) = \dfrac{1}{1 + x^2}$         |
| $f(x) = \mathrm{arccot}(x)$                    | $f'(x) = \dfrac{-1}{1 + x^2}$        |
[/class]

> 前两个公式有直接的几何解释。常值函数 $f(x) = c$ 的图像是平行于 $x$ 轴的直线，因此它在每个点的斜率都是 $0$。$f(x) = x$ 的图像是第一和第三象限的角平分线，其斜率在每个点都是 $1$。幂法则 $f(x) = x^a$，导数为 $f'(x) = ax^{a-1}$，将 $f(x) = x$（当 $a = 1$ 时得到）和 $f(x) = \sqrt{x}$（当 $a = \frac{1}{2}$ 时得到）作为特例包含在内。

## 实数指数的幂法则

表中列出了任意实数指数 $a$ 的[幂函数](../power-function/) $f(x) = x^a$ 的导数，这是上面的几何注解无法证明的公式。当 $x > 0$ 时，幂具有等价形式 $x^a = e^{a\ln(x)}$，将其用指数函数和自然对数来表示，而这两个函数的导数已在上表中列出。应用[链式法则](../chain-rule/)，以外层函数 $e^t$、内层函数 $a\ln(x)$（其导数为 $a/x$），可得：

$$
\begin{align}
D[x^a] &= D\left[e^{a\ln(x)}\right] \\[6pt]
&= e^{a\ln(x)} \cdot \frac{a}{x} \\[6pt]
&= x^a \cdot \frac{a}{x} \\[6pt]
&= ax^{a-1}
\end{align}
$$

该论证要求 $x > 0$，因为指数中出现了对数。对于正整数指数 $n$，同样的结果可由[乘积法则](../differentiation-rules/)应用于 $n$ 个相等因子的乘积得出，此时它对所有实数 $x$ 均成立。

## 求导法则

常数 $c$ 与可导函数 $f(x)$ 的乘积的导数，等于该常数与函数导数的乘积：

$$D[c \cdot f(x)] = c \cdot f'(x)$$

例如，设 $c = 3$ 和 $f(x) = x^2$，则：

$$D[3x^2] = 3 \cdot D[x^2] = 3 \cdot 2x = 6x$$

- - -

两个可导函数 $f(x)$ 和 $g(x)$ 之和的导数，等于它们各自导数之和：

$$D[f(x) + g(x)] = f'(x) + g'(x)$$

例如，设 $f(x) = x^2$ 和 $g(x) = 3x$，则：

$$D[x^2 + 3x] = D[x^2] + D[3x] = 2x + 3$$

- - -

两个可导函数 $f(x)$ 和 $g(x)$ 的乘积的导数由乘积法则给出：

$$D[f(x) \cdot g(x)] = f'(x) \cdot g(x) + f(x) \cdot g'(x)$$

例如，设 $f(x) = x^2$ 和 $g(x) = 3x$，则：

$$
\begin{align}
D[x^2 \cdot 3x] &= 2x \cdot 3x + x^2 \cdot 3 \\[6pt]
& = 6x^2 + 3x^2 \\[6pt]
& = 9x^2
\end{align}
$$

> 该结果与直接计算一致，因为 $x^2 \cdot 3x = 3x^3$ 且 $D[3x^3] = 9x^2$。

- - -

两个可导函数 $f(x)$ 和 $g(x)$ 的商的导数（其中 $g(x) \neq 0$）由商法则给出：

$$D\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x) \cdot g(x)-f(x) \cdot g'(x)}{g^2(x)}$$

例如，设 $f(x) = x^2$ 和 $g(x) = 3x + 1$，则：

$$
\begin{align}
D\left[\frac{x^2}{3x + 1}\right] &= \frac{2x \cdot (3x + 1)-x^2 \cdot 3}{(3x + 1)^2} \\[6pt]
&= \frac{6x^2 + 2x-3x^2}{(3x + 1)^2} \\[6pt]
&= \frac{3x^2 + 2x}{(3x + 1)^2}
\end{align}
$$

- - -

可导函数 $f(x)$ 的倒数的导数（其中 $f(x) \neq 0$）是商法则的一个特例：

$$D\left[\frac{1}{f(x)}\right] = -\frac{f'(x)}{f^2(x)}$$

例如，设 $f(x) = 3x + 1$，则：

$$D\left[\frac{1}{3x + 1}\right] = -\frac{3}{(3x + 1)^2}$$

- - -

当对两个函数的复合求导时，上述法则不够用。此时需要应用[链式法则](../chain-rule/)，它用各分量函数的导数来表示复合函数的导数。关于上述法则的系统论述及其由导数定义出发的证明，参见[求导法则](../differentiation-rules/)词条。

## 高阶导数

到目前为止讨论的都是函数 $y = f(x)$ 的一阶导数。由于导数 $f'(x)$ 本身也是一个函数，求导过程可以迭代进行，产生二阶导数、三阶导数，依此类推。

例如，设 $f(x) = 3x^3 - 2x^2 + 1$。函数的一阶导数为：

$$f'(x) = 9x^2 - 4x$$

再次求导，二阶导数为：

$$f''(x) = 18x - 4$$

继续求导，得到三阶导数：

$$f'''(x) = 18$$

一阶和二阶导数描述了函数的局部行为，特别是[极大值、极小值和拐点](../maximum-minimum-and-inflection-points/)的位置。关于该主题的系统论述，包括记号、一般公式和二阶导数判别法，参见[高阶导数](../higher-order-derivatives/)词条。

## 微分学中的定理

微分学中的几个重要定理建立在导数的基础之上。

+ [魏尔斯特拉斯定理](../weierstrass-theorem/)保证：闭区间上的连续函数能取得其最大值和最小值。
+ [费马定理](../fermat-theorem/)给出了局部极值的一个必要条件。
+ [罗尔定理](../rolle-theorem/)和[拉格朗日定理](../lagrange-theorem/)（也称中值定理）描述了闭区间上可导函数的性质。
+ [柯西定理](../cauchy-theorem/)推广了这些结果，而[洛必达法则](../hopital-rule/)则将导数的应用扩展到极限的[不定式](../indeterminate-forms/)求值。
+ [达布定理](../darboux-theorem/)表明，即使导数不连续，它也具有介值性质。

## 切线方程

函数 $f(x)$ 的图像在点 $x_0$ 处的切线斜率由导数 $f'(x_0)$ 给出。该值是函数在该点的瞬时变化率，与趋近 $x_0$ 的割线斜率的极限一致。

更精确地说，如果考虑第二个点 $x_0 + h$，过点 $(x_0, f(x_0))$ 和 $(x_0 + h, f(x_0 + h))$ 的割线斜率为：

$$\frac{f(x_0 + h) - f(x_0)}{h}$$

如果当 $h \to 0$ 时该表达式的极限存在，则函数在 $x_0$ 处可导，且该极限等于 $f'(x_0)$。因此，切线被理解为割线的极限位置。

如果导数存在且有限，则切线不是竖直的。此时，其方程可以写成点斜式。由于该直线过点 $(x_0, f(x_0))$ 且斜率为 $f'(x_0)$，其方程为：

$$y - f(x_0) = f'(x_0)(x - x_0)$$

这个线性函数是 $f$ 在 $x_0$ 附近的最佳线性近似。事实上，当 $x$ 接近 $x_0$ 时，函数的增量满足：

$$f(x) \approx f(x_0) + f'(x_0)(x - x_0)$$

这一近似表达了这样一个思想：在足够小的尺度下，可导函数的行为近似于其切线。这一概念在[函数的微分](../differential-of-a-function/)词条中有精确阐述。

## 例 2

考虑由方程 $y = 2x^2 + 3x$ 定义的[抛物线](../parabola/)，求其在点 $P(1, 5)$ 处的切线。

首先，计算函数的导数：

$$f'(x) = 4x + 3$$

在 $x = 1$ 处求导数的值，得到切线的斜率：

$$f'(1) = 4(1) + 3 = 7$$

因此，切线的斜率为 $m = 7$。代入直线的点斜式，得：

$$y - f(1) = f'(1)(x - 1) \implies y - 5 = 7(x - 1)$$

完成计算，得到切线方程：

$$y = 7x - 2$$

## 例 3

切线恰好为水平线的点就是导数为零的点。作为应用，我们来求以下函数图像上切线为水平线的点：

$$f(x) = \frac{6x}{x^2 + 9}$$

应用商法则，导数为：

$$
\begin{align}
f'(x) &= \frac{6(x^2 + 9) - 6x \cdot 2x}{(x^2 + 9)^2} \\[6pt]
&= \frac{54 - 6x^2}{(x^2 + 9)^2}
\end{align}
$$

由于分母对所有的 $x \in \mathbb{R}$ 都严格为正，导数恰在分子为零时为零：

$$54 - 6x^2 = 0 \implies x^2 = 9 \implies x = \pm 3$$

在这些点处计算函数的值，得 $f(3) = \frac{18}{18} = 1$ 和 $f(-3) = \frac{-18}{18} = -1$。我们得出，$f$ 的图像在点 $(3, 1)$ 和 $(-3, -1)$ 处的切线为水平线。

## 偏导数

导数推广到多元微积分中。当一个函数依赖于多个变量时，在其他变量保持不变的条件下，函数对某一个变量的变化率就是偏导数：

$$\frac{\partial f}{\partial x_i}(x_0) = \lim_{h \to 0} \frac{f(x_1^0, \ldots, x_i^0 + h, \ldots, x_n^0) - f(x_0)}{h}$$

所有偏导数构成的[向量](../vectors/)形成梯度 $\nabla f$，它指示 $f$ 增长最快的方向。关于该主题的全面论述，包括高阶导数、施瓦茨定理、雅可比矩阵以及多元函数的链式法则，请参阅[偏导数](../partial-derivatives/)词条。
