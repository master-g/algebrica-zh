## 全局最大值点与最小值点

[函数](../functions/) $f(x)$ 的最大值和最小值，分别是它在[定义域](../determining-the-domain-of-a-function/)中取得的最高值和最低值。给定定义域为 $D$ 的函数 $y = f(x)$，若点 $x_0 \in D$ 满足对每个 $x \in D$ 都有 $f(x_0) \geq f(x)$，则该点是全局最大值点。值 $f(x_0) = M$ 是函数的全局最大值。

![图 1](/assets/derivatives/svg/maximum-minimum-inflection-points-1.zh.svg)

给定定义域为 $D$ 的函数 $y = f(x)$，若点 $x_0 \in D$ 满足对每个 $x \in D$ 都有 $f(x_0) \leq f(x)$，则该点是全局最小值点。值 $f(x_0) = m$ 是函数的全局最小值。

![图 2](/assets/derivatives/svg/maximum-minimum-inflection-points-2.zh.svg)

如果函数的全局最大值和全局最小值存在，那么它们各自都是唯一的，尽管每个值都可能在定义域的多个点上取得。根据[魏尔斯特拉斯定理](../weierstrass-theorem/)，如果函数在闭区间且有界的 $[a, b]$ 上[连续](../continuous-functions/)，那么它会在该区间上同时取得全局最大值和全局最小值。

不满足该定理假设时，函数可能无法取得最大值或最小值，例如定义在开区间上的函数或无界函数。在这些情形下，函数值集合仍然有上确界和下确界（可能为无穷值），相关内容见[上确界与下确界](../supremum-and-infimum/)词条。

## 局部最大值点与最小值点

函数可能有多个局部最大值点和局部最小值点，也就是只在某个邻域内取得最高值或最低值的点，而不一定是整个定义域上的极值点。

给定定义在区间 $[a, b]$ 上的函数 $y = f(x)$，点 $x_0 \in [a, b]$ 是局部最大值点，当存在以点 $x_0$ 为中心的邻域 $I$，使得对[区间](../intervals/) $I$ 中的每个 $x$ 都有 $f(x_0) \geq f(x)$。

![图 3](/assets/derivatives/svg/maximum-minimum-inflection-points-3.zh.svg)

识别局部最大值点的一个充分判据基于一阶导数的符号。设函数 $y = f(x)$ 在点 $x_0$ 的某个邻域内有定义且连续，并且在该邻域内除 $x_0$ 外的每一点都可导。假设邻域内每个 $x$ 的导数满足：

$$
\begin{align}
f'(x) &> 0 \qquad x < x_0 \\[6pt]
f'(x) &< 0 \qquad x > x_0
\end{align}
$$

在这些条件下，$x_0$ 是函数 $f(x)$ 的局部最大值点。其行为可由下面的符号表概括：

[class="table-sign"]

|           |               | $x_0$         |
| :-------: | :-----------: | :-----------: |
| $f'(x)$   | $+$           | $-$           |
| $f(x)$    | $\nearrow$    | $\searrow$    |
[/class]

- - -

给定定义在区间 $[a, b]$ 上的函数 $y = f(x)$，点 $x_0 \in [a, b]$ 是局部最小值点，当存在以点 $x_0$ 为中心的邻域 $I$，使得对区间 $I$ 中的每个 $x$ 都有 $f(x_0) \leq f(x)$。

![图 4](/assets/derivatives/svg/maximum-minimum-inflection-points-4.zh.svg)

在连续性和可导性的假设相同的情况下，假设邻域内每个 $x$ 的导数满足：

$$
\begin{align}
f'(x) &< 0 \qquad x < x_0 \\[6pt]
f'(x) &> 0 \qquad x > x_0
\end{align}
$$

此时，$x_0$ 是函数 $f(x)$ 的局部最小值点。相应的符号表为：

[class="table-sign"]

|           |               | $x_0$         |
| :-------: | :-----------: | :-----------: |
| $f'(x)$   | $-$           | $+$           |
| $f(x)$    | $\searrow$    | $\nearrow$    |
[/class]

- - -

根据[费马定理](../fermat-theorem/)，可导函数位于定义域内部的局部最大值点和最小值点都是驻点。这意味着，局部最大值点或最小值点处的切线平行于 x 轴。此时，函数的[导数](../derivatives/)满足 $f'(x_0) = 0$。

## 一阶导数判据的证明

上面的符号判据来自[拉格朗日定理](../lagrange-theorem/)，它分别应用在 $x_0$ 的两侧。考虑局部最大值的情形：$f$ 在 $x_0$ 的某个邻域内连续，并且除 $x_0$ 外处处可导；同时，$x < x_0$ 时 $f'(x) > 0$，$x > x_0$ 时 $f'(x) < 0$。

取邻域内满足 $x < x_0$ 的一点。在区间 $[x, x_0]$ 上，函数连续且在内部可导，因此由拉格朗日定理，存在点 $\xi \in (x, x_0)$，使得：

$$f(x_0) - f(x) = f'(\xi)(x_0 - x)$$

点 $\xi$ 位于 $x_0$ 左侧，所以 $f'(\xi) > 0$，而因子 $x_0 - x$ 为正。右侧为正，从而得到 $f(x) < f(x_0)$。

现在取邻域内满足 $x > x_0$ 的一点。在区间 $[x_0, x]$ 上，同一定理给出点 $\xi \in (x_0, x)$，使得：

$$f(x) - f(x_0) = f'(\xi)(x - x_0)$$

这次 $\xi$ 位于 $x_0$ 右侧，所以 $f'(\xi) < 0$，而 $x - x_0$ 为正。右侧为负，因此同样有 $f(x) < f(x_0)$。

对于邻域内每个 $x \neq x_0$，我们都得到了 $f(x) < f(x_0)$，这正是 $x_0$ 成为局部最大值点的条件。局部最小值的判据可以将同样的论证应用于 $-f$ 得到，因为这会反转导数符号的不等式。

> $f$ 在 $x_0$ 处的连续性，使得我们可以在以 $x_0$ 为端点的区间上应用拉格朗日定理，而不必假设导数本身在 $x_0$ 处存在。因此，该判据不仅能识别 $f'(x_0) = 0$ 的驻点，也能识别角点和尖点这样的极值点。

## 向上凹与向下凹

设函数 $f(x)$ 在 $x_0$ 处可导，因此其图像在 $x_0$ 处的切线有定义。如果存在 $x_0$ 的某个邻域 $I$，使得对其中每个满足 $x \neq x_0$ 的 $x$，函数 $f(x)$ 的值都大于直线 $y = t(x)$ 的值，该直线是 $f(x)$ 在 $x_0$ 处的切线，那么称函数 $f(x)$ 在 $x_0$ 处向上凹：

$$f(x) > t(x) \quad \forall x \in I \setminus \{x_0\}$$

![图 5](/assets/derivatives/svg/maximum-minimum-inflection-points-5.zh.svg)

类似地，如果存在 $x_0$ 的某个邻域 $I$，使得对其中每个满足 $x \neq x_0$ 的 $x$，函数 $f(x)$ 的值都小于直线 $y = t(x)$ 的值，那么称函数 $f(x)$ 在 $x_0$ 处向下凹：

$$f(x) < t(x) \quad \forall x \in I \setminus \{x_0\}$$

![图 6](/assets/derivatives/svg/maximum-minimum-inflection-points-6.zh.svg)

这些概念的解析表述见[函数的凸性与凹凸性](../convexity-and-concavity-of-functions/)词条。

## 拐点与凹凸性的变化

拐点是函数凹凸性发生变化的点。

考虑定义在区间 $(a, b)$ 上的函数 $y = f(x)$，设 $x_0 \in (a, b)$，且该点要么是 $f(x)$ 可导的点，要么满足：

$$\lim_{x \to x_0} f'(x) \in \{+\infty, -\infty\}$$

如果函数在 $x_0$ 处改变凹凸性，那么点 $x_0$ 就是拐点。

![图 7](/assets/derivatives/svg/maximum-minimum-inflection-points-7.zh.svg)

如果拐点处的切线平行于 x 轴，则称拐点为水平拐点；如果切线平行于 y 轴，则称为竖直拐点；其他情形称为斜拐点。

![图 8](/assets/derivatives/svg/maximum-minimum-inflection-points-8.zh.svg)

对于函数 $f(x)$，如果 $f'(x_0) = 0$，并且存在 $x_0$ 的某个邻域，使得对其中每个 $x \neq x_0$，$f'(x)$ 的符号都相同，那么点 $x_0$ 是水平拐点：

[class="table-sign"]

|           |               | $x_0$         |
| :-------: | :-----------: | :-----------: |
| $f'(x)$   | $+$           | $+$           |
| $f(x)$    | $\nearrow$    | $\nearrow$    |
[/class]

> $x_0$ 邻域内的符号可以都为正（如上表），也可以都为负。

## 如何计算局部最大值点与最小值点

给定一个连续函数，要寻找局部最大值点和最小值点，我们分析一阶导数的符号。步骤如下：

+ 计算导数 $f'(x)$ 并确定其定义域，以找出函数不可导的点，例如尖点和角点，详见[不可导点](../points-of-non-differentiability/)词条。
+ 通过分析 $f'(x)$ 何时为正、为负或为零，研究导数的符号。
+ 确定局部最大值点和最小值点。如果 $f'(x)$ 在 $x_0$ 附近由正变负，则点 $x_0$ 是局部最大值点；如果 $f'(x)$ 在 $x_0$ 附近由负变正，则点 $x_0$ 是局部最小值点。

基于 $f'$ 符号变化的判据适用于定义域内部的点。如果函数定义在闭区间上，则必须单独检查端点，因为端点处只能获得导数的单侧行为。

当函数二阶可导时，二阶导数的符号可以对驻点进行分类，无需研究其两侧 $f'$ 的符号。如果 $f'(x_0) = 0$ 且 $f''(x_0) \neq 0$，那么当 $f''(x_0) < 0$ 时 $x_0$ 是局部最大值点，当 $f''(x_0) > 0$ 时是局部最小值点，具体取决于图像在 $x_0$ 处向下凹还是向上凹。这个判据称为二阶导数判别法。

当 $f''(x_0) = 0$ 时，判别法无法给出结论；$x_0$ 的性质要根据 $f'$ 的符号，或根据[高阶导数](../higher-order-derivatives/)词条中讨论的高阶导数来确定。

## 例 1

我们来计算下面函数的局部最大值点和最小值点：

$$y = f(x) = x^3 - \frac{1}{2}x^2$$

它是一个[多项式函数](../polynomial-function/)，因此对所有 $x \in \mathbb{R}$ 都连续且可导。函数的一阶导数为：

$$f'(x) = 3x^2 - x$$

通过令下式成立来研究导数的符号：

$$3x^2 - x > 0$$

转而考察对应的方程并提取因子 $x$，得到：

$$3x^2 - x = 0 \implies x(3x -1) = 0$$

该方程在 $x = 0$ 和 $x = \dfrac{1}{3}$ 时成立。回到不等式，由于与 $3x^2 - x$ 对应的抛物线开口向上，可知当 $x < 0$ 以及 $x > \dfrac{1}{3}$ 时，$f'(x) > 0$。

符号表显示：当 $x < 0$ 时函数递增，当 $0 < x < \dfrac{1}{3}$ 时递减，当 $x > \dfrac{1}{3}$ 时再次递增：

[class="table-sign"]

|           |               | $0$           |               | $\dfrac{1}{3}$ |               |
| :-------: | :-----------: | :-----------: | :-----------: | :-----------: | :-----------: |
| $f'(x)$   | $+$           |               | $-$           |               | $+$           |
| $f(x)$    | $\nearrow$    |               | $\searrow$    |               | $\nearrow$    |
[/class]

当 $x = 0$ 时，函数值为 $f(0) = 0^3 - \dfrac{1}{2} \cdot 0^2 = 0$。因此点 $(0,0)$ 是局部最大值点。当 $x = \dfrac{1}{3}$ 时，函数值为：

$$
\begin{align}
f\left( \dfrac{1}{3} \right) &= \left( \dfrac{1}{3} \right)^3 - \dfrac{1}{2} \left( \dfrac{1}{3} \right)^2 \\[6pt]
&= \dfrac{1}{27} - \dfrac{1}{18} \\[6pt]
&= -\dfrac{1}{54}
\end{align}
$$

因此，点 $\left( \dfrac{1}{3}, -\dfrac{1}{54} \right)$ 是局部最小值点。

## 如何确定函数的凹凸性

设 $y = f(x)$ 在点 $x_0$ 的某个邻域内连续且二阶可导。

如果在 $x_0$ 处有 $f''(x_0) \neq 0$，那么：

+ 当 $f''(x_0) > 0$ 时，函数向上凹。
+ 当 $f''(x_0) < 0$ 时，函数向下凹。

- - -

回到例 1 中的函数，确定其[凸性与凹凸性](../convexity-and-concavity-of-functions/)：

$$y = f(x) = x^3 - \frac{1}{2}x^2$$

函数的二阶导数为：

$$f''(x) = 6x - 1$$

令其为正来研究符号：

$$6x - 1 > 0 \implies x > \frac{1}{6}$$

符号表给出了函数向上凹或向下凹的区间：

[class="table-sign"]

|           |           |   $1/6$   |
| :-------: | :-------: | :-------: |
| $f''(x)$  |    $-$    |    $+$    |
|  $f(x)$   | $\bigcap$ | $\bigcup$ |
| 凹凸性 | 向下凹 | 向上凹 |
[/class]

因此，当 $x < 1/6$ 时函数向下凹，当 $x > 1/6$ 时向上凹。由于二阶导数在 $x = 1/6$ 处变号，函数在该处有拐点。相应的纵坐标为：

$$f\left( \dfrac{1}{6} \right) = \dfrac{1}{216} - \dfrac{1}{2} \cdot \dfrac{1}{36} = \dfrac{1}{216} - \dfrac{3}{216} = -\dfrac{1}{108}$$

由于 $f'\left( \dfrac{1}{6} \right) = \dfrac{3}{36} - \dfrac{1}{6} = -\dfrac{1}{12} \neq 0$，拐点处的切线既不水平也不竖直，点 $\left( \dfrac{1}{6}, -\dfrac{1}{108} \right)$ 是斜拐点。

## 识别拐点

当二阶导数 $f''(x)$ 在 $x_0$ 两侧变号时，点 $x_0$ 是拐点。拐点的类型取决于一阶导数在 $x_0$ 处的行为。

+ 如果 $f'(x_0) = 0$ 且 $f''(x_0) = 0$，并且凹凸性在 $x_0$ 的邻域内变号，那么点 $x_0$ 是水平拐点。此时，$x_0$ 处的切线是水平的。
+ 如果当 $x \to x_0$ 时 $f'(x)$ 的极限为 $+\infty$ 或 $-\infty$，且两侧符号相同，同时凹凸性在 $x_0$ 附近变号，那么点 $x_0$ 是竖直拐点。此时函数连续但在 $x_0$ 处不可导，切线为竖直线，详见[不可导点](../points-of-non-differentiability/)词条。
+ 如果 $f'(x_0) \neq 0$ 且 $f''(x_0) = 0$，并且凹凸性在 $x_0$ 附近变号，那么点 $x_0$ 是斜拐点。此时切线既不水平也不竖直，而是具有非零斜率。
