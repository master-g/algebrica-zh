## 定义

有理函数是分子和分母都是[多项式](../polynomials/)的[函数](../functions/)，次数分别为 $n$ 和 $m$。它们写成两个多项式之比。

$$y = \frac{P(x)}{Q(x)}$$

其中 $P(x)$ 和 $Q(x)$ 是满足 $Q(x) \neq 0$ 的多项式。将其完全展开后，有理函数具有如下形式：

$$y = \frac{a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0}{b_m x^m + b_{m-1} x^{m-1} + \dots + b_1 x + b_0}$$

考虑函数：

$$R(x) = \frac{2x + 3}{x - 1}$$

这里分子和分母都是一次多项式。除了使分母为零的取值外，该表达式对每个实数都有定义。这里使分母为零的是 $x = 1$，必须排除该值。函数的[定义域](../determining-the-domain-of-a-function/)为：

$$\{\ x \in \mathbb{R} : x \neq 1 \ \}$$

这个初等例子已经展示了有理函数的特征：由多项式之比给出的代数形式，由分母的零点确定的定义域，以及通过极限、渐近线和代数化简描述的行为。

## 性质

[定义域](../determining-the-domain-of-a-function/)由除去分母 $Q(x)$ 的零点后的所有实数组成：

$$D = \mathbb{R} \setminus \{\ x \in \mathbb{R} \mid Q(x) = 0 \ \}$$

值域是函数所取得的[实数值](../types-of-numbers/)组成的集合。它取决于函数的具体形式，无法一概而论。

函数的[奇偶性](../even-and-odd-functions/)，以及有界性、[单调性](../increasing-and-decreasing-functions/)、凹性和凸性，都不能预先确定。这些性质取决于有理函数的具体形式。

## 特殊情形与代数结构

每个多项式都是有理函数，即它与常数多项式 $1$ 的比值。常数也符合相同的描述，因为数是次数为零的多项式。因此，[多项式](../polynomials/)和常函数都是有理函数的特殊情形，即分母不含变量的有理函数。只有能够写成两个多项式之比的函数才是有理函数，因此 $\sqrt{x}$、$\sin x$ 和 $e^x$ 等表达式都不属于有理函数，因为它们都不是多项式之商。

有理函数在四则运算下封闭。两个有理函数的和、差与积仍然是多项式之比；当除数不是零函数时，它们的商也仍然如此。在这些运算下，有理函数构成一个域，正如整数的分数构成[有理数](../rational-numbers/)一样。

## 真有理函数与假有理函数

当分子的次数小于分母的次数，即 $n < m$ 时，有理函数称为真有理函数；当 $n \geq m$ 时，称为假有理函数。这一区分很重要，因为假有理函数可以化为一个多项式与一个真有理部分之和。将 $P(x)$ 除以 $Q(x)$，得到商 $E(x)$ 和余数 $S(x)$，其中 $\deg S < \deg Q$，于是

$$\frac{P(x)}{Q(x)} = E(x) + \frac{S(x)}{Q(x)}$$

当 $|x|$ 很大时，多项式 $E(x)$ 决定函数的主要行为，因为真有理部分 $S(x)/Q(x)$ 趋于零。函数 $R(x)$ 的图像趋近于曲线 $y = E(x)$，即

$$\frac{P(x)}{Q(x)} - E(x) \to 0 \qquad (|x| \to \infty)$$

这一分解是[有理函数的积分](../integral-of-rational-functions/)的基础，也解释了斜渐近线：当 $n = m + 1$ 时，商 $E(x)$ 的次数为 1，直线 $E(x) = ax + b$ 就是渐近线。

例如，将 $R(x) = \frac{x^2 + 1}{x - 1}$ 的分子除以分母。商为 $x + 1$，余数为 $2$，因此

$$R(x) = x + 1 + \frac{2}{x - 1}$$

多项式部分 $x + 1$ 是斜渐近线，而 $2/(x - 1)$ 这一项在 $x \to \pm\infty$ 时趋于零。

## 最简形式与可去间断

当分子和分母没有公共的多项式因子时，有理函数处于最简形式，也称既约形式。如果它们有公共因子，约去该因子后得到的较简单表达式，会在原函数有定义的所有地方与原函数一致。被约去的因子会留下一个可去间断：该点不属于定义域，但如果在那里延拓，函数本来可以连续。

考虑 $\frac{x^2 - 1}{x - 1}$。分子可分解为 $(x - 1)(x + 1)$，约去公共因子 $x - 1$ 得到

$$\frac{x^2 - 1}{x - 1} = x + 1 \qquad x \neq 1$$

约简后的表达式 $x + 1$ 是处处有定义的多项式，但原函数在 $x = 1$ 处无定义。它的图像是直线 $y = x + 1$，只是在 $x = 1$ 处缺少一个点；这属于可去间断，而不是竖直渐近线。因此，在判断函数行为之前，必须先将其化为最简形式，才能区分真正的渐近线与可去间断点。

## 有理函数的连续性

有理函数是多项式之商，而多项式在整个 $\mathbb{R}$ 上连续。因此，在满足 $Q(x_0) \neq 0$ 的每个点 $x_0$ 处，有理函数都连续。间断只会出现在 $Q(x) = 0$ 的解处，因为函数在那里没有定义。间断的类型取决于分子。如果两个多项式都在 $x_0$ 处为零，即 $P(x_0) = 0$ 且 $Q(x_0) = 0$，则因子 $x - x_0$ 同时整除二者，所以公共因子总能约去。间断是否可去取决于零点的重数：只有当分子中零点的重数至少等于分母中零点的重数时，间断才是可去的；否则，约去公共因子后仍会保留竖直渐近线。如果只有分母在该点为零，即 $P(x_0) \neq 0$ 且 $Q(x_0) = 0$，函数就会发散并出现竖直渐近线。

## 有理函数在无穷远处的极限

要理解有理函数在 $x$ 取很大值时的行为，需要比较分子和分母的增长。在远离原点时，次数较低的项变得可以忽略，函数的行为由两个多项式的次数和首项系数决定。考虑有理函数 $R(x) = P(x)/Q(x)$，其中 $P(x)$ 和 $Q(x)$ 的次数分别为 $n$ 和 $m$。$n$ 与 $m$ 的比较决定了 $x \to \pm\infty$ 时的行为。

如果 $n < m$，分母占主导，因此极限为零：

$$\lim_{x \to \pm\infty} R(x) = 0$$

如果 $n = m$，最高次项相互平衡，极限等于首项系数之比：

$$\lim_{x \to \pm\infty} R(x) = \frac{a_n}{b_m}$$

如果 $n = m + 1$，函数在 $|x|$ 很大时表现得像一条直线，因此有斜渐近线。极限不是有限值，但存在一条合适的直线 $ax + b$，使得差值 $R(x) - (ax + b)$ 趋于零。

如果 $n > m + 1$，分子增长得更快，函数的绝对值发散：

$$\lim_{x \to \pm\infty} R(x) = \pm\infty$$

每个单侧极限的符号取决于 $a_n/b_m$ 的符号以及 $n - m$ 的奇偶性。

## 分母为零点处的极限

微妙的情形出现在分母为零的 $x$ 值处。必须区分两种情况。第一种情况是，分母在点 $x_0$ 处为零，而分子不为零：

$$Q(x_0) = 0 \qquad P(x_0) \neq 0$$

在 $x_0$ 附近，表达式的形式相当于 $P(x_0)/0$，所以当 $x$ 趋近该值时，函数会无界增长。直线 $x = x_0$ 是竖直渐近线，极限为无穷。

$$\lim_{x \to x_0^\pm} R(x) = \pm\infty$$

极限的符号由分母在 $x_0$ 两侧如何变化决定。

- - -

另一种情况是分子和分母在同一点为零，这会产生[不定式](../indeterminate-forms/)：

$$\frac{0}{0}$$

此时，不能直接根据在 $x_0$ 处代入多项式所得的值读出极限。函数可能化简为有限极限，也可能发散。为了确定结果，可以将分子和分母因式分解并约去公共因子，或者在条件满足时应用[洛必达法则](../hopital-rule/)。

## 渐近线

有理函数不一定有[渐近线](../asymptotes/)。多项式没有渐近线；当 $n > m + 1$ 且分母永不为零时，分式会发散而没有渐近线。当渐近线存在时，其类型取决于两个多项式的次数以及分母的零点。可以确定以下情形：

+ 如果 $Q(x_0) = 0$ 且 $P(x_0) \neq 0$，那么直线 $x = x_0$，即分母为零的点所在的直线，是竖直渐近线。
+ 如果 $n = m$，函数有一条水平渐近线，其值为首项系数之比 $a_n/b_m$。如果 $n < m$，水平渐近线是直线 $y = 0$。
+ 当 $P(x)$ 的次数比分母 $Q(x)$ 的次数高 1 时，即 $n = m + 1$，会出现斜渐近线。

## 部分分式分解

真有理函数可以拆分为若干较简单的分式之和，分母的每个因子对应一个分式。将 $Q(x)$ 分解为一次因式和不可约二次因式后，函数可以写成若干项之和，每一项的分母就是这些因式之一，分子则留下待确定的常数或一次式。这种[部分分式分解](../partial-fraction-decomposition/)把一个复杂的比值变成若干易于求导、积分和展开的部分。考虑：

$$\frac{3x + 5}{(x - 1)(x + 2)}$$

并设法找出常数 $A$ 和 $B$，使得

$$\frac{3x + 5}{(x - 1)(x + 2)} = \frac{A}{x - 1} + \frac{B}{x + 2}$$

两边乘以 $(x - 1)(x + 2)$，得到 $3x + 5 = A(x + 2) + B(x - 1)$。令 $x = 1$，得到 $8 = 3A$，所以 $A = 8/3$。令 $x = -2$，得到 $-1 = -3B$，所以 $B = 1/3$。分解结果为

$$\frac{3x + 5}{(x - 1)(x + 2)} = \frac{8/3}{x - 1} + \frac{1/3}{x + 2}$$

当分子次数至少等于分母次数时，先进行多项式除法，提取多项式部分，再对真有理余项进行分解。决定部分分式形式的因子就是分母的零点，因此，这种分解也有助于分析竖直渐近线，以及计算[有理函数的积分](../integral-of-rational-functions/)。

## 导数与积分

有理函数在其整个定义域上[连续](../continuous-functions/)且可导。[导数](../derivatives/)没有统一的闭式，但可以使用商法则计算：

$$\frac{d}{dx} \left[ \frac{P(x)}{Q(x)} \right] = \frac{P'(x)Q(x) - P(x)Q'(x)}{[Q(x)]^2}$$

- - -

积分也没有统一的标准方法，而取决于函数的具体形式。一般方法结合前面介绍的两种分解。首先通过多项式除法将多项式部分与真有理余项分开：

$$\int \frac{P(x)}{Q(x)} \ dx = \int E(x) \ dx + \int \frac{S(x)}{Q(x)} \ dx$$

多项式部分 $E(x)$ 可以直接积分，而真有理部分 $S(x)/Q(x)$ 则通过部分分式分解为若干项，分别积分得到对数和反正切函数。完整步骤将在[有理函数的积分](../integral-of-rational-functions/)中展开。
