## 引言

对数函数的形式为 $y = \log_a x$，其中 $a > 0$ 且 $a \neq 1$，对每个 $x \in \mathbb{R}^+$ 都有定义。它是[指数函数](../exponential-function/)的[反函数](../inverse-function/)，因此二者的[定义域](../determining-the-domain-of-a-function/)和值域互换。

当底数 $a > 1$ 时，函数递增。

![图 1](/assets/powers-radicals-logarithms/svg/logarithms-1.zh.svg)

当 $0 < a < 1$ 时，函数递减。

![图 2](/assets/powers-radicals-logarithms/svg/logarithms-2.zh.svg)

函数等于 $0$ 的唯一点是 $x = 1$，因为 $\log_a(1) = 0$。这是因为根据[幂的性质](../powers/)，$a^0 = 1$。直线 $x = 0$ 是一条竖直[渐近线](../asymptotes/)，因为当 $x$ 从右侧趋近于零时，函数会发散。

将对数定义为指数函数的反函数是一种初等方法，它假定对每个实指数 x，$a^x$ 已经构造完毕。下面的自然对数一节将通过积分给出一种定义，并把指数函数定义为对数的反函数。

> 底数的取值决定函数是递增还是递减。对于[对数不等式](../logarithmic-inequalities/)，底数在 $0$ 与 $1$ 之间时函数递减，因此必须反转不等号方向。

## 性质

以下性质都直接来自对数函数是指数函数反函数的定义。

+ 定义域：$(0, +\infty)$
+ 值域：$\mathbb{R}$
+ 根：$x = 1$
+ 当 $a > 1$ 时，函数在 $(0,+\infty)$ 上严格[递增](../increasing-and-decreasing-functions/)；当 $0 < a < 1$ 时严格递减。
+ 函数既不是偶函数也不是奇函数，因为它对负数 $x$ 没有定义。
+ 函数在 $(0, +\infty)$ 上[连续](../continuous-functions/)。
+ 对数函数是可导指数函数的反函数，因此在整个定义域上可导，其导数为：

$$f'(x) = \frac{1}{x\ln(a)}$$

+ 函数在定义域上没有[最大值或最小值](../maximum-minimum-and-inflection-points/)，因为它在零附近和无穷远处都是无界的。

## 极限、导数与积分

在零附近和无穷远处的[极限](../limits/)取决于底数。当底数 $a > 1$ 时，$x$ 从右侧趋近于零时，对数无界减小；当 $x$ 趋于无穷时，对数无界增大：

$$\lim_{x \to 0^+} \log_a x = -\infty$$

$$\lim_{x \to +\infty} \log_a x = +\infty$$

当 $0 < a < 1$ 时，极限方向相反：

$$\lim_{x \to 0^+} \log_a x = +\infty$$

$$\lim_{x \to +\infty} \log_a x = -\infty$$

- - -

底数为 $a$ 的对数函数的[导数](../derivatives/)可以由标准求导法则得到。对于 $x > 0$、$a > 0$ 且 $a \neq 1$，$\log_a(x)$ 对 $x$ 的导数为：

$$\frac{d}{dx}\log_a(x) = \frac{1}{x\ln(a)}$$

- - -

底数为 $a$ 的对数函数的[不定积分](../indefinite-integrals/)可以由不同底数对数之间的关系得到：

$$\log_a(x) = \frac{\ln(x)}{\ln(a)}$$

这样问题就归结为自然对数的积分。利用[分部积分](../integration-by-parts/)，得到：

$$\int \frac{\ln(x)}{\ln(a)} \ dx = \frac{x(\ln(x)-1)}{\ln(a)} + c$$

## 自然对数

自然对数可以直接定义为一个积分。当 $x > 0$ 时，定义为：

$$\ln(x) = \int_{1}^{x} \frac{1}{t} \ dt$$

结果的符号来自这个定义。当 $x > 1$ 时，积分区间长度为正，被积函数也为正，因此 $\ln(x) > 0$。当 $0 < x < 1$ 时，积分区间的方向使符号反转，因此 $\ln(x) < 0$。当 $x = 1$ 时，上下限相同，故 $\ln(1) = 0$。

[微积分基本定理](../fundamental-theorem-of-calculus/)直接给出由此定义得到的导数：

$$\frac{d}{dx}\ln(x) = \frac{1}{x}$$

对数的加法性质也可以从积分形式推出：比较导数并使用链式法则。固定 $y > 0$，令 $g(x) = \ln(xy)$。[链式法则](../chain-rule/)给出：

$$g'(x) = \frac{1}{xy}\cdot y = \frac{1}{x}$$

因此 $g$ 与 $\ln$ 的导数相同，二者相差一个常数。在 $x = 1$ 处取值，可知该常数为 $\ln(y)$，从而得到：

$$\ln(xy) = \ln(x) + \ln(y)$$

自然对数的底数是[欧拉数](../euler-number-limit-sequence/) $e$，它定义为使其对数等于 $1$ 的唯一值：

$$\ln(e) = \int_{1}^{e} \frac{1}{t} \ dt = 1$$

这个条件说明 $e$ 介于 $2$ 和 $4$ 之间，因为用 $1/t$ 的积分从上下界估计数值 $1$，等价于比较 $1$ 与 $\ln(2)$ 和 $\ln(4)$。在区间 $[1,2]$ 上，常数 $1$ 是 $1/t$ 的上界，因此相应的积分小于 $1$：

$$\ln(2) = \int_{1}^{2} \frac{1}{t} \ dt < 1$$

在区间 $[1,4]$ 上，分段函数在 $[1,2]$ 上等于 $\frac{1}{2}$、在 $[2,4]$ 上等于 $\frac{1}{4}$，它是 $1/t$ 的下界；其积分为 $\frac{1}{2}(2-1) + \frac{1}{4}(4-2) = 1$，因此对应的积分大于 $1$：

$$\ln(4) = \int_{1}^{4} \frac{1}{t} \ dt > 1$$

这两个不等式把数值 $1$ 夹在 $2$ 和 $4$ 的对数之间：

$$\ln(2) < 1 = \ln(e) < \ln(4)$$

由于 $\ln$ 递增，真数也保持相同的顺序，因此 $2 < e < 4$。一旦得到 $e$，自然对数就等同于以 $e$ 为底的对数：

$$\ln(x) = \log_e(x)$$

换底公式可以用任意其他底数 $a$ 表示它：

$$\ln(x) = \frac{\log_a(x)}{\log_a(e)}$$

自然对数是[指数函数](../exponential-function/) $e^x$ 的反函数。指数函数的增长速度超过每一个 $x$ 的幂，因为对每个自然数 $n$，都有：

$$\lim_{x \to +\infty} \frac{e^x}{x^n} = +\infty$$

因此，对数的增长速度低于每个正幂次的 $x$；这正是“增长缓慢”的严格含义。

- - -

自然对数还有一种积分表示，使用从原点开始的区间上 $\ln(t)$ 的[定积分](../definite-integrals/)：

$$\int_{0}^{x} \ln(t) \ dt$$

这个积分对 $x > 0$ 有定义。被积函数 $\ln(t)$ 在 $t = 0$ 处无定义，因此该积分应解释为[反常积分](../improper-integrals/)。其值由分部积分得到：

$$\int \ln(t) \ dt = t\ln(t) - t + c$$

应用这个原函数，并令下限趋近于零，可得：

$$\int_{0}^{x} \ln(t) \ dt = \bigl[t\ln(t) - t\bigr]_{0}^{x} = x\ln(x) - x + 1$$

- - -

自然对数的一个定积分为：

$$\int_{0}^{1} \ln(x) \ dx = -1$$

这同样是反常积分，因为 $\ln(x)$ 在 $x = 0$ 处无定义。其值来自在下限处取极限的原函数 $x\ln(x) - x$。在区间 $(0,1)$ 上，$\ln(x)$ 的负值产生净负面积，结果为 $-1$。

## 二分查找与对数函数

对数的一种用途是分析算法复杂度。二分查找的每一步都回答一个“是/否”问题，对应一个二进制位，因此对数可以计算定位一个元素所需的二元决策次数。

假设要在含有 $N$ 个元素的有序列表中查找一个元素。逐个检查元素时，如果目标在第 $n$ 个位置，最多可能需要 $n$ 步。这种方法是线性查找，其最坏情况下的[时间复杂度](../big-o-notation/)为：

$$\mathcal{O}(n)$$

对于大型列表，线性查找效率很低。二分查找会在每一步缩小搜索空间：它把有序列表分成两半，只保留可能包含目标元素的一半。这个过程持续到找到元素，或列表无法再继续划分。

每一步都将搜索空间除以 $2$。如果初始列表有 $n$ 个元素，那么在达到 $1$ 之前，$n$ 能被 $2$ 除尽的次数决定了步数，这就是以 $2$ 为底的对数。若用 s 表示步数，则

$$s \approx \log_2 n$$

因此，二分查找的时间复杂度为：

$$\mathcal{O}(\log n)$$

其他分治算法和决策树中也会出现相同的反复二分模式。如果列表含有 $1{,}000{,}000$ 个元素，二分查找至多需要：

$$\log_2(1{,}000{,}000) \approx 19.9$$

所需步数少于 $20$，而线性查找最多可能需要 $1{,}000{,}000$ 步。

> 二分查找要求元素已经排序，通常是按升序排列。如果没有确定的顺序，算法就无法判断应该丢弃列表的哪一半。
