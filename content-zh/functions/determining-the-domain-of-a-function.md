## 系统确定函数定义域的方法

在[函数](../functions/)的介绍中，我们讨论了函数的定义域，即表达式在数学上有意义时允许的输入值集合。我们还考察了[多项式](../polynomials/)、[根式](../radicals/)、[对数](../logarithms/)和[三角](../sine-and-cosine/)表达式等基本函数族的定义域如何确定。

实际中，我们经常遇到在同一个公式中组合多种函数类型的复杂表达式。此时，定义域并不能立即看出，因为每个内部成分都可能引入自身的限制条件。可以将策略概括为以下步骤：

+ 检查表达式的内部成分，确定每个成分所要求的定义域。
+ 逐层向外推进，传播每个新运算或函数施加的限制。
+ 对所有得到的条件取交集，因为整体定义域只包含同时满足全部约束的值。

下面的例子将逐步把这一方法应用于具体表达式。

## 区间的类型

定义域总能表示为实数[区间](../intervals/)的并集，因此我们先回顾这些集合如何定义。区间描述实数轴上的连续部分，以紧凑的方式指定允许哪些 $x$ 值。第一类是开区间，它包含严格位于两个端点之间的所有点，但不包含端点本身。描述性形式写作：

$$
\{\,x : a < x < b\,\}
$$

区间记号写作：

$$
(a, b)
$$

当 $a$ 和 $b$ 对应函数无定义的点或出现[间断点](../discontinuities-of-real-functions/)时，这种记号非常方便。在图形上，端点 $a$ 和 $b$ 用空心圆表示，说明它们不包含在区间内；连接两端点的线段则覆盖 $a$ 与 $b$ 之间的所有值。

[shortcode="intervals"]

|     | $a$  | $b$      |     |
|:----|------------|---------------|-----|
|     | sign+l-in-o-h  |   sign+r-in-o-h  |     |
[/shortcode]

第二类是闭区间，它包含两个端点。描述性形式写作：

$$
\{\,x : a \le x \le b\,\}
$$

相应的区间记号写作：

$$
[a, b]
$$

当函数在边界点 $a$ 和 $b$ 处有定义且连续时，通常使用这种表示。闭区间在图形上通过填实端点来表示。实心点说明两个边界值都包含在内，而两点之间的线段覆盖从 $a$ 到 $b$ 的每个点。

[shortcode="intervals"]

|     | $a$  | $b$      |     |
|:----|------------|---------------|-----|
|     | sign+l-in-c-h  |   sign+r-in-c-h  |     |
[/shortcode]

端点还可以采用其他开闭组合。例如，可以有半闭区间 $[a, +\infty)$，也可以有在边界处混合包含与排除的区间，如 $(a, b]$。描述无限延伸或从特定边界值开始的定义域时，常使用这些形式。

[shortcode="intervals"]

|     | $a$  | $b$      |     |
|:----|------------|---------------|-----|
|     | sign+l-c-h  |    |     |
|     | sign+l-in-o-h  |   sign+r-in-c-h  |     |
[/shortcode]

## 初等函数的定义域

最常见的表达式会产生以下定义域限制：

+ 多项式：在 $\mathbb{R}$ 上总有定义
+ 有理函数：分母 $\neq 0$
+ 偶次根：被开方数 $\ge 0$
+ 奇次根：在 $\mathbb{R}$ 上总有定义
+ 对数：真数 $> 0$，底数 $> 0$，且底数 $\neq 1$
+ 绝对值：在 $\mathbb{R}$ 上总有定义
+ 三角函数 $\sin x$ 和 $\cos x$：在 $\mathbb{R}$ 上总有定义
+ 反三角函数：真数必须处于特定范围内

> 偶次根的条件是被开方数非负，即 $\ge 0$，而不是严格为正，因为 $\sqrt{0} = 0$ 有定义。

## 例 1

为了说明如何使用图形方法，考虑函数：

$$
f(x) = \log(x - 1) + \sqrt{x + 4}
$$

为了确定其定义域，必须分别检查每个成分，因为函数只有在 $x$ 同时满足所有底层条件时才有定义。

- - -

对数项 $\log(x - 1)$ 要求其真数严格为正，因此得到条件：

$$
x - 1 > 0
$$

只有大于 $1$ 的值才允许取用；小于或等于 $1$ 的值都会违反对数的定义。图形上表示这一条件如下：

[shortcode="intervals"]

|     | $1$  |       |    
|:----|------------|---------------|
|     | sign+l-o  |    |
[/shortcode]

平方根项 $\sqrt{x + 4}$ 要求其被开方数非负：

$$
x + 4 \ge 0
$$

因此允许 $x \ge -4$。与对数条件相比，这个要求限制较少，因为每个大于 $1$ 的值自动都大于 $-4$。把这一结果加入前一个图示后，得到：

[shortcode="intervals"]

|     | $-4$  | $1$      |     |
|:----|------------|---------------|-----|
|     |   |   sign+l-o   |     |
|     | sign+l-c |     |     |
|     |   |   sign+l-o-h   |     |
[/shortcode]

综合起来，定义域由两个条件 $x > 1$ 和 $x \ge -4$ 的交集得到。由于 $x > 1$ 已经蕴含 $x \ge -4$，交集可化为不等式 $x > 1$。定义域对应于高亮线段，即区间：

$$
(1, +\infty)
$$

## 例 2

考虑一个同时包含平方根、对数和三角函数的例子：

$$
f(x) = \sqrt{\frac{\log(2 + \sin x)}{\sinh(x)}}
$$

定义域并不能立即看出。三角项提示我们得到的条件可能会周期性重复。我们应用上面概述的方法，从最内层成分开始，检查每个成分引入的限制。

- - -

首先遇到的是[对数](../logarithms/)：

$$\log(2 + \sin x)$$

由于对数只对严格为正的真数有定义，因此要求：

$$2 + \sin x > 0$$

由于 $\sin x$ 的取值介于 $-1$ 和 $1$ 之间，这个表达式能取得的最小值是 $2 - 1 = 1$，已经为正。因此，对数不会引入限制，因为对每个实数 $x$，其真数都为正。

向外推进一步，对数出现在分数的分子中，分母是[双曲正弦](../hyperbolic-sine-and-cosine/) $\sinh(x)$。分母不能为零，因为除以零在[实数](../real-numbers/)中没有定义，所以要排除满足 $\sinh(x) = 0$ 的 $x$ 值。双曲正弦仅在 $x = 0$ 时为零，因此必须从定义域中移除这一点。

最后，整个分数位于平方根下，因此其被开方数必须非负。

+ 分子 $\log(2 + \sin x)$ 总是非负，并且恰好在 $\sin x = -1$ 时为零，也就是在 $x = -\frac{\pi}{2} + 2k\pi$ 这些点上。此时分数为零，因此可以接受；前提是分母不为零，而这除了已经排除的 $x = 0$ 外都成立。
+ 对其他所有值，$\log(2 + \sin x)$ 严格为正，因此分数的符号只取决于 $\sinh(x)$ 的符号。当 $x > 0$ 时双曲正弦为正，当 $x < 0$ 时为负。由于被开方数必须非负，分数恰好在 $x > 0$ 或分子为零时可取。

综合这些观察，定义域由所有大于零的 $x$，以及 $\sin x = -1$ 时的离散点组成。因此定义域为：

$$
(0, +\infty) \;\cup\; \left\{ -\frac{\pi}{2} + 2k\pi \,\middle|\, k \in \mathbb{Z} \right\}
$$

## 例 3

确定函数的定义域：

$$
f(x) = \sqrt{\cos^{2}(3x - 1) - \log\!\bigl(5 - |2x|\bigr)}
$$

我们从内向外检查表达式，识别每个成分引入的限制，最后将它们合并。首先施加约束的是对数。由于对数只接受严格为正的真数，因此要求：

$$
5 - |2x| > 0
$$

解这个涉及[绝对值](../absolute-value/)的[不等式](../inequalities-with-absolute-value/)，得到：

$$
|2x| < 5 \quad \rightarrow \quad -\frac{5}{2} < x < \frac{5}{2}
$$


三角部分 $\cos^{2}(3x - 1)$ 不引入额外限制，因为[余弦函数](../cosine-function/)及其平方对所有实数 $x$ 都有定义。


现在向外移动一层，考虑平方根下的整个表达式。平方根只在其被开方数非负时有定义，因此施加：

$$
\cos^{2}(3x - 1) - \log(5 - |2x|) \ge 0
$$

这个不等式连接了行为不同的两个项。平方余弦在 $0$ 和 $1$ 之间振荡，而在允许的区间上，对数的取值范围为 $\left(-\infty, \log 5\right]$；当 $|2x|$ 从下方趋近 $5$ 时，它趋于 $-\infty$。只有当对数项不超过平方余弦时，不等式才成立：

$$
\log(5 - |2x|) \le \cos^{2}(3x - 1)
$$


解集包含在 $\left(-\frac{5}{2}, \frac{5}{2}\right)$ 中，因为在该区间之外对数无定义。对两个要求取交集，定义域就是该区间中同时满足被开方数条件的点集：

$$
\mathrm{dom}(f) = \left\{\, x \in \left(-\tfrac{5}{2}, \tfrac{5}{2}\right) \ \middle|\ \cos^{2}(3x - 1) \ge \log(5 - |2x|) \,\right\}
$$

最后这个不等式没有初等闭式解，必须用数值或图形方法考察。例如在 $x = 0$ 附近，$\log 5 \approx 1.61$，大于 $\cos^{2}(1) \approx 0.29$，所以原点附近的一段区域被排除。因此定义域是 $\left(-\frac{5}{2}, \frac{5}{2}\right)$ 的真子集。
