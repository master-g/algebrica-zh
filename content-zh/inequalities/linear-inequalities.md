## 引言

不等式是涉及代数表达式的数学命题，我们要找出使不等式成立的变量的值。一般而言，两个代数表达式 $A(x)$ 与 $B(x)$ 之间的不等式定义为如下关系：

$$A(x) > B(x)$$

解不等式就是确定解集，即所有满足上述不等式的 $x$ 的取值。对于含一个实变量的线性不等式，解集始终是 $\mathbb{R}$ 的一个子集，形式为一个区间，可能是无界区间；在退化情形下，则为整个实数轴或空集。

高次不等式或涉及多个变量的不等式，会给出更复杂的解集，相关内容见专门条目。

给定两个实数 $a$ 与 $b$，且 $a < b$，有界[区间](../intervals/)是由介于 $a$ 与 $b$ 之间的[实数](../real-numbers/)组成的[集合](../sets/)，其中 $a$ 与 $b$ 分别是下界与上界。无界区间由小于或大于某个边界值的数构成。若两个端点都包含在内，该区间称为闭区间；若都不包含，则称为开区间；仅包含一个端点时称为半开区间。

[shortcode="intervals"]
|                      | $-3$              | $6$                   |     |
|----------------------|-----------------|---------------------|-----|
|                      |   sign+l-c      |                     |     |
|                      |   sign+l-in-c   | sign+r-in-o         |     |
[/shortcode]

> 在第一个区间中，数 $-3$ 包含在区间内。它记作 $[-3,\infty)$，在 $-3$ 处封闭、向无穷方向开放。在第二个区间中，数 $-3$ 包含在区间内，而数 $6$ 被排除在外。它记作 $[-3,6)$，在 $-3$ 处封闭、在 $6$ 处开放。

- - -

不等号决定了解区间在边界处是开的还是闭的。用 $>$ 或 $<$ 表示的严格不等式排除边界值，得到开区间。用 $\geq$ 或 $\leq$ 表示的非严格不等式则包含边界值，得到闭区间或半开区间。

| 不等式 | 区间 |
|---|---|
| $x > a$ | $(a, +\infty)$ |
| $x \geq a$ | $[a, +\infty)$ |
| $x < a$ | $(-\infty, a)$ |
| $x \leq a$ | $(-\infty, a]$ |
| $a < x < b$ | $(a, b)$ |
| $a \leq x \leq b$ | $[a, b]$ |

> 上表总结了一元一次不等式中不等号与所得区间记号之间的对应关系。

- - -

不等式的次数对应于将该不等式改写成 $P(x) > 0$ 形式后所得[多项式](../polynomials/) $P(x)$ 的次数。一元一次不等式在最一般的形式下，是两个一次表达式之间的比较：

$$ax + b > cx + d$$

当 $c = d = 0$ 时，上式简化为 $ax + b > 0$，即一个一次多项式与零的比较。将所有含 $x$ 的项移到一边、常数项移到另一边后，每个一次不等式都可以改写成等价的最简形式：

$$Ax > B$$

其中 $A = a - c$ 且 $B = d - b$。后续讨论一律采用此最简形式。

每一个满足 $A \neq 0$ 的一次不等式都以一个取值区间作为其解。条件 $A \neq 0$ 是必要的。当 $A = 0$ 时，变量从不等式中完全消失，问题退化为两个常数的比较。将 $A = 0$ 代入最简形式可得如下结果。

$$0 \cdot x > B$$

上式化简为 $0 > B$。若 $B < 0$，则不等式对 $x$ 的任何取值都成立，解集为整个 $\mathbb{R}$。若 $B \geq 0$，则不等式永不成立，解集为空。在这两种情形下，都不存在由边界点确定的区间：结果要么是一个全局成立的真命题，要么是一个矛盾，而非真正意义上的一次不等式。

- - -

给定一个不等式，可以在两边同时加上同一个数或表达式，从而得到一个等价的不等式，前提是该表达式在相同的[定义域](../determining-the-domain-of-a-function/)内有定义。不等式 $5x - 2 > x + 3$ 等价于不等式 $4x - 2 > 3$，这是通过从两边同时减去 $x$ 得到的。

将两边同时除以或乘以同一个非零值，也可以得到等价的不等式。这些运算与求解[线性方程](../linear-equations/)时所用的运算相同，但有一个关键区别：若该值为负，则必须反转不等号的方向。将形如 $-x + 5 < -3$ 的一次不等式改写成 $x - 5 > 3$ 的形式总是有益的。改变符号时需要反转不等号的方向。

## 几何解释

当 $A \neq 0$ 时，一次不等式的解集对应实数轴上的一条射线，即从一个边界点起沿单一方向无限延伸的无界区间。

+ 当不等式为严格不等式时，边界点被排除在外，该射线在此端为开的。

+ 当不等式为非严格不等式时，边界点属于解集，该射线为闭的。

以简单不等式 $x \geq 1$ 为例。其解集为闭射线 $[1, +\infty)$，如下图所示。

|---|----------|---|
|   | sign+l-c |   |
[/shortcode]

这一几何解读阐明了为何在 $A \neq 0$ 时，一次不等式的解不会是孤立点或有界区间：表达式 $Ax - B$ 的线性结构保证了其符号恰好在 $x = B/A$ 处改变一次，将实数轴划分为两个区域，其中一个即为解集。

## 例 1

考虑以下不等式：

$$-\frac{x}{2} + 5 > 2x - 5$$

目标是将其化为标准形式 $Ax > B$。由于左边含有分母为 $2$ 的分式，两边同乘 $2$ 即可消去分母且不改变不等号方向，因为该乘数为正。

$$-x + 10 > 4x - 10$$

将含 $x$ 的所有项移到左边，常数项移到右边，得到如下结果。

$$-5x > -20$$

两边同除以 $-5$ 即可分离变量。由于除数为负，不等号方向必须反转。

$$x < 4$$

[shortcode="intervals"]
|   | $4$        |   |
|---|----------|---|
|   | sign+r-o |   |
[/shortcode]

解集为开区间 $(-\infty, 4)$。

## 含参一次不等式的求解方法

对于含参一次不等式，变量的系数并非固定常数，而是依赖于一个或多个参数。考虑以下不等式。

$$z(x - 1) < 2x + 1$$

第一步是展开并合并同类项，将表达式改写为标准形式 $Ax > B$、$Ax < B$、$Ax \geq B$ 或 $Ax \leq B$ 之一。展开左边并将含 $x$ 的所有项移到左边，得到如下结果。

$$\begin{align}
&zx - z < 2x + 1 \\[6pt]
&zx - 2x < z + 1 \\[6pt]
&(z - 2)x < z + 1
\end{align}$$

此时不等式已化为 $Ax < B$ 的形式，其中 $A = z - 2$，$B = z + 1$。由于两边同除以 $A$ 需要知道其符号，而 $z - 2$ 的符号又取决于参数 $z$ 的取值，因此必须区分三种情况分别讨论。

- - -

当 $z > 2$ 时，系数 $z - 2$ 为正。两边同除以一个正数保持不等号方向不变，得到如下结果：

$$x < \frac{z + 1}{z - 2}$$

当 $z = 2$ 时，系数 $z - 2$ 为零。代入该值后不等式化为 $0 \cdot x < 3$，对一切 $x \in \mathbb{R}$ 均成立。解集为整个 $\mathbb{R}$。

当 $z < 2$ 时，系数 $z - 2$ 为负。两边同除以一个负数使不等号方向反转，得到如下结果：

$$x > \frac{z + 1}{z - 2}$$

## 绝对值不等式

绝对值不等式是遵循[绝对值](../absolute-value/)性质的不等式，其形式为：

$$|x| < z$$

一般而言，涉及绝对值的不等式不属于线性不等式这一类，因为绝对值函数是分段定义的，且不等式的代数表达式会在绝对值内部表达式为零的点处改变形式。

然而，通过适当的分解过程，它们可以被转化为一个或多个等价的线性不等式组，从而可以使用与一次不等式相同的方法进行分析。

更系统、更完整的讨论见专门条目[含绝对值的不等式](../inequalities-with-absolute-value/)，而使用不等式组来合并所得条件的内容则在[不等式组](../systems-of-inequalities/)条目中讨论。

- - -

为了求解它们，需要根据绝对值内部表达式的符号分两种情形讨论：

+ $|x| < z$ 当且仅当 $-z < x < z$。
+ $|x| > z$ 当且仅当 $x < -z \quad \text{或} \quad x > z$。

因此需要求解上述各情形所产生的不等式组。这一过程比普通的一次不等式稍复杂，计算时必须仔细注意符号和不等号的方向。

## 例 2

求解以下绝对值不等式：

$$|x - 1| < 2x + 4$$

首先，根据 $x - 1$ 的符号展开绝对值：

$$|x - 1| =
\begin{cases}
x - 1 & \quad x \ge 1 \\[6pt]
-x + 1 & \quad x < 1
\end{cases}$$

将第一个分支代入不等式并求解，得到以下不等式组。

$$\begin{cases}
x \geq 1 \\[6pt]
x - 1 < 2x + 4
\end{cases}$$

第二个不等式化简为 $x > -5$。该不等式组的解是 $x \geq 1$ 与 $x > -5$ 的交集，即 $x \geq 1$。

[shortcode="intervals"]
| | $-5$            | $1$                  |     |
|-|---------------|--------------------|-----|
| |               | sign+l-c           |     |
| | sign+l-o      |                    |     |
| |               | sign+l-c-h         |     |
[/shortcode]

将第二个分支代入不等式并求解，得到以下不等式组：

$$\begin{cases}
x < 1 \\[6pt]
-x + 1 < 2x + 4
\end{cases}$$

第二个不等式化简为 $x > -1$。该不等式组的解是 $x < 1$ 与 $x > -1$ 的交集，即开区间 $(-1, 1)$。

[shortcode="intervals"]
|                      | $-1$              | $1$                   |     |
|----------------------|-----------------|---------------------|-----|
|                      |   sign+l-in-o   | sign+r-in-o         |     |
|                      |   sign+l-in-o-h | sign+r-in-o-h       |     |
[/shortcode]

将两个部分解集取并集，即得完整解。由于 $x \geq 1$ 和 $(-1, 1)$ 是相邻区间，合起来覆盖了所有大于 $-1$ 的值，因此该不等式的解如下。

$$x > -1$$
