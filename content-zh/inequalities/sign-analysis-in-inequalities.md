## 什么是符号分析

不等式的符号分析是一种方法，用于确定给定表达式为正、为负或为零的区间。这种方法对于求解[多项式不等式](../polynomial-inequalities/)和[分式不等式](../rational-inequalities/)，以及分析函数在指定[定义域](../determining-the-domain-of-a-function/)内的行为特别有价值。

乘积的符号由负因子的个数是偶数还是奇数决定。当负因子的个数为偶数时，乘积为正；当负因子的个数为奇数时，乘积为负。对于两个因子，该规则写为：

$$\begin{align}
(+)\times(+) &= + \\[6pt]
(+)\times(-) &= - \\[6pt]
(-)\times(+) &= - \\[6pt]
(-)\times(-) &= +
\end{align}$$

考虑以下简单的[二次不等式](../quadratic-inequalities/)：

$$x^2 + x - 2 > 0$$

我们需要确定满足该不等式的 x 的取值范围。首先，可以将[多项式因式分解](../factoring-polynomials-ac-method/)为以下形式：

$$(x - 1)(x + 2) > 0$$

根据乘积规则，当两个因子同号时，即两者都为正或都为负时，表达式为正。为了追踪这种情况发生在何处，我们分别研究每个因子的符号：

$$\begin{align}
&x - 1 > 0 \iff x > 1 \\[6pt]
&x + 2 > 0 \iff x > -2
\end{align}$$

值 $x = 1$ 和 $x = -2$ 将实数轴划分为不相交的区间。由于表达式是[连续的](../continuous-functions/)，且仅在其零点处才能变号，因此其符号在每个区间内保持不变。然后将这些值标记在数轴上，用 $+$ 和 $-$ 表示每个区间上的符号。

[class="table-sign"]

|             |      | $$-2$$      | $$1$$  |
|:-----------:|:------------------:|:------------:|:----------------:|
| $x - 1 > 0$ | $\boldsymbol{-}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ |
| $x + 2 > 0$  | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
| $(x - 1)(x+2) > 0$ | $\boldsymbol{+}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ |
[/class]

最后一行的每一项是通过将相应区间内两个因子的符号相乘得到的。满足初始不等式 $(x - 1)(x + 2) > 0$ 的区间为：

$$x < -2 \quad \text{或} \quad x > 1$$

用区间记法表示，解集为：

$$(-\infty, -2) \cup (1, +\infty)$$

> 如果不等式是非严格的，则表达式的零点属于解。对于不等式 $x^2 + x - 2 \geq 0$，步骤完全相同，但由于表达式等于零时不等式也成立，因此零点 $x = -2$ 和 $x = 1$ 被包含在解集 $(-\infty, -2] \cup [1, +\infty)$ 中。

填写符号表的等价方法是测试点法。由于表达式在每个区间上的符号不变，只需在区间内任选一点代入表达式求值即可。例如，将 $x = 0$ 代入 $(x-1)(x+2)$ 得到 $(-1)(2) = -2 < 0$，这表明表达式在整个区间 $(-2, 1)$ 上都为负。

## 不等式符号分析的系统化步骤

一般而言，不等式的符号分析遵循一套系统化步骤，这套步骤适用于任何多项式或分式。

+ 将不等式改写为 $f(x) > 0$（或 $< 0$、$\geq 0$、$\leq 0$），使右端为零。
+ 将 $f(x)$ 分解为线性或不可约因式的积或商。对于分式不等式，分别分析分子与分母。
+ 求出每个因式的零点。分母的零点绝不属于解，必须在数轴上用空心圆标记。
+ 将各零点按升序排列在实数轴上，从而把 $\mathbb{R}$ 划分为互不相交的若干区间。对每个区间，确定每个因式的符号。
+ 利用乘积法则合并每个区间的符号：负因式的个数为偶数时总体符号为正，为奇数时为负。重数为偶数的因式在其对应零点处不产生符号变化。
+ 找出总体符号满足原不等式的区间。对于严格不等式，将零点排除在解之外；对于非严格不等式，将其包含在内。始终排除分母的零点。
+ 用集合记号表示解，并用 $\cup$ 合并互不相交的区间。

## 几何表示

当不等式形如 $ax^2 + bx + c \ge 0$ 或 $ax^2 + bx + c > 0$（其中 $a > 0$），且对应的[二次方程](../quadratic-equations/) $ax^2 + bx + c = 0$ 有两个不同的实数解 $x_1 < x_2$ 时，有：

$$\begin{align}
&x \leq x_1 \lor x \geq x_2  &&\text{当} \quad ax^2+bx+c \geq 0 \\[6pt]
&x < x_1 \lor x > x_2  &&\text{当} \quad ax^2+bx+c > 0
\end{align}$$

条件 $a > 0$ 对应开口向上的抛物线，它在两根所确定的区间之外取正值，在两根之间取负值。若 $a < 0$，则将不等式两边乘以 $-1$ 并反转不等号方向，即可将问题归约为前述情形。

若函数 $f(x)$ 在区间 $[a,b]$ 上[连续](../continuous-functions/)，且 $f(a)$ 与 $f(b)$ 异号，则由介值定理知存在至少一点 $c \in (a,b)$ 使得 $f(c) = 0$。

![图 1](/assets/inequalities/svg/sign-analysis-in-inequalities-1.zh.svg)

> 换言之，对于[连续函数](../continuous-functions/)，符号的改变只能发生在穿过函数某个零点之时，而零点即满足 $f(x) = 0$ 的点。在上图所示的例子中，符号的改变恰好发生在与不等式相关联的方程的解处，即 $x = -2$ 与 $x = 1$。

## 示例 1

同样的方法也可用于求解以下类型的分式不等式：

$$\frac{N(x)}{D(x)} > 0$$

商的符号法则与乘积相同，因此我们分别研究分子的符号和分母的符号。当两者符号相同（同为正或同为负）时，商在相应区间上为正；当两者符号相反（一个为正、另一个为负）时，商为负。分母的零点必须始终排除，因为表达式在那里无定义。

考虑以下分式不等式：

$$\frac{2x - 3}{1 - x} > 0$$

我们分别研究分子和分母的符号，即求解 $N(x) > 0$ 和 $D(x) > 0$：

$$\begin{align}
&2x - 3 > 0 \iff x > \frac{3}{2} \\[6pt]
&1 - x > 0 \iff x < 1
\end{align}$$

将符号表示在数轴上，得到：

[class="table-sign"]

|                      |                  |      $$1$$       |     $$3/2$$      |
| :------------------: | :--------------: | :--------------: | :--------------: |
|        $N(x)$        | $\boldsymbol{-}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ |
|        $D(x)$        | $\boldsymbol{+}$ | $\boldsymbol{-}$ | $\boldsymbol{-}$ |
| $\dfrac{N(x)}{D(x)}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{-}$ |

[/class]

因此，满足原不等式的取正区间为：

$$x \in \left(1, \dfrac{3}{2}\right)$$

> 即使不等式是非严格不等式，点 $x = 1$ 仍然要排除，因为它是分母的零点，表达式在该点无定义。而点 $x = \frac{3}{2}$ 是分子的零点，则应被包含。

## 示例 2

考察下面的不等式，其中含有一个具有偶数重数的因子：

$$(x - 1)^2(x + 3) > 0$$

它的零点是 $x = 1$（重数为 $2$）和 $x = -3$（重数为 $1$）。它们将实数轴划分成三个区间：

[class="table-sign"]

|                |                  |      $$-3$$      |      $$1$$       |
| :------------: | :--------------: | :--------------: | :--------------: |
|   $(x-1)^2$    | $\boldsymbol{+}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
|    $x + 3$     | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
| $(x-1)^2(x+3)$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
[/class]

因子 $(x-1)^2$ 始终非负，且仅在 $x = 1$ 处等于零。因此，乘积的符号完全由因子 $(x+3)$ 决定，在 $x = 1$ 处不发生符号变化。整体的符号只在 $x = -3$ 处才由 $-$ 变为 $+$，因为在那里因子 $(x+3)$ 改变了符号。

因此该不等式的解为：

$$x \in (-3, 1) \cup (1, +\infty)$$

> 点 $x = 1$ 被排除在外，因为这是一个严格不等式，且 $f(1) = 0$，尽管该处不发生符号变化。
