## 定义

无理不等式是未知数出现在[根式](../radicals/)内或具有分数[指数](../powers/)幂的不等式。更准确地说，无论严格与否、无论不等号方向如何，只要至少一项含有形如 $\sqrt[n]{f(x)}$ 或等价的 $f(x)^{p/q}$，其中 $p$、$q$ 为整数且 $q \geq 2$，就属于无理不等式。与[无理方程](../irrational-equations/)一样，根式会对[定义域](../determining-the-domain-of-a-function/)施加约束，而这些约束会影响不等式的方向。

区分无理不等式与其方程对应物的核心困难在于：将两边同时乘方是一种单调运算，但仅在某些特定的符号条件下才成立：

+ 当两边均非负时，同取偶次幂后不等号方向保持不变。
+ 当两边均非正时，偶数次幂运算会反转不等式的方向。
+ 当其中一边的符号不确定时，该运算完全不可行，必须先根据该边的符号将不等式划分为子情形。

> 在实践中，求解无理不等式需要仔细控制容许值，因为代数变换可能引入增解，必须将其代回原不等式检验。

## 偶次根式与奇次根式

无理不等式的行为取决于根式的根指数 $n$ 为偶数还是奇数，这一区分决定了整个求解策略。当根指数为奇数时，若采用借助[符号函数](../sign-function/)定义的实值约定，函数 $\sqrt[n]{x}$ 在整个实数轴上均有定义且严格递增：

$$\sqrt[n]{x} = \mathrm{sign}(x) \cdot |x|^{1/n}$$

该约定将奇数次根扩展到负实数。在此约定下，$\sqrt[3]{-8} = -2$，更一般地，奇次根式是奇数次幂函数 $t \mapsto t^n$ 的反函数。由此可得：

$$\sqrt[n]{f(x)} \leq \sqrt[n]{g(x)}
 \Longleftrightarrow
f(x) \leq g(x)$$

而无需任何额外的定义域条件，因为该函数在 $\mathbb{R}$ 上单调。同样的等价关系对严格不等式也成立。因此，奇次情形更为简单，它对应于对奇次无理方程的处理。

作为奇次情形的一个示例，考虑下面的不等式。

$$\sqrt[3]{x} \geq x$$

由于立方根在整个实数轴上递增，两边同时立方是一种等价变换，不要求对任一边的符号附加条件。因此该不等式等价于 $x \geq x^3$，即 $x^3 - x \leq 0$。对左边因式分解得到 $x(x-1)(x+1) \leq 0$，对该乘积进行[符号分析](../sign-analysis-in-inequalities/)即可得到解。

$$(-\infty, -1] \cup [0, 1]$$

右边可以为负而不影响论证，这正是奇次情形区别于下文讨论的偶次情形的关键特征。

- - -

当根指数为偶数时，情况更为微妙。函数 $\sqrt[n]{x}$ 仅对非负实数有定义，其值域被限制为非负值。这意味着任何形如 $\sqrt[n]{f(x)} \leq g(x)$ 且 $n$ 为偶数的不等式都带有隐含约束。

![偶次根函数在定义域内严格递增](/assets/inequalities/svg/irrational-inequalities-1.zh.svg)

被开方数必须非负；根据 $g(x)$ 的符号，该不等式可能自动成立，也可能需要两边平方。因此，偶次情形需根据右边的符号划分为子情形。

## 一般形式与求解策略

涉及平方根的最常见无理不等式归纳如下。每一类都需要特定的求解方法。对于形如以下的不等式：

$$\sqrt{f(x)} \leq g(x)$$

求解过程如下。若 $g(x) < 0$，则不等式在该处无解，因为平方根恒为非负。若 $g(x) \geq 0$，则两边均为非负，平方后不等号方向保持不变。因此完整条件为以下[不等式组](../systems-of-inequalities/)。

$$\begin{cases} f(x) \geq 0 \\[6pt] g(x) \geq 0 \\[6pt] f(x) \leq \bigl(g(x)\bigr)^2 \end{cases}$$

> 三个条件缺一不可。特别地，$f(x) \leq \bigl(g(x)\bigr)^2$ 并不蕴含 $g(x) \geq 0$，因为 $g(x)$ 取负值时平方仍为正。

- - -

对于以下情形，需分两种子情形讨论：

$$\sqrt{f(x)} \geq g(x)$$

当 $g(x) < 0$ 时，对于 $\sqrt{f(x)}$ 的定义域内的每一个 $x$，不等式都自动成立，因为左边非负，故恒大于一个负数。此子情形对应以下不等式组。

$$\begin{cases} f(x) \geq 0 \\[6pt] g(x) < 0 \end{cases}$$

当 $g(x) \geq 0$ 时，两边均为非负，可以平方，得到以下不等式组。

$$\begin{cases} g(x) \geq 0 \\[6pt] f(x) \geq \bigl(g(x)\bigr)^2 \end{cases}$$

在第二个不等式组中，条件 $f(x) \geq 0$ 自动满足，因为 $f(x) \geq \bigl(g(x)\bigr)^2$ 已经迫使被开方数非负。于是完整解即为两个不等式组解集的并集。

- - -

对于形如以下的不等式：

$$\sqrt{f(x)} \leq \sqrt{g(x)}$$

由于两边在定义域内均为非负，故只要两个被开方数非负，平方就总是允许的，不等式组简化为以下形式。

$$\begin{cases} f(x) \geq 0 \\[6pt] f(x) \leq g(x) \end{cases}$$

条件 $g(x) \geq 0$ 不必显式写出，因为它可由 $g(x) \geq f(x) \geq 0$ 推出。显式写出并不算错，但简化后的不等式组已足够。

- - -

当不等式为严格不等式时，同样的方案依然适用，只需在平方条件中改用严格比较。有一点需要注意：在形式 $\sqrt{f(x)} < g(x)$ 中，右端的条件变为 $g(x) > 0$，因为平方根非负，不可能严格小于零。对称地，对于 $\sqrt{f(x)} > g(x)$，第一个子情形变为 $g(x) < 0$ 连同 $f(x) \geq 0$；而在情形 $g(x) \geq 0$ 中，平方后的条件写作 $f(x) > \bigl(g(x)\bigr)^2$。

求解无理不等式与求解无理方程遵循相同的基本原理，即通过两边同取适当次幂来消去根式，再连同根式所限定的定义域条件一起分析所得的代数不等式。关键区别在于，每一步都必须仔细审视不等号的方向，因为平方仅在非负实数上才是单调运算。

## 典型求解步骤

无论不等式的具体形式如何，求解过程都按一致的顺序执行若干步骤。

+ 确定根式所限定的定义域。
+ 分析非根式一边的符号。
+ 仅当两边均非负时才进行平方。
+ 求解所得的代数不等式。
+ 与定义域条件取交集。

> 每一步都依赖于前一步：跳过定义域分析或忽略右端的符号，是求解无理不等式时最常见的两类错误来源。

## 示例 1

考虑以下不等式：

$$\sqrt{2x - 1} \leq x - 2$$

左端仅在被开方数非负时有定义，因此需要施加的第一个条件是 $2x - 1 \geq 0$，即 $x \geq \frac{1}{2}$。由于平方根恒非负，右端也必须非负该不等式才可解，这要求 $x - 2 \geq 0$，即 $x \geq 2$。

在此两个条件下两端均为非负，对两边平方是保号的有效操作。问题归约为以下不等式组。

$$\begin{cases} x \geq \dfrac{1}{2} \\[6pt] x \geq 2 \\[6pt] 2x - 1 \leq (x-2)^2 \end{cases}$$

展开第三式右端得 $(x-2)^2 = x^2 - 4x + 4$，故该不等式变为 $2x - 1 \leq x^2 - 4x + 4$，即 $x^2 - 6x + 5 \geq 0$。相应[二次方程](../quadratic-equations/) $x^2 - 6x + 5 = 0$ 的[根](../roots-of-a-polynomial/)为 $x = 1$ 与 $x = 5$，故相应的[二次不等式](../quadratic-inequalities/)在区间 $[1, 5]$ 之外非负，给出 $x \leq 1$ 或 $x \geq 5$。

现将三条件取交集。前两个要求 $x \geq 2$，第三个要求 $x \leq 1$ 或 $x \geq 5$。在区域 $x \geq 2$ 内，仅有部分 $x \geq 5$ 得以保留。在实数轴上表示这些条件，得到下图。

因此解为区间 $[5, +\infty)$。

## 示例 2

考虑以下不等式：

$$\sqrt{x^2 - 3x} \geq x - 1$$

[定义域](../determining-the-domain-of-a-function/)要求 $x^2 - 3x \geq 0$，即 $x(x-3) \geq 0$，这对 $x \leq 0$ 或 $x \geq 3$ 成立。现在根据右边的符号分两种子情形讨论。

第一种情形是 $x - 1 < 0$，即 $x < 1$。在此区域内右边为负而左边非负，故不等式自动成立。此子情形的贡献是 $x < 1$ 与定义域 $x \leq 0$ 或 $x \geq 3$ 的交集，得 $x \leq 0$。

第二种情形是 $x - 1 \geq 0$，即 $x \geq 1$。两边均非负，可以平方。不等式变为 $x^2 - 3x \geq (x-1)^2 = x^2 - 2x + 1$，即 $-3x \geq -2x + 1$，从而 $-x \geq 1$，得 $x \leq -1$。这必须与 $x \geq 1$ 取交集，交集为空，故第二种子情形不贡献解。

综合两种子情形，完整解为 $(-\infty, 0]$。在实数轴上表示这些条件得下图。

|---|---|---|---|---|
| | sign+r-c | | sign+l-c | |
| | sign+r-c | | | |
| | | sign+p-c | | |
| | sign+r-c-h | | | |

高亮行表示各条件的交集，即所有条件同时满足时 $x$ 取值的集合。

因此解为区间 $(-\infty, 0]$。

## 示例 3

考虑以下不等式：

$$\sqrt{x^2 - x - 6} \leq \sqrt{2x + 2}$$

由于两边都涉及平方根，两个根号内的被开方数都必须非负。定义域条件为 $x^2 - x - 6 \geq 0$ 和 $2x + 2 \geq 0$。第一个因式分解为 $(x-3)(x+2) \geq 0$，得到 $x \leq -2$ 或 $x \geq 3$。第二个给出 $x \geq -1$。这两个条件的交集为 $x \geq 3$。

由于两边在定义域上都非负，平方是允许的，该不等式等价于 $x^2 - x - 6 \leq 2x + 2$，即 $x^2 - 3x - 8 \leq 0$。$x^2 - 3x - 8 = 0$ 的根如下。

$$x = \frac{3 \pm \sqrt{9 + 32}}{2} = \frac{3 \pm \sqrt{41}}{2}$$

由于 $\sqrt{41} \approx 6.40$，两根分别约为 $x \approx -1.70$ 和 $x \approx 4.70$。该二次式在两根之间非正，因此不等式成立的范围为：

$$\frac{3 - \sqrt{41}}{2} \leq x \leq \frac{3 + \sqrt{41}}{2}$$

在实数轴上表示这些条件得到下图。

|---|---|---|---|---|---|---|
| | sign+r-c | | |  sign+l-c |  | |
| |  | |sign+l-c |   | | |
| | | sign+l-c | | | | |
| | | sign+l-in-c | sign+s | | sign+r-in-c | |
| | | | | sign+l-in-c-h | sign+r-in-c-h | |
[/shortcode]

高亮行表示各条件的交集，即所有条件同时满足时 $x$ 取值的集合。因此解为以下闭区间：

$$\left[3, \dfrac{3 + \sqrt{41}}{2}\right]$$

## 示例 4

现在考虑更一般的情形，其中右侧含有一个[实参数](../equations-with-parameters/) $k$。解集的结构取决于 $k$ 的取值，完整讨论需要进行分情形分析。考虑以下不等式。

$$\sqrt{x + 4} \leq k$$

定义域要求 $x + 4 \geq 0$，即 $x \geq -4$。此时解的性态取决于 $k$ 的符号。

若 $k < 0$，则右侧为负，而左侧始终非负，因此不等式恒不成立。无解。

若 $k = 0$，不等式化为 $\sqrt{x + 4} \leq 0$。由于平方根始终非负，唯一可能是 $\sqrt{x + 4} = 0$，即 $x = -4$。解为单点 $\{-4\}$。

若 $k > 0$，两边均非负，可以平方。不等式变为 $x + 4 \leq k^2$，即 $x \leq k^2 - 4$。与定义域 $x \geq -4$ 取交集后，解为如下闭区间。

$$-4 \leq x \leq k^2 - 4$$

只要 $k^2 - 4 \geq -4$，即只要 $k^2 \geq 0$（恒成立），此区间就非空。对于 $k > 0$ 的情形，将解表示在实数轴上如下图所示。

[field_math]
| | $-4$ | $k^2-4$ | |
|---|---|---|---|
| | sign+l-in-c |sign+r-in-c  | |
| | sign+l-in-c-h | sign+r-in-c-h | |
[/field_math]

注意，当 $k \to 0^+$ 时，右端点 $k^2 - 4$ 从右侧趋近于 $-4$，区间收缩为单点 $\{-4\}$，与 $k = 0$ 的情形一致。因此解为如下闭区间：

$$[-4, k^2 - 4]$$

## 嵌套根式

当根式嵌套时，会出现更高层次的复杂度，例如如下形式的不等式：

$$\sqrt{a + \sqrt{f(x)}} \leq g(x)$$

此时需将上述方法迭代应用。先分离外层根式并平方，再以同样的分析处理内层根式。每一步都要累加定义域条件，并将其全部的交集贯穿到最终解中。每一层嵌套都适用同样的单调性论证。

作为示例，考虑以下不等式。

$$\sqrt{2 + \sqrt{x}} \leq 2$$

内层根式要求 $x \geq 0$，在此条件下外层被开方数 $2 + \sqrt{x}$ 自动为正，故不产生额外的定义域限制。右侧为正常数 $2$，因此两边均非负，可以平方。

不等式变为 $2 + \sqrt{x} \leq 4$，即 $\sqrt{x} \leq 2$。此内层不等式两边仍非负，故可作第二次平方，得到 $x \leq 4$。与定义域条件 $x \geq 0$ 取交集后，解为闭区间 $[0, 4]$。
