## 引言

分式不等式是至少含有一个分式的不等式，其中分子和分母均为[多项式](../polynomials/)。此类表达式的自然定义域是所有使分母不为零的实数构成的集合；任何使分母等于零的 $x$ 的值都被排除在定义域之外，且不能属于解集。每个分式不等式都可以化为以下标准形式之一。

$$\frac{P(x)}{Q(x)} > 0 \qquad \frac{P(x)}{Q(x)} \geq 0$$

$$\frac{P(x)}{Q(x)} < 0 \qquad \frac{P(x)}{Q(x)} \leq 0$$

在每种情形中，$P(x)$ 和 $Q(x)$ 都是具有实系数的多项式，且左端的表达式仅在 $Q(x) \neq 0$ 处有定义。这类不等式与有理函数和[有理方程](../rational-equations/)密切相关。四种形式均用同一方法处理，如下面的例子所示。

- - -

解分式不等式意味着在表达式的自然定义域内找到所有使不等式成立的 $x$ 的值。标准方法按以下步骤进行。

+ 第一步是改写不等式，使所有项出现在左端，右端为零，从而将问题化为上述标准形式之一。这样便可以研究单个分式的符号，而无需比较两个独立的表达式。
+ 第二步是确定分式的自然[定义域](../determining-the-domain-of-a-function/)，方法是找出所有使分母为零的 $x$ 的值。无论不等号为何，这些值都必须从解集中排除。
+ 第三步是分别求出分子的零点和分母的零点。这些临界点合在一起，将实数轴划分为若干开区间，在每个开区间上分式保持恒定的符号，因为比的符号只能在分子或分母等于零处改变。
+ 第四步是构造[符号表](../sign-analysis-in-inequalities/)，在每个区间中记录分子的符号和分母的符号，然后按标准法则确定比的符号：当分子与分母同号时比为正，当两者异号时比为负。
+ 第五步是收集表达式的符号与原不等式一致的区间，注意当且仅当不等式非严格时才纳入分子的零点，而无论何种情形都要排除分母的零点。

> 该方法所依据的关键观察是：分式 $P(x)/Q(x)$ 只能在 $P(x)$ 的零点或 $Q(x)$ 的零点处改变符号。在任意两个相邻临界点之间，该表达式要么恒为严格正，要么恒为严格负，因此只需在每个区间中检验一个代表值即可。

## 重数与符号变化

每个零点的重数，对于确定分式在其临界点处符号如何变化至关重要。奇数重数的零点，无论出现在分子还是分母中，都会使表达式在 $x$ 跨越该点时发生符号改变。表达式在该点的一侧为正，另一侧为负。

与此相反，偶数重数的零点不会引起符号改变。表达式在该点两侧保持相同的符号，因为对应的因子以偶数次幂出现，而偶次幂在该零点的邻域内不会改变符号。

在制作符号表时，必须显式考虑这一行为。把所有临界点都当作符号改变点而不顾其重数，是一种常见错误，当分子或分母中出现重复因子时，这种做法会得到错误的解集。

- - -

考察以下不等式，它展示了偶数重数对符号表的影响。

$$\frac{(x-1)^2}{x-3} \geq 0$$

分母在 $x = 3$ 处为零，因此无论不等号为何，该点都必须从解集中排除，因为表达式在该点无定义。于是自然定义域是 $x \neq 3$ 的所有实数的集合。分子在 $x = 1$ 处为零，这是一个二重零点。临界点是 $x = 1$ 和 $x = 3$，它们把实数轴划分为三个区间。

[class="table-sign"]

|                                  |                      |       $$1$$        |       $$3$$        |
| :------------------------------- | :------------------: | :------------------: | :------------------: |
| $$(x-1)^2 \geq 0$$             | $\boldsymbol{+}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
| $$x - 3 \geq 0$$               | $\boldsymbol{-}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ |
| $$\frac{(x-1)^2}{x-3} \geq 0$$ | $\boldsymbol{-}$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ |
[/class]

由于 $(x-1)^2$ 对所有实数 $x$ 都非负，且仅在 $x = 1$ 处等于零，因此它不会在 $x$ 跨越 $x = 1$ 时改变符号。于是整个表达式的符号完全由分母 $x - 3$ 的符号决定。

表达式在 $x > 3$ 时为正，在 $x = 1$ 处等于零。点 $x = 3$ 被排除在解集之外，因为它不属于表达式的自然定义域。解集如下。

$$\{1\} \cup (3, +\infty)$$

点 $x = 1$ 在解集中表现为孤立点，这是对应零点为偶数重数的后果。

- - -

当偶数重数的零点位于分母中时，同样的推理也适用，但有一个区别：该点必须从解集中剔除，而不是作为孤立点加入。考察以下不等式。

$$\frac{x + 1}{(x - 2)^2} > 0$$

因子 $(x-2)^2$ 对每个 $x \neq 2$ 都为正，因此在整个自然定义域内，表达式的符号与分子 $x + 1$ 的符号一致。于是表达式对 $x > -1$ 为正，但点 $x = 2$ 除外，因为在该点表达式无定义。解集如下。

$$(-1, 2) \cup (2, +\infty)$$

分母的零点不会引起符号改变，然而它必须从解集中排除，从而留下一个有洞的区间。

## 解集的结构

分式不等式的解集始终是实数轴上若干区间的并集，可能还包含若干孤立点。解集中的每个区间都以临界点为界，其端点要么是分子的零点（若不等式为非严格不等式则可能包含在内），要么是分母的零点（始终被排除在外）。当分子中出现偶数重数的零点时，它为解集贡献的是孤立点而非区间，正如前面关于重数与符号变化的章节所述。

为具体说明，考虑一个有理表达式，其临界点为 $x = 1$、$x = 2$ 和 $x = 4$，其中 $x = 2$ 是分母的零点。若符号表显示该表达式在 $[1, 2)$ 和 $(2, 4]$ 上非负，则解集如下。

$$[1, 2) \cup (2, 4]$$

点 $x = 2$ 在两个区间中都不出现，因为它不属于该表达式的自然定义域，尽管相邻的两个区间从两侧都延伸到它。

## 示例 1

求满足下列不等式的 $x$ 的值。

$$\frac{x - 1}{2 - x} < 0$$

该不等式已是规范形式。分母 $2 - x$ 在 $x = 2$ 处为零，因此必须将此值排除在解集之外。该表达式的自然定义域如下。

$$D = \{\ x \in \mathbb{R} : x \neq 2 \ \}$$

为了确定不等式成立的区间，我们利用这样一个事实：有理表达式恰好在其分子与分母符号相反时为负。分子 $x - 1$ 在 $x < 1$ 时为负，而分母 $2 - x$ 在 $x > 2$ 时为负。通过构造[符号表](../sign-analysis-in-inequalities/)，可得：

[class="table-sign"]

|                           |              |      $$1$$             |     $$2$$              |
|:-------------------------|:------------------------:|:------------------------:|:-------------------------:|
| $$x - 1 \lt 0$$       | $\boldsymbol{-}$   | $\boldsymbol{+}$   | $\boldsymbol{+}$    |
| $$2 - x \lt 0$$       | $\boldsymbol{+}$   | $\boldsymbol{+}$   | $\boldsymbol{-}$    |
| $$\frac{x-1}{2-x} \lt 0$$ | $\boldsymbol{-}$ | $\boldsymbol{+}$   | $\boldsymbol{-}$    |
[/class]

由符号表可知，该表达式在区间 $x < 1$ 和 $x > 2$ 上为负。由于该不等式是严格不等式，端点被排除在外，故解集如下：

$$(-\infty, 1) \cup (2, +\infty)$$

## 示例 2

确定满足以下不等式的 $x$ 的值。

$$\frac{x - 1}{x^2 - 5x + 6} \geq 0$$

分母是一个二次多项式，其零点可通过求解相应的[二次方程](../quadratic-equations/)得到，这与[二次不等式](../quadratic-inequalities/)的处理方式相同。该多项式[因式分解](../factoring-quadratic-equations/)如下。

$$(x-2)(x-3) = 0$$

由此得到 $x = 2$ 和 $x = 3$，这两个值使分母为零，因此必须从解集中排除。自然定义域如下。

$$D = \{\ x \in \mathbb{R} : x \neq 2, x \neq 3 \ \}$$

分子在 $x = 1$ 处为零，它与 $x = 2$ 和 $x = 3$ 一起给出三个临界点，将实数轴划分为四个开区间。现在我们在[符号表](../sign-analysis-in-inequalities/)上表示它们的符号：

[class="table-sign"]

|             |      | $$1$$   | $$2$$     |    $$3$$      |
|:-----------|:------------------:|:------------:|:----------------:|:----------------:|
| $$x-1 \geq 0$$ | $\boldsymbol{-}$ | $\boldsymbol{+}$  |  $\boldsymbol{+}$  |  $\boldsymbol{+}$ |
| $$x^2 - 5x + 6 \geq 0$$ |  $\boldsymbol{+}$ |$\boldsymbol{+}$  | $\boldsymbol{-}$  | $\boldsymbol{+}$  |
| $$\frac{x - 1}{x^2 - 5x + 6} \geq 0$$ | $\boldsymbol{-}$  | $\boldsymbol{+}$ |  $\boldsymbol{-}$  | $\boldsymbol{+}$ |
[/class]

由符号表可知，该表达式在区间 $1 \leq x < 2$ 和区间 $x > 3$ 上非负。端点 $x = 2$ 和 $x = 3$ 被排除，因为它们不属于自然定义域；而 $x = 1$ 被包含在内，因为该不等式是非严格的，且分子在该点处为零。解集如下：

$$[1, 2) \cup (3, +\infty)$$

## 化为标准形式

上述方法要求不等式已经处于标准形，即左边是单个分式表达式，右边是零。实际遇到的不等式并非总是这种形式。常见的一种情形是两边都出现分式表达式，如下所示。

$$\frac{2x + 1}{x - 3} \geq \frac{1}{x + 1}$$

正确的做法是将所有项移到左边，合并成单个分式表达式。两边同时减去右边，得到下式。

$$\frac{2x + 1}{x - 3} - \frac{1}{x + 1} \geq 0$$

随后将两个分式在公分母上合并。

$$\frac{(2x + 1)(x + 1) - (x - 3)}{(x - 3)(x + 1)} \geq 0$$

展开分子，得到下式。

$$\frac{2x^2 + 3x + 1 - x + 3}{(x - 3)(x + 1)} \geq 0$$

化简后得到下式。

$$\frac{2x^2 + 2x + 4}{(x - 3)(x + 1)} \geq 0$$

分子 $2x^2 + 2x + 4$ 可写作 $2(x^2 + x + 2)$。$x^2 + x + 2$ 的判别式为 $\Delta = 1 - 8 = -7 < 0$，因此该二次式[没有实根](../quadratic-equations-with-complex-solutions/)，且对所有实数 $x$ 严格取正。于是整个表达式的符号完全由分母 $(x-3)(x+1)$ 的符号决定，当 $x < -1$ 或 $x > 3$ 时分母为正。由于分子永远不为零，两个端点都不能包含在内，解集如下。

$$(-\infty, -1) \cup (3, +\infty)$$

当右边是非零常数时，同样的化简仍然适用，例如 $\frac{x+2}{x-1} \leq 2$。减去该常数并在公分母 $x - 1$ 上合并后，同样得到与零比较的单个分式表达式，之后符号表照常进行。

此类问题中常见的错误，是在未考虑因子符号的情况下，直接将原不等式两边乘以 $x - 3$ 或 $x + 1$。由于线性表达式的符号取决于 $x$，这样的乘法需要分类讨论，比上述化为标准形式的方法更易出错。

另一处需要警惕的是分子与分母之间的公因式。在任何约分之前，必须先确定自然定义域，因为约去的因式仍然将其零点排除在定义域之外。考虑下式。

$$\frac{(x - 1)(x + 2)}{x - 1} > 0$$

当 $x \neq 1$ 时，该表达式等于 $x + 2$，因此化简后的不等式 $x + 2 > 0$ 在 $x > -2$ 上成立。点 $x = 1$ 不属于自然定义域，即使约分后也必须剔除，所以解集如下。

$$(-2, 1) \cup (1, +\infty)$$

若先约分而忘记被排除的值，会得到错误答案 $(-2, +\infty)$，其中包含点 $x = 1$，而原表达式在该点处无定义。

## 倒数法则

一类特殊的分式不等式涉及未知数的函数的倒数，形式为 $1/f(x) > k$ 或比较 $1/f(x) > 1/g(x)$。这类不等式值得单独讨论，因为直接对两边取倒数的诱惑是常见的错误来源。

倒数与[序关系](../properties-of-real-numbers/)之间的相互作用受以下法则支配。对于任意符号相同且满足 $a < b$ 的实数 $a$ 和 $b$：

$$0 < a < b \quad \Longrightarrow \quad \frac{1}{b} < \frac{1}{a}$$

$$a < b < 0 \quad \Longrightarrow \quad \frac{1}{b} < \frac{1}{a}$$

在两种情况下，取倒数时不等式的方向都反转。当 $a$ 和 $b$ 符号相反时，同样的结论不成立，因为此时倒数在符号上不同，原关系的方向不能转移到倒数上。

考虑不等式：

$$\frac{1}{x} > 4$$

简单套用倒数法则会得出 $x < \frac{1}{4}$，但这个结论是错误的，因为该法则仅在两边符号已知相同时才适用。条件 $\frac{1}{x} > 4$ 要求 $\frac{1}{x}$ 为正，而这又要求 $x > 0$，因此基于 $x$ 符号的情况分析已内含于推理之中。正确的步骤遵循标准方法：将所有项移到一边，并在公分母上合并。

$$\frac{1}{x} - 4 > 0$$

在公分母 $x$ 上合并两项，得到如下结果。

$$\frac{1 - 4x}{x} > 0$$

临界点为 $x = 0$ 和 $x = \frac{1}{4}$。分子和分母的符号表如下。

[class="table-sign"]

|                          |          | $$0$$            | $$\frac{1}{4}$$  |
| :----------------------- | :------: | :--------------: | :--------------: |
| $$1 - 4x > 0$$           | $\boldsymbol{+}$ | $\boldsymbol{+}$ | $\boldsymbol{-}$ |
| $$x > 0$$                | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{+}$ |
| $$\frac{1 - 4x}{x} > 0$$ | $\boldsymbol{-}$ | $\boldsymbol{+}$ | $\boldsymbol{-}$ |
[/class]

比值在开区间 $\left(0, 1/4\right)$ 上为正，这正是正确的解集。简单的倒数步骤会产生更大的集合 $\left(-\infty, 1/4\right)$，将每个 $x < 0$ 作为增解引入，因为不等式 $1/x > 4$ 在左侧为负的 $x < 0$ 上自动不成立。

> 倒数法则及其操作运用，是[解的丢失与引入](../loss-of-solutions-in-inequalities/)条目中所分析的更一般现象的特例。化为标准形式是系统的对策，以分子和分母上的单一符号表取代变量表达式符号的情况分析。
