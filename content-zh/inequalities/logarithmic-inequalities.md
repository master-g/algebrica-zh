## 引言

对数不等式是指未知数出现在[对数](../logarithms/)内部的[不等式](../inequalities/)，未知数可能出现在真数中，有时也可能出现在底数中。它们的一般形式为：

$$\log_a f(x) > \log_a g(x)$$

或在较简单的情形中，形式为：

$$\log_a f(x) > b$$

同样的定义也适用于用符号 $<$、$\geq$ 和 $\leq$ 代替 $>$ 的情形。底数 $a$ 必须满足 $a > 0$ 和 $a \neq 1$，这与[对数方程](../logarithmic-equations/)所要求的可容许条件相同。此外，每个对数的真数都必须严格为正，因为[对数函数](../logarithmic-function/)仅在正实数上有定义。这一要求赋予了对数不等式一个指数不等式所没有的特征，即求解过程必须始终从确定定义域开始。

求解依赖于对数函数的单调性。当 $a > 1$ 时，函数 $\log_a x$ 严格递增，因此较大的真数产生较大的对数。

当 $0 < a < 1$ 时，函数严格[递减](../increasing-and-decreasing-functions/)，因此较大的真数产生较小的对数。因此，两个同底数对数之间的比较可以转化为真数之间的比较：第一种情形方向相同，第二种情形方向相反。

## 对数不等式的求解方法

形如 $\log_a f(x) > \log_a g(x)$ 的不等式的求解可以组织为四个步骤。

+ 确定[定义域](../determining-the-domain-of-a-function/)，要求每个对数的真数严格为正，由此得到不等式组 $f(x) > 0$ 和 $g(x) > 0$。
+ 如果不等式涉及不同底数的对数，通过换底公式将所有对数项统一为同一底数，并利用对数的性质进行合并。
+ 利用单调性去掉对数。当 $a > 1$ 时，真数之间的不等式保持原方向不变；当 $0 < a < 1$ 时，方向反转。
+ 求解所得的代数不等式，并将其解集与第一步中求得的定义域取交集。

由于对数函数是严格单调的，去掉对数后得到的不等式在定义域内与原不等式等价。只要最后与定义域取交集，就不会增解或失解。

最后一步取交集绝非形式上的步骤。去掉对数后所得的代数不等式，通常会被那些原对数甚至没有定义的值所满足，这些值必须被排除。

## 对数与常数的比较

一个常见的特殊情形是单个对数与常数之间的比较。常数总可以写成同底数的对数，因为 $b = \log_a a^b$，此后便可应用单调性法则。考虑不等式：

$$\log_3(2x + 5) \leq 2$$

定义域要求 $2x + 5 > 0$，即 $x > -\frac{5}{2}$。将 $2 = \log_3 9$ 改写后，不等式化为以 $3 > 1$ 为底数的两个对数之间的比较，因此去掉对数时方向保持不变：

$$
\begin{align}
&2x + 5 \leq 9 \\[6pt]
&x \leq 2
\end{align}
$$

与定义域取交集，得到解集 $\left(-\frac{5}{2}, 2\right]$。

- - -

底数介于零和一之间时，同样的步骤需要反转不等号方向。考虑：

$$\log_{\frac{1}{2}}(x + 1) \geq -2$$

定义域要求 $x > -1$。将 $-2 = \log_{\frac{1}{2}} 4$ 改写，由于 $\left(\frac{1}{2}\right)^{-2} = 4$，并利用底数严格介于零和一之间这一事实，真数之间的比较方向反转，得到 $x + 1 \leq 4$，即 $x \leq 3$。与定义域取交集，得到解集 $(-1, 3]$。

> 解的下端点来自定义域，上端点来自不等式本身。若忽略定义域，会错误地纳入诸如 $x = -1$ 这样的值，而对数在这些值处没有定义。

## 示例 1

我们求解一个两侧底数相同且大于一的对数不等式：

$$\log_2(x^2 - 3) > \log_2(2x)$$

定义域要求两个真数都严格为正：

$$\begin{cases}
x^2 - 3 > 0 \\[6pt]
2x > 0
\end{cases}$$

第一个条件给出 $x < -\sqrt{3}$ 或 $x > \sqrt{3}$，第二个给出 $x > 0$。它们的交集是 $x > \sqrt{3}$，即该不等式的定义域。

底数为 $2 > 1$，因此对数函数严格递增，去掉对数后不等号方向不变：

$$
\begin{align}
&x^2 - 3 > 2x \\[6pt]
&x^2 - 2x - 3 > 0
\end{align}
$$

所得的[二次不等式](../quadratic-inequalities/)对应的方程为 $(x + 1)(x - 3) = 0$，根为 $x_1 = -1$ 和 $x_2 = 3$。抛物线开口向上，故三项式在两个外侧区间为正，即 $x < -1$ 或 $x > 3$。与定义域 $x > \sqrt{3}$ 取交集后，整个分支 $x < -1$ 被排除，另一支被截短，得到解集：

$$(3, +\infty)$$

[shortcode="intervals"]
| | $-1$            | $\sqrt{3}$       |     $3$      |     |
|-|---------------|----------|-----------|-----|
| |  sign+r-o     |          | sign+l-o   |     |
| |               | sign+l-o |            |     |
| |               |          | sign+l-o-h |     |
[/shortcode]

> 分支 $x < -1$ 满足该代数不等式，但不含任何容许值，因为 $2x$ 在那里为负。这正是定义域重塑对数不等式解集的典型方式。

## 示例 2

我们求解一个底数介于零与一之间的不等式：

$$\log_{\frac{1}{3}}(x - 2) > \log_{\frac{1}{3}}(8 - x)$$

定义域要求两个真数都严格为正：

$$\begin{cases}
x - 2 > 0 \\[6pt]
8 - x > 0
\end{cases}$$

第一个条件给出 $x > 2$，第二个给出 $x < 8$，故定义域为区间 $(2, 8)$。

底数为 $1/3$，严格介于零与一之间，因此对数函数严格递减，两个真数之间的比较方向反转：

$$
\begin{align}
&x - 2 < 8 - x \\[6pt]
&2x < 10 \\[6pt]
&x < 5
\end{align}
$$

与定义域 $(2, 8)$ 取交集，得到解集：

$$(2, 5)$$

[shortcode="intervals"]
| | $2$             | $5$       |     $8$      |     |
|-|---------------|----------|-----------|-----|
| |  sign+l-o     |          | sign+r-o   |     |
| |               | sign+r-o |            |     |
| | sign+l-in-o-h | sign+r-in-o-h  |      |     |
[/shortcode]

快速验证可以确认结果。当 $x = 3$ 时，不等式比较 $\log_{\frac{1}{3}} 1 = 0$ 与 $\log_{\frac{1}{3}} 5$，后者为负，比较成立。当 $x = 6$ 时，比较 $\log_{\frac{1}{3}} 4$ 与 $\log_{\frac{1}{3}} 2$，前者是两者中较小的一个，因此不等式不成立。

## 统一底数

当不等式中出现的对数具有不同的底数时，[换底公式](../logarithms/)将每一项都统一到同一底数，之后即可按照通常的步骤求解。考虑不等式：

$$\log_4 x + \log_2 x \geq 3$$

定义域要求 $x > 0$。第一项可以改写为以 $2$ 为底数的形式，因为：

$$\log_4 x = \frac{\log_2 x}{\log_2 4} = \frac{1}{2}\log_2 x$$

代入不等式并合并对数项，得到：

$$
\begin{align}
&\frac{1}{2}\log_2 x + \log_2 x \geq 3 \\[6pt]
&\frac{3}{2}\log_2 x \geq 3 \\[6pt]
&\log_2 x \geq 2
\end{align}
$$

底数为 $2 > 1$，因此过渡到真数时方向保持不变，得到 $x \geq 2^2 = 4$。该下界位于定义域内，因此解集为半直线：

$$[4, +\infty)$$

> 最后一步乘以 $\frac{2}{3}$ 时不等号方向保持不变，因为该因子为正。当换底产生负系数时，不等式乘以负常数会使方向反转。

## 通过换元化为多项式的不等式

一类常见的对数不等式多次出现同一个对数，且其中一项常为平方项。这类不等式通过引入一个等于该对数的新变量来求解，从而将问题转化为一个代数不等式。考虑不等式：

$$\ln^2 x - \ln x - 6 \leq 0$$

定义域要求 $x > 0$。令 $t = \ln x$，不等式变为关于该辅助变量的一个[二次不等式](../quadratic-inequalities/)：

$$t^2 - t - 6 \leq 0$$

相应的方程因式分解为 $(t + 2)(t - 3) = 0$，根为 $t_1 = -2$ 和 $t_2 = 3$。抛物线开口向上，因此该三项式在两个根之间取非正值：

$$-2 \leq t \leq 3$$

回代 $t = \ln x$ 得到双重不等式 $-2 \leq \ln x \leq 3$。由于自然对数严格递增，过渡到真数时两个比较关系都保持不变，未知数满足：

$$e^{-2} \leq x \leq e^{3}$$

两个端点均为正，因此整个区间都在定义域内，解集为闭区间 $[e^{-2}, e^{3}]$。

> 与用于[指数不等式](../exponential-inequalities/)的换元 $t = a^x$ 不同，换元 $t = \log_a x$ 对 $t$ 不施加任何符号限制，因为对数可取任意实数值。此处的负值 $t = -2$ 是完全允许的，并产生端点 $x = e^{-2}$。对原变量的约束完全来自定义域 $x > 0$。

## 底数中含未知数的不等式

当未知数出现在对数的底数中时，容许条件 $h(x) > 0$ 和 $h(x) \neq 1$ 限制定义域，而去掉对数后不等式的方向也不再预先固定。$\log_{h(x)}$ 的单调性取决于底数大于还是小于一，因此问题分两种情形讨论。考虑不等式：

$$\log_x 9 < 2$$

底数条件要求 $x > 0$ 和 $x \neq 1$。写 $2 = \log_x x^2$ 将不等式化为同一底数下两个对数的比较，然后分情形讨论。

当 $x > 1$ 时对数严格递增，因此方向保持，不等式化为 $9 < x^2$。对于正值这意味着 $x > 3$，与 $x > 1$ 结合，第一种情形给出 $x > 3$。

当 $0 < x < 1$ 时对数严格递减，因此方向反转，不等式变为 $9 > x^2$，即对正值有 $x < 3$。$(0, 1)$ 中的每个数都满足此条件，故第二种情形贡献整个区间 $(0, 1)$。

合并两种情形，解集为并集：

$$(0, 1) \cup (3, +\infty)$$

> 区间 $(0, 1)$ 乍看可能令人意外，但对于零到一之间的底数，$9$ 的对数为负，而负数当然小于 $2$。情形分析自动捕捉了这一行为。

## 解集的结构与定义域的作用

对数不等式的解集是包含在定义域内的有限个区间的并集，可能为空。基本不等式 $\log_a x > b$ 在 $a > 1$ 下有解 $x > a^b$，这是一条端点总为正的半直线；而在 $0 < a < 1$ 下有解 $0 < x < a^b$，这是一个左端由定义域限定为零的有界区间。两种情形下，边界 $x = a^b$ 都是对数等于 $b$ 的唯一点，这是对数函数单射性的推论。

定义域在这里比在[指数不等式](../exponential-inequalities/)中发挥更关键的作用，在后者中未知数可取任何实数值。诸如乘积法则和商法则之类的代数运算会扩大满足变换后不等式的值的集合，正如它们在[对数方程](../logarithmic-equations/)中引入增根一样。因此，与一开始确定的定义域取交集是该方法不可或缺的组成部分，而非可省略的最后验证。
