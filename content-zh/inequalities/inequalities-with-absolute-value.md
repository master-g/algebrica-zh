## 引言

实数 $x$ 的[绝对值](../absolute-value/)定义如下：

$$|x| = \begin{cases} +x & x \geq 0 \\[6pt]
-x & x < 0 \end{cases}
 \qquad \forall x \in \mathbb{R}$$

在几何上，$|x|$ 表示 $x$ 在实数轴上与原点的距离，更一般地，$|x - a|$ 表示 $x$ 与点 $a$ 之间的距离。这种几何解释通常是理解涉及绝对值的不等式最自然的方式，它也将为下文讨论的求解方法提供直觉指引。

- - -

求解此类不等式所依据的性质如下。对于每个[实数](../properties-of-real-numbers/) $k > 0$ 和每个实值表达式 $f(x)$，以下等价关系成立：

+ $|f(x)| \leq k$ 当且仅当 $-k \leq f(x) \leq k$。
+ $|f(x)| \geq k$ 当且仅当 $f(x) \leq -k$ 或 $f(x) \geq k$。

同样的等价关系可推广到严格不等式的情形，将 $\leq$ 替换为 $<$，将 $\geq$ 替换为 $>$。$k$ 的其余取值由绝对值的非负性直接确定。当 $k = 0$ 时，不等式 $|f(x)| \leq 0$ 仅在 $f(x) = 0$ 时成立，而 $|f(x)| < 0$ 无解。对于 $k < 0$，不等式 $|f(x)| \leq k$ 对任何 $x$ 都无解。对称地，当 $k \leq 0$ 时，$|f(x)| \geq k$ 被 $f$ 定义域内的每个 $x$ 所满足，而 $|f(x)| > 0$ 对除 $f$ 的零点外的每个 $x$ 都成立。

另一种方法适用于绝对值内部的表达式为[线性](../linear-inequalities/)的情形，它通过分段定义来分析该表达式的符号。先找出该表达式等于零的点，将实数轴划分为相应的两条半直线，再分别在其上重写不等式并去掉绝对值，最后将各部分解取并集。

> 求解涉及绝对值的不等式遵循与求解[含绝对值的方程](../absolute-value-equations/)相同的原则：运用绝对值函数的定义性质在代数上去掉它，从而将问题化归为一组普通的不等式，再分别求解并加以组合。

## 三角不等式

与绝对值不等式密切相关的一个基本结论是三角不等式。对于任意两个实数 $a$ 和 $b$，以下关系成立：

$$|a + b| \leq |a| + |b|$$

该不等式表明，和的绝对值不超过绝对值之和。一个有用的伴生结论是反三角不等式，它给出了绝对值之差的上界：

$$\bigl| |a| - |b| \bigr| \leq |a - b|$$

这两个结论的证明及其推论的详细讨论见[绝对值](../absolute-value/)词条。

> 在处理涉及绝对值之和的表达式时，牢记该结论是有益的，因为它提供了一个直接的上界，可以简化估计而无需逐一分情况分析。

## 示例 1

考虑以下简单的不等式：

$$|x - 3| \leq 5$$

对 $\leq$ 的情形应用该基本性质，可得到一个复合不等式，等价于两个同时成立的条件构成的[不等式组](../systems-of-inequalities/)：

$$-5 \leq x - 3 \leq 5$$

为分离 $x$，对该复合不等式的三个部分同加 $3$。此操作是合法的，因为在不等式各部分加上同一个量不会改变不等号的方向。

$$-5 + 3 \leq x \leq 5 + 3$$

$$-2 \leq x \leq 8$$

将所得的值在实数轴上表示出来，得到下图：

[shortcode="intervals"]
| | $-2$     | $8$   |     |
|----------------------|---------------|--------------------|-----|
| |              |      sign+r-c       |     |
| | sign+l-c      |                    |     |
| |    sign+l-in-c-h           |     sign+r-in-c-h   |     |
[/shortcode]

高亮的一行表示两个条件的交集，即所有使两个不等式同时成立的 $x$ 的取值构成的集合。因此，解为闭区间 $[-2, 8]$。

> 由几何解释同样可得该结论。不等式 $|x - 3| \leq 5$ 要求与 $3$ 的距离不超过 $5$ 的点，而这些点恰好构成区间 $[3 - 5, 3 + 5] = [-2, 8]$。

## 示例 2

考虑下面的不等式：

$$|2x + 1| > 3$$

对于 $>$ 的情形应用基本性质，该不等式分裂为两个并列条件，其中至少一个必须成立。

$$2x + 1 < -3$$

$$2x + 1 > 3$$

处理第一个条件，从两边减去 $1$ 得到 $2x < -4$，再除以 $2$ 得到 $x < -2$。由于除数为正，不等号方向保持不变。

用同样的方式处理第二个条件，减去 $1$ 得到 $2x > 2$，再除以 $2$ 得到 $x > 1$。

在实数轴上表示所得到的值，得到下面的图：

[shortcode="intervals"]
| | $-2$      | $1$  |     |
|----------------------|---------------|--------------------|-----|
| | sign+r-o      |                    |     |
| |               |      sign+l-o      |     |
| | sign+r-o-h    |         sign+l-o-h           |  |
[/shortcode]

与上一个情形不同，高亮的行表示两个条件的并集，即满足两个不等式中至少一个的 $x$ 的取值集合。

因此解为开区间 $(-\infty, -2) \cup (1, +\infty)$ 的并集。

> 从几何上看，两边除以 $2$ 将不等式改写为 $\left|x + \frac{1}{2}\right| > \frac{3}{2}$，它要求与 $-\frac{1}{2}$ 的距离超过 $\frac{3}{2}$ 的点。这些正是位于 $-2$ 左侧或 $1$ 右侧的点。

## 示例 3

基本等价关系不依赖于绝对值内部表达式的代数形式，当其中的式子不是线性式时同样适用。考虑下面的不等式：

$$|x^2 - 9| < 7$$

对于 $<$ 的情形应用基本性质，该不等式等价于一个复合条件：

$$-7 < x^2 - 9 < 7$$

给复合不等式的三个部分同加 $9$，从而分离出 $x^2$，得到：

$$2 < x^2 < 16$$

两个部分必须同时成立。左边的不等式 $x^2 > 2$ 对 $x < -\sqrt{2}$ 或 $x > \sqrt{2}$ 成立，而右边的不等式 $x^2 < 16$ 对 $-4 < x < 4$ 成立。交集由位于 $(-4, 4)$ 中、同时又位于闭区间 $[-\sqrt{2}, \sqrt{2}]$ 之外的点组成。

因此解为两个开区间的并集：

$$\left(-4, -\sqrt{2}\right) \cup \left(\sqrt{2}, 4\right)$$

## 示例 4

当不等式的右端不是常数，而是与 $x$ 相关时，绝对值的分段定义提供了一条系统化的求解路径。考察下述不等式：

$$|x - 4| > -2x + 1$$

表达式 $x - 4$ 在 $x = 4$ 处为零，实数轴由此被划分为两条半直线 $x \geq 4$ 和 $x < 4$。在每一条上，都可以去掉绝对值，把不等式改写为基本形式。

- - -

情形 $x \geq 4$。在该区域 $x - 4 \geq 0$，绝对值保持其自变量不变。不等式变为：

$$x - 4 > -2x + 1$$

两边同加 $2x$，再加 $4$，得到 $3x > 5$，于是 $x > \frac{5}{3}$。与区域 $x \geq 4$ 取交，得到 $x \geq 4$，因为 $\frac{5}{3} < 4$。

- - -

情形 $x < 4$。在该区域 $x - 4 < 0$，绝对值会改变符号。不等式变为：

$$-(x - 4) > -2x + 1$$

$$-x + 4 > -2x + 1$$

两边同加 $2x$，得到 $x + 4 > 1$，于是 $x > -3$。与区域 $x < 4$ 取交，得到 $-3 < x < 4$。

- - -

将两部分结果取并集，由第一种情形得到的点 $x \geq 4$ 与由第二种情形得到的点 $-3 < x < 4$ 合起来覆盖了一切大于 $-3$ 的值。

因此，解集为开半直线 $\left(-3, +\infty\right)$。

> 与此类型不等式的另一种处理方式，依据的是右端的符号而非自变量的符号，将在下文关于非常数右端不等式的小节中讨论。

## 示例 5

考虑下面的不等式，其中出现了两个不同的绝对值：

$$|x + 1| + |x - 2| > 4$$

当不等式包含不止一个绝对值时，最系统的方法是根据各绝对值内表达式的零点对实数轴进行划分。表达式 $x + 1$ 和 $x - 2$ 分别在 $x = -1$ 和 $x = 2$ 处为零，由此得到三个区域，需要分别分析。

- - -

情形 $x < -1$。在该区域内 $x + 1 < 0$ 且 $x - 2 < 0$，两个表达式均为负，绝对值改变它们的符号。不等式变为如下形式：

$$-(x + 1) + (-(x - 2)) > 4$$

$$-x - 1 - x + 2 > 4$$

$$-2x + 1 > 4$$

两边减去 $1$，得到 $-2x > 3$。由于除数为负，两边除以 $-2$ 并反转不等号方向，得到如下结果：

$$x < -\frac{3}{2}$$

该条件必须在区域 $x < -1$ 内成立。由于 $-\frac{3}{2} < -1$，条件 $x < -\frac{3}{2}$ 是两者中更严格的一个，与 $x < -1$ 的交集简化为 $x < -\frac{3}{2}$。因此，该情形的贡献为 $\left(-\infty, -\frac{3}{2}\right)$。

- - -

情形 $-1 \leq x < 2$。在该区域内 $x + 1 \geq 0$ 且 $x - 2 < 0$。不等式变为如下形式：

$$(x + 1) + (-(x - 2)) > 4$$

$$x + 1 - x + 2 > 4$$

$$3 > 4$$

这是一个矛盾，对 $x$ 的任何值都不成立。因此，中间的情形无解。

- - -

情形 $x \geq 2$。在该区域内 $x + 1 > 0$ 且 $x - 2 \geq 0$，两个表达式均非负，绝对值不改变它们。不等式变为如下形式：

$$(x + 1) + (x - 2) > 4$$

$$2x - 1 > 4$$

两边加上 $1$，得到 $2x > 5$，再除以 $2$，得到如下结果：

$$x > \frac{5}{2}$$

与 $x \geq 2$ 取交集：由于 $\frac{5}{2} > 2$，有效条件为 $x > \frac{5}{2}$。因此，该情形的贡献为 $\left(\frac{5}{2}, +\infty\right)$。

- - -

综合三个情形的贡献，在实数轴各区域上得到的局部解如下图所示。

[shortcode="intervals"]
| | $-\frac{3}{2}$      | $\frac{5}{2}$   |     |
|----------------------|---------------|--------------------|-----|
| | sign+r-o      |                    |     |
| |               |      sign+l-o      |     |
| | sign+r-o-h    |         sign+l-o-h           |  |
[/shortcode]

两条开半直线的并集给出完整的解集。

因此，不等式的解为：

$$\left(-\infty, -\frac{3}{2}\right) \cup \left(\frac{5}{2}, +\infty\right)$$

> 几何解释说明了为什么中间的情形为空。量 $|x + 1| + |x - 2|$ 是 $x$ 到点 $-1$ 和 $2$ 的距离之和。对于位于两者之间的每个 $x$，该和等于两点之间的固定距离 $3$，而它小于 $4$，因此在该区域内不可能产生解。

## 示例 6

现在考虑一个更复杂的情形：不等式的右端不是一个固定数值，而是一个[实参数](../equations-with-parameters/) $k$。解集的结构取决于 $k$ 的值，因此完整的讨论需要分几种情形单独处理。考虑以下不等式：

$$|x - 1| > k$$

解的行为会随 $k$ 为负、为零或为正而发生根本性变化，这正是我们要确定的。

- - -

情形 $k < 0$。由于绝对值总是非负的，左端对任意实数 $x$ 都满足 $|x - 1| \geq 0 > k$。因此不等式对所有实数都成立，解为 $\mathbb{R}$。

- - -

情形 $k = 0$。不等式化简为 $|x - 1| > 0$，它对除绝对值等于零的那一点外的所有 $x$ 都成立。由于 $|x - 1| = 0$ 当且仅当 $x = 1$，所以解为 $\mathbb{R} \setminus \{1\}$。

- - -

情形 $k > 0$。对 $>$ 的情形应用基本性质，不等式分解为两个择一的条件：

$$x - 1 < -k$$

$$x - 1 > k$$

将 $1$ 加到每个条件的两边，得到：

$$x < 1 - k \qquad \lor \qquad x > 1 + k$$

- - -

在实数轴上表示该解，得到以下图像：

[shortcode="intervals"]
| | $1-k$      | $1+k$   |     |
|----------------------|---------------|--------------------|-----|
| | sign+r-o      |                    |     |
| |               |      sign+l-o      |     |
| | sign+r-o-h    |         sign+l-o-h           |  |
[/shortcode]

当 $k \to 0^+$ 时，两个边界点 $1 - k$ 和 $1 + k$ 从两侧逼近 $1$，解集趋于 $\mathbb{R} \setminus \{1\}$，这与情形 $k = 0$ 一致。

因此解是两个开区间的并集：

$$\left(-\infty, 1-k\right) \cup \left(1+k, +\infty\right)$$

## 右端为非常数的不等式

上面所述的等价关系是针对正的常数 $k$ 给出的，但当右端本身是 $x$ 的一个函数时，例如 $g(x)$，它们仍然成立。考虑以下不等式。

$$|f(x)| \leq g(x)$$

运用与前面相同的推理，这等价于以下复合不等式。

$$-g(x) \leq f(x) \leq g(x)$$

此等价关系对 $g(x)$ 的符号没有任何限制。在任何满足 $g(x) < 0$ 的点处，原不等式不成立，因为左端非负；复合不等式也不成立，因为 $-g(x) \leq g(x)$ 迫使 $g(x) \geq 0$。因此两种表述处处一致。

> 由于左端非负，每个解都必须满足 $g(x) \geq 0$。尽管这一条件已经隐含在复合不等式中，但在一开始就将其显式写出通常能简化计算，因为它从一开始便将分析限制在更小的区域。

作为一个具体例子，考虑如下情形。

$$|x - 1| \leq 2x - 3$$

右端 $g(x) = 2x - 3$ 仅当 $x \geq \frac{3}{2}$ 时非负，因此每个解都必须位于此半直线内。在边界点 $x = \frac{3}{2}$ 处，不等式将要求 $|x - 1| \leq 0$，即 $x = 1$，这是不可能的，因此分析可以限制在区域 $x > \frac{3}{2}$ 内。在此区域中，不等式等价于以下复合不等式。

$$-(2x - 3) \leq x - 1 \leq 2x - 3$$

左边的不等式 $-(2x - 3) \leq x - 1$ 化简为 $-2x + 3 \leq x - 1$，即 $4 \leq 3x$，得出 $x \geq \frac{4}{3}$。右边的不等式 $x - 1 \leq 2x - 3$ 化简为 $2 \leq x$，得出 $x \geq 2$。由于 $\frac{4}{3} < \frac{3}{2} < 2$，条件 $x \geq \frac{4}{3}$ 已经由要求 $x > \frac{3}{2}$ 所蕴含，而三者中起约束作用的条件是 $x \geq 2$。在实数轴上表示解，得到以下图形。

[shortcode="intervals"]
|   | $\frac{4}{3}$ | $\frac{3}{2}$ | $2$ |   |
|---|------------------|------------------|--------|---|
|   |     sign+l-c              |         |        |   |
|   |                  |      sign+l-c             | |   |
|   |                  |                  | sign+l-c |   |
|   |                  |                  | sign+l-c-h |   |
[/shortcode]

图中出现的三个临界值反映了求解过程中导出的三个条件：来自左不等式的阈值 $\frac{4}{3}$、来自 $g(x)$ 的符号要求的阈值 $\frac{3}{2}$，以及来自右不等式的阈值 $2$。由于每个条件都比前一个更严格，有效解完全由最右侧的界值确定。

因此解为区间 $[2, +\infty)$。

右端为非常数的伴随情形 $|f(x)| \geq g(x)$ 允许类似的无条件化简，等价于两个条件之一：$f(x) \leq -g(x)$ 或 $f(x) \geq g(x)$。

在实际操作中，根据右端的符号来分情况分析通常是方便的。在满足 $g(x) \leq 0$ 的地方，不等式自动成立，因为左端非负；而在满足 $g(x) > 0$ 的地方，分别求解两个普通不等式。完整的解是两个区域贡献的并集，这恰好就是上面示例 4 中观察到的结构。

## 两边同时带有绝对值

当不等式两边同时带有绝对值时，会出现一种特殊情形，如 $|f(x)| \lessgtr |g(x)|$。由于两边均为非负，且平方映射 $t \mapsto t^2$ 在 $[0, +\infty)$ 上递增，平方是一种等价变换而非单向蕴涵，无需附加的符号条件。该不等式因此等价于两边平方之间的相应不等式。

$$|f(x)| < |g(x)| \iff f(x)^2 < g(x)^2$$

将 $<$ 换成 $\leq$、$>$ 或 $\geq$ 时，同样的等价关系仍然成立。把每一项移到一边并对平方差因式分解，可将问题化归为对乘积的[符号分析](../sign-analysis-in-inequalities/)。

$$f(x)^2 - g(x)^2 = \bigl(f(x) - g(x)\bigr)\bigl(f(x) + g(x)\bigr)$$

作为一个具体实例，考虑以下不等式。

$$|x - 1| < |2x + 3|$$

两边平方并将各项移到左边，得到 $(x-1)^2 - (2x+3)^2 < 0$。对平方差因式分解，得到如下结果。

$$\bigl((x-1) - (2x+3)\bigr)\bigl((x-1) + (2x+3)\bigr) < 0$$

两个因式分别化简为 $-x - 4$ 和 $3x + 2$，因此该不等式变为 $(-x - 4)(3x + 2) < 0$。两边乘以 $-1$ 并反转不等号方向，得到 $(x + 4)(3x + 2) > 0$，该乘积在其两个根 $x = -4$ 和 $x = -2/3$ 所确定的区间之外取正值。

因此解集为两个开区间的并集。

$$\left(-\infty, -4\right) \cup \left(-\frac{2}{3}, +\infty\right)$$
