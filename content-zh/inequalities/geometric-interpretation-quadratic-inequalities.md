## 从不等式到曲线

标准形式的[二次不等式](../quadratic-inequalities/)由下式给出：

$$ax^2 + bx + c > 0, \quad a \neq 0$$

同一形式，将记号 $>$ 替换为 $<$、$\geq$ 或 $\leq$，即可适用于所有情形。一旦将左端视作 $x$ 的函数的输出值，也就是引入第二个变量后，几何解读便成为可能。

$$y = ax^2 + bx + c$$

满足该关系的数对 $(x, y)$ 在[笛卡儿平面](../the-cartesian-coordinate-plane/)上构成一条[抛物线](../parabola/)，而不等式 $ax^2 + bx + c > 0$ 所求的，是使输出值 $y$ 为正的那些 $x$ 的值。于是，求多项式取正值范围这一代数问题，便转化为确定抛物线位于水平轴上方区域的几何问题。抛物线的形状与位置由三个系数决定。

+ 系数 $a$ 控制曲线的开口方向与宽窄。其符号决定抛物线开口向上还是向下，$|a|$ 的值越大图像越窄，值越小则越宽。
+ 系数 $b$ 与 $a$ 共同确定对称轴从而也确定顶点的水平位置，其横坐标为 $-b/2a$。
+ 常数项 $c$ 给出曲线与纵轴相交的高度，因为令 $x = 0$ 即得 $y = c$。

> 关于抛物线作为曲线的完整论述，包括其焦点与准线，见[抛物线](../parabola/)专条。此处的讨论仅限于不等式及其解集所承载的几何内容。

## 二次式的符号作为平面上的区域

抛物线 $y = ax^2 + bx + c$ 位于水平轴上方的平面上的点，其横坐标恰好满足严格不等式 $ax^2 + bx + c > 0$；位于水平轴下方的点，其横坐标满足 $ax^2 + bx + c < 0$。抛物线与水平轴相交的点，对应于相应的[二次方程](../quadratic-equations/)的根，此时该表达式取值为零。

这一对应使二次不等式的解集具有直接的几何对应物。严格不等式的解，是抛物线严格位于水平轴上方或下方的部分向水平轴的投影；非严格不等式的解则还包括与水平轴的交点。因此，抛物线相对于水平轴的位置，编码了不等式的完整解集。

## 判别式作为几何判据

抛物线与水平轴的交点个数由对应二次方程的[判别式](../quadratic-formula/)决定。

$$\Delta = b^2 - 4ac$$

根据其符号的不同分为三种情形，每一种情形产生一种独特的几何构型，从而决定该不等式解集的结构。

- - -

**情形 1。** 当 $\Delta > 0$ 时，抛物线在两个不同的点 $x_1$ 和 $x_2$ 处穿过水平轴，其中 $x_1 < x_2$。曲线在两根之间位于轴的一侧，在区间 $(x_1, x_2)$ 之外位于另一侧。

![图 1](/assets/inequalities/svg/geometric-interpretation-quadratic-inequalities-1.zh.svg)

当 $a > 0$ 时，抛物线开口向上，因此在两个外部区间 $(-\infty, x_1)$ 和 $(x_2, +\infty)$ 上为正，在内部区间 $(x_1, x_2)$ 上为负。$ax^2 + bx + c > 0$ 的解是两个外部区间的并集，而 $ax^2 + bx + c < 0$ 的解是该内部区间。

当 $a < 0$ 时，抛物线开口向下，三个区间上的符号反转：在 $(x_1, x_2)$ 上为正，在两个外部区间上为负。

- - -

**情形 2。** 当 $\Delta = 0$ 时，抛物线在唯一点处与水平轴相切，该点即顶点，其横坐标是重数为二的重根 $x_0$。曲线在此点处与轴相切，其余各处均位于同一侧，在整个实数轴上保持首项系数 $a$ 的符号，唯独在 $x_0$ 处该表达式为零。

![图 2](/assets/inequalities/svg/geometric-interpretation-quadratic-inequalities-2.zh.svg)

当 $a > 0$ 时，该表达式对一切 $x \neq x_0$ 为正，且在 $x_0$ 处等于零。$ax^2 + bx + c > 0$ 的解是集合 $\mathbb{R} \setminus \{x_0\}$，而 $ax^2 + bx + c \geq 0$ 的解是整个 $\mathbb{R}$。相应的不等式 $ax^2 + bx + c < 0$ 和 $ax^2 + bx + c \leq 0$ 的解集分别为空集和单点集 $\{x_0\}$。

当 $a < 0$ 时，四种情形相应地互换角色。

- - -

**情形 3。** 当 $\Delta < 0$ 时，抛物线与水平轴完全不相交，整体位于其一侧。该表达式对一切实数 $x$ 均保持首项系数 $a$ 的符号，无一例外。

![图 3](/assets/equations/svg/geometric-interpretation-quadratic-equations-3.zh.svg)

当 $a > 0$ 时，抛物线严格位于水平轴之上，该表达式对一切 $x$ 严格为正。$ax^2 + bx + c > 0$ 的解是整个 $\mathbb{R}$，而 $ax^2 + bx + c < 0$ 的解是空集。

当 $a < 0$ 时，抛物线严格位于轴之下，符号反转：该表达式处处严格为负，因此 $ax^2 + bx + c < 0$ 的解为 $\mathbb{R}$，而 $ax^2 + bx + c > 0$ 的解集为空。

## 顶点与对称性

每个形如 $y = ax^2 + bx + c$ 的抛物线都关于垂直直线 $x = -\frac{b}{2a}$ 对称，该直线即为对称轴，而顶点是抛物线上位于此轴上的点。其坐标为：

$$V = \left(-\frac{b}{2a}, -\frac{\Delta}{4a}\right)$$

当 $a > 0$ 时，顶点是最小值；当 $a < 0$ 时，顶点是最大值。纵坐标 $-\frac{\Delta}{4a}$ 的符号与 $a$ 的符号相结合，决定顶点位于水平轴上方、轴上还是轴下方，而这恰好决定了不等式解集的结构。

+ 当 $a > 0$ 且顶点位于轴下方时，抛物线开口向上，并在两个不同的点处穿过该轴，形成情形一的构型。
+ 当 $a > 0$ 且顶点位于轴上时，抛物线在顶点处与该轴相切，形成情形二的构型。
+ 当 $a > 0$ 且顶点位于轴上方时，抛物线完全位于该轴上方，形成情形三的构型。

两个不同的根（若存在）关于对称轴对称放置。通过[求根公式](../quadratic-formula/)将它们写出，得到如下结果。

$$x_{1, 2} = -\frac{b}{2a} \pm \frac{\sqrt{\Delta}}{2a}$$

公共项 $-\frac{b}{2a}$ 是对称轴的横坐标，因此两个交点的中点与对称轴的垂足重合。每个根到轴的距离为 $\frac{\sqrt{\Delta}}{2|a|}$，当 $\Delta = 0$ 时该距离收缩为零，正是两个交点合并为切点的情形。

## 解集的判读规则

综合前面的观察，可以得到二次不等式解集的实用判读规则。一旦已知根和首项系数的符号，便可通过观察几何构型得出解，无需进一步的代数运算。

该规则取决于抛物线的朝向（由 $a$ 的符号编码）以及不等式的方向。当 $a > 0$ 且有两个不同的实根 $x_1 < x_2$ 时，多项式在区间 $[x_1, x_2]$ 之外取正值，在其内部取负值，每个不等式的解遵循显而易见的约定。

+ $ax^2 + bx + c > 0$ 的解：并集 $(-\infty, x_1) \cup (x_2, +\infty)$。
+ $ax^2 + bx + c \geq 0$ 的解：并集 $(-\infty, x_1] \cup [x_2, +\infty)$。
+ $ax^2 + bx + c < 0$ 的解：区间 $(x_1, x_2)$。
+ $ax^2 + bx + c \leq 0$ 的解：区间 $[x_1, x_2]$。

当 $a < 0$ 时，抛物线开口向下，四个不等式的解集成对互换：$ax^2 + bx + c > 0$ 的解变为内部区间，$ax^2 + bx + c < 0$ 的解变为两个外部区间的并集。同样的互换也适用于非严格版本。

> 对于任意二次不等式，一种实用程序包含三个步骤：计算判别数并在根存在时求出根，根据 $a$ 的符号确定抛物线的朝向，然后根据抛物线相对于水平轴的位置读出解集。该程序本质上基于图形，避免了构造符号表，而符号表更适合用于[因式分解法](../factoring-quadratic-equations/)以及[更高次的多项式不等式](../polynomial-inequalities/)。
