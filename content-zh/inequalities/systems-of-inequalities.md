## 定义

不等式组是由涉及一个或多个变量的两个或更多[不等式](../inequalities/)构成的集合，这些不等式必须同时成立。不等式组的解是同时满足所有不等式的变量取值的集合，也就是与各个不等式相对应的解集的交集。

本节关注单实变量 $x$ 的不等式组。这类不等式组可以写成一般形式：

$$
\begin{cases}
f_1(x) \geq 0 \\[6pt]
f_2(x) \geq 0 \\[6pt]
\quad \quad \vdots \\[6pt]
f_k(x) \geq 0
\end{cases}
$$

此表达式中每个 $f_i(x)$ 是关于变量 $x$ 的函数或表达式，每行的关系可以是任意一个不等号 $<$、$\leq$、$>$、$\geq$。

> 左侧的大括号表示逻辑合取，因为不等式组中的每个不等式都必须同时满足。这就是各不等式的解集通过求交集而非求并集来组合的原因。

无解的不等式组称为矛盾的不等式组。若不等式组中哪怕只有一个不等式的解集为空集，整个不等式组就是矛盾的。反之则不然，因为即使每个不等式单独来看都有解，只要各个解集没有公共点，整个不等式组也可能是矛盾的。

在关于[线性不等式](../linear-inequalities/)的小节中我们已经看到，求解涉及[绝对值的不等式](../inequalities-with-absolute-value/)会归结为不等式组。下面的例子展示如何在实际中求解线性不等式组。

## 例 1

考虑下面的线性不等式组：

$$
\begin{cases}
3x + 6 > 0 \\[6pt]
x - 3 \geq 0 \\[6pt]
9 - x > 0
\end{cases}
$$

我们需要确定同时满足三个不等式的 $x$ 的取值，因此先分别求解每个不等式。

对于第一个不等式，两边减去 $6$ 得到 $3x > -6$。两边除以 $3$（它为正，因此保持不等号方向），得到 $x > -2$。

第二个不等式只需在两边加上 $3$，得到 $x \geq 3$。

对于第三个不等式，两边减去 $9$ 得到 $-x > -9$。两边乘以 $-1$ 反转不等号方向，得到 $x < 9$。

因此三个解集分别是 $x > -2$、$x \geq 3$ 和 $x < 9$。不等式组的解是三者共同的取值。将三个区间表示在实数轴上，交集便一目了然。

[shortcode="intervals"]
|     | $-2$                 | $3$           | $9$                |     |
|:----|----------------------|---------------|--------------------|-----|
|     | sign+l-o             |               |                    |     |
|     |                      | sign+l-c      |                    |     |
|     |                      |               | sign+r-o           |     |
|     |                      | sign+l-in-c-h | sign+r-in-o-h      |     |
[/shortcode]

不等式组的解是半开区间：

$$x \in [3, 9)$$

此区间包含 $3$（因为第二个不等式不是严格的），不包含 $9$（因为第三个不等式是严格的）。

> 关于实数轴上区间的结构和解读的详细讨论，参见[专门条目](../determining-the-domain-of-a-function/)。

## 求解不等式组的一般策略

上一个例子中的不等式组非常简单，由关于变量 $x$ 的三个线性不等式构成。不等式组可能复杂得多，可以涉及有理式、[根式](../radicals/)、[幂](../powers/)、[对数](../logarithms/)、指数函数和[三角函数](../sine-and-cosine/)。

虽然每个不等式的求解依赖于所涉及函数的具体形式和性质，但基本原则不变：不等式组的解必须同时满足其中所有不等式，也就是各个解集的交集。

不等式组的求解遵循一组明确的步骤：

+ 分别求解每个不等式并确定其解集。
+ 适当时，将解集表示在实数轴上，以便直观显示所得区间。
+ 找出所有解集的交集，因为只有所有不等式的公共取值才满足该不等式组。
+ 用区间记号表示最终解，并正确处理每个端点是否包含。

> 这一过程提供了一个适用于多种问题的可靠框架。即使所涉及的函数更加复杂，同样的原则仍能指导分析，使每一步在逻辑上都有据可循。

## 例 2

考虑下面的不等式组，其中第一个不等式包含对数：

$$
\begin{cases}
\log_2(2x+4) > \log_2(x) \\[6pt]
x - 2 > 0
\end{cases}
$$

在求解第一个不等式之前，需要确定对数表达式的[定义域](../determining-the-domain-of-a-function/)，因为对数仅在其真数大于零时有定义。这个要求产生两个条件。

$$
\begin{align}
2x + 4 > 0 \ &\rightarrow \ x > -2 \\[6pt]
x > 0 \ &\rightarrow \ x > 0
\end{align}
$$

两个条件的交集为 $x > 0$，这就是第一个不等式有意义的集合。

现在可以求解第一个不等式。两个对数有相同的底数 $2$；因为该底数大于 $1$，对数函数严格递增。因此，在定义域内，对数之间的不等式等价于真数之间的同向不等式。

$$2x + 4 > x \ \rightarrow \ x > -4$$

将此条件与定义域 $x > 0$ 取交集，可得第一个不等式对 $x > 0$ 成立。第二个不等式两边加上 $2$ 后化为 $x > 2$。现在求两个解集的交集。

[shortcode="intervals"]
|     | $0$                    | $2$             |   |
|:----|----------------------|---------------|---|
|     | sign+l-o             |               |   |
|     |                      | sign+l-o      |   |
|     |                      | sign+l-o-h    |   |
[/shortcode]

该不等式组的解是无界区间：

$$x > 2$$

由于 $(2, +\infty)$ 包含在 $(0, +\infty)$ 中，不等式组的每一个解都自动满足对数定义域的条件。

## 矛盾不等式组

即使不等式组中的每个不等式各自都有解，整个不等式组仍可能无解。考虑下面的不等式组：

$$
\begin{cases}
x - 5 > 0 \\[6pt]
2 - x \geq 0
\end{cases}
$$

第一个不等式给出 $x > 5$，第二个不等式给出 $x \leq 2$。每个解集都是非空区间，但没有任何实数能同时大于 $5$ 且小于等于 $2$。两个区间的交集为空，因此这是一个矛盾不等式组，其解集为空集 $\varnothing$。

## 多元不等式组

更复杂的不等式组由涉及 $m$ 个变量的 $k$ 个不等式构成，其一般形式为：

$$
\begin{cases}
f_1(x_1, x_2, \ldots, x_m) \geq 0 \\[6pt]
f_2(x_1, x_2, \ldots, x_m) \geq 0 \\[6pt]
\quad \quad \vdots \\[6pt]
f_k(x_1, x_2, \ldots, x_m) \geq 0
\end{cases}
$$

在这种情况下，解集是 $\mathbb{R}^m$ 中的一个区域，而不是若干区间的并集。确定这样的解集需要更高级的方法，如图解法、符号分析、线性规划以及各种数值方法。两个变量的情形在二元线性不等式和二元线性不等式组的相关条目中讨论。
