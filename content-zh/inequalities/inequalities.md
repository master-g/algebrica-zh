## 定义

不等式是断言两个表达式之间满足某种序关系的数学命题，通常写作 $F(x) > G(x)$、$F(x) < G(x)$、$F(x) \geq G(x)$ 或 $F(x) \leq G(x)$ 的形式，其中一个或多个变量作为未知数在某个指定的[集合](../types-of-numbers/)（例如 $\mathbb{R}$）上取值。求解不等式，就是在适当的[定义域](../determining-the-domain-of-a-function/)内确定使该序关系成立的一切变量取值。许多不等式都可以整理成如下形式：

$$F(x) > 0$$

这种表示方式简化了对不等式的研究，凸显了其结构，并为不同的求解方法提供了统一框架。同一形式，只需把符号 $>$ 替换为 $<$、$\geq$ 或 $\leq$，便可涵盖所有情形。

不等式的解是使序关系成立的一切变量取值构成的集合。与[方程的解](../equations/)——通常是离散的点集——不同，不等式的解通常是实数轴上若干[区间](../intervals/)的并，可能还附带若干孤立点。根据不等式及其结构，解集可能是：

+ 单个区间，有界或无界
+ 若干互不相交区间的并
+ 空集，当没有任何值满足该不等式时
+ 整个 $\mathbb{R}$，当该不等式恒成立时

> 每个区间的端点取决于不等式是严格的还是非严格的。严格不等式用 $>$ 或 $<$ 表示，排除边界点，产生开区间；非严格不等式用 $\geq$ 或 $\leq$ 表示，包含边界点，产生闭区间或半开区间。

对于三角不等式，解集往往是无限的且具有周期性，这反映了相关函数的周期性。对于代数不等式，解集的结构由将所有项移到一侧后所得多项式的零点所决定。

## 等价不等式与允许的运算

两个不等式当其解集完全相同时等价。求解不等式的目标，是施加一系列保持这种等价性的变换，将不等式化简为解集一目了然的更简单形式。这些变换所遵循的代数规则源于[实数的序性质](../properties-of-real-numbers/)，正是这些性质把 $\mathbb{R}$ 刻画为一个有序域，一切允许的变形均可由此导出。

某些运算必然产生等价的不等式。在两边同时加上或减去同一个表达式，既不改变序关系，也不改变解集，这与[方程](../equations/)的情形完全一致。乘法与除法的情形更为微妙，因为乘数的符号会影响不等号的方向。

+ 两边同时乘以或除以一个正的常数，保持不等号的方向。
+ 两边同时乘以或除以一个负的常数，反转不等号的方向。

这一区别在方程的理论中没有对应物，也是初等不等式运算中最常见的错误来源。举例而言，不等式 $-2x > 4$ 在两边同时除以 $-2$ 后变为 $x < -2$，其中不等号方向发生反转。

其他运算可能以更隐蔽的方式破坏等价性。在两边同时乘以一个含变量的表达式，需要对该表达式进行[符号分析](../sign-analysis-in-inequalities/)，因为只有在该表达式取值为负的那些区间上才必须反转不等号方向。类似地，仅当两边均已知为非负数时，才可以同时平方，这一条件在[无理不等式](../irrational-inequalities/)中自然出现。

关于哪些变形可能向解集中引入多余值、或从中剔除有效值，以及相应的应对措施，[失解与增解](../loss-of-solutions-in-inequalities/)条目中给出了系统的讨论。

## 代数不等式

代数不等式是指两边都完全由[多项式](../polynomials/)构成的不等式。将所有项移到一边后，问题归结为研究单个多项式 $P(x)$ 的符号。代数不等式按此多项式的次数进行分类。

[线性不等式](../linear-inequalities/)的次数为 $1$。变量的幂不超过一次，且首项系数非零时，解集总是一条半直线。

[二次不等式](../quadratic-inequalities/)的次数为 $2$，其标准形式为 $ax^2 + bx + c > 0$，其中 $a \neq 0$。其解集的结构由相应方程的[判别式](../quadratic-formula/) $\Delta = b^2 - 4ac$ 以及首项系数 $a$ 的符号决定。

+ 若 $\Delta > 0$，则根据不等号的方向，解集为两个外侧区间的并集，或两根之间那个内侧区间。
+ 若 $\Delta = 0$，则解集要么是整个 $\mathbb{R}$，要么是空集，且可能包含或排除该二重根。
+ 若 $\Delta < 0$，则该二次式全程保持 $a$ 的符号，因此解集要么是整个 $\mathbb{R}$，要么是空集。

上述各种情形的详细论述见[二次不等式](../quadratic-inequalities/)条目，其几何含义则在[二次不等式的几何解释](../geometric-interpretation-quadratic-inequalities/)中讨论。

次数高于二的[多项式不等式](../polynomial-inequalities/)遵循同样的原则。将多项式分解为一次因子与不可约二次因子，再借助[符号表](../sign-analysis-in-inequalities/)研究乘积的符号——该表记录每个因子在由实根确定的各个区间上的贡献。

在高次不等式中，二项不等式与三项不等式尤其值得关注。它们仅含两个或三个不同的项，往往可以通过换元或开方来求解，从而把问题降为低次不等式。

## 分式不等式

[分式不等式](../rational-inequalities/)至少含有一个分式表达，其分子与分母均为多项式。将所有项移到一边并通分合并后，问题归结为如下标准形式之一：

$$\frac{P(x)}{Q(x)} > 0 \qquad \frac{P(x)}{Q(x)} \geq 0$$

自然定义域排除所有使 $Q(x) = 0$ 的取值，而这些被排除的值绝不可能属于解集。商的符号分别由 $P(x)$ 与 $Q(x)$ 的符号决定：二者同号时商为正，异号时商为负。

> 通过两边同乘 $Q(x)$ 来去分母的做法一般不能直接采用，因为 $Q(x)$ 的符号依赖于 $x$，需要分情况讨论。标准做法是保留商的标准形式，借助符号表分析分子与分母的符号。

## 无理不等式

[无理不等式](../irrational-inequalities/)中变量出现在根式内。一个典型的此类不等式只含一个根式，例如：

$$\sqrt[n]{f(x)} > g(x)$$

所用方法取决于根指数的奇偶性以及两边的符号。当根指数为偶数时，为使根式在实数范围内有定义，被开方数必须非负；仅当不等式两边均非负时，才可同时平方。

因此求解需要分情况讨论，每种情形都由一个多项式不等式组所约束。当根指数为奇数时，根式对被开方数的任意实数值都有定义，此时用两边同取 $n$ 次幂来替代平方步骤，且对符号没有任何限制。

每种情形都需仔细验证，因为两边同取偶次幂可能引入并不满足原不等式的增解。

## 绝对值不等式

[含绝对值的不等式](../inequalities-with-absolute-value/)是未知数出现在[绝对值](../absolute-value/)表达式中的不等式。最简单的情形为 $|x| < a$ 或 $|x| > a$，其中 $a$ 是实常数，其解集由一对线性不等式描述。

+ 当 $a > 0$ 时，不等式 $|x| < a$ 等价于 $-a < x < a$，对应开区间 $(-a, a)$。
+ 当 $a > 0$ 时，不等式 $|x| > a$ 等价于 $x < -a$ 或 $x > a$，对应两个无界区间的并集。
+ 当 $a \leq 0$ 时，结构发生退化：$|x| < a$ 无解，而 $|x| > a$ 在 $a < 0$ 时被所有实数 $x$ 满足，在 $a = 0$ 时被所有 $x \neq 0$ 满足。

含多项式或有理表达式的绝对值不等式需要根据内层表达式的符号进行分情形讨论。每个情形产生一个不等式组，最终的解集由所有情形的解合并得到。

## 超越不等式

超越不等式是一个或多个变量出现在超越函数（如[指数函数](../exponential-function/)、[对数函数](../logarithmic-function/)或[三角函数](../sine-function/)）中的不等式。这类不等式超越了多项式或有理形式，其求解通常依赖于所涉及函数的单调性。

[对数不等式](../logarithmic-inequalities/)中变量出现在对数表达式内部。其求解利用对数的性质来分离未知数，同时须满足每个对数的真数都严格为正的条件。

[指数不等式](../exponential-inequalities/)中变量出现在指数位置。求解利用指数函数的单调性：当底数大于一时，指数间的不等式方向与原不等式相同；当底数严格介于零与一之间时，方向相反。

[三角不等式](../trigonometric-inequalities/)涉及周期函数，如 $\sin(x)$、$\cos(x)$ 或 $\tan(x)$。周期性使得解集本身也具有周期性，通常表示为由无穷多个以函数周期为间隔的区间的并集。

## 二元不等式

当一个不等式的解集是笛卡儿平面 $\mathbb{R}^2$ 的子集而非实数轴的子集时，称该不等式为二元不等式。二元线性不等式的形式为 $ax + by + c > 0$，其中符号 $>$ 可替换为 $<$、$\geq$ 或 $\leq$，其解集始终是以直线 $ax + by + c = 0$ 为边界的半平面。根据不等式是非严格的还是严格的，边界直线分别被包含或排除，而所选半平面由测试点法确定。

同样的构造可推广到同时考虑多个不等式的情形。二元线性不等式组定义了平面上由各对应半平面的交集构成的区域。该区域始终是凸的，可能为空，也可能无界，即为该不等式组的可行域。当该区域是有界凸多边形时，其顶点在该区域上线性目标函数的优化中起着关键作用，这也是线性规划的几何出发点。

当定义不等式的函数不是两个未知数的线性组合时，该不等式属于二元非线性不等式类。边界不再是直线而是曲线，通常是圆锥曲线，如抛物线、[圆](../circumference/)、椭圆或双曲线，解集是由该曲线所确定的平面区域之一。测试点法确定正确区域的方式与线性情形完全相同，而非线性不等式组产生的可行域可以是非凸的，且由不同曲线的弧段围成。

## 不等式组

[不等式组](../systems-of-inequalities/)产生于多个不等式须被同一变量同时满足的情形。不等式组的解集是各个不等式解集的交集，因为变量的一个值属于不等式组的解，当且仅当它同时满足每一个不等式。

区间的交集在数轴上以图形方式计算，其中每个不等式由其解集表示，而不等式组的解就是所有对应标记重合的区域。这一方法在绝对值不等式、无理不等式和含参不等式所需的分情形讨论中被系统性地使用。二元的类似情形，即交集在笛卡儿平面而非实数轴上进行的情形，在二元线性不等式组条目中讨论。

与不等式组相关的一种记法变体是连不等式，其中两个共享同一中间表达式的不等式被合并为一个形如 $a < f(x) < b$ 的链式陈述。当未知数仅出现在中间表达式中时，连不等式通过对三个部分同时进行运算来求解；当未知数出现在不止一个部分中时，它归结为由两个分量不等式构成的不等式组。

## 含参不等式

当一个不等式的某些系数依赖于一个被视为常数的实参数时，该不等式属于更广泛的含参不等式类。其解集不再是 $\mathbb{R}$ 的固定子集，而是以参数为索引的子集族，分析过程通过将参数值域划分为解的行为一致的若干区域来进行。

两种基本情形分别在含参线性不等式和含参二次不等式条目中单独讨论。两种情形的一般原理相同：每一个改变系数符号或判别式符号的参数值，都标志着不同定性解结构之间的转变，必须单独考察。
