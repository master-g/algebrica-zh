## 为何会失解或增解

求解[不等式](../inequalities/)时，通常会依次进行一系列变形，把原不等式化为解集显而易见的简单形式。这一过程以每一步变形都保持等价性为前提，即变形后的不等式与原不等式具有完全相同的解集。一旦某一步不保持等价性，变形前后的解集便会出现差异，而且差异可能朝两个方向发生。

+ 失解是指变形排除了原本满足不等式的值，使所得解集成为正确解集的真子集。
+ 增解是指变形加入了满足变形后不等式、却不满足原不等式的值，使所得解集成为正确解集的真超集。

这两种现象根源相同。变换仅在定义域的一部分上有效，而原不等式与变换后不等式之间的差异，集中在变换不适用的那一部分上。

标准做法是：在每一步都追踪定义域；根据两边所乘或所除的任意表达式的符号进行分类讨论；每当使用了非等价变换，都将候选解代入原不等式加以检验。

> 对于方程的类似现象，在[失根](../loss-of-roots/)词条中讨论。方程与不等式的区别在于，不等式的解构成一个连续统而非离散集合，因此解的丢失或引入影响的是整个[区间](../intervals/)，而非孤立的点。

## 乘以符号可变的表达式

在不等式中，解的丢失或引入最常见的来源，是用一个依赖于未知数的表达式对两边相乘或相除。

+ 当乘数是固定的正常数时，不等号方向保持不变，不可能出错。
+ 当乘数是固定的负常数时，方向必须反转；只要执行了反转，该过程仍保持等价性。
+ 当乘数依赖于未知数时，其符号取决于未知数的取值，不等号的方向可能在某些区间上需要保持，在另一些区间上需要反转。

考虑不等式：

$$\frac{1}{x - 2} > 1$$

一个常见的错误是通过两边乘以 $x - 2$ 来消去分母，得到线性不等式 $1 > x - 2$，即 $x < 3$。这一做法是错误的，因为 $x - 2$ 的符号不是常数：该表达式在 $x > 2$ 时为正，在 $x < 2$ 时为负。两边乘以 $x - 2$ 在区域 $x > 2$ 上保持不等式，但在区域 $x < 2$ 上将其反转。

未区分两种情形所得到的结果 $x < 3$ 仅在 $x > 2$ 上正确，给出 $2 < x < 3$；而在 $x < 2$ 上是错误的，此时应给出相反的条件 $1 < x - 2$，即 $x > 3$，它与 $x < 2$ 无交集，不贡献任何解。

[shortcode="intervals"]
|                      | $2$               | $3$                   |     |
|----------------------|-----------------|---------------------|-----|
|                     |   sign+l-o      |                     |     |
|                     |                 | sign+r-o            |     |
|                 |   sign+l-in-o-h   | sign+r-in-o-h     |     |
[/shortcode]

因此正确的解集是 $(2, 3)$，而上述直接变形产生了错误的集合 $(-\infty, 3)$，把每一个值 $x \leq 2$ 都作为增解引入。点 $x = 2$ 还因不在原不等式的定义域内而无效。

正确的做法是将不等式化为标准形式：把所有项移到一边并通分合并，如[分式不等式](../rational-inequalities/)词条中所示。从两边减去 $1$ 并合并，得到如下结果。

$$\frac{1 - (x - 2)}{x - 2} > 0 \quad \rightarrow \quad \frac{3 - x}{x - 2} > 0$$

该比值的符号由分子和分母上的[符号表](../sign-analysis-in-inequalities/)确定，临界点为 $x = 2$ 与 $x = 3$。该比值恰在内部区间 $(2, 3)$ 上为正，这就是正确的解集。

> 化为标准形式的过程在整个定义域上保持等价性，因此不会增加或丢失任何解。相比之下，直接相乘之所以失败，是因为它暗中假定了乘数的符号，舍弃了另一种情形。

## 约去公因式

一个相关的错误，是从不等式两边约去一个公因式。约去等价于除以该因式，因此与乘以或除以任何含未知数的表达式一样，都需同样谨慎。考虑以下不等式：

$$x(x - 3) > 2(x - 3)$$

从不等式两边约去公因式 $(x - 3)$，得到线性不等式 $x > 2$。这一步骤是错误的，因为 $x - 3$ 的符号不是常数。该因式在 $x > 3$ 上为正，在 $x < 3$ 上为负，因此约去在 $x > 3$ 上保持不等号方向，在 $x < 3$ 上反转不等号方向。此外，约去会丢弃取值 $x = 3$，在该点原不等式两边都为零，需要单独考虑。

正确的做法是将所有项移到一边，并对所得表达式因式分解，把不等式化为 $f(x) > 0$ 的形式。

$$x(x - 3) - 2(x - 3) > 0 \quad \rightarrow \quad (x - 3)(x - 2) > 0$$

乘积在由根 $x = 2$ 和 $x = 3$ 确定的两个外侧区间上为正，因此正确的解集如下。

$$(-\infty, 2) \cup (3, +\infty)$$

直接约去公因式只能得到右半射线 $x > 2$，从而将 $2 < x \leq 3$ 作为增解引入，并丢失整个区间 $x < 2$。其中 $x = 3$ 是增解，因为原不等式两边在该点相等，严格不等式不成立。

## 两边平方

对不等式两边平方是求解[无理不等式](../irrational-inequalities/)和[含绝对值的不等式](../inequalities-with-absolute-value/)时的标准技巧，但一般来说它并不是等价变形。函数 $t \mapsto t^2$ 在 $\mathbb{R}$ 上不是单调的，在 $[0, +\infty)$ 上递增，在 $(-\infty, 0]$ 上递减，因此只有当两个数都非负时，平方才能保持它们之间的大小顺序。

于是，不等式两边平方的规则如下。

+ 若两边已知均非负，则不等式 $A > B$ 等价于 $A^2 > B^2$。
+ 若两边已知均非正，则不等式 $A > B$ 等价于 $A^2 < B^2$，且不等号方向取反。
+ 若两边可能异号或符号无法确定，则平方不保持等价性，需要分情况讨论。

一个常见的错误来源是不验证符号条件就进行平方。考虑不等式：

$$\sqrt{x + 1} < x - 1$$

左边在其定义域 $x \geq -1$ 上非负，但右边的符号是变化的，仅当 $x \geq 1$ 时非负，当 $x < 1$ 时为负。若不进行分情况讨论就直接两边平方，会得到不等式 $x + 1 < (x - 1)^2$，即 $x^2 - 3x > 0$，其解为 $x < 0$ 或 $x > 3$。

其中 $-1 \leq x < 0$ 这一区间完全由增解组成，因为此时右边 $x - 1$ 为负，而左边 $\sqrt{x + 1}$ 非负，所以原不等式恒不成立。

正确的方法是根据右边的符号分情况，并将平方步骤与被开方式的定义域条件以及右边的符号条件结合起来。求解得到解集 $(3, +\infty)$，而仅限于定义域的朴素平方会给出更大的集合 $[-1, 0) \cup (3, +\infty)$，其中 $[-1, 0)$ 是被错误引入的增解。

忽略一边为负的情形时，平方也可能造成失解。考虑反向的不等式：

$$\sqrt{x + 1} > x - 1$$

当 $-1 \leq x < 1$ 时右边为负，而左边非负，因此不等式在该区间上的每一点都成立，无需平方。当 $x \geq 1$ 时两边均非负，平方可行，得到 $x + 1 > (x - 1)^2$，即 $x^2 - 3x < 0$，结合 $x \geq 1$ 得到 $1 \leq x < 3$。完整的解集是两种情况的并集，即 $[-1, 3)$。若不分情况就直接平方，只会得到区间 $(0, 3)$，而丢掉了区间 $[-1, 0]$，后者中每一点都满足原不等式。

> 一般原则是：只有当两边都已知非负时，才可以不分情况直接平方。在其他任何情况下，求解都必须根据每一侧的符号分情况，并且候选解必须代回原不等式进行检验。

## 偶数次幂

关于平方的说明可推广到将两边同时提升为偶数次幂的每一种变形。函数 $t \mapsto t^{2k}$ 是偶函数，且仅在 $[0, +\infty)$ 和 $(-\infty, 0]$ 上分别单调，因此只有当两个数同号时，才能根据它在相应半轴上的单调性确定次序如何变化。

奇数次幂则不受这一限制。函数 $t \mapsto t^{2k+1}$ 在 $\mathbb{R}$ 上严格[递增](../increasing-and-decreasing-functions/)，因此将其作用于不等式两边是等价变形。对于任意正整数 $k$，不等式 $A > B$ 等价于 $A^{2k+1} > B^{2k+1}$，不需要任何符号限制。

这一区别解释了在求解[无理不等式](../irrational-inequalities/)时偶数次根式与奇数次根式之间的不对称性。形如 $\sqrt[2k+1]{f(x)} > g(x)$ 的不等式可以直接通过将两边提升为 $(2k+1)$ 次幂并化为多项式不等式来求解，无需验证任何符号条件。

形如 $\sqrt[2k]{f(x)} > g(x)$ 的不等式则需要对 $g(x)$ 的符号进行分情况讨论，并对被开方式 $f(x) \geq 0$ 施加定义域条件。

## 施加单调函数

关于[幂](../powers/)的规则是一条一般原则的特例。对不等式两边应用严格递增函数，会保持不等号方向和解集；应用严格递减函数，则会反转不等号方向。只有当函数在所考虑的整个区间上不单调（如偶数次幂），或函数定义域小于原不等式的定义域时，这类变形才会破坏等价性。后一种情形下，变形后的不等式必须附带定义域条件。

这条原则尤其支配着[指数不等式](../exponential-inequalities/)和[对数不等式](../logarithmic-inequalities/)的求解。当 $a > 1$ 时，不等式 $a^{f(x)} > a^{g(x)}$ 等价于 $f(x) > g(x)$；当 $0 < a < 1$ 时，则等价于 $f(x) < g(x)$，因为底数小于一的指数函数严格递减。关于底数的同一分类也适用于对数，但还需额外要求真数为正。若省略底数在 $0$ 与 $1$ 之间时的不等号反向，或省略对数真数的正性条件，就会产生上文所述的失解与增解现象。

## 不等式的组合

一个相关的错误来源是：在不注意不等号方向的情况下，将两个不等式逐项相加或相减。

+ 将两个同向不等式相加是允许的。由 $A > B$ 和 $C > D$ 可以推出 $A + C > B + D$，因为两个正差 $A - B$ 与 $C - D$ 之和为正。
+ 相减则不能同样处理，因为由 $A > B$ 和 $C > D$ 一般不能推出 $A - C > B - D$，所得不等式的方向取决于各个量的大小。
+ 当四个量均为非负时，将两个不等式逐项相乘是允许的。由 $0 \leq A \leq B$ 和 $0 \leq C \leq D$ 可推出 $AC \leq BD$。当某些量为负时，乘法可能以意想不到的方式反转方向，因此需要进行分情况讨论。

> 这些限制反映了一个事实：[实数](../real-numbers/)上的序关系与四则运算以不同方式相互作用。加法和减法以单向方式保持序关系：两个同向不等式总能相加，但不能据此直接相减。乘法和除法仅在非负半轴上保持序关系，在负半轴上则会将其反转。每一种变形在应用前都必须对照这些基本规则加以检验。

## 一般原则

若干原则有助于在求解不等式时防止无意的失解或增解。

最可靠的策略是将所有项移到一边，把不等式化为标准形式 $f(x) > 0$，然后通过[符号表](../sign-analysis-in-inequalities/)研究单一函数 $f(x)$ 的符号。化为标准形式能保持不等式在整个定义域上的等价性，并避免因乘以或除以变号表达式而带来的困难。

应避免将两边乘以或除以含未知量的表达式，除非已知该表达式在整个定义域上具有常号。当这种乘法似乎不可避免时，必须根据乘数的符号进行分情况讨论：在乘数为正的区间上保持不等式方向，在乘数为负的区间上反转方向。

当不等式涉及偶数下标的根式或绝对值时，求解时必须根据相关表达式的符号分情况讨论。只有当两边均已知为非负时，才允许将两边平方，而一边为负的另一情形必须单独考察。

将每个候选值代回原不等式是一种有用的验证手段，尤其是在某个并非严格保等价的步骤之后。这种验证既能发现由非等价操作引入的增解，也能发现可能在中途被丢失的有效解。

与方程的情形不同——在方程中验证涉及有限的候选值列表——不等式的验证需要在候选解集的每个区间中选取一个代表点进行检验，因为其解一般是一个连续统，而非离散的点集。
