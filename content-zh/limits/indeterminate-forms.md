## 什么是不定式

在处理极限时，下面类型的表达式会反复出现：

$$\frac{0}{0} \qquad \frac{\infty}{\infty} \qquad 0 \cdot \infty \qquad \infty - \infty$$

$$1^{\infty} \qquad 0^{0} \qquad \infty^{0}$$

这些表达式称为不定式，因为仅凭符号本身无法确定极限的值。不同的[函数](../functions/)可能产生相同的符号形式，却得到完全不同的结果。下面的各节将回顾这些形式的含义、它们为何称为不定式，以及实践中如何处理它们。

简单来说，不定式并不代表某个具体的数，而是说明直接代入不足以求出极限。例如，设两个函数 $f(x)$ 和 $g(x)$ 在 $x$ 趋近某个值 $a$ 时都趋于零：

$$\lim_{x \to a} f(x) = 0 \qquad \lim_{x \to a} g(x) = 0$$

如果尝试求它们商的极限，直接代入会得到：

$$\lim_{x \to a} \frac{f(x)}{g(x)} \to \frac{0}{0}$$

单凭这个记号无法说明商会如何变化。取决于 $f(x)$ 和 $g(x)$ 趋于零的方式，极限可能是任意有限数、零、无穷大，也可能根本不存在。不定式并不能解决问题；它只是提示还需要进一步分析。

在分析每种形式之前，应牢记以下三点：

+ 不定式不代表某个具体的数。
+ 它不表示等式关系。
+ 它是描述相关表达式极限行为的标签。

## $\frac{0}{0}$ 形式

这是最常见的不定式，通常出现在分子和分母在同一点同时为零时。在求极限之前，往往可以先通过代数运算化简表达式。例如，考虑：

$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$$

直接代入得到 $\dfrac{0}{0}$。将分子因式分解：

$$x^2 - 4 = (x - 2)(x + 2)$$

于是，对 $x \neq 2$：

$$\frac{x^2 - 4}{x - 2} = x + 2$$

因此可得：

$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = 4$$

> 完成化简后，表达式的内在结构变得清晰，不定式也随之消失。在更复杂的问题中，只要满足相应假设，[洛必达法则](../hopital-rule/)就能系统地处理这类极限。另一种互补方法是使用带[小 o 记号](../little-o-notation/)的[Taylor 展开](../taylor-series/)，分离分子和分母的首项。

## $\dfrac{\infty}{\infty}$ 形式

当分子和分母都发散时，就会出现这种形式。例如，考虑：

$$\lim_{x \to \infty} \frac{3 x^2 + 1}{2 x^2 - 5}$$

直接代入得到 $\dfrac{\infty}{\infty}$。为了消除不定性，在分子和分母中分别提出 $x$ 的最高次幂：

$$
\begin{align}
\frac{3 x^2 + 1}{2 x^2 - 5}
&= \frac{x^2 (3 + 1/x^2)}{x^2 (2 - 5/x^2)} \\[6pt]
&= \frac{3 + 1/x^2}{2 - 5/x^2}
\end{align}
$$

当 $x \to \infty$ 时，$1/x^2$ 和 $5/x^2$ 都趋于零，因此极限为：

$$\lim_{x \to \infty} \frac{3 x^2 + 1}{2 x^2 - 5} = \frac{3}{2}$$

> 仅凭符号形式并不足够。$x$ 很大时主导项的行为才决定答案，而提出最高次幂的过程将这一思想形式化。由于 $\dfrac{\infty}{\infty}$ 形式也适用于该定理，连续应用两次[洛必达法则](../hopital-rule/)同样可以得到结论。

## $0 \cdot \infty$ 形式

当一个因子趋于零而另一个因子无界增大时，就会出现这种形式。例如：

$$\lim_{x \to 0^+} x \ln x$$

当 $x$ 从右侧趋近零时，$\ln x$ 越来越负，因此乘积呈现 $0 \cdot (-\infty)$ 的形式。为了消除不定性，将表达式改写为商：

$$x \ln x = \frac{\ln x}{1/x}$$

现在，当 $x \to 0^+$ 时：

$$\ln x \to -\infty \qquad \frac{1}{x} \to +\infty$$

表达式呈现 $\dfrac{-\infty}{+\infty}$ 的形式，可以通过[对数](../logarithms/)与幂之间的渐近比较，或通过[洛必达法则](../hopital-rule/)来处理。结果是：

$$\lim_{x \to 0^+} x \ln x = 0$$

> 关键步骤是把乘积变为商，从而将问题化为更熟悉的 $0/0$ 或 $\infty/\infty$ 形式之一。

## $\infty - \infty$ 形式

这种形式可能掩盖两个发散量部分抵消的事实。例如，考虑：

$$\lim_{x \to \infty} \left( \sqrt{x^2 + x} - x \right)$$

两项都无界增长，因此得到 $\infty - \infty$ 形式。为了消除不定性，用共轭式乘除原表达式进行有理化：

$$
\begin{align}
\sqrt{x^2 + x} - x
&= \frac{\left( \sqrt{x^2 + x} - x \right) \left( \sqrt{x^2 + x} + x \right)}{\sqrt{x^2 + x} + x} \\[6pt]
&= \frac{x^2 + x - x^2}{\sqrt{x^2 + x} + x} \\[6pt]
&= \frac{x}{\sqrt{x^2 + x} + x}
\end{align}
$$

接下来从分母中提出 $x$：

$$
\begin{align}
\frac{x}{\sqrt{x^2 + x} + x}
&= \frac{x}{x \left( \sqrt{1 + 1/x} + 1 \right)} \\[6pt]
&= \frac{1}{\sqrt{1 + 1/x} + 1}
\end{align}
$$

当 $x \to \infty$ 时取极限：

$$\lim_{x \to \infty} \frac{1}{\sqrt{1 + 1/x} + 1} = \frac{1}{\sqrt{1} + 1} = \frac{1}{2}$$

> 化简后，表面的发散消失，极限为有限值。

## 使用共轭式的理由

处理 $\infty - \infty$ 形式时使用的技巧依赖于共轭式，即除了两项之间的符号相反之外，其余与原表达式完全相同的表达式。下面考察这一选择背后的理由。考虑极限：

$$\lim_{x \to \infty} \left( \sqrt{x^2 + 2 x + 3} - x \right)$$

两项都无界增大，因此直接代入得到不定式 $\infty - \infty$。根本问题不在于发散本身，而在于两个量以相同的首阶增长。相减后，主导项的抵消被隐藏起来，当前形式无法展示抵消后还剩下什么。用共轭式乘除可将抵消显式化：

$$
\begin{align}
\frac{\left( \sqrt{x^2 + 2 x + 3} - x \right) \left( \sqrt{x^2 + 2 x + 3} + x \right)}{\sqrt{x^2 + 2 x + 3} + x}
&= \frac{x^2 + 2 x + 3 - x^2}{\sqrt{x^2 + 2 x + 3} + x} \\[6pt]
&= \frac{2 x + 3}{\sqrt{x^2 + 2 x + 3} + x}
\end{align}
$$

现在，原来的差被表示为一个商。最高次的 $x^2$ 项被消去，接下来可以从分子和分母中提出 $x$，继续分析剩余表达式：

$$
\begin{align}
\frac{2 x + 3}{\sqrt{x^2 + 2 x + 3} + x}
&= \frac{x \left( 2 + 3/x \right)}{x \left( \sqrt{1 + 2/x + 3/x^2} + 1 \right)} \\[6pt]
&= \frac{2 + 3/x}{\sqrt{1 + 2/x + 3/x^2} + 1}
\end{align}
$$

当 $x \to \infty$ 时，$3/x$、$2/x$ 和 $3/x^2$ 都趋于零，极限化简为：

$$\lim_{x \to \infty} \left( \sqrt{x^2 + 2 x + 3} - x \right) = \frac{2}{1 + 1} = 1$$

> 使用共轭式可以明确展示主导项的抵消，并揭示真实的增长阶。最高次的 $x^2$ 项相互抵消，行为由低阶项决定。这一视角自然连接到[大 O](../big-o-notation/)和[小 o 记号](../little-o-notation/)，其中极限通过比较相对增长速率来理解。

## 指数不定式

处理包含指数表达式的极限时，还会出现三种不定式：

$$1^{\infty} \qquad 0^{0} \qquad \infty^{0}$$

这些形式出现在：

$$\lim_{x \to a} F(x)^{G(x)}$$

其中底数和指数的行为相互冲突。与其他不定式一样，仅凭符号形式无法确定结果。

标准做法是进行对数变换。取[对数](../logarithms/)可以把指数结构变成乘积，然后再改写为商，并用洛必达法则或 Taylor 展开求解。一般步骤如下。假设要计算：

$$L = \lim_{x \to a} F(x)^{G(x)}$$

对等式两边取自然对数：

$$\ln L = \lim_{x \to a} G(x) \ln F(x)$$

这样就把问题化为 $0 \cdot \infty$ 或 $\dfrac{0}{0}$ 形式的极限，这两种形式都可以用前面讨论的技巧处理。一旦确定了 $\ln L$，原极限便可通过 $L = e^{\ln L}$ 恢复。

作为具体例子，考虑：

$$\lim_{x \to 0} (1 + x)^{1/x}$$

它具有 $1^{\infty}$ 形式。令 $L$ 等于该极限并取对数：

$$\ln L = \lim_{x \to 0} \frac{\ln(1 + x)}{x}$$

现在是 $\dfrac{0}{0}$ 形式。应用[洛必达法则](../hopital-rule/)，分别对分子和分母求导：

$$\lim_{x \to 0} \frac{\ln(1 + x)}{x} = \lim_{x \to 0} \frac{1/(1+x)}{1} = 1$$

因此：

$$L = e^{1} = e$$

这个值与定义[数 $e$](../euler-number-limit-sequence/)的[重要极限](../remarkable-limits/)一致。

> 指数形式隐藏着一个商结构。应用对数变换可以揭示这一结构，将问题化为熟悉的形式。

七种不定式都有一个共同特征：仅凭符号表达式无法确定极限的值。决定性因素始终是相关量增长或趋于零的相对速率。识别不定式只是第一步；要计算极限，还需要更仔细地分析相关函数。

## 计算极限的策略

每种不定式都有不止一种解法，方法的选择会影响计算多快能得到确定表达式。实用的策略始于识别形式，然后采用针对该情形最直接的主要技巧；如果第一次尝试代数运算繁重或无法得出结论，再转向替代方法。

对于化为 $\dfrac{0}{0}$ 的商，首先尝试将分子和分母因式分解并约去共同的零因子，进行代数化简。如果化简不明显，[重要极限](../remarkable-limits/)可以提供直接捷径，尤其适合原点附近的三角、指数或对数表达式。如果两条路都不可行，可以用带[小 o 记号](../little-o-notation/)的[渐近展开](../asymptotic-expansion/)分离分子和分母的首项。[洛必达法则](../hopital-rule/)则留给前述方法不便使用的情形，因为它可能掩盖极限的结构信息。

对于化为 $\dfrac{\infty}{\infty}$ 的商，标准做法是从分子和分母中提出主导项，并从剩余的比值读出极限。当主导项无法立即识别时，比较对数、幂、指数与阶乘的增长速率即可得出答案。洛必达法则仍然可用，但主导项方法通常更快。

对于 $0 \cdot \infty$ 形式的乘积，要将乘积改写为商。变换后的表达式会呈现 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 形式，然后应用上述技巧。

对于 $\infty - \infty$ 形式的差，恰当的步骤取决于两个发散量的代数结构。如果它们拥有共同的主导项，共轭式会产生抵消，从而显露低阶行为。如果两项可以通分，差就会化为商。在这两种情形下，不定性都会被转化为 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$ 形式。

对于 $1^{\infty}$、$0^{0}$ 或 $\infty^{0}$ 指数形式，对数变换会把计算化为 $0 \cdot \infty$ 的乘积，再用前面列出的技巧处理。

## 化解技巧

将反复使用的技巧与其通常适用的形式列成简表，可以让策略保持条理清晰。

+ 因式分解与约分：当分子和分母有共同的零因子时，适用于 $\dfrac{0}{0}$。
+ 用共轭式有理化：用于 $\infty - \infty$，以及含平方根的 $\dfrac{0}{0}$ 表达式；共轭式能明确展示主导项的抵消。
+ 除以主导项：处理涉及多项式、有理函数或不同次数单项式之和的 $\dfrac{\infty}{\infty}$ 时的主要工具。
+ 换元：例如令 $t = 1/x$ 或 $t = x - a$，把极限转化为更适合其他技巧处理的形式。
+ 重要极限：通过代数运算把表达式化为标准目录中的已知模式。
+ 带小 o 记号的 Taylor 展开：当需要比较分子和分母的更高阶项，或原本需要组合多个重要极限时不可或缺。
+ 洛必达法则：处理 $\dfrac{0}{0}$ 和 $\dfrac{\infty}{\infty}$ 的最后手段，但必须先验证其假设。

下表将每种不定式与主要技巧和一种典型替代方法对应起来。

[class="table-1"]

|                          |                                                                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| $\dfrac{0}{0}$           | 因式分解并化简，应用[洛必达法则](../hopital-rule/)，或用[Taylor 级数](../taylor-series/)展开 |
| $\dfrac{\infty}{\infty}$ | 提出主导项，或应用洛必达法则                                                          |
| $0 \cdot \infty$         | 改写为 $\dfrac{0}{1/\infty}$ 或 $\dfrac{\infty}{1/0}$，从而得到 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$   |
| $\infty - \infty$        | 乘以共轭式，或通分                                                          |
| $1^{\infty}$             | 取对数，化为 $0 \cdot \infty$                                                                |
| $0^{0}$                  | 取对数，化为 $0 \cdot \infty$                                                                |
| $\infty^{0}$             | 取对数，化为 $0 \cdot \infty$                                                                |
[/class]

这里总结的技巧建立在[极限的代数](../algebra-of-limits/)之上；当所研究的函数可以被两个具有相同极限的函数夹住时，还会连接到[夹逼定理](../squeeze-theorem/)。

## 使用洛必达法则和 Taylor 展开的注意事项

洛必达法则要求极限化为 $\dfrac{0}{0}$ 或 $\dfrac{\infty}{\infty}$，分子和分母在该点的邻域内可导，分母的导数在那里非零，并且导数之比的极限存在。在假设不成立时应用该法则，虽然形式上可以推导出结果，但在逻辑上并无依据。一个常见错误是：经过前面的代数步骤，商已经变成确定形式，却仍对其应用洛必达法则，结果把一个不再需要处理的不定式重新引入计算。

Taylor 展开可以在分子和分母展开到足够高的阶数、使首个非零主导项显现时求出极限。过早截断会造成表面的抵消，不能反映函数的真实行为。因此，展开阶数应通过检查主导项的消失阶来选择，而不能机械决定。

> 洛必达法则和 Taylor 展开的选择，往往归结为视角的差异。洛必达法则偏向程序化、近乎机械，但会模糊相关函数的结构；Taylor 展开揭示这种结构，并说明极限由哪一阶决定，但代数运算会稍微繁重一些。
