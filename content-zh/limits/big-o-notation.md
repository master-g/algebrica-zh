## 定义

符号 $O(g(x))$ 读作“$g(x)$ 的大 O”，属于 Landau 记号家族，用来刻画[函数](../functions/)之间的渐近关系。这一记号表达了这样的思想：当输入趋近某个值时，一个函数至多被另一个函数的某个常数倍所界定。从这个意义上说，$O(g(x))$ 通过表示一个函数在[极限](../limits/)中的增长不超过另一个函数，形式化了[渐近](../asymptotes/)控制。

**定义 1。** 设 $f, g : A \to \mathbb{R}$（或 $\mathbb{C}$）是定义在集合 $A$ 上的两个函数，且 $x_0$ 是 $A$ 的一个聚点。我们称 $f(x)$ 是 $g(x)$ 的大 O（当 $x \to x_0$），如果存在常数 $M > 0$ 和 $\delta > 0$，使得只要 $0 < |x - x_0| < \delta$，就有不等式 $|f(x)| \leq M \cdot |g(x)|$ 成立。记为：

$$f(x) = O(g(x)) \quad x \to x_0 \quad \iff \quad \exists\ M > 0, \ \delta > 0 \ : \ 0 < |x - x_0| < \delta \implies |f(x)| \leq M|g(x)|$$

关系 $f(x) = O(g(x))$ 表示在 $x_0$ 附近，$f(x)$ 的渐近增长不快于 $g(x)$。

![图 1](/assets/limits/svg/big-o-notation-1.zh.svg)

这里的等号是约定俗成的记号滥用：$O(g(x))$ 表示满足上述界的所有函数组成的类，因此符号 $=$ 应理解为“属于”。

> 将 $x \to x_0$ 替换为 $x \to \infty$，同一定义也适用于无穷远处的极限；此时条件 $0 < |x - x_0| < \delta$ 替换为对某个 $N > 0$ 有 $|x| > N$。它也扩展到[数列](../sequences/)，用整数索引 $n$ 替换连续变量 $x$，并令 $n \to \infty$。

## 示例

为了具体说明这个概念，考虑多项式：

$$f(x) = 3x^2 + 2x + 1 \quad x \to \infty$$

目标是证明 $f(x) = O(x^2)$。当 $x$ 很大时，$f(x)$ 与 $x^2$ 的比值有统一上界：

$$\frac{3x^2 + 2x + 1}{x^2} = 3 + \frac{2}{x} + \frac{1}{x^2}$$

当 $x \to \infty$ 时，这个表达式趋近 $3$。更精确地说，当 $x \geq 1$ 时，右侧两个分式都不超过 $1$，因此：

$$\frac{3x^2 + 2x + 1}{x^2} \leq 3 + 2 + 1 = 6$$

取 $M = 6$，并选择任意一个与 $x \geq 1$ 相容的 $\delta$ 条件，就有不等式 $|f(x)| \leq 6x^2$ 成立。结论是：

$$3x^2 + 2x + 1 = O(x^2) \quad x \to \infty$$

数值比较可以进一步说明这个界：

+ 当 $x = 10$ 时，$f(x) = 321$，而 $6x^2 = 600$；
+ 当 $x = 100$ 时，$f(x) = 30201$，而 $6x^2 = 60000$；
+ 当 $x = 1000$ 时，$f(x) = 3002001$，而 $6x^2 = 6000000$。

在每种情形下都有 $f(x) \leq 6x^2$，这体现了大 O 记号的本质：当输入趋近某个特定值时，一个函数的增长至多和另一个函数的常数倍一样快。

## $O(1)$ 的含义

符号 $O(1)$ 表示当 $x$ 趋近某个特定点 $x_0$ 时保持有界的函数类。当 $f(x)$ 在 $x \to x_0$ 的极限过程中始终被某个常数所界定，就说它属于 $O(1)$。形式上，当且仅当满足下式时，称 $f(x) = O(1)$（$x \to x_0$）：

$$\exists\ M > 0, \ \delta > 0 \ : \ 0 < |x - x_0| < \delta \implies |f(x)| \leq M$$

所有属于 $O(1)$ 的函数可以写成：

$$O_{x_0}(1) = \\{\ f : B(x_0, \delta) \setminus \\{x_0\\} \to \mathbb{R} \mid \exists\ M > 0 \ : \ |f(x)| \leq M \quad x \to x_0 \ \\}$$

这个表达式的各个组成部分含义如下：

+ 所考虑的函数定义在 $x_0$ 的某个邻域内，但不包含点 $x_0$ 本身。
+ 当 $x$ 趋近 $x_0$ 时，函数必须保持有界。
+ 记号 $O(1)$ 标识所有相对于常数 $1$ 有界的函数组成的集合。
+ 符号 $B(x_0, \delta)$ 表示一个以 $x_0$ 为中心、半径为 $\delta$ 的开邻域，函数定义在该邻域上。

## 零点附近的 $\sin(x)/x$ 示例

$O(1)$ 类的经典例子是函数：

$$f(x) = \frac{\sin x}{x} \quad x \to 0$$

利用 $\sin x$ 在原点附近的 Taylor 展开：

$$\sin x = x - \frac{x^3}{6} + O(x^5) \quad x \to 0$$

两边除以 $x$，函数可以表示为：

$$\frac{\sin x}{x} = 1 - \frac{x^2}{6} + O(x^4) \quad x \to 0$$

当 $x \to 0$ 时，$\dfrac{x^2}{6}$ 和余项 $O(x^4)$ 都保持有界。常数 $1$ 也同样有界，因此整个表达式在原点附近有界：

$$\frac{\sin x}{x} = O(1) \quad x \to 0$$

> 这个表达式说明，尽管函数在 $x = 0$ 处无定义，但在其附近仍保持有界。极限的实际值为 $1$，它是[重要极限](../remarkable-limits/)之一。

## 性质

大 O 记号的一条基本性质可以直接由定义得到。如果当 $x \to x_0$ 时 $f(x) = O(g(x))$，那么两个函数的比值保持有界：

$$\limsup_{x \to x_0} \left|\frac{f(x)}{g(x)}\right| < \infty$$

- - -

关系 $f(x) = O(g(x))$ 具有自反性，但不具有对称性。对于任意非零函数 $f$：

$$f(x) = O(f(x)) \quad x \to x_0$$

逆命题 $g(x) = O(f(x))$ 一般并不能由 $f(x) = O(g(x))$ 推出。例如，当 $x \to \infty$ 时有 $x = O(x^2)$，但 $x^2 \neq O(x)$ 当 $x \to \infty$ 时并不成立。

- - -

函数乘以非零常数不会改变其在大 O 记号中的渐近行为。对于任意常数 $c \neq 0$ 和任意函数 $g(x)$，当 $x \to x_0$ 时：

$$O(c \cdot g(x)) = O(g(x))$$

$$c \cdot O(g(x)) = O(g(x))$$

> 大 O 记号会吸收常数因子：乘以非零常数不会影响 $x_0$ 附近的渐近上界。

- - -

大 O 项在加法下也有可预测的行为。同一个函数的两个大 O 项之和仍然是该函数的大 O 项。形式化地，当 $x \to x_0$ 时：

$$O(f(x)) + O(f(x)) = O(f(x))$$

> 将两个都以渐近方式被 $f(x)$ 界定的函数相加，所得的和仍然被 $f(x)$ 渐近界定，只是常数可能更大。

- - -

当大 O 项乘以一个函数时，结果是一个新的大 O 项，其渐近阶相应缩放。对于函数 $f(x)$ 和 $g(x)$，当 $x \to x_0$ 时：

$$f(x) \cdot O(g(x)) = O(f(x) g(x))$$

例如，如果 $g(x) = x$ 且 $O(g(x)) = O(x)$，那么乘以 $f(x) = x^2$ 可得：

$$x^2 \cdot O(x) = O(x^3) \quad x \to x_0$$

- - -

另一个重要性质涉及函数的幂。如果当 $x \to x_0$ 时 $f(x) = O(g(x))$，那么将两个函数都提升到相同的正幂会保持大 O 关系。对于 $a > 0$：

$$f(x) = O(g(x)) \implies [f(x)]^a = O([g(x)]^a) \quad x \to x_0$$

当 $|f(x)| \leq M|g(x)|$ 时，$|f(x)|^a \leq M^a |g(x)|^a$，因此正幂下的渐近上界保持一致。例如，如果 $x \to \infty$ 时 $f(x) = O(x)$，那么：

$$[f(x)]^2 = O(x^2) \quad x \to \infty$$

- - -

大 O 记号具有传递性。如果当 $x \to x_0$ 时 $f(x) = O(g(x))$ 且 $g(x) = O(h(x))$，那么：

$$f(x) = O(h(x)) \quad x \to x_0$$

证明很直接。根据假设，存在正的常数 $M_1$、$M_2$ 以及 $x_0$ 的一个邻域，使得 $|f(x)| \leq M_1 |g(x)|$ 和 $|g(x)| \leq M_2 |h(x)|$ 同时成立。合并两个不等式得到 $|f(x)| \leq M_1 M_2 |h(x)|$，所以 $f(x) = O(h(x))$，常数为 $M = M_1 M_2$。例如，当 $x \to \infty$ 时，$x^3 = O(x^4)$ 且 $x^4 = O(x^5)$，因此由传递性可得 $x^3 = O(x^5)$ 当 $x \to \infty$ 时也成立。

> 传递性支持渐近界的链式使用：如果 $f$ 被 $g$ 界定，$g$ 又被 $h$ 界定，那么 $f$ 也被 $h$ 界定。

## Taylor 展开中的大 O 记号

大 O 记号经常出现在[Taylor 展开](../taylor-series/)中，用来描述余项。设函数 $f(x)$ 在 $x_0$ 的某个邻域内 $(n+1)$ 次可导，其 $n$ 阶 Taylor 展开为：

$$f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2!}(x - x_0)^2 + \cdots + \frac{f^{(n)}(x_0)}{n!}(x - x_0)^n + O\big((x - x_0)^{n+1}\big)$$

余项 $O((x - x_0)^{n+1})$ 表达了精确的渐近信息：当 $x \to x_0$ 时，误差被 $(x - x_0)^{n+1}$ 的某个常数倍所界定，因此受展开中第一个省略的幂控制。

一个具体例子是 $\cos x$ 在零点附近的 Taylor 展开：

$$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \cdots$$

在第二项之后截断级数时，对于零点附近的 $x$，余项被 $x^4$ 的某个常数倍所界定。结果可以写成：

$$\cos x = 1 - \frac{x^2}{2} + O(x^4) \quad x \to 0$$

这意味着存在常数 $M > 0$，使得：

$$\left| \cos x - 1 + \frac{x^2}{2} \right| \leq M x^4$$

对零点某个邻域内的所有 $x$ 都成立。由于级数的下一项是 $x^4/24$，当 $x$ 足够小时，取 $M = 1/24$ 就足够了。这是[渐近展开](../asymptotic-expansion/)的一种形式：不保留整个无穷级数，只保留达到所需阶数的项，并将所有高阶贡献并入一个余项。

- - -

下面的表格汇集了 $x = 0$ 附近常见函数的 Taylor 展开，每个展开都带有显式的大 O 余项：

[class="table-1"]

|                  |                                                                       |
| ---------------- | --------------------------------------------------------------------- |
| $e^x$            | $1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + O(x^4)$                  |
| $\sin x$         | $x - \dfrac{x^3}{6} + O(x^5)$                                         |
| $\cos x$         | $1 - \dfrac{x^2}{2} + \dfrac{x^4}{24} + O(x^6)$                       |
| $\ln(1+x)$       | $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} + O(x^4)$                        |
| $(1+x)^\alpha$   | $1 + \alpha x + \dfrac{\alpha(\alpha-1)}{2} x^2 + O(x^3)$              |

[/class]

这些展开是处理[不定式](../indeterminate-forms/)的有效工具，也可以与[极限的代数](../algebra-of-limits/)结合使用，因为大 O 余项吸收了所有高阶贡献，同时保持对近似的严格控制。

## 数列中的大 O 记号

大 O 记号自然扩展到[数列](../sequences/)。如果存在常数 $M > 0$ 和 $N \in \mathbb{N}$，使得对所有满足 n ≥ N 的指标都有：

$$|a_n| \leq M |b_n| \quad \forall n \geq N$$

那么，数列 $\\{a_n\\}$ 当 $n \to \infty$ 时是数列 $\\{b_n\\}$ 的大 O，记为 $a_n = O(b_n)$。这个条件与连续情形相对应，只是由阈值 $N$ 扮演 $\delta$ 的角色。该记号广泛用于描述数列的增长或衰减速率，以及将其与 $1/n$、$n^k$ 或 $\log n$ 等参考数列进行比较。例如：

$$\frac{1}{n} + \frac{2}{n^2} = O\\!\left(\frac{1}{n}\right) \quad n \to \infty$$

因为对每个 $n \geq 1$，都有 $|1/n + 2/n^2| \leq 3/n$。

## 与小 o 记号的关系

大 O 记号与[小 o 记号](../little-o-notation/)密切相关。二者都属于 Landau 记号家族，但描述的渐近行为不同。大 O 给出相差一个常数倍的上界，而小 o 提出更严格的要求：两个函数的比值必须在极限中趋于零。

两种关系通过单向蕴含相连：

+ 如果当 $x \to x_0$ 时 $f(x) = o(g(x))$，那么当 $x \to x_0$ 时 $f(x) = O(g(x))$；
+ 反之一般不成立：$f(x) = O(g(x))$ 并不意味着 $f(x) = o(g(x))$。

一个简单的反例是当 $x \to \infty$ 时取 $f(x) = x$、$g(x) = x$。显然满足界 $|f(x)| \leq 1 \cdot |g(x)|$，因此 $f(x) = O(g(x))$。然而，小 o 条件要求：

$$\lim_{x \to \infty} \frac{x}{x} = 0$$

这个条件不成立，因为该比值恒等于 $1$。用集合包含关系可以概括二者：满足 $f = o(g)$ 的函数类严格包含于满足 $f = O(g)$ 的函数类之内。

> 大 O 记录一个函数至多被另一个函数的常数倍支配，而小 o 记录一个函数相对于另一个函数最终可以忽略。两种记号在渐近分析中互为补充，并且在描述[Taylor 展开](../taylor-series/)的结构和处理[不定式](../indeterminate-forms/)时经常结合使用。
